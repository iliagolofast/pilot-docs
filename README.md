# Документация PILOT

Справка по платформе GPS-мониторинга PILOT на 5 языках (ru, en, uk, ar, es).

Сайт: https://iliagolofast.github.io/pilot-docs/

## Памятка редактору: как работать через ChatGPT

### Один раз: подключение

1. Получите приглашение в этот репозиторий (придёт на почту GitHub) и примите его.
2. В ChatGPT откройте **Codex** (chatgpt.com/codex) и подключите GitHub: **Connect GitHub** → разрешите доступ к репозиторию `pilot-docs`.
3. Создайте окружение (environment) для репозитория `pilot-docs`. Настройки по умолчанию подходят; в setup script можно указать `npm ci`.

Codex сам прочитает файл `AGENTS.md` — там для ИИ описано, как устроены статьи и как собирать сайт.

### Как вносить изменения

1. В Codex выберите репозиторий `pilot-docs` и напишите задачу обычным языком, например:
   - «В статье про датчики уровня топлива добавь раздел про калибровку: …»
   - «Исправь опечатку на странице „Вход в систему“: …»
   - «Создай статью „Как настроить уведомления“ в разделе Личный кабинет и переведи её на все языки»
2. Codex внесёт правку и покажет изменения. Проверьте текст.
3. Нажмите **Create PR** (создать pull request), затем на GitHub — **Merge pull request**.
4. Через 1–3 минуты сайт обновится сам (вкладка **Actions** показывает ход сборки).

Картинку можно приложить к задаче в Codex или загрузить на GitHub в папку `images/` нужного раздела (**Add file → Upload files**), а потом попросить ИИ вставить её в статью.

### Если что-то пошло не так

- Во вкладке **Actions** сборка красная → откройте её, скопируйте текст ошибки в Codex и попросите исправить.
- Нужно откатить правку → на GitHub откройте смерженный pull request и нажмите **Revert**.

## Для разработчика

- Статьи: `content/` (ru), переводы: `i18n/<язык>/`, глоссарий: `i18n/BRIEF.md`.
- Сборка: `npm ci && npm run build` → `data/`. Её же запускает GitHub Action при изменении статей.
- Оболочка сайта и интерактивные демо: `index.html`.
- Подробные правила: `AGENTS.md`.
