В  версии  7.6 усилили безопасность данных наших клиентов. Расширили функционал и повысили стабильность системы, добавив новые возможности и исправив ошибки.

### Усилили безопасность

Установили дополнительную защиту данных пользователей. Повысили безопасность хранения паролей: теперь они сохраняются в зашифрованном виде с использованием современного и надежного алгоритма шифрования.

### Улучшили Telegram-бот

Мы обновили наш Telegram-бот. Поработали над стабильностью — больше никаких неожиданных сбоев и повторной авторизации. Добавили возможность выбора языка общения с ботом. Сделали поиск автомобилей быстрее — просто перечислите интересующие вас машины, и бот сразу предоставит информацию.

### Дополнительная защита аккаунтов

Предоставили возможность для партнёров сделать двухфакторную аутентификацию обязательной для всех пользователей при входе в систему. Теперь для входа в систему, помимо логина и пароля, пользователю нужно ввести одноразовый код из приложения-аутентификатора.

![](images/drex_pilot_7_6__custom.png)

### Создали новый API

Одним запросом вы можете получить самую важную информацию о вашем транспорте. Новый API предоставляет отчёт, включающий: пройденный путь, случаи превышения скорости, резкие торможения и нарушения использования ремня безопасности.

### Новый протокол ретрансляции

Добавили протокол ретрансляции Tripia для передачи данных о транспортных средствах.

### Провели интеграцию видеоустройств Hikvision

Добавили поддержку нескольких мобильных устройств Hikvision: портативного видеорегистратора для записи видео, автомобильного регистратора для записи поездок и камеры, которая автоматически распознает номерные знаки. Теперь эти устройства доступны для подключения и управления в нашей системе.

### Выбор языка в «Планировщике отчётов»

Появилась возможность выбора языка для формирования отчётов в настройках планировщика. Вы можете выбрать желаемый язык из выпадающего списка, который будет применяться к отчётам независимо от языка интерфейса системы.

![](images/drex_pilot_7_6__custom_2.png)

### Звуковые оповещения при алертах

Звуковые оповещения для уведомлений снова доступны в системе. При необходимости функцию можно отключить.

![](images/drex_pilot_7_6__custom_3.png)

### Доступ к руководству пользователя

В интерфейс добавили вкладку «Manual». Пользователи аккаунта могут просматривать документацию, которую прикрепят администраторы

![](images/drex_pilot_7_6__custom_4.png)

### Год выпуска автомобиля необязателен

Поле «Год выпуска» стало необязательным. Вы можете создавать новые автомобили, не указывая год выпуска, если эта информация неизвестна или не важна. Сохраняйте автомобиль без указания года выпуска и редактируйте эти данные позже.

### Длительность парковки в истории

В историю перемещений автомобилей добавили информацию о количестве и продолжительности парковок. Теперь вы увидите, сколько времени каждый автомобиль провёл на стоянке.

![](images/drex_pilot_7_6__custom_5.png)

### Точное отображение времени отсутствия связи

Улучшили отображение статуса «Нет связи». Система показывает точное время отсутствия подключения в часах, днях, месяцах.

![](images/drex_pilot_7_6__custom_6.png)

### Модуль «Тахограф» в новом интерфейсе

Добавили «Тахограф» в обновлённый интерфейс. Теперь легко управлять настройками модуля и просматривать отчёты.

![](images/drex_pilot_7_6__custom_7.png)

### Отслеживание изменений в истории водителей

Добавили функцию в «Историю аудита», которая позволяет администраторам отслеживать изменения в истории водителей, даже если записи были удалены.

### Новое в работе с картами

Вы можете выбрать, какая карта будет открываться первой по умолчанию. Также появилась возможность скрыть неиспользуемые карты.

### Инфракрасная карта с раздельной статистикой пассажиропотока

Добавили инфракрасную карту для отчёта «Статистика по пассажиропотоку», на которой наглядно отображается раздельная статистика вошедших и вышедших пассажиров.

![](images/drex_pilot_7_6__custom_8.png)

### Дата отчёта в письме

Теперь в теме электронного письма указана дата формирования отчёта.

### Сохранение уведомлений «Сервиса»

Если вы получили уведомление из модуля «Сервис», но пропустили его, информация о нём автоматически сохранится в «Событиях».

### Новые поля и функция синхронизации данных в FOTA

В интерфейсе FOTA для машин с устройствами Teltonika добавили новые поля — ICCID, идентификатор группы и описание, которые помогают идентифицировать SIM-карты, учётные записи и транспортные средства. Кнопка синхронизации позволяет обновлять данные между FOTA и Pilot и автоматически заполнять карточку автомобиля.

![](images/drex_pilot_7_6__custom_9.png)

### Добавили последнюю стоянку в отчёт

Исправили ошибку в отчёте «Поездки и стоянки», из-за которой стоянки после поездок не отображались. Теперь в отчёте каждая поездка заканчивается стоянкой.

![](images/drex_pilot_7_6__custom_10.png)

### Исправили ошибку с кнопкой добавления сервиса

При нажатии на кнопку «Добавить новый сервис» откроется всплывающее окно с формой для создания сервиса.

### Обновили интерфейсы разделов «История» и «Отчёты»

Теперь есть возможность отображения дополнительных полей. Вы можете настроить вид отображаемой информации в данных разделах под ваши задачи.

![](images/drex_pilot_7_6__custom_11.png)

### Добавили фильтрацию по дополнительным полям

Появилась возможность фильтрации по дополнительным полям, которые вы создаёте для транспортных средств и водителей. При добавлении нового поля в редакторе полей автоматически становится доступна функция поиска и фильтрации по этому параметру.

### Новые поля водителя в отчёте

Добавили новые поля с информацией о водителях в «Конструктор отчёта». Теперь в отчёт можно включать имя водителя, его группу, срок действия водительского удостоверения, телефон, метки и описание.
