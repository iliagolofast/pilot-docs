Отчёт — это собранная информация об объектах наблюдения за выбранный период времени.

### Чтобы посмотреть отчёт

1. В главном меню перейдите в раздел «Отчёты» и выберите объект, отметив его галочкой в списке объектов.
2. Выберите временной интервал для построения отчёта, нажав на иконку календаря.
3. Выберите тип отчёта.
4. Укажите разбивку отчёта: по суткам, неделям или без разбивки на интервалы.
5. Выберите группировку: по датам — для анализа изменений показателей во времени, или по объектам — для сравнения показателей между объектами.
6. Выберите группы датчиков, по которым будет сформирован отчёт.
7. Нажмите кнопку «Построить отчёт».

После нажатия кнопки «Построить отчёт» появится отчёт в выбранном формате. Готовый отчёт можно сохранить в форматах CSV, Excel, PDF или распечатать.
