Во вкладке «Настройки» указываются данные учётной записи, параметры входа и доступный пользователю период истории.

![](images/drex_nastrojki_polzovatelya_custom.png)

## Основные настройки

![](images/drex_nastrojki_polzovatelya_custom_2.png)

Заполните данные пользователя. Обязательные поля выделены красной рамкой:

-   Логин — имя, которое пользователь вводит при входе в PILOT
    
-   Пароль — пароль для входа. Чтобы создать или изменить его, нажмите значок редактирования ![](images/drex_nastrojki_polzovatelya_custom_3.png) в поле
    
-   Название — имя сотрудника или другое понятное название учётной записи
    
-   Тип — определяет уровень доступа:
    
-   Администратор — может добавлять пользователей и объекты, работать с водителями и управлять правами пользователей договора
    
-   Пользователь — работает с назначенными ему объектами и функциями. Доступные возможности определяются его правами
    
-   Информация — дополнительные сведения о сотруднике. Поле заполняется при необходимости
    
-   Email — адрес электронной почты. Нажмите значок отправки ![](images/drex_nastrojki_polzovatelya_custom_4.png) в поле, чтобы отправить пользователю письмо со ссылкой для входа в PILOT
    
-   Мобильный телефон — контактный номер сотрудника
    

## Дополнительные настройки

-   Количество попыток входа (The number of possible login attempts) — укажите допустимое количество попыток авторизации. Параметр ограничивает повторные попытки входа с неверными учётными данными. Значение 0 отключает подсчёт попыток.
    
-   Количество дней для хранения истории — укажите период, за который пользователю будут доступны исторические данные, в том числе при построении отчётов:
    
-   0 — использовать стандартный период 365 дней
    
-   положительное число — хранить историю указанное количество дней
    
-   −1 — не хранить историю
    

Максимальный период определяется конфигурацией договора [Users default parameters](../../../../panel-administratora/partnyery/kak-dobavit-konfiguratsiyu-k-partnyeru.html#__Users_default_parameters). Её добавляет пользователь с доступом к административной панели. Если вам нужно увеличить доступный период, обратитесь к администратору или в техническую поддержку.

![](images/drex_nastrojki_polzovatelya_custom_5.png)

Например, значение 730 в параметре max\_days\_available\_history позволяет предоставить пользователям договора доступ к истории за два года. После применения конфигурации значение в поле «Количество дней для хранения истории» заполняется установленным количеством дней.

![](images/drex_nastrojki_polzovatelya_custom_6.png)

После заполнения полей нажмите «Сохранить». Затем перейдите на другие вкладки карточки, чтобы назначить пользователю объекты, теги и необходимые права доступа.
