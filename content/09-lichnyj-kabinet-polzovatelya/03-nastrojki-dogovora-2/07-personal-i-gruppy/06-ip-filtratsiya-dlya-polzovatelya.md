IP-фильтрация ограничивает вход в учётную запись по IP-адресу. После её включения пользователь сможет войти в PILOT только с разрешённых адресов.

### Чтобы настроить IP-фильтрацию:

1\. Во вкладке «Персонал и группы» найдите нужного пользователя

![](images/drex_ip_filtratsiya_dlya_polzovatelya_custom.png)

2\. Нажмите значок фильтра ![](images/drex_ip_filtratsiya_dlya_polzovatelya_custom_2.png) рядом с его именем

3\. В открывшемся окне установите галочку «Включить фильтрацию»

![](images/drex_ip_filtratsiya_dlya_polzovatelya_custom_3.png)

4\. Укажите разрешённые IP-адреса — по одному адресу в каждой строке

![](images/drex_ip_filtratsiya_dlya_polzovatelya_custom_4.png)

5\. Нажмите «Сохранить список IP»

При включении фильтрации текущий IP-адрес добавляется в список автоматически. При необходимости добавьте другие адреса, с которых пользователь будет входить в PILOT.
