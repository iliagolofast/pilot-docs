Планировщик отчётов — инструмент для автоматического формирования и отправки отчётов по расписанию.

С помощью планировщика можно:

— выбрать нужный тип отчёта

— настроить период, за который в отчёт будут включаться данные

— указать время и периодичность формирования отчёта

— выбрать объекты или теги

— указать адреса электронной почты, на которые будет отправлен отчёт

## Как создать расписание

1\. Откройте вкладку «Планировщик отчётов»

2\. Нажмите «Добавить новое расписание» ![](images/drex_planirovshchik_otchyetov_custom_2.png)

3\. В открывшемся окне настройте параметры отчёта, период данных и расписание формирования

![](images/drex_planirovshchik_otchyetov_custom_3.png)

4\. Выберите объекты или теги, по которым нужно сформировать отчёт

5\. Нажмите «Сохранить»

После этого расписание будет создано, а отчёты начнут формироваться и отправляться с заданной периодичностью.

### Параметры отчёта

В блоке «Параметры отчёта» заполните следующие поля:

![](images/drex_planirovshchik_otchyetov_custom_4.png)

-   Название — введите понятное название расписания
    
-   Язык — выберите язык, на котором будет сформирован отчёт
    
-   Тип отчёта — выберите нужный отчёт из списка. В списке отображаются только те типы отчётов, к которым у вас есть доступ. Доступные отчёты можно посмотреть на вкладке [«Список отчётов»](spisok-otchyetov-1.html)
    
-   Группы датчиков (Select tags) —  выберите метки датчиков, данные которых нужно включить в отчёт. Метки позволяют сформировать отчёт только по нужным датчикам. Назначить метки можно [в настройках датчиков](../datchiki-1/metki-datchikov.html). Доступность поля и список меток зависят от выбранного типа отчёта.
    
-   Группировка — укажите, как группировать данные в отчёте: например, по датам или по объектам
    
-   Разбивка — выберите, на какие интервалы разбивать данные внутри отчёта: например, по суткам, по неделям или без дополнительной разбивки
    

Если выбран тип отчёта, который поддерживает отображение карт, в планировщике появляются дополнительные настройки. Их состав зависит от выбранного отчёта:

![Планировщик отчётов](images/drex_planirovshchik_otchyetov_screen.png)

-   Показать карту (Show maps) — добавляет в отчёт статичную карту с маршрутом объекта за отчётный период.
    
-   Тип карты (Map Type) — позволяет выбрать картографическую основу для карты в отчёте, например OSM или Google Sat. Выбранная основа используется при включённом параметре «Тип карты» (Show maps)
    
-   Показывать парковки — отмечает места стоянок на карте значками **P**. Параметр доступен только после включения «Показать карты» (Show maps)
    
-   Показать одометр (Show odometer) — добавляет в таблицу показания одометра на начало и окончание поездки, если выбранный отчёт поддерживает эту возможность
    

![Планировщик отчётов](images/drex_planirovshchik_otchyetov_screen_2.png)

Эти настройки сохраняются в расписании и применяются при каждом автоматическом формировании отчёта.

-   Часовой пояс отчёта — выберите часовой пояс, который будет использоваться при определении периода данных и времени событий в отчёте
    
-   Формат — выберите формат файла: PDF или Excel
    
-   Размер страницы (Page size) — выберите размер страницы, например, A4
    
-   Ориентация (Orientation) — выберите расположение страницы: «Портрет» — вертикальное или «Ландшафт» — горизонтальное. Для отчётов с большим количеством столбцов выбирайте «Ландшафт», чтобы разместить таблицу по ширине страницы.
    
-   Emails — укажите один или несколько адресов электронной почты, на которые нужно отправлять отчёт.Чтобы удалить адрес из списка, нажмите крестик рядом с ним.
    

Убедитесь, что ваш адрес электронной почты подтверждён во вкладке [«Приватность»](privatnost.html#Как_подтвердить_электронную_почту:_). Без подтверждённого адреса использовать планировщик отчётов не получится.

Получатели могут отписаться от конкретного отчёта по ссылке в письме. Если в списке не осталось получателей, PILOT приостанавливает формирование отчёта. Расписание сохраняется. После добавления нового получателя отправка возобновится с актуального периода.

### Период данных отчёта

В блоке «Период данных отчёта» (Report data period) настройте временной интервал, данные за который должны попадать в отчёт.

-   От — укажите время, с которого нужно включать данные в отчёт
    
-   Предыдущий день (Previous day) — включите параметр, если время начала периода должно относиться к предыдущему дню
    
-   До — укажите время, до которого нужно включать данные в отчёт
    
-   Период — выберите продолжительность периода
    

Параметр «Предыдущий день» позволяет формировать отчёты за интервалы, которые начинаются в одни сутки, а заканчиваются в другие.

Например, если указать:

-   начало периода — 20:00
    
-   включить «Предыдущий день»
    
-   окончание периода — 08:00
    

то в отчёт попадут данные с 20:00 предыдущего дня до 08:00 текущего дня.

### Расписание формирования

В блоке «Расписание формирования» (Generation schedule) укажите, когда и как часто нужно создавать отчёт.

-   Следующая генерация — выберите дату и время ближайшего формирования и отправки отчёта
    
-   Периодичность (Generate) — укажите, как часто нужно формировать отчёт:
    
-   ежедневно — отчёт формируется каждый день
    
-   еженедельно — отчёт формируется один раз в неделю
    
-   ежемесячно — отчёт формируется один раз в месяц
    
-   по выбранным дням (selected days) — отчёт формируется только в указанные дни недели
    

Под настройками расписания отображается «Расчётный период данных» (Data period) — автоматически рассчитанный интервал, данные за который войдут в ближайший отчёт.

### Выбор объектов или тегов

В правой части окна выберите, по каким объектам нужно сформировать отчёт:

-   «Объекты» — отчёт будет сформирован для выбранных объектов
    
-   «Теги» — отчёт будет сформирован для объектов, объединённых выбранными тегами
    

Можно выбрать отдельные объекты или всю группу объектов. Для быстрого поиска используйте строку поиска и фильтры.

![](images/drex_planirovshchik_otchyetov_custom_5.png)

### Сохранение расписания

Перед сохранением проверьте настройки расписания и нажмите «Сохранить».

Расписание появится в планировщике, после чего отчёты будут автоматически формироваться и отправляться указанным получателям.

![](images/drex_planirovshchik_otchyetov_custom_6.png)

## Отписка от запланированного отчёта

Вы можете прекратить получение запланированного отчёта по ссылке в письме. Для отписки входить в PILOT не требуется.

Отписка действует только для отчёта и адреса электронной почты, указанных на странице подтверждения. Другие запланированные отчёты продолжат приходить. Остальные получатели этого отчёта сохранят подписку.

### Как отписаться

1\. Откройте письмо с запланированным отчётом

2\. Нажмите ссылку «Отписаться от этого запланированного отчета»

![Планировщик отчётов](images/drex_planirovshchik_otchyetov_screen_3.png)

3\. На открывшейся странице проверьте название отчёта и адрес электронной почты

4\. Нажмите кнопку «Отписаться»

PILOT удалит указанный адрес из списка получателей и покажет сообщение об успешной отписке с названием отчёта.

Если вы уже вошли в PILOT, переход по ссылке и отписка сохранят текущую сессию.
