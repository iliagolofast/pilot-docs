Токен — это уникальный код доступа, который позволяет другим пользователям видеть местоположение объектов, не имея доступа к вашему аккаунту.

Проще говоря, токен — это как временный пропуск. Он даёт ограниченный доступ к определённой информации, не раскрывая ваши личные данные или пароль.

Во вкладке «Токены» можно создать два типа токена:

-   [Monitor token](tokeny.html#Токен_для_просмотра_\(Monitor_token\)) — для просмотра местоположения выбранных объектов по общедоступной ссылке
    
-   [Access token](tokeny.html#Токен_для_входа_\(Access_token\)) — для входа в PILOT без ввода пароля
    

![](images/drex_tokeny_custom.png)

## Токен для просмотра (Monitor token)

Monitor token предоставляет другому человеку доступ к карте с выбранными объектами и их перемещениями. Получатель ссылки не получает логин, пароль и полный доступ к аккаунту.

### Права на управление токенами для просмотра

Для управления Monitor tokens используются отдельные права:

-   Edit Tokens — позволяет создавать и изменять токены мониторинга и ссылки общего доступа к местоположению.
    
-   Delete Tokens — позволяет удалять токены мониторинга.
    

Чтобы обычный пользователь мог создать, изменить или удалить ссылку в веб-версии PILOT, администратор или мастер должен предоставить ему право на изменение и удаление токенов.

### Как предоставить права пользователю

-   В «Настройках договора» откройте вкладку [«Персонал и группы»](personal-i-gruppy/index.html)
    

2\. Дважды щёлкните пользователя в списке, чтобы открыть его карточку

3\. Перейдите на вкладку [«Права»](personal-i-gruppy/kartochka-polzovatelya/prava.html)

4\. Раскройте группу «Токены»

5\. Выберите необходимые права:

-   Edit Tokens — для создания и изменения токенов
    
-   Delete Tokens — для удаления токенов
    

![](images/drex_tokeny_custom_2.png)

6\. Нажмите «Сохранить»

### Как создать токен для просмотра

-   В секции «Monitor tokens» нажмите кнопку «Добавить токен» ![](images/drex_tokeny_custom_3.png)
    
    2\. В открывшемся окне заполните информацию о токене:
    

![](images/drex_tokeny_custom_4.png)

-   Укажите период действия  — выберите дату и время начала и окончания работы токена
    
-   Выберите, какую карту использовать для отображения объектов
    
-   Укажите, отображать ли на карте маркеры объектов или датчики
    
-   Из списка выберите объекты, которые нужно отслеживать через этот токен
    
    3\. Нажмите «Сохранить»
    
    4\. Система создаст уникальную ссылку или iframe — код для встраивания
    
    5\. Скопируйте полученную ссылку или код и отправьте тому, кому нужен доступ к информации
    

## Токен для входа (Access token)

Этот тип токена используется для авторизации в системе без пароля. При переходе по специальной ссылке PILOT выполняет вход от имени пользователя так же, как при использовании логина и пароля. Токен может иметь ограниченный срок действия или быть бессрочным.

### Как создать токен входа

-   Нажмите в секции «Access tokens» кнопку «Добавить токен» ![](images/drex_tokeny_custom_3.png)
    
-   В новом окне укажите дату и время начала и окончания действия токена. Если не укажете окончание действия — токен будет работать бессрочно. 
    
-   Нажмите «Сохранить»
    

![](images/drex_tokeny_custom_5.png)

Чтобы изменить токен, нажмите на значок карандаша ![](images/drex_tokeny_custom_6.png),  а для удаления — на значок корзины ![](images/drex_tokeny_custom_7.png).

![](images/drex_tokeny_custom_8.png)
