Шаблоны — это готовый набор параметров, который используют для быстрой настройки однотипных устройств.

<table><tbody><tr><td><span></span></td><td><div>Шаблон датчиков можно применять только к объектам с устройствами одного типа.</div><div>Например, шаблон от Teltonika FMB120 подойдёт только для Teltonika FMB120</div></td></tr></tbody></table>

Есть два типа шаблонов:

-   Локальные шаблоны — ваши собственные настройки, которые вы создаёте сами на объекте
    
-   Глобальные шаблоны — готовые настройки, которые может использовать любой пользователь
    

### Как создать локальный шаблон:

![Шаблоны датчиков](images/drex_shablony_datchikov_screen.png)

-   Настройте датчики так, как вам нужно
    
    2\. Во вкладке «Датчики» нажмите кнопку «Сохранить шаблон»
    

3\. Укажите название шаблона и его описание

![](images/drex_shablony_datchikov_custom.png)

4\. Нажмите «Сохранить как новый»

![](images/drex_shablony_datchikov_custom_2.png)

### Как применить шаблон к одному объекту:

-   Перейдите к объекту, к которому хотите применить шаблон
    
    <table><tbody><tr><td><span></span></td><td><div>Шаблоны датчиков подходят только к объектам с одинаковым типом GPS-устройства. Если вы создали шаблон для одного объекта, он сработает только на других объектах с таким же устройством.</div></td></tr></tbody></table>
    
-   Откройте через меню объекта окно датчиков
    
-   Во вкладке «Датчики» выберите сохранённый шаблон из выпадающего списка шаблонов
    

![Шаблоны датчиков](images/drex_shablony_datchikov_screen_2.png)

1 — Применить шаблон

2 — Удалить шаблон

4\. Нажмите кнопку «Применить шаблон»

5\. При необходимости удалите старые датчики

![](images/drex_shablony_datchikov_custom_3.png)

6\. Нажмите «Применить» — датчики из шаблона отобразятся во вкладке «Датчики»  

Чтобы удалить шаблон из списка, нажмите крестик.

### Как применить шаблон к нескольким объектам:

-   В списке объектов выберите несколько объектов, удерживая клавишу Cntrl на клавиатуре
    

2\. Щёлкните правой кнопкой мыши по объектам — откроется меню для работы с несколькими объектами

3\. Выберите в меню «Шаблоны датчиков»

![](images/drex_shablony_datchikov_custom_4.png)

4\. В открывшемся окне выберите сохранённый шаблон

![](images/drex_shablony_datchikov_custom_5.png)

5\. Нажмите «Применить шаблон»

### Где найти глобальные шаблоны:

-   Во вкладке «Датчики» в выпадающем списке шаблонов
    

![](images/drex_shablony_datchikov_custom_6.png)

2\. В окне [«Шаблоны датчиков»](shablony-datchikov.html#Шаблоны_датчиков_для_нескольких_объектов) при работе с несколькими объектами

![](images/drex_shablony_datchikov_custom_7.png)
