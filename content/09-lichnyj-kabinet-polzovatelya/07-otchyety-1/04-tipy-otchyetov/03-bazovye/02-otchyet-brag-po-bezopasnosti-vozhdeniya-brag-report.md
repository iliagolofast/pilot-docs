Отчёт BRAG Report предназначен для оценки безопасности вождения и распределения водителей по категориям BRAG. Отчёт разработан с учётом требований QatarEnergy к системам мониторинга транспорта IVMS.

Система анализирует зарегистрированные нарушения: превышение скорости, резкие ускорения, торможения и повороты, а также нарушения правил использования ремня безопасности. По результатам каждому активному водителю присваивается итоговая оценка и цветовая категория.

Перед построением отчёта необходимо выбрать период, транспортные средства или группу транспортных средств. В расчёт попадают водители, по которым за выбранный период получены данные.

![](images/drex_otchyet_brag_po_bezopasnosti_vozhdeniya__brag_report__custom.png)

### Общая информация

В верхней части отчёта отображаются:

-   Contractor — название подрядчика
    
-   Project — название проекта
    
-   Отдел — подразделение, для которого сформирован отчёт
    
-   Период отчёта — начало и окончание анализируемого периода
    
-   Generated — дата и время формирования отчёта
    
-   Тип отчёта — тип отчёта, например, Weekly/Monthly
    

![](images/drex_otchyet_brag_po_bezopasnosti_vozhdeniya__brag_report__custom_2.png)

### Fleet Overview

Блок Fleet Overview содержит общие сведения об автопарке:

-   Total Vehicles — общее количество выбранных транспортных средств
    
-   Active Drivers — количество водителей, по которым зарегистрирована активность за выбранный период
    
-   Total Distance (km) — общий пробег транспортных средств в километрах
    
-   Общая продолжительность — суммарная продолжительность работы транспорта
    

Количество активных водителей может быть меньше количества транспортных средств: в распределение BRAG включаются только водители, по которым система получила необходимые данные.

### BRAG Performance Distribution

В блоке BRAG Performance Distribution показано распределение активных водителей по четырём категориям. Для каждой категории отображаются количество водителей и их доля от общего числа активных водителей:

-   BLUE — Outstanding — отличные показатели вождения
    
-   GREEN — Acceptable — приемлемые показатели
    
-   AMBER — Attention Required — показатели требуют внимания
    
-   RED — Action Required — необходимо принять меры
    

Цвет категории также используется для выделения имени водителя в подробной таблице:

-   синий — категория BLUE
    
-   зелёный — категория GREEN
    

![](images/drex_otchyet_brag_po_bezopasnosti_vozhdeniya__brag_report__custom_3.png)

-   жёлтый — категория AMBER
    
-   красный — категория RED
    

![](images/drex_otchyet_brag_po_bezopasnosti_vozhdeniya__brag_report__custom_4.png)

Чем выше итоговая оценка и количество нарушений, тем больше внимания требует стиль вождения.

### Fleet Performance Summary

Блок Fleet Performance Summary содержит сводные показатели по выбранному автопарку:

-   Fleet Average Score — средняя итоговая оценка водителей
    
-   Total events — общее количество зарегистрированных событий и нарушений
    
-   Events per 100 km — количество событий в среднем на 100 км пробега. Этот показатель позволяет сравнивать результаты водителей и подразделений с разным пробегом.
    

### Individual Driver Performance

В блоке Individual Driver Performance приводятся подробные результаты каждого водителя.

В таблице отображаются:

-   Driver ID — идентификатор водителя
    
-   Driver Name — имя водителя
    
-   Длительность HH:MM:SS — общая продолжительность работы водителя
    
-   Расстояние (km) — пройденное расстояние
    
-   Overspeed 120 kph — количество событий превышения скорости в категории 120 км/ч
    
-   Overspeed 100 kph — количество событий превышения скорости в категории 100–119 км/ч
    
-   Overspeed 80 kph — количество событий превышения скорости в категории 80–99 км/ч
    
-   Overspeed 60 kph — количество событий превышения скорости в категории 60–79 км/ч
    
-   Overspeed 40 kph — количество событий превышения скорости в категории 40–59 км/ч
    
-   Overspeed 30 kph — количество событий превышения скорости в категории 30–39 км/ч
    
-   Резкое Accel — количество резких ускорений
    
-   Резкое Торможение — количество резких торможений
    
-   Резкое Cornering — количество случаев резкого прохождения поворотов
    
-   Seatbelt Нарушение — количество нарушений правил использования ремня безопасности
    
-   Водитель Счёт — итоговая оценка водителя, на основании которой определяется его категория BRAG
    

## Подготовка данных для отчёта

Данные о нарушениях поступают в отчёт из [уведомлений](../../../moduli-1/uvedomleniya/index.html), настроенных для транспортных средств. Поэтому перед использованием отчёта необходимо [создать необходимые уведомления](../../../moduli-1/uvedomleniya/kak-sozdat-uvedomlenie.html) и назначить их соответствующим транспортным средствам.

Алгоритм определяет тип события по названию уведомления. Названия должны строго соответствовать установленному шаблону:

-   BRAG Harsh Braking
    
-   BRAG Harsh Acceleration
    
-   BRAG Harsh Cornering
    
-   BRAG Overspeed
    
-   BRAG Overspeed 30-39
    
-   BRAG Overspeed 40-59
    
-   BRAG Overspeed 60-79
    
-   BRAG Overspeed 80-99
    
-   BRAG Overspeed 100-119
    
-   BRAG Overspeed 120
    
-   BRAG Seatbelt Violation
    

![Отчёт BRAG по безопасности вождения (BRAG Report)](images/drex_otchyet_brag_po_bezopasnosti_vozhdeniya__brag_report__screen.png)

Уведомления необходимо назначить тем транспортным средствам, данные которых должны учитываться в отчёте.

![](images/drex_otchyet_brag_po_bezopasnosti_vozhdeniya__brag_report__custom_5.png)

Если название уведомления изменено, уведомление отсутствует или назначено не тому транспортному средству, алгоритм может не распознать событие. В этом случае нарушение не попадёт в отчёт и итоговые показатели могут быть рассчитаны некорректно.
