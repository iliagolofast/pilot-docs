Отчёт «Качество данных» предназначен для проверки качества телематических данных, поступающих от объектов мониторинга за выбранный период. С его помощью можно выявить отсутствие и задержки данных, разрывы между пакетами, проблемы GPS, резкие скачки координат и другие отклонения.

Отчёт помогает оценить, насколько полученные данные подходят для построения треков, расчёта пробега, обработки показаний датчиков и выполнения последующих перерасчётов. Он учитывает не только отсутствие связи с объектом, но и качество уже полученных данных.

Показатели рассчитываются отдельно для каждого объекта за каждые сутки выбранного периода.

![](images/drex_kachestvo_dannykh__data_quality__custom.png)

### Что анализируется

При оценке качества данных система проверяет:

— задержку поступления пакетов на сервер

— интервалы между соседними пакетами

— резкие скачки координат

— качество GPS-сигнала, включая количество спутников и значение HDOP

— невалидные пакеты и пакеты без координат

— пакеты с одинаковыми временными метками

— превышение максимальной скорости, установленной для объекта

### Что отображается в отчёте

-   Объект — название или номер объекта мониторинга
    
-   Старт — начало анализируемого периода
    
-   Стоп — окончание анализируемого периода
    
-   Счёт — итоговая оценка качества данных по шкале от 0 до 100. Чем выше значение, тем лучше качество данных
    
-   Статус — итоговое состояние качества данных:
    
-   ok— данные соответствуют установленным требованиям
    
-   warning— обнаружены отклонения, требующие внимания
    
-   bad— обнаружены существенные проблемы с качеством данных
    
-   no\_data— данные за анализируемый период отсутствуют
    
-   Точки — количество телематических пакетов, полученных за период
    
-   Проблемы — общее количество обнаруженных отклонений
    
-   Delay max — максимальная задержка поступления пакета на сервер
    
-   Gaps — количество значительных разрывов между соседними пакетами
    
-   Longest gap — продолжительность самого длительного разрыва
    
-   GPS problems — количество проблем, связанных с недостаточным числом спутников или превышением допустимого значения HDOP
    
-   Coord jumps — количество обнаруженных резких скачков координат

### Пороговые значения

Для анализа используются допустимые интервалы передачи данных, задержки, разрывы, скорость изменения координат и другие пороговые значения. Они могут быть настроены индивидуально для объекта.

Если отдельные параметры не заданы, система использует значения по умолчанию и существующие настройки объекта, включая минимальное количество спутников, максимальный HDOP, максимальную скорость и допустимое время отсутствия связи.
