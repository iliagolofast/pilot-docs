**Отчёт содержит:**

-   # Объект  -
    
    объект мониторинга на котором фиксировалось качество вождения;
    
-   # Общее расстояние (км) -
    
    расстояние на протяжении которого совершалось нарушение;
    
-   # Продолжительность поездки -
    
    длительность на протяжении которой совершалось нарушение;
    
-   # Макс. скорость-
    
    максимальная скорость зафиксированная во время поездки.
    
-   # Зона превышения скорости - **участок дороги, на котором установлено ограничение максимальной скорости движения транспортных средств**;
    
-   # Превышение скорости норма - **движение транспортного средства с скоростью, превышающей установленные законом или дорожными знаками ограничения**;
    
-   # Область продолжительности превышения скорости -  **продолжительность  превышения  скорости;**
    
-   # Продолжительность превышения скорости нормальная-**время, в течение которого транспортное средство движется с превышением установленного ограничения скорости**;
    
-   # Общая продолжительность превышения скорости -**время, в течение которого транспортное средство движется с превышением установленного ограничения скорости**;
    
-   # Оценка скорости -  **значение оценки скорости;**
    
-   # Общее ускорение итого -  **значение  общего ускорения за указанный период;**
    
-   # Оценка ускорения -**значение оценки ускорения;**
    
-   # Общее количество замедлений - **значение  общего замедления за указанный период;**
    
-   # Оценка замедления  - **значение оценки замедления;**
    
-   # Время без ремня безопасности- **время  поездки без  ремня  безопасности  за  отчетный  период;**
    
-   # Оценка нарушений ремней безопасности - **значение за нарушения без  ремня  безопасности;**
    
-   # Чрезмерный холостой ход **\-двигатель автомобиля работает на холостых оборотах дольше, чем это необходимо;**
    
-   # Продолжительность простоя - **значение  о продолжительности простоя;**
    
-   # Общий счет - **итоговая  оценка поездки.**
