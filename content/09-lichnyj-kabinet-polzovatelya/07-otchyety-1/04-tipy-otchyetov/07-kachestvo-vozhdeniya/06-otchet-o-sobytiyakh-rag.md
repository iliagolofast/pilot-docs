# **Отчет о событиях RAG - это отчет , в котором содержится обзор основных событий** **по качеству вождения.**

**Отчёт содержит:**

-   # Водитель -
    
    водитель назначенный на данный объект;
    
-   # Общее расстояние (км) -
    
    расстояние на протяжении которого совершалось нарушение;
    
-   # Общее ускорение -  **общее значение оценки ускорения;**
    
-   # Оценка ускорения - **значение оценки ускорения;**
    
-   # Общее количество замедлений- **общее значение оценки замедления;**
    
-   # Оценка замедления -**значение оценки замедления;**
    
-   # Максимальная скорость (км/ч) -
    
    максимальная скорость зафиксированная во время поездки.
    
-   # Общее время превышения скорости -
    
    общее время, на протяжении которого была превышена скорость;
    
-   # Оценка скорости - **значение оценки скорости;**
    
-   # Время без ремня безопасности - **время  за которое  водитель двигался без  ремня безопасности;**
    
-   # Оценка нарушений ремней безопасности - **значение оценки движения без  ремня безопасности;**
    
-   # Счет -
    
    формируется на основе суммы резких поворотов, торможений и ускорений.
