**Отчёт по расходу жидкостей (таблица)**

Отчёт по расходу жидкостей (таблица) предназначен для вывода информации об израсходованной жидкости в заданный период времени.

Данный тип отчёта предназначен только для импульсных датчиков.

**Отчёт содержит:**

-   **Дата** - период времени для которого строится отчёт
    
-   **Объект** - объект мониторинга для которого выводятся соответствующие данные в отчёте.
    
-   **Датчик** - название датчика.
    
-   **Старт** - дата и время начала движения жидкости.
    
-   **Стоп** - дата и время окончания движения жидкости.
    
-   **Длительность** - длительность движения жидкости.
    
-   **Топливо** - количество израсходованного топлива.
