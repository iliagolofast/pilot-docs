Отчет предназначен для вывода информации  по  состоянию   расхода топлива за  период времени.

**Отчёт содержит:**

-    **№** \- порядковый номер объекта мониторинга в отчёте.
    
-   **Транспортное средство** - объект мониторинга, для которого предоставляется согласующая информация.
    
-   **Модель** - модель объекта мониторинга.
    
-   **Номер машины** - госномер объекта мониторинга.
    
-   **Расстояние** - пробег значений объекта мониторинга на начало и окончание периода, для которого строится отчёт.
    
-   Период - пробег за период, для которого строится отчёт.
    
-   С начала года - пробег с начала года.
    
-    **Моточасы** \- количество моточасов объекта наблюдения.
    
-   Период - количество моточасов за период, для которого строится отчёт.
    
-   С начала года - количество моточасов с начала года.
    
-    **Норма расхода, л** - норма расхода топлива объекта мониторинга (норма задаётся во вкладке топливо).
    
-   Лето - норма расхода топлива летом.
    
-   Зима - норма расхода топлива зимой.
    
-    **Топливная карта** - топливные карты объектов мониторинга.
    
-   **Расход (л)** \- расход топлива различных марок.
    
-    **Поставщик топлива** \- поставщики топливных карт.
    
-   **Растояние** - пробег значений объекта мониторинга на начало и окончание периода, для которого строится отчёт.
