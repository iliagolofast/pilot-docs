**Отчёт по топливу (норма)**

Данный тип отчёта содержит информацию о расходе топлива рассчитанному по норме. Расход рассчитывается как норма умноженная на пробег. Норма задаётся во вкладке топливо.

**Отчёт содержит:**

-   **Объект** - объект мониторинга, для которого выводится соответствующая информация.
    
-   **Дата** - период времени, для которого выводится соответствующая информация.
    
-   **Тип топлива** \- тип топлива объекта мониторинга.
    
-   **Тип подсчета по норме** - пробег объекта мониторинга за указанную дату.
    
-   **Норма -** норма расхода топлива указанного объекта мониторинга.
    
-   **Расход**  **топлива** - количество израсходованного топлива объекта мониторинга за указанную дату.
    
-   **Пробег** - пробег указанных объектов мониторинга за указанную дату.
    
-   **Моточасы**  - количество моточасов за указанную дату.
