**Отчёт по топливу суммарный**

Данный тип отчёта предназначен для вывода суммарной информации по расходу топлива за указанный период.

Данные о топливе формируются на основе показаний датчика топлива.

**Отчёт содержит:**

-   **Объект** - объект мониторинга, для которого выводятся соответствующие данные.
    
-   **Дата** - дата, для которой выведены соответствующие данные.
    
-   **Расстояние, км** - пробег объекта мониторинга за указанную дату.
    
-   **Остаток на начало, л** - количество топлива в баке на начало указанной даты.
    
-   **Остаток на конец, л** - количество топлива в баке на конец указанной даты.
    
-   **Заправлено, л** - количество заправленного топлива в указанную дату.
    
-   **Слито, л** - количество слитого топлива в указанную дату.
    
-   **Расход, л** - количество израсходованного топлива за указанную дату.
    
-   **Средний расход, л/100 км** - количество расходуемого топлива на 100 км пробега, рассчитывается как (Расход \* 100 км)/Пробег.
    
-   **Моточасы** - количество моточасов за указанную дату.
    
-   **Средний расход, л/ч** - количество расходуемого топлива за один моточас, рассчитывается как Расход/Моточасы.
