#  **Реестр ТС - это реестр транспортных средств.**

 **Отчет содержит :**

-   # Номер машины -   **объект в  системе мониторинга;**
    
-   # Марка - **марка  объекта;**
    
-   # Модель - **модель  объекта;**
    
-   # Год выпуска - **год выпуска  объекта;**
    
-   # Тип ТС  -   **тип  транспорта в системе ;**
    
-   # Номер двигателя - **номер двигателя;**
    
-   # Объем двигателя - **обьем двигателя**;
    
-   # VIN - **вин код   кузова;**
    
-   # Лицензия на транспортное средство **\- сведения лицензии;**
    
-   # Дата выдачи ПТС - **дата выдачи  паспорта транспортного средства.**
