## Как создать отчёт

1\. Перейдите в раздел «Отчёты»

![Как работать с конструктором](images/drex_kak_rabotat_s_konstruktorom_screen.png)

2\. Найдите кнопку «Конструктор» ![](images/drex_kak_rabotat_s_konstruktorom_custom.png)

3\. Нажмите её — откроется окно конструктора

![](images/drex_kak_rabotat_s_konstruktorom_custom_2.png)

В конструкторе:

4\. Нажмите «Добавить» ![](images/drex_kak_rabotat_s_konstruktorom_custom_3.png)

5\. Выберите [тип отчёта](tipy-otchyetov-v-konstruktore.html)

![](images/drex_kak_rabotat_s_konstruktorom_custom_4.png)

6\. В поле «Название» укажите название отчёта

![](images/drex_kak_rabotat_s_konstruktorom_custom_5.png)

7\. В блоке «Колонки» нажмите «+» и добавьте нужные поля

8\. Укажите данные, формулы, фильтры и другие параметры колонок

9\. При необходимости заполните поле «Конфигурация»

10\. Нажмите «Сохранить»

После сохранения отчёт станет доступен в разделе «Отчёты».

Например, можно создать отчёт Idle – Summary Table.

## Как построить отчёт

![](images/drex_kak_rabotat_s_konstruktorom_custom_7.png)

5\. Нажмите «Построить отчёт»

![](images/drex_kak_rabotat_s_konstruktorom_custom_8.png)

Система сформирует отчёт по заданной форме.

## Группировка отчёта

Данные отчёта, созданного в конструкторе, можно объединить в отдельные блоки с помощью группировки. В зависимости от типа отчёта доступны следующие варианты:

-   по водителям
    
-   по датам
    
-   по объектам
    
-   по группам объектов
    

Чтобы настроить группировку:

1\. Перейдите в раздел «Отчёты»

2\. Выберите отчёт, созданный в конструкторе

3\. В поле «Группировка» выберите подходящий вариант

![Как работать с конструктором](images/drex_kak_rabotat_s_konstruktorom_screen_3.png)

4\. Выберите объекты и при необходимости другие данные для построения отчёта

5\. Нажмите «Построить отчёт»

Например, при группировке по группам объектов для каждой выбранной группы формируется отдельный блок с относящимися к ней данными.

![](images/drex_kak_rabotat_s_konstruktorom_custom_13.png)

## Конфигурация отчёта

Поле «Конфигурация» предназначено для дополнительных настроек отчёта. Параметры указываются в формате JSON и определяют способ обработки и отображения данных.

![Как работать с конструктором](images/drex_kak_rabotat_s_konstruktorom_screen_4.png)

### Разбивка данных по часам

Чтобы разделить данные на часовые интервалы, укажите:

<table><tbody><tr><td><span></span></td><td><div>{"split": "hour"}</div></td></tr></tbody></table>

При построении отчёта данные за каждый час будут отображаться в отдельном блоке.

![](images/drex_kak_rabotat_s_konstruktorom_custom_21.png)

### Разбивка данных по сменам

Данные отчёта можно разделить по рабочим сменам. Для каждой смены система сформирует отдельный интервал и рассчитает показатели только по данным, которые относятся к нему.

Чтобы настроить разбивку, укажите в параметре split время начала и окончания каждой смены, например,

<table><tbody><tr><td><span></span></td><td><div>{</div><div>&nbsp; "split": ["08-20", "20-08"]</div><div>}</div></td></tr></tbody></table>

![](images/drex_kak_rabotat_s_konstruktorom_custom_22.png)

В этом примере настроены две смены:

-   с 08:00 до 20:00
    
-   с 20:00 до 08:00 следующего дня
    

Если параметр show не указан, в отчёте отображаются все настроенные смены.

**Пример отчёта по всем сменам**

В примере отчёт «Хронология эксплуатации погрузчика» разделён на дневные и ночные смены. Для каждой смены отображается отдельный блок с объектом, временем начала и окончания интервала и показателями работы оборудования.

Ночная смена отображается как один непрерывный интервал с 20:00 текущего дня до 08:00 следующего дня.

Так как выбранный период отчёта начинается в 00:00, в начале отчёта также отображается оставшаяся часть ночной смены — с 00:00 до 08:00.

![](images/drex_kak_rabotat_s_konstruktorom_custom_23.png)

**Отображение одной смены**

Чтобы включить в отчёт только одну из настроенных смен, добавьте параметр show:

<table><tbody><tr><td><span></span></td><td><div>{</div><div>&nbsp; "split": ["08-20", "20-08"],</div><div>&nbsp; "show": 1</div><div>}</div></td></tr></tbody></table>

Значение параметра соответствует порядковому номеру смены в списке:

-   show: 1— показать первую смену, с 08:00 до 20:00
    
-   show: 2— показать вторую смену, с 20:00 до 08:00
    

**Пример отчёта по одной смене**

В примере указан параметр show: 1, поэтому отчёт содержит только дневные смены с 08:00 до 20:00. Для каждого дня формируется отдельный блок. Ночные смены в отчёте не отображаются.

![](images/drex_kak_rabotat_s_konstruktorom_custom_24.png)

**Разделение смены при переходе через полночь**

По умолчанию смена с 20:00 до 08:00 считается одним непрерывным интервалом. Чтобы разделить её по границе календарных суток, добавьте параметр split\_days:

<table><tbody><tr><td><span></span></td><td><div>{</div><div>&nbsp; "split": ["08-20", "20-08"],</div><div>&nbsp; "split_days": 1</div><div>}</div></td></tr></tbody></table>

Ночная смена будет разделена на два интервала:

-   с 20:00 до 00:00
    
-   с 00:00 до 08:00
    

Дневная смена остаётся одним блоком с 08:00 до 20:00.

Параметр show не указан, поскольку в отчёте присутствуют и дневная, и ночная смены.

![](images/drex_kak_rabotat_s_konstruktorom_custom_25.png)

Все параметры можно использовать одновременно:

<table><tbody><tr><td><span></span></td><td><div>{</div><div>&nbsp; "split": ["08-20", "20-08"],</div><div>&nbsp; "show": 1,</div><div>&nbsp; "split_days": 1</div><div>}</div></td></tr></tbody></table>

В этом примере отчёт отображает только первую смену, а смены, переходящие через полночь, разделяются по календарным суткам.

### Фильтрация данных

С помощью конфигурации можно определить, какие данные должны попадать в отчёт.

Например, для отчёта Idle – Summary Table можно добавить следующие колонки:

-   Транспортное средство
    
-   Время простоя
    
-   Общее количество простоев
    
-   Топливо в начале
    
-   Топливо в конце
    

Чтобы включить в отчёт только объекты, для которых зарегистрирован хотя бы один простой, укажите:

<table><tbody><tr><td><span></span></td><td><div>{"filter":[{"key":"total_idle_events_number","rule":"&gt;","value":0}]}</div></td></tr></tbody></table>

В результате строки, в которых значение поля «Общее количество простоев» равно нулю, не будут отображаться.

![](images/drex_kak_rabotat_s_konstruktorom_custom_6.png)

### Объединение строк

Чтобы объединить несколько строк за один период разбивки в итоговую строку, укажите:

<table><tbody><tr><td><span></span></td><td><div>{"merge": true}</div></td></tr></tbody></table>

 В объединённой строке отображаются значения настроенных колонок, а промежуточные строки скрываются. Настройте колонки, которые должны входить в отчёт, и сохраните изменения.

![](images/drex_kak_rabotat_s_konstruktorom_custom_26.png)

Пример объединения строк

![](images/drex_kak_rabotat_s_konstruktorom_custom_27.png)

В примере отчёт сгруппирован по водителям и разбит по суткам. Для каждого водителя создаётся отдельный блок, а его данные за каждый день объединяются в одну строку. В строке отображаются транспортное средство, дата, время начала первой и окончания последней поездки, суммарное время движения и простоя, а также общий пробег за день.

## Импорт и экспорт отчётов

Отчёты из конструктора можно переносить между аккаунтами. Для этого используйте кнопки «Экспорт» ![](images/drex_kak_rabotat_s_konstruktorom_custom_18.png) и «Импорт»![](images/drex_kak_rabotat_s_konstruktorom_custom_17.png)   

![Как работать с конструктором](images/drex_kak_rabotat_s_konstruktorom_screen_5.png)

### Как экспортировать отчёт

1\. Нажмите «Экспорт» ![](images/drex_kak_rabotat_s_konstruktorom_custom_18.png)

2\. Выберите место на устройстве

3\. Сохраните файл

### Как импортировать отчёт

1\. Нажмите «Импорт» ![](images/drex_kak_rabotat_s_konstruktorom_custom_17.png)

2\. В открывшемся окне при необходимости включите опцию Remove existing reports (Удалить существующие отчёты), если нужно удалить существующие отчёты в конструкторе  
![](images/drex_kak_rabotat_s_konstruktorom_custom_28.png)

3\. Выберите файл отчёта

4\. Нажмите «Импорт»

Отчёт будет загружен в аккаунт.
