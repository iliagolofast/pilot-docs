При создании отчёта вы сначала выбираете тип конструктора отчёта.

![](images/drex_tipy_otchyetov_v_konstruktore_custom.png)

Именно он определяет:

— какие данные будут использоваться

— какие поля будут доступны в разделе «Колонки»

— как будет выглядеть итоговый отчёт

## Доступные типы отчётов

В системе доступны следующие типы:

-   [Суммарная таблица](tipy-otchyetov-v-konstruktore.html#Суммарная_таблица) — сводные данные: итоги, суммы, количество событий и другие агрегированные показатели
    
-   [Работа](tipy-otchyetov-v-konstruktore.html#Работа) — активность объекта или датчиков за выбранный период
    
-   [Эко-события](tipy-otchyetov-v-konstruktore.html#Эко-события) — события, связанные с экономичным и неэкономичным вождением, расходом топлива
    
-   [График](tipy-otchyetov-v-konstruktore.html#График) — визуализация данных в виде графиков
    
-   [Таблица поездок](tipy-otchyetov-v-konstruktore.html#Таблица_поездок) — список поездок с параметрами: время, пробег, начало и окончание
    
-   [Таблица геозон](tipy-otchyetov-v-konstruktore.html#Таблица_геозон) — данные по геозонам: въезды, выезды, время нахождения
    
-   [Текущее состояние](tipy-otchyetov-v-konstruktore.html#Таблица_текущего_состояния) — состояние объекта на момент формирования отчёта
    
-   [Работа датчиков](tipy-otchyetov-v-konstruktore.html#Работа_датчиков) — данные по работе датчиков за период
    
-   [События датчиков](tipy-otchyetov-v-konstruktore.html#События_датчиков) — срабатывания, изменения состояния и пороговые события
    
-   [Потеря связи](tipy-otchyetov-v-konstruktore.html#Потеря_связи) — информация об отключениях связи
    
-   [Уведомления](tipy-otchyetov-v-konstruktore.html#Уведомления) — список уведомлений системы
    
-   [Карты](tipy-otchyetov-v-konstruktore.html#Карты) — данные по топливным картам и транзакциям
    
-   [Поведение водителя](tipy-otchyetov-v-konstruktore.html#Поведение_водителя) — события, связанные со стилем вождения
    
-   [Сводка по автопарку](tipy-otchyetov-v-konstruktore.html#Сводка_по_автопарку) — общая информация по всем объектам
    
-   [RFID-метки](tipy-otchyetov-v-konstruktore.html#RFID-метки) — данные по RFID
    
-   [События заправки и слива](tipy-otchyetov-v-konstruktore.html#События_заправки_и_слива) — операции с топливом
    
-   [PTM](tipy-otchyetov-v-konstruktore.html#PTM ) — специализированные отчёты для PTM-модуля
    

### Как формируются данные в отчёте

1\. Вы выбираете тип отчёта

2\. Система подгружает доступные для него категории и поля

3\. В разделе «Колонки» вы выбираете нужные данные

![](images/drex_tipy_otchyetov_v_konstruktore_custom_2.png)

4\. В отчёте отображаются только выбранные колонки

Набор доступных колонок зависит от выбранного типа отчёта

В конструкторе есть:

-   универсальные (основные) поля — доступны в большинстве типов отчётов
    
-   специализированные категории — появляются только для определённых типов
    

### Пример 1. Тип «Текущее состояние»

Для этого типа доступны данные о текущем состоянии транспортного средства.

![](images/drex_tipy_otchyetov_v_konstruktore_custom_3.png)

Помимо базовых данных (например, марка, модель, скорость), появляется категория «Сервисы», где можно добавить поля по обслуживанию:

-   Last TO motohours — последние моточасы ТО
    
-   Next TO motohours — следующие моточасы ТО
    
-   Mh until next TO — моточасы до следующего ТО
    
-   Last TO date — дата последнего ТО
    
-   Last TO number — номер последнего ТО
    
-   Next TO date — дата следующего ТО
    
-   Last TO mileage — пробег на последнем ТО
    

Эти поля помогают контролировать текущее состояние и обслуживание транспорта.

### Пример 2. Тип «Карты»

Для типа «Карты» доступны данные по топливным картам и транзакциям.

![](images/drex_tipy_otchyetov_v_konstruktore_custom_4.png)

В колонках появляется категория CardTransactions, где можно выбрать, например:

-   Transaction Type — тип операции
    
-   Transaction Location — место
    
-   Transaction Time — время
    
-   Номер карты — номер карты
    
-   Distance Previous-Current — расстояние между значениями
    
-   Current — текущее значение
    
-   Transaction Amount — сумма
    

Этот тип используется для анализа операций по картам.

## Примеры типов отчётов

В конструкторе доступно несколько типов отчётов — каждый из них решает свою задачу. Ниже — краткое описание и примеры, чтобы было проще сориентироваться.

## Суммарная таблица

Суммарная таблица помогает получить сводные данные по объектам за выбранный период.

Вы настраиваете:

-   какие колонки будут в отчёте
    
-   по какому показателю считать итог
    
-   как отсортировать данные
    

![](images/drex_tipy_otchyetov_v_konstruktore_custom_5.png)

При создании отчёта этого типа вы можете задать:

-   Название — имя отчёта
    
-   Сортировка — порядок строк
    
-   Суммарно — основной показатель для сводки
    
-   Desc — сортировка по убыванию
    
-   Колонки — какие данные показывать
    
-   Конфигурация — дополнительные настройки
    

Пример построенного отчёта из конструктора

![](images/drex_tipy_otchyetov_v_konstruktore_custom_6.png)

 Поле «Суммарно» задаёт главный показатель, по которому строится отчёт.

![](images/drex_tipy_otchyetov_v_konstruktore_custom_7.png)

 Поле «Сортировка» определяет порядок строк.

![](images/drex_tipy_otchyetov_v_konstruktore_custom_8.png)

Например, если выбрать сортировку по Vehicle, то в готовом отчёте строки будут отсортированы по транспортным средствам.

## Работа

Отчёт «Работа» показывает активность объектов или водителей за период.

С помощью этого отчёта можно увидеть:

— когда произошло событие

— по какому объекту

— где оно зафиксировано

— значения параметров

В отчёт можно включить значения дискретных, двухпозиционных и многопозиционных датчиков. Нужный датчик выбирается по назначенной ему метке при настройке колонки.

![](images/drex_tipy_otchyetov_v_konstruktore_custom_10.png)

При создании отчёта этого типа вы можете задать:

-   Название — имя отчёта
    
-   Сортировку — по какому полю будут упорядочены данные
    
-   Desc — сортировку по убыванию
    
-   Колонки — набор данных, которые будут отображаться в отчёте
    
-   Конфигурацию — дополнительные параметры и фильтры
    

В примере на скриншоте создаётся отчёт Overspeed CAN general — отчёт по превышению скорости по данным CAN.  В поле «Конфигурация» задан фильтр — в отчёт попадут только те события, где значение датчика больше 85.

## График

График — это тип отчёта, который строит визуальное представление данных в виде графиков. Он предназначен для анализа динамики изменения показателей во времени: скорости, расхода топлива, температуры, пробега, работы оборудования и других параметров.

Можно добавить несколько групп данных:

-   Скорость — график скорости движения объекта
    
-   ODO — график пробега
    
-   Топливо — уровень топлива и расход
    
-   Температура — температура различных датчиков (можно выбрать конкретные).
    
-   Спецдатчики — специальные датчики
    
-   Оборудование — данные с оборудования
    
-   Eco Pies — экологические события и нарушения (резкие торможения, повороты, столкновения, непристёгнутый ремень и др.).
    

![](images/drex_tipy_otchyetov_v_konstruktore_custom_11.png)

Для каждой группы можно:

-   Включить или отключить её отображение.
    
-   Выбрать конкретные датчики или типы событий
    
-   Настроить «Показать ось» — отображать ли отдельную ось Y для этой группы
    
-   Настроить «Single axle» — использовать одну общую ось Y
    
    Для Eco Pie можно выбрать дополнительные настройки:
    
-   Show per hour — показывать количество событий в час
    
-   Show duration — показывать длительность событий
    

После сохранения отчёта и его построения в разделе «Отчёты» система выводит интерактивный график:

![](images/drex_tipy_otchyetov_v_konstruktore_custom_12.png)

-   По оси X — время
    
-   По оси Y — значения выбранных параметров (может быть несколько осей)
    
-   Каждому параметру присваивается свой цвет линии
    
-   При наведении курсора на график появляется всплывающая подсказка с точным временем и значениями всех параметров в этой точке
    
-   Внизу графика отображается легенда — какие линии за какие параметры отвечают
    
-   График можно масштабировать, двигать и анализировать отдельные участки времени
    

![](images/drex_tipy_otchyetov_v_konstruktore_custom_13.png)

## Эко-события

Тип «Эко-события» используется для построения отчётов по событиям, связанным с:

— экономичным или неэкономичным стилем движения

— расходом топлива

— экологическим поведением транспорта

Такой отчёт помогает анализировать, когда и где происходили эко-события, а также какой тип события был зафиксирован.![](images/drex_tipy_otchyetov_v_konstruktore_custom_14.png)

При создании отчёта этого типа вы можете задать:

-   Название — имя отчёта
    
-   Сортировку — по какому полю будут упорядочены данные
    
-   Desc — сортировку по убыванию
    
-   Summarize — сводный режим отчёта
    
-   Колонки — набор данных, которые будут отображаться в отчёте
    
-   Конфигурацию — дополнительные параметры и фильтры

-   Конфигурацию — дополнительные параметры и фильтры
    

После построения отчёта система выводит таблицу с поездками за выбранный период.

![](images/drex_tipy_otchyetov_v_konstruktore_custom_16.png)

## Таблица геозон

Таблица геозон — тип отчёта для анализа посещений геозон и работы оборудования внутри них. В отчёте можно отображать въезды и выезды, продолжительность нахождения в зоне, периоды работы датчиков и другие связанные данные.

![](images/drex_tipy_otchyetov_v_konstruktore_custom_17.png)

При создании отчёта настройте следующие параметры:

-   Название — укажите название отчёта
    
-   Строки (Rows) — выберите принцип формирования строк:
    
-   Посещения геозон (Geofence visits) — одна строка соответствует одному посещению геозоны
    
-   Периоды работы оборудования (Equipment work periods) — одна строка соответствует отдельному периоду работы выбранного датчика внутри геозоны
    

![](images/drex_tipy_otchyetov_v_konstruktore_custom_18.png)

-   Сортировка — выберите поле, по которому будут упорядочены данные
    
-   По убыванию (Desc) — включите сортировку по убыванию
    
-   Колонки — настройте данные, которые должны отображаться в отчёте
    
-   Конфигурация — при необходимости укажите дополнительные параметры и фильтры
    

Набор доступных данных и колонок может зависеть от выбранного режима формирования строк.

Чтобы построить отчёт по форме из конструктора:

1\. Перейдите в раздел «Отчёты»

2\. Выберите тип отчёта 

3\. Указать нужные объекты

4\. Выберите нужные геозоны

5\. Задайте период отчёта и нажмите «Построить отчёт»

После этого система сформирует таблицу по выбранным геозонам.

![](images/drex_tipy_otchyetov_v_konstruktore_custom_19.png)

## Уведомления

Уведомления — это тип отчёта, который используется для просмотра событий, созданных системой уведомлений.

Такой отчёт помогает анализировать, например:

— какие уведомления были сгенерированы

— когда они произошли

— по какому объекту

— где именно было зафиксировано событие

— через какой канал связи было отправлено уведомление

![](images/drex_tipy_otchyetov_v_konstruktore_custom_27.png)

При создании отчёта этого типа вы можете задать:

-   Название — имя отчёта
    
-   Notifications Type — типы уведомлений, которые нужно включить в отчёт
    
-   Filter by — фильтр по каналу или способу доставки уведомления
    
-   Сортировку — по какому полю будут упорядочены данные
    
-   Desc — сортировку по убыванию
    
-   Colors — цветовое отображение
    
-   Колонки — набор данных, которые будут отображаться в отчёте
    
-   Конфигурацию — дополнительные параметры и фильтры

-   Email — письмо на электронную почту

-   Команда на устройство — отправка команды на трекер
    
-   Telegram — уведомление через [Telegram-бот](../../../mobilnye-prilozheniya/telegram-bot/index.html)
