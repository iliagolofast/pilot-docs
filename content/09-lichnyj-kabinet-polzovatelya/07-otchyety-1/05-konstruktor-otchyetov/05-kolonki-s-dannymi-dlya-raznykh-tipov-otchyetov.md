При создании отчёта сначала выбирается тип отчёта, а затем — добавляются колонки с данными.

![](images/drex_kolonki_s_dannymi_dlya_raznykh_tipov_otchyetov_custom.png)

Набор доступных данных зависит от выбранного типа отчёта:

1\. Вы выбираете тип отчёта

2\. Система автоматически подгружает доступные категории и поля данных

3\. В разделе «Колонки» вы добавляете нужные данные

4\. При построении отчёта отображаются только выбранные колонки

### Пример: тип отчёта «RFID-метки»

Если выбрать тип «RFID-метки», станут доступны данные, связанные с RFID.

Такой отчёт помогает анализировать:

-   какие RFID-метки были зафиксированы
    
-   когда произошло событие
    
-   где оно произошло
    
-   к какому объекту или устройству относится запись
    

![](images/drex_kolonki_s_dannymi_dlya_raznykh_tipov_otchyetov_custom_2.png)

При создании отчёта указываются основные настройки:

-   Название — имя отчёта
    
-   Сортировка — поле, по которому будут упорядочены данные
    
-   Desc — сортировка по убыванию
    
-   Колонки — данные, которые будут отображаться
    
-   Конфигурация — дополнительные параметры и фильтры
    

После этого можно переходить к добавлению колонок:

1\. Нажмите кнопку добавления в разделе «Колонки» ![](images/drex_kolonki_s_dannymi_dlya_raznykh_tipov_otchyetov_custom_3.png)

2\. В поле «Данные» выберите нужный параметр из списка

Доступные поля будут зависеть от выбранного типа отчёта.

![](images/drex_kolonki_s_dannymi_dlya_raznykh_tipov_otchyetov_custom_4.png)

Пример доступных данных (RFID)

Помимо общих данных (транспорт, устройство, ID, группа и т.д.), появятся специализированные поля:

-   RFID Time — время считывания метки
    
-   RFID Name — название метки (например, имя сотрудника или объект)
    
-   RFID Location — место считывания
    
-   RFID UID — уникальный код метки
    
-   RFID Group — группа меток
    

Добавьте нужные колонки, чтобы сформировать структуру отчёта.
