В системе PILOT можно использовать разные типы видеоустройств. Для каждого типа есть свои параметры подключения:

### Howen

-   Server 1 (телематика): Server URL, port 20009
    
-   Server 2 (видео): video.pilot-gps.com, port 33000
    
    Для Howen используется отдельный ключ url\_howen в [«Настройке модуля»](nastrojka-modulej-v-paneli-administratora.html#Настройка_модуля)
    
    Пароль для подключения не нужен.
    

![](images/drex_kakie_ustrojstva_mozhno_podklyuchat_custom.png)

### CMS

-   Адрес сервера (Host): video.pilot-gps.com
    
-   Порт: 6608
    

### Cipia

-   Адрес сервера (Host): video.pilot-gps.com
    
-   Порт:1883
    

### Teltonika DualCam

-   Адрес сервера (Host): video.pilot-gps.com
    
-   Порт: 20233
    

### Hikvision

Подключение устройств Hikvision зависит от конкретной модели.

Для некоторых моделей используется стандартное подключение к серверу video.pilot-gps.com.

Например, для Hikvision G40:

• Адрес сервера (Host): video.pilot-gps.com

• Порт: 6608

Другие модели Hikvision, подключаемые к PILOT:

-   DS-MCW407 (BWS) — нательная камера для видео и аудио с онлайн-передачей.
    
-   AE-MN5043 (DVR) — мобильный видеорегистратор с GPS для транспорта.
    
-   AE-VC583I-IS/P(H) — автомобильная IP-камера высокого разрешения (распознавание номеров).
    

Для разных моделей Hikvision могут применяться разные параметры подключения. Чтобы уточнить, какие именно, обратитесь в поддержку.
