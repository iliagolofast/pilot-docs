## Как работать со списком водителей

Все водители отображаются во вкладке «Водители» в виде списка.

![](images/drex_kak_rabotat_s_voditelyami_1_custom.png)

В таблице можно увидеть:

-   Имя водителя
    
-   Метки (теги)
    
-   Транспорт, за которым водитель сейчас закреплён
    
-   Ключ идентификации iButton (если используется)
    
-   Другие данные — в зависимости от настроек колонок таблицы
    
    ### Как настроить колонки таблицы
    

Вы можете настроить список водителей: выбрать нужные колонки, включить сортировку и фильтры.

![](images/drex_kak_rabotat_s_voditelyami_1_custom_2.png)

1\. В заголовке любой колонки нажмите на стрелку ![](images/drex_kak_rabotat_s_voditelyami_1_custom_3.png) — откроется меню настроек

![](images/drex_kak_rabotat_s_voditelyami_1_custom_4.png)

2\. В меню доступны:

— сортировка данных по возрастанию или убыванию

— фильтрация по выбранной колонке

— выбор колонок для отображения

3\. Чтобы выбрать, какие колонки показывать:

— нажмите «Колонки»

— отметьте галочками нужные параметры — таблица обновится автоматически

### Как открыть карточку водителя

Чтобы открыть карточку водителя для просмотра или редактирования:

1\. Найдите нужного водителя в списке

2\. Дважды кликните по строке с его именем

Карточка водителя откроется в отдельном окне.

![](images/drex_kak_rabotat_s_voditelyami_1_custom_5.png)

## Как настроить привязку водителей к машинам

Чтобы связать водителей с машинами, откройте окно DriversLink. Для этого во вкладке «Водители» нажмите кнопку «Привязать водителя к объекту» в верхней части списка.

![Как работать с водителями](images/drex_kak_rabotat_s_voditelyami_1_screen.png)

В этом окне можно:

— привязывать водителей к машинам

 — настраивать доступ к автомобилям по ID / iButton

DriversLink позволяет не просто связать водителя и машину, а создать группу привязки.

В такой группе сохраняется:

— список машин

— список водителей

— выбранный режим доступа

![Как работать с водителями](images/drex_kak_rabotat_s_voditelyami_1_screen_2.png)

1\. Выберите режим доступа

![Как работать с водителями](images/drex_kak_rabotat_s_voditelyami_1_screen_3.png)

В верхней части окна выберите нужный режим:

**\[0\] Выключено**

Контроль по ID отключён. Машина доступна без идентификации водителя.

**\[1\] Only authorized ID can unlock the vehicle**

Машину могут использовать только назначенные водители.

**\[2\] Any ID can unlock the vehicle**

Любой ID может начать движение. Система только фиксирует, кто сел за руль.

2\. В блоке «Объекты» отметьте галочками машины, к которым нужно применить настройку

![](images/drex_kak_rabotat_s_voditelyami_1_custom_12.png)

3\. В блоке «Водители» отметьте водителей, которым разрешён доступ к выбранным машинам.

Если выбран режим \[0\] Выключено — выбирать водителей не нужно.

Если выбран режим \[1\] или \[2\] — водителей нужно назначить.

4\. Создайте группу привязки

После выбора машин и водителей:

1) Нажмите «Сохранить».

2) В появившемся окне введите название группы и нажмите OK.

![](images/drex_kak_rabotat_s_voditelyami_1_custom_13.png)

Группа появится в списке слева. В ней будет сохранено:

— выбранный режим доступа

— список машин

— список водителей

У выбранных машин в колонке «Группа» появится название этой группы.

![](images/drex_kak_rabotat_s_voditelyami_1_custom_14.png)

5\. Нажмите кнопку «Сохранить» внизу окна.

После этого выбранные настройки будут применены ко всем машинам из группы.
