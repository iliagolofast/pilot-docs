Камеры Mettax могут распознавать лицо водителя и передавать его идентификатор в PILOT. После успешного распознавания PILOT автоматически назначает водителя объекту по тому же принципу, который используется для меток iButton и RFID.

Функция позволяет определять, кто управляет транспортным средством, если одним объектом пользуются несколько водителей.

## Подготовка водителей на устройстве

Сначала водителей необходимо зарегистрировать на устройстве Mettax. После регистрации устройство создаёт для каждого водителя идентификатор faceId.

<table><tbody><tr><td><span></span></td><td><div>Способ добавления водителей зависит от модели и настроек камеры. Если вы не знаете, как зарегистрировать водителей на устройстве, обратитесь к специалисту, который устанавливал или настраивал камеру.</div></td></tr></tbody></table>

После регистрации водителя устройство должно:

1\. Распознавать его лицо

2\. Передавать созданный faceId в PILOT

3\. Передавать результат распознавания в параметре faceRecogn

Идентификатор faceId создаётся устройством Mettax. Полученное от устройства значение связывается [с карточкой](opredelenie-voditelya-po-face-id.html#Связывание_Face_ID_с_водителем) соответствующего водителя в PILOT.

## Данные распознавания

При проверке лица устройство передаёт в PILOT следующие параметры:

-   faceId — идентификатор водителя, созданный на устройстве
    
-   faceRecogn — результат распознавания
    
-   alarm — тип выполненной проверки
    

Параметр faceRecogn может принимать следующие значения:

-   1 — лицо успешно распознано
    
-   0 — проверка завершилась неуспешно
    
-   2 — определить лицо не удалось
    
-   3 — сравнение завершилось ошибкой
    

Для автоматического назначения водителя необходимо, чтобы устройство передало faceRecogn=1.

Камера может передавать следующие события проверки:

-   alarm=647 — периодическая проверка водителя
    
-   alarm=648 — проверка водителя при включении зажигания
    

## Отображение данных в сырых точках

При проверке лица камера Mettax передаёт в сырых данных объекта параметры alarm, faceId и faceRecogn.

![](images/drex_opredelenie_voditelya_po_face_id_custom.png)

В выделенной строке примера отображаются следующие значения:

<table><tbody><tr><td><span></span></td><td><div>alarm=647; faceId=1; faceRecogn=1;</div></td></tr></tbody></table>

Здесь:

-   alarm=647 — камера выполнила периодическую проверку водителя
    
-   faceId=1 — устройство передало идентификатор водителя 1
    
-   faceRecogn=1 — лицо успешно распознано
    

В расположенных выше строках камера передала:

<table><tbody><tr><td><span></span></td><td><div>faceId=20210301001; faceRecogn=0;</div></td></tr></tbody></table>

Значение faceRecogn=0 показывает, что распознать лицо не удалось.

В строке с alarm=648 проверка запущена при включении зажигания. Значение faceRecogn=0 также означает, что лицо не распознано.

Для автоматического назначения водителя необходимо, чтобы в одной точке одновременно поступили идентификатор faceId и успешный результат faceRecogn=1. Полученное значение faceId должно совпадать со значением в поле [iButton](opredelenie-voditelya-po-face-id.html) карточки водителя.

## Настройка датчика Face ID

Чтобы PILOT мог использовать полученный faceId для определения водителя, на объекте необходимо создать специальный датчик с назначением iButton.

1\. Добавьте новый датчик на объект

2\. Укажите следующие параметры:

-   Назначение — iButton
    
-   Тип — Специальный
    
-   Название и описание
    
-   Поле — например, faceId
    
-   Формула преобразования — \*%faceRecogn%. Она умножает значение faceId на результат распознавания. При успешном распознавании (faceRecogn=1) значение faceId не меняется, и PILOT может сопоставить его с идентификатором в карточке водителя. При других значениях результат формулы не совпадает с исходным faceId.
    
-   Максимальное значение — значение, позволяющее сохранить используемые идентификаторы faceId
    

![](images/drex_opredelenie_voditelya_po_face_id_custom_2.png)

5\. При необходимости включите «Закрытие сеанса водителя при выключении зажигания». После выключения зажигания назначенный водитель перестанет считаться активным для объекта

6\. Сохраните датчик

### Проверка формулы

Перед сохранением датчика проверьте формулу на тестовых данных.

1\. Нажмите «Тест» рядом с формулой преобразования

![](images/drex_opredelenie_voditelya_po_face_id_custom_3.png)

2\. В открывшемся окне найдите параметры faceid и faceRecogn

3\. В параметре faceid укажите тестовый идентификатор водителя, например: faceid=20210301001

Значение 20210301001 — пример идентификатора faceId, созданного устройством Mettax.

4\. Замените автоматически подставленное значение faceRecogn на 1: faceRecogn=1. 

Параметр faceRecogn=1 соответствует успешному распознаванию лица.

5\. Нажмите Test

При успешной проверке результат должен совпасть со значением faceid: Success: 20210301001

**![](images/drex_opredelenie_voditelya_po_face_id_custom_4.png)**

Формула \*%faceRecogn% умножает faceid на результат распознавания. При faceRecogn=1 она возвращает исходный идентификатор водителя. При других значениях результат формулы не совпадает с исходным faceId.

Автоматически подставленные тестовые значения не являются данными устройства. Перед проверкой замените faceRecogn на одно из значений, поддерживаемых камерой Mettax: 0, 1, 2 или 3.

## Связывание Face ID с водителем

При регистрации водителя устройство Mettax создаёт для него уникальный идентификатор faceId. Чтобы PILOT мог автоматически определить водителя, этот идентификатор необходимо указать в его карточке.

1\. Узнайте идентификатор faceId, присвоенный водителю устройством Mettax

2\. Скопируйте значение faceId

3\. Откройте карточку соответствующего водителя в PILOT

4\. Перейдите на вкладку «Основное»

5\. Вставьте значение faceId в поле iButton

![Определение водителя по Face ID](images/drex_opredelenie_voditelya_po_face_id_screen.png)

6\. Сохраните изменения

Значение в поле iButton должно полностью совпадать с идентификатором faceId, который передаёт камера. Для каждого водителя используется отдельный идентификатор.

После успешного распознавания камера передаёт faceId и faceRecogn=1. PILOT сопоставляет полученный faceId со значением в поле iButton и назначает соответствующего водителя объекту.
