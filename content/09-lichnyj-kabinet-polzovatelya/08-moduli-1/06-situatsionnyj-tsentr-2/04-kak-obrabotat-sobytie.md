## Панель модуля

Когда срабатывает уведомление с привязанным алгоритмом, событие сразу появляется в интерфейсе — в рабочей панели оператора для обработки событий.

Панель «Ситуационного центра» — Control room, находится внизу интерфейса раздела «Основные».

Чтобы раскрыть панель, нажмите на стрелку ![](images/drex_kak_obrabotat_sobytie_custom.png).

![Как обработать событие](images/drex_kak_obrabotat_sobytie_screen.png)

В панели отражается список всех событий, которые пришли по уведомлениям и ждут реакции оператора.

![Как обработать событие](images/drex_kak_obrabotat_sobytie_screen_2.png)

### Верхняя часть

Верхняя часть панели помогает найти нужные события.

Здесь доступны:

-   Группы событий — фильтр по типу (скорость, температура, геозона и т.д.)
    
-   Поиск ![](images/drex_kak_obrabotat_sobytie_custom_2.png)— поиск по объекту или тексту события
    
-   Обновить ![](images/drex_kak_obrabotat_sobytie_custom_3.png) — вручную обновляет список
    
-   Дополнительные действия ![](images/drex_kak_obrabotat_sobytie_custom_4.png):
    
    — Интервал обработки событий — время, в течение которого событие считается актуальным и доступным для обработки. Выберите нужный интервал из списка, чтобы определить, как долго событие будет отображаться в списке перед его автоматическим переносом в статус «необработанное».
    
    — Page size — количество событий, отображаемых на одной странице
    

— Группировка — объединяет одинаковые события по одному объекту в одну строку для удобства.

— Обработано — поставьте галочку, чтобы показывать обработанные события. По умолчанию отображаются только необработанные.

![](images/drex_kak_obrabotat_sobytie_custom_5.png)

### Таблица событий

Каждая строка — это объект с текущим событием или группой событий.

Основные столбцы:

-   Дата — время последнего события
    
-   Объект — название объекта. Под ним может отображаться адрес или зона
    
-   Стадия — текущий шаг алгоритма
    
-   Оператор — кто взял событие в работу
    
-   Событие:
    
-   [Группа](kak-nastroit-parametry-sobytij.html#группы_событий), к которой относится событие
    
-   Красный кружок с числом показывает, сколько событий ещё не обработано
    
-   Текст — стандартное описание события
    
-   Альтернативный текст — пользовательское описание из настроек уведомления (если задано)
    

![Как обработать событие](images/drex_kak_obrabotat_sobytie_screen_3.png)

Слева от строки есть стрелка ![](images/drex_kak_obrabotat_sobytie_custom_6.png) — она раскрывает список всех событий внутри группы.

## Как начать обработку события

1\. Когда уведомление срабатывает, событие появляется в списке на панели

2\. Кликните по строке — событие отобразится на карте

![](images/drex_kak_obrabotat_sobytie_custom_7.png)

3\. Раскройте строку и выберите нужное событие

4\. Нажмите:

-   «Старт» — чтобы обработать событие
    
-   «Пропустить» — если событие не требует обработки
    

## Окно «Обработка события»

После нажатия «Старт» открывается пошаговое окно обработки — оно следует логике вашего алгоритма.

![](images/drex_kak_obrabotat_sobytie_custom_8.png)

В верхней части:

-   ID события — внутренний номер
    
-   Адрес — место события. Его можно скопировать — нажмите ![](images/drex_kak_obrabotat_sobytie_custom_9.png)
    
-   Текст события — описание
    
-   Информация по событию — подсказка оператору из алгоритма
    

Ниже:

-   Комментарий — что оператор сделал по событию
    

Если алгоритм содержит дополнительные шаги, могут появляться:

-   списки выбора причины или статуса
    
-   кнопка «Следующий шаг» — переход к следующему блоку алгоритма
    

![](images/drex_kak_obrabotat_sobytie_custom_10.png)

## Завершение обработки

На последнем шаге алгоритма может быть две кнопки:

-   Да — подтверждение события (нарушение было, действие выполнено)
    
-   Нет — альтернативный результат (ложное срабатывание, действия не требуются)
    

![](images/drex_kak_obrabotat_sobytie_custom_11.png)

После выбора:

— алгоритм завершается

— событие считается обработанным

— результат сохраняется в истории

Если в алгоритме нет развилки, вместо «Да / Нет» будет кнопка «Завершить».

![](images/drex_kak_obrabotat_sobytie_custom_12.png)

## Как работать с окном обработки события

  ![Как обработать событие](images/drex_kak_obrabotat_sobytie_screen_4.png)

В окне обработки нажмите на иконку карты ![](images/drex_kak_obrabotat_sobytie_custom_13.png)— внизу откроется встроенная карта.

На карте вы увидите:

-   положение объекта в момент события
    
-   трек движения до и после события
    
-   адрес и координаты
    

![](images/drex_kak_obrabotat_sobytie_custom_14.png)

Нажмите на значок ![](images/drex_kak_obrabotat_sobytie_custom_15.png) в окне обработки — откроется дополнительная панель с подробными данными по объекту и событию.

![](images/drex_kak_obrabotat_sobytie_custom_16.png)

В ней три блока:

1\. Датчики

— значения датчиков в момент события

— текущие значения сейчас

2\. Обработанные события

— дата предыдущих событий по этому объекту

— кто из операторов их обрабатывал

— время обработки, группа и текст события

3\. Информация о задании

— номер и статус задания

— время смены статусов

— маршрут и фактические времена

На этой панель оператор видит весь контекст события, не выходя из окна обработки.
