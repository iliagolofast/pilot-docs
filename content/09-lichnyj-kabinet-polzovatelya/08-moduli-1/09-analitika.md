# Статистика отображается  за последние 24 часа.

-   Открыть вкладку Панель.
    
-   Выбрать объект из списка.
    
-   Выбрать дату.
    
-   Просмотр инфоблока ТС.
    

Отчеты из Модуля Аналитики не предусмотрены.

![](images/drex_analitika__custom.png)

<table><tbody><tr><td><span></span></td><td><div>&nbsp;</div><div><span>Важно! В&nbsp; зависимости от подключенных модулей, к примеру Эко вождение, модуль ПТМ или нарушения в Геозонах, эти значения&nbsp; также&nbsp; будут выведены в&nbsp; графики по соответствующим темам.</span></div></td></tr></tbody></table>

![](images/drex_analitika__custom_2.png)

Из блока геозон реализован переход на вкладку "Онлайн" с выделением этих автомобилей в дереве объектов, находящихся в указанных геозонах.

**Как  следует отобразить объекты?**

-   Нажать на столбик обозначающий  геозону.
    
-   Нажать на меню  правой кнопкой мыши. "Показать транспортные средства на главной карте".
    
    • В дереве объектов  будут выделены только те объекты которые находятся в данной зоне.
    

Вернитесь  в модуль обычным  способом.

![](images/drex_analitika__custom_3.png)

В этом примере отображаются все 6 объектов, которые система выделила для данной геозоны.

![](images/drex_analitika__custom_4.png)

Кнопка  обновления данных.

![](images/drex_analitika__custom_5.png)

Выбрать шаблон

Пользователь может создать собственный профиль и установить его по умолчанию.

Администратор  системы  может создать профиль и установить его по умолчанию для партнерской учетной записи. В этом случае все пользователи будут видеть этот профиль как профиль по умолчанию.

![](images/drex_analitika__custom_6.png)

Создать шаблон

После того как выбраны  дополнительные параметры, нажать "Сохранить как новый".

![](images/drex_analitika__custom_7.png)

 Щелкните правой кнопкой мыши по графику, и система предложит несколько отчетов для построения.

![](images/drex_analitika__custom_8.png)

Вернуться к  Аналитике, нажмите "Назад".

![](images/drex_analitika__custom_9.png)

<table><tbody><tr><td><span></span></td><td><div><span>Формируйте отчеты по соответствующим темам к примеру отчеты связанные с&nbsp; пробегом, расходом&nbsp; топлива, работа техники.</span></div></td></tr></tbody></table>

**К примеру, на графике Пробег доступно построить отчет:**

-   Отчет по пробегу.
    
-   Отчет по пробегу № 2.
    
-   Пробег  с водителями.
    

![](images/drex_analitika__custom_10.png)

Отчеты будут построены в  обычной  вкладке  "Отчеты" со всеми  деталями о длительности, расстоянии,  адресе и другими полями.

![](images/drex_analitika__custom_11.png)

<table><tbody><tr><td><span></span></td><td><div><span>Для возврата к модулю аналитика из раздела Отчеты , перейдите на вкладку Панель, обычным способом.</span></div></td></tr></tbody></table>
