Модуль «Контроль нарушений» автоматически отслеживает превышение скорости транспортным средством.

Во время движения система сравнивает фактическую скорость автомобиля с разрешённой скоростью на текущем участке дороги. Если скорость превысит допустимое значение больше, чем на установленный порог, система зарегистрирует нарушение скоростного режима.

## Как настроить контроль нарушений

1\. Откройте карточку объекта — дважды щёлкните по объекту в списке объектов

![](images/drex_kontrol_narushenij__custom.png)

2\. Перейдите на вкладку «Контроль нарушений»

![](images/drex_kontrol_narushenij__custom_2.png)

3.  Установите флажок «Нарушение скоростного режима», чтобы включить контроль превышения скорости

![](images/drex_kontrol_narushenij__custom_3.png)

4\. Установить значение в поле «Порог превышения разрешённой скорости»

5.  При необходимости установите флажок «Слать оповещения», чтобы получать уведомления о зарегистрированных нарушениях

![](images/drex_kontrol_narushenij__custom_4.png)

6\. Нажмите «Сохранить»

После сохранения система начнёт отслеживать превышение скорости по указанным настройкам.

## Параметры настройки

### Нарушения скоростного режима

Включает или отключает контроль превышения скорости для выбранного объекта.

Если галочка включена, система будет отслеживать скорость движения и фиксировать нарушения в соответствии с заданным настройками.

![Контроль нарушений ](images/drex_kontrol_narushenij__screen.png)

### Порог превышения разрешённой скорости

Определяет, насколько скорость автомобиля должна превысить разрешённую скорость на дороге, чтобы система зарегистрировала нарушение.

![Контроль нарушений ](images/drex_kontrol_narushenij__screen_2.png)

Например, если:

-   разрешённая скорость на участке дороги — 80 км/ч;
    
-   установленный порог — 20 км/ч,
    

то нарушение будет зарегистрировано только тогда, когда скорость автомобиля превысит 100 км/ч.

### Слать оповещения

Если установить эту галочку, система будет отправлять уведомления каждый раз при регистрации нарушения.

Данные о зафиксированных нарушениях скоростного режима будут доступны в модуле [«События»](sobytiya.html)

![Контроль нарушений ](images/drex_kontrol_narushenij__screen_3.png)

## Ограничения скорости

При определении превышения скорости система использует ограничения скорости для каждого участка дороги.

По умолчанию эти данные берутся из картографического сервиса OpenStreetMap (OSM). Для каждого типа дороги в системе хранится значение разрешённой скорости, которое используется при расчёте нарушений.

При необходимости эти значения можно изменить. Для этого нажмите «Изменить значения ограничений скорости».

![Контроль нарушений ](images/drex_kontrol_narushenij__screen_4.png)

Откроется таблица ограничений скорости для различных типов дорог и категорий транспортных средств.

![](images/drex_kontrol_narushenij__custom_5.png)

В первом столбце отображаются типы дорог, используемые OpenStreetMap. Названия выводятся в виде внутренних идентификаторов OSM. Например: AT:rural — загородные дороги в Австрии,  DE:urban — городские дороги в Германии, bus\_guideway — дорога, предназначенная для движения автобусов.

Для каждого типа дороги можно задать отдельные ограничения скорости для разных категорий транспортных средств:

-   Общее — значение по умолчанию
    
-   Грузовые — для грузовых автомобилей
    
-   Автобусы — для автобусов
    
-   Легковые машины — для легковых автомобилей
    

Если для категории транспорта задано собственное значение, при определении нарушения система будет использовать именно его.

### Как изменить ограничение скорости

1\. Нажмите «Изменить значения ограничений скорости»

![Контроль нарушений ](images/drex_kontrol_narushenij__screen_4.png)

2\. Найдите нужный тип дороги

![](images/drex_kontrol_narushenij__custom_5.png)

3\. Дважды щёлкните по ячейке с нужной категорией транспортного средства

![](images/drex_kontrol_narushenij__custom_6.png)

4\. Введите новое значение ограничения скорости.

5\. Нажмите «Сохранить»

6\. Закройте окно и нажмите «Сохранить» в карточке объекта
