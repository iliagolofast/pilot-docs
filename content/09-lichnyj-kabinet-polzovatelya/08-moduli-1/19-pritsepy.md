Модуль «Прицепы» предназначен для создания, настройки и управления прицепами, используемыми совместно с объектами мониторинга.

![](images/drex_pritsepy__custom.png)

Прицеп может использоваться в двух вариантах:

— как информационный объект — хранит сведения о прицепе и может быть привязан к транспортному средству

— как объект мониторинга — имеет собственный GPS-трекер, датчики и передаёт данные в систему

После привязки прицепа к транспортному средству система отображает их как единый состав и позволяет отслеживать информацию как о тягаче, так и о самом прицепе.

## Как создать прицеп

1\. Перейдите во вкладку «Прицепы»

![](images/drex_pritsepy__custom_2.png)

2\. Нажмите кнопку Добавить ![](images/drex_pritsepy__custom_3.png) 

![Прицепы ](images/drex_pritsepy__screen.png)

Откроется карточка создания прицепа.

Заполните необходимые параметры и нажмите «Сохранить».

![](images/drex_pritsepy__custom_4.png)

### Параметры прицепа

-   Название прицепа — название, под которым прицеп будет отображаться в системе
    
-   Ассоциированный объект — выберите объект мониторинга, от которого прицеп будет получать данные о местоположении, состоянии датчиков и других параметрах.
    

<table><tbody><tr><td><span></span></td><td><div><span>Ассоциированный объект — это не транспортное средство, к которому прицеп будет присоединён, а объект мониторинга, данные которого относятся к данному прицепу.</span></div></td></tr></tbody></table>

Тип — выберите тип прицепа

![](images/drex_pritsepy__custom_5.png)

<table><tbody><tr><td><span></span></td><td><div><span>Если нужного типа нет в списке, обратитесь в техническую поддержку для его добавления.</span></div></td></tr></tbody></table>

-   Ширина — укажите ширину прицепа и выберите единицу измерения: миллиметры, сантиметры, метры
    

![](images/drex_pritsepy__custom_4.png)

-   Группа — выберите группу, в которой будет находиться прицеп
    
-   RFID — RFID-код, который передаётся RFID-датчиком транспортного средства при подключении прицепа. По этому идентификатору система автоматически определяет, какой прицеп подключён к транспортному средству.
    
-   Описание — дополнительная информация о прицепе.
    

### Дополнительные параметры

![Прицепы ](images/drex_pritsepy__screen_2.png)

-   Эксклюзивный — определяет порядок привязки прицепов.
    

Если параметр включён, при подключении этого прицепа все остальные прицепы, ранее привязанные к транспортному средству, будут автоматически отвязаны. Используйте этот параметр, если к транспортному средству одновременно может быть подключён только один прицеп.

-   Агро — используется совместно с модулем сельского хозяйства ([Агро](agro.html)). Включайте этот параметр только для объектов, работающих с функциональностью агромодуля.
    
-   Слать оповещения — включает отправку уведомлений о событиях, связанных с этим прицепом
    

### Доступ к объектам

Выберите в списке объекты, которым будет доступен данный прицеп. Если поле оставить пустым, прицеп будет доступен всем объектам.

![](images/drex_pritsepy__custom_6.png)

## Как привязать прицеп

Привязать прицеп к транспортному средству можно двумя способами.

### Через карточку прицепа

В нижней части карточки откройте раздел «Объекты».

Выберите галочками одно или несколько транспортных средств, к которым необходимо предоставить доступ или выполнить привязку.

![Прицепы ](images/drex_pritsepy__screen_3.png)

Для поиска нужного объекта можно использовать:

-   фильтр ![](images/drex_pritsepy__custom_7.png) 
    
-   поиск с подсветкой совпадений ![](images/drex_pritsepy__custom_8.png) — найденные символы будут выделены жёлтым цветом
    

После выбора объектов нажмите «Сохранить».

### Через карточку объекта

1\. Выберите объект в списке

2\. Щёлкните по нему правой кнопкой мыши

3\. В контекстном меню выберите «Прицепы»

![](images/drex_pritsepy__custom_9.png)

4\. Выполните одно из действий:

-   Привязать — чтобы подключить прицеп
    
-   Отвязать — чтобы отключить ранее привязанный прицеп.
    

## Работа с прицепами

После привязки прицепа:

— значок объекта на карте изменится на значок транспорта с прицепом

![Прицепы ](images/drex_pritsepy__screen_4.png)

— в колонке «Прицеп» списка объектов появится название подключённого прицепа

![Прицепы ](images/drex_pritsepy__screen_5.png)

### Информация на карте

Вы можете просмотреть подсказку объекта на карте с информацией о прицепе.

![Прицепы ](images/drex_pritsepy__screen_6.png)

Чтобы открыть подсказку объекта, щёлкните левой кнопкой мыши по его значку.

Если отображение прицепов включено в настройках, в подсказке объекта будет показана информация о подключённом прицепе. При наличии ассоциированного объекта можно просмотреть сведения, поступающие от GPS-трекера прицепа.

Чтобы включить отображение прицепов в подсказке:

1\. Перейдите в «Настройки договора»

2\. Откройте вкладку «Персонализация»

3\. В разделе «Элементы всплывающей подсказки» установите флажок «Прицеп»

![](images/drex_pritsepy__custom_10.png)

4\. Сохраните изменения

### Информация в списке объектов

Чтобы просмотреть сведения о прицепе во всплывающей подсказке, наведите курсор на объект в списке.

![Прицепы ](images/drex_pritsepy__screen_7.png)

Чтобы всплывающая подсказка отображалась в списке объектов, в [«Персонализации»](../nastrojki-dogovora-2/personalizatsiya.html#общие_настройки_отображения) выберите опцию «Показать подсказки дерева объектов».

## История прицепа

Для каждого прицепа доступна история привязок.

Чтобы открыть историю:

1\. Щёлкните правой кнопкой мыши по прицепу на вкладке «Прицепы»

2\. Выберите «Показать историю»

![](images/drex_pritsepy__custom_11.png)

В истории отображается:

![](images/drex_pritsepy__custom_12.png)

-   объект, к которому был привязан прицеп
    
-   название прицепа
    
-   дата и время привязки
    
-   дата и время отвязки
    
-   RFID-код
    

Чтобы удалить запись из истории, нажмите значок ![](images/drex_pritsepy__custom_13.png).

## Как удалить прицеп

1\. Щёлкните правой кнопкой мыши по прицепу на вкладке «Прицепы»

2\. Выберите «Удалить»

![](images/drex_pritsepy__custom_11.png)
