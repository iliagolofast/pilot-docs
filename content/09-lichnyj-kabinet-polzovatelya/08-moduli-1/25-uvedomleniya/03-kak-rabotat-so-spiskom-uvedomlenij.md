## Список уведомлений

В таблице отображаются все уведомления, доступные в текущем аккаунте.

![](images/drex_kak_rabotat_so_spiskom_uvedomlenij_custom_2.png)

Для каждого уведомления показывается:

-   ID — внутренний идентификатор уведомления
    
-   Пользователь — пользователь, который создал уведомление
    
-   Название — имя уведомления
    
-   Тип — тип события, по которому работает уведомление
    
-   Дата — дата и время создания уведомления
    
-   Транспорт — объекты, к которым привязано уведомление
    

Справа в строке доступны действия:

![](images/drex_kak_rabotat_so_spiskom_uvedomlenij_custom_3.png) Редактировать — открыть уведомление для изменения

![](images/drex_kak_rabotat_so_spiskom_uvedomlenij_custom_4.png) Удалить — удалить уведомление

## Шаблоны уведомлений

Во вкладке доступны функции экспорта и импорта уведомлений. Вы можете использовать уже настроенные уведомления как шаблоны и переносить их в другой аккаунт.

![Как работать со списком уведомлений](images/drex_kak_rabotat_so_spiskom_uvedomlenij_screen.png)

1 — Экспорт уведомлений

2 — Импорт уведомлений

### Экспорт уведомлений

При экспорте текущий список уведомлений сохраняется в JSON-файл.

1\. Нажмите «Экспорт уведомлений»

2\. Система создаст файл в формате JSON

Этот файл можно использовать как шаблон — например, чтобы быстро настроить уведомления в другом аккаунте.

При экспорте из файла автоматически исключаются: транспортные средства, геозоны, номера телефонов, email-адреса. Это сделано потому, что в другом аккаунте могут быть другие объекты и контакты. После импорта эти данные нужно будет указать вручную.

### Импорт уведомлений

Импорт позволяет загрузить ранее сохранённые уведомления из JSON-файла.

Перед импортом выберите подходящий вариант:

-   Не удалять старые уведомления — новые будут добавлены к существующим
    
-   Удалить старые уведомления — текущие настройки будут заменены импортированными
    

Как выполнить импорт:

1\. Выберите файл для загрузки

2\. Нажмите «Импорт»

![](images/drex_kak_rabotat_so_spiskom_uvedomlenij_custom_5.png)

## Автоматическое добавление уведомлений

Параметр «Включить автоматическое добавление уведомлений» определяет, будут ли уведомления автоматически применяться к новым объектам.

![Как работать со списком уведомлений](images/drex_kak_rabotat_so_spiskom_uvedomlenij_screen_2.png)

Если опция включена, все созданные уведомления автоматически назначаются новым объектам, которые вы добавляете в аккаунт.

Если опция выключена, новые объекты нужно будет добавлять в уведомления вручную.
