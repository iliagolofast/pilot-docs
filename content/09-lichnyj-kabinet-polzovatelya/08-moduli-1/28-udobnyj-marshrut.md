Интеграция передаёт в PILOT сведения о поездках и оплате проезда из системы «Удобный маршрут». На основе этих данных можно анализировать пассажиропоток и формировать отчёты по автобусам.

Настройка состоит из трёх этапов:

1\. Администратор договора подключает необходимые модули

2\. Администратор сервера настраивает доступ к API

3\. Пользователь привязывает терминалы оплаты к автобусам

Перед началом настройки подготовьте:

-   логин и пароль для доступа к API
    
-   адрес API
    
-   Terminal ID каждого терминала оплаты

-   список автобусов, в которых установлены терминалы
    

<table><tbody><tr><td><span></span></td><td><div>Перед настройкой подготовьте адрес API, логин и пароль, а также идентификаторы терминалов для автобусов. -   доступ к панели администратора PILOT
    
-   доступ к файлу config.php на сервере
    

### 1\. Подключите модуль

Этот этап выполняет администратор PILOT

1\. Откройте панель администратора

2\. Перейдите на вкладку Договоры.

3\. Выберите нужный договор и нажмите на него правой кнопкой мыши

4\. Выберите в «Редактировать»

![](images/drex_udobnyj_marshrut_custom.png)

5 В карточке договора перейдите на вкладку «Модули» и подключите модули «Удобный маршрут» и «Пассажиропоток»

![Удобный маршрут](images/drex_udobnyj_marshrut_screen.png)

6\. После подключения модулей в карточке договора перейдите в «Настройку модулей»

7\. Найдите и выберите модуль «Интеграция Удобный Маршрут»

![](images/drex_udobnyj_marshrut_custom_2.png)

8\. В блоке «Конфиги» добавьте параметры

9\. Нажмите «Сохранить»

### 2\. Настройте подключение к API

Этот этап выполняет администратор сервера.

Откройте файл config.php на сервере и добавьте параметры:

**![](images/drex_udobnyj_marshrut_custom_3.png)**

Вместо заполнителей укажите логин и пароль, полученные для организации.

Сохраните изменения в файле config.php.

### 3\. Укажите Terminal ID автобус

Этот этап выполняет пользователь с правами на редактирование транспортных средств.

Способ заполнения зависит от значения параметра field\_name и конфигурации договора.

Если используется поле Terminal ID:

1\. Откройте карточку нужного автобуса

2\. Перейдите в раздел «Основные»

3\. Найдите поле «Terminal ID»

![Удобный маршрут](images/drex_udobnyj_marshrut_screen_2.png)

4\. Введите идентификатор терминала, установленного в этом автобусе

5\. Нажмите «Сохранить»

В некоторых конфигурациях отдельное поле Terminal ID может не отображаться. Если нужного поля нет или вы не уверены, куда вводить идентификатор, обратитесь к администратору договора или в службу поддержки PILOT.

### 4\. Проверьте поступление данных

После настройки дождитесь появления новых транзакций в системе «Удобный маршрут». Затем сформируйте отчёт:

1\. Откройте раздел «Отчёты».

2\. Перейдите в группу «Пассажиропоток»

3\. Выберите автобус

4\. Укажите период, в котором по терминалу проходили оплаты

5\. Выберите отчёт «Суммарный по удобному маршруту»

6\. Сформируйте отчёт

7\. Проверьте наличие данных

При подключенной интеграции также могут быть доступны следующие отчёты:

-   Суммарный по АСОП № 2
    
-   Суммарный по АСОП № 3
    
-   Суммарный по АСОП № 4
    
-   Городской автобус + Удобный маршрут
    
-   Отчёт по пассажирским перевозкам
    
-   другие отчёты группы [«Пассажиропоток»](../otchyety-1/tipy-otchyetov/passazhiropotok/index.html)
