В разделе «Акты» вы можете просматривать все акты, которые были созданы по завершённым заданиям. Акт — это официальный документ, подтверждающий выполнение работы по заданию.

![](images/drex_akty_custom.png)

### Фильтрация актов

Чтобы быстро найти нужный акт, воспользуйтесь строкой «Поиск» — ведите ID задания, ID акта, название, адрес или любой другой текст, связанный с актом.

![](images/drex_akty_custom_2.png)

Также можно отфильтровать акты по периоду. Для этого выберите дату в полях «От» и «До». После этого нажмите «Установить фильтр по дате» ![](images/drex_akty_custom_3.png). Чтобы сбросить фильтр, нажмите «Очистить фильтр» ![](images/drex_akty_custom_4.png).

### Действия с актами

Для каждого акта отображаются основные данные:

-   Уникальный номер и название акта
    
-   Адрес, по которому оформлен акт
    
-   Название и тип задания
    
-   Водитель и машина, выполнившие работу
    
-   Время начала, принятия, завершения
    

В правой части каждой строки акта находятся кнопки для работы с ним:

![](images/drex_akty_custom_5.png)

 ![](images/drex_akty_custom_6.png)Просмотреть акт — откроется акт для просмотра

 ![](images/drex_akty_custom_7.png)Выгрузить акт — сохранить акт на свой компьютер

 ![](images/drex_akty_custom_8.png)Напечатать акт — распечатайте акт для физической документации

 ![](images/drex_akty_custom_9.png)Удалить запись акта — удалите акт, если он больше не нужен
