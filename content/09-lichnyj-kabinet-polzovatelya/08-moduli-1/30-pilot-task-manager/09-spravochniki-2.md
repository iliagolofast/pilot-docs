В разделе «Справочники» вы можете создавать и настраивать списки данных, которые используются при работе с заданиями, машинами и водителями. Например, это могут быть списки водителей, статусов заданий или типов груза. Использование справочников упрощает создание заданий, так как вам достаточно выбрать нужные данные из уже подготовленных списков, а не вводить их вручную каждый раз.

### Как подключить раздел «Справочники»

1\. Раздел «Справочники» не всегда доступен в меню PTM и подключается по запросу. Чтобы подключить этот раздел, обратитесь в техподдержку

2\. После подключения раздел будет пустым, так как готовых справочников в системе нет. Вы сможете самостоятельно добавлять и настраивать справочники, создавая нужные вам списки

## Как создать справочник

![](images/drex_spravochniki_2_custom.png)

1\. Откройте раздел «Справочники»

2\. В панели «Список справочников» нажмите кнопку «Добавить» ![](images/drex_spravochniki_2_custom_2.png)

![](images/drex_spravochniki_2_custom_3.png)

-   Псевдоним — техническое имя справочника
    
-   Первичный ключ, Вторичный ключ, Ключ для отображения, Родительский псевдоним — эти поля относятся к настройке структуры справочника и связям с другими таблицами.

4\. Нажмите «Добавить» над таблицей справа ![](images/drex_spravochniki_2_custom_2.png)

## Примеры справочников

В разделе «Справочники» вы можете создавать и настраивать различные списки данных, которые помогут вам упростить процесс работы с заданиями. Начальный список всегда пустой, и вам предстоит заполнить его нужной информацией. Давайте рассмотрим несколько примеров справочников, которые можно настроить.

### Справочник шаблонов

Во вкладке «Шаблоны» хранится список всех типов заданий и документов. Каждый шаблон определяет, какие поля будут отображаться в карточке задания, какие колонки увидит диспетчер в журнале и какие формы акта выполняются по заданию.

![](images/drex_spravochniki_2_custom_6.png)

Как добавить новый шаблон:

1\. Откройте раздел Справочники → Шаблоны

2\. Нажмите «Добавить» ![](images/drex_spravochniki_2_custom_2.png). Откроется окно «Добавление шаблона»

![](images/drex_spravochniki_2_custom_7.png)

В нём заполните:

-   Введите понятное имя шаблона, например: «Доставка по городу», «Сервисный выезд» и т.п.
    
    2\. Опишите, для чего этот шаблон
    
    3\. Установите дополнительные флажки:
    
-   Шаблон по умолчанию — если включите, именно этот шаблон будет подставляться автоматически при создании нового задания
    
-   Отправка СМС водителю — при создании задания по этому шаблону водителю будет уходить СМС
    
-   Отправка СМС инициатору —  СМС получит инициатор задания
    
    4\. Header template — в этом поле хранится техническое описание «шапки» таблицы и экспорта в Excel. Если вы не знаете, что сюда вносить, обратитесь в техподдержку.
    
    5\. Нажмите «Отправить» — новый шаблон появится в списке
    

После того как вы создали шаблон и он появился в списке, его нужно наполнить полями. Нажмите «Параметры», чтобы настроить:

![Справочники](images/drex_spravochniki_2_screen.png)

— какие поля будут в карточке задания

— в каком порядке они показываются

— какие колонки будут в журнале заданий

— какие поля обязательные, служебные и т.п

Как добавить новое поле в шаблон:

1\. В разделе «Шаблоны» выделите нужный шаблон

2\. Нажмите «Параметры» — откроется таблица полей

![](images/drex_spravochniki_2_custom_8.png)

3\. Нажмите «Добавить» ![](images/drex_spravochniki_2_custom_2.png)

4\. В форме добавления заполните:

![](images/drex_spravochniki_2_custom_9.png)

-   Тип — выберите тип данных
    
-   Псевдоним — внутреннее имя поля латиницей
    
-   Название — как поле будет называться
    
-   Название группы
    
-   Значение по умолчанию
    
-   Вес — определяет порядок отображения поля
    
-   Настройки — установите флажки:
    

— Значение является результатом формулы? — поле заполняется автоматически по формуле

— Поле может быть пустым —  если включено, поле не обязательно к заполнению

— Поле активное — поле используется и показывается в форме

—  Поле можно удалять —  разрешает в будущем удалить это поле из шаблона

— Видимость только при редактировании — поле видно, только когда задание редактируют, в режиме просмотра скрыто

— Показать название склада / Показать идентификатор заказа — специальные опции для шаблонов, где нужны эти данные

— Является индексом ключа для поиска — поле будет использоваться для поиска

-   Права на поле:
    

— Шаблоны разрешений  — выберите роли (шаблоны прав), которым поле будет доступно.

— Запретить редактирование для шаблонов разрешений — роли, для которых поле будет только для чтения \\

3\. После заполнения нажмите «Сохранить» в форме параметра. Новое поле появится в этом шаблоне

Как создать акт выполненных работ для шаблона:

1\. Зайдите в Справочники → Шаблоны

2\. Выберите нужный шаблон

3\. Вверху нажмите кнопку «Акт выполненных работ»

<table><tbody><tr><td><span></span></td><td><div>Если этот пункт не отображается, его нужно добавить в правах <a href="spravochniki-2.html#Шаблон_разрешений"><span>шаблона разрешений</span></a>. В случае проблем обратитесь в техподдержку.</div></td></tr></tbody></table>

![Справочники](images/drex_spravochniki_2_screen_2.png)

4\. Откроется окно со списком актов для этого шаблона

![](images/drex_spravochniki_2_custom_10.png)

5\. В окне нажмите «Добавить» ![](images/drex_spravochniki_2_custom_2.png) — откроется форма «Добавление акта выполненных работ»

6\. Заполните поля сверху:

-   Название —  как будет называться акт
    
-   Existing file — если нужно взять за основу уже существующий файловый шаблон.
    
-   Файл —  при необходимости можно загрузить свой файл-шаблон с диска
    

 7. Оформите текст акта — во вкладке «Редактор» напишите текст акта

Чтобы в акт автоматически подставлялись данные из задания:

![Справочники](images/drex_spravochniki_2_screen_3.png)

1\. Справа в блоке «Параметры для акта» выберите нужный параметр:

![](images/drex_spravochniki_2_custom_11.png)

-   вкладка «Базовые» — номер задания, даты, адреса, суммы и т.п.;
    
-   вкладка «Исполнитель» — то, что именно водитель заполняет в акте в мобильном приложении. Поля для актов водителей должны отображаться после базовых данных в тексте акта
    
-   вкладка «Шаблон» — поля, специфичные именно для этого шаблона
    

2\. В списках вкладок выберите нужные поля (например, текстовые поля, чекбоксы, подпись и т.п.) и скопируйте их названия в текст акта.

![](images/drex_spravochniki_2_custom_12.png)

3\. При необходимости отметьте этот акт по умолчанию для шаблона

![Справочники](images/drex_spravochniki_2_screen_4.png)

4\. Нажмите «Сохранить»

Теперь при заданиях этого шаблона можно печатать акт по настроенной форм.

### Справочник подписантов

Здесь настраиваются люди, которые будут подписывать документы и акты. С помощью шаблонов подписи можно легко определить, кто и в каком порядке должен подписывать документы.

![](images/drex_spravochniki_2_custom_13.png)

### Типы заданий

Здесь настраиваются различные типы заданий, например, «Доставка», «Ремонт», «Погрузка». Также можно указать приоритеты и описание.

![](images/drex_spravochniki_2_custom_14.png)

### Приоритеты заданий

Этот справочник настраивает различные уровни срочности заданий: «Не срочно», «Срочно», «Очень срочно».

![](images/drex_spravochniki_2_custom_15.png)

### Статусы заданий

В этом справочнике задаются все возможные статусы для заданий: «Новое», «В процессе», «Выполнено», «Отправлено водителю» и так далее.

![](images/drex_spravochniki_2_custom_16.png)

### Классификатор адресов

В этом справочнике хранятся адреса, которые уже были использованы в заданиях ранее. Вместо того чтобы вводить каждый адрес вручную при создании нового задания, вы можете выбрать нужный адрес из этого списка.

![](images/drex_spravochniki_2_custom_17.png)

### Справочник водителей

Здесь вы можете хранить информацию о водителях, работающих по договору. Этот справочник нужен для того, чтобы назначать таких водителей на задания.

![](images/drex_spravochniki_2_custom_18.png)

### Настройки уведомлений

В этом справочнике вы настраиваете, какие уведомления нужно отправлять и каким способом — через SMS, email, Push-уведомления или Telegram.

![](images/drex_spravochniki_2_custom_19.png)

Чтобы добавить уведомление нажмите ![](images/drex_spravochniki_2_custom_2.png) и заполните форму уведомления:

![](images/drex_spravochniki_2_custom_20.png)

1\. Блок «Информация об уведомлении»:

-   Название — придумайте понятное имя правила, например, «Превышение времени разгрузки»
    
-    Уведомление — выберите, по какому событию сработает правило
    
-   Ресурсы — если уведомление относится не ко всем, выберите конкретные машины/ресурсы.
    
    Если должно срабатывать для всех — поставьте галочку «Все».
    

2\. Блок «Параметры»

-   Цвет события — выберите цвет, которым уведомление будет отмечаться в интерфейсе
    
-   Выберите каналы доставки:
    

— E-mail — в поле ниже укажите e-mail-адреса

— SMS — в поле ниже укажите номера телефонов

— Telegram 

— Всплывающее окно

— Push в мобильное приложение

-   Для всех пользователей — если уведомление должны видеть все
    
-   Адрес геозоны — укажите точку/геозону, если уведомление связано с конкретным местом
    

3\. Блок «Условие»

Здесь вы уточняете, в каких случаях именно срабатывает уведомление:

-   Тип шаблона — при необходимости ограничьте правило конкретными шаблонами заданий, либо отметьте «Все».
    
-   Типы заданий — выберите, для каких типов действует уведомление
    
-   Статусы устройств — по каким статусам трекера/ТС работать правилу
    
-   Статусы заданий — для каких статусов задания
    
-   Время в статусе, мин — если нужно срабатывать не сразу, а только если задание «зависло» в статусе дольше указанного времени
    

4.  Проверьте заполненные поля и нажмите «Сохранить» внизу справа. Новое правило появится в списке настроек уведомлений и начнёт работать по заданным условиям.
