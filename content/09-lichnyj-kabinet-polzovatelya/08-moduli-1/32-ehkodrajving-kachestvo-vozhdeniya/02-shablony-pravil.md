Шаблон правил — это сохранённый набор настроек качества вождения. С помощью шаблона можно применить готовые правила к транспортному средству, не настраивая каждое правило вручную. Шаблон можно подобрать по типу устройства и транспортного средства, применить к объекту или создать самостоятельно.

## Готовые шаблоны

Чтобы открыть список шаблонов:

1\. Откройте карточку транспортного средства

2\. Перейдите на вкладку «Качество вождения»

3\. Раскройте список «Шаблон»

В списке отображаются подходящие шаблоны и отдельная группа «Универсальные шаблоны».

![](images/drex_shablony_pravil_custom.png)

 Универсальные шаблоны не связаны с определённым устройством или типом транспортного средства, поэтому их можно применять к разным транспортным средствам.

В системе также доступны готовые шаблоны для определённых моделей телематического оборудования:

-   CIPIA
    

![](images/drex_shablony_pravil_custom_2.png)

-   FLEX — для устройств, работающих по протоколу Flex, например, Smart 2333
    

![](images/drex_shablony_pravil_custom_3.png)

-   GB100 ECO — для Queclink GB100
    

![](images/drex_shablony_pravil_custom_4.png)

-   GV65 ECO — для Queclink GV65
    

![](images/drex_shablony_pravil_custom_5.png)

-   Ruptela
    

![](images/drex_shablony_pravil_custom_6.png)

-   Teltonika
    

![](images/drex_shablony_pravil_custom_7.png)

Выбирайте шаблон, соответствующий оборудованию и типу транспортного средства.

## Как применить шаблон

1\. Откройте вкладку «Качество вождения»

2\. В поле «Шаблон» выберите нужный шаблон

![](images/drex_shablony_pravil_custom.png)

3\. Нажмите «Применить» ![](images/drex_shablony_pravil_custom_8.png)

![Шаблоны правил](images/drex_shablony_pravil_screen.png)

4\. Правила из шаблона загрузятся в таблицу. Проверьте их и нажмите «Сохранить» в нижней части карточки транспортного средства.

![](images/drex_shablony_pravil_custom_9.png)

Если тип транспортного средства не указан, для подбора используется тип «Легковой», но поле в карточке автоматически не заполняется.</div></td></tr></tbody></table>

## Как создать собственный шаблон

Сначала настройте правила качества вождения. Чтобы добавить правило:

1\. Нажмите значок плюса ![](images/drex_shablony_pravil_custom_10.png)

2\. Заполните параметры правила

3\. Нажмите «Сохранить» в строке правила

![](images/drex_shablony_pravil_custom_11.png)

Чтобы сохранить настроенные правила как шаблон:

1\. Нажмите значок сохранения ![](images/drex_shablony_pravil_custom_12.png) рядом со списком «Шаблон»

![Шаблоны правил](images/drex_shablony_pravil_screen_2.png)

2\. В окне «Сохранить как шаблон» укажите:

-   Имя шаблона
    
-   Тип устройства — необязательно
    
-   Тип ТС — необязательно
    

![](images/drex_shablony_pravil_custom_13.png)

3\. Нажмите «Сохранить»

<table><tbody><tr><td><span></span></td><td><div>Если оставить тип устройства или тип транспортного средства незаполненным, шаблон можно будет использовать с любым значением этого параметра.</div></td></tr></tbody></table>

Созданный шаблон появится в списке доступных шаблонов.

![](images/drex_shablony_pravil_custom_14.png)

## Как настроить применимость шаблона

Применимость определяет, для каких устройств и транспортных средств будет доступен шаблон.

### Область применения шаблона

Шаблон можно связать:

— с типом устройства и типом транспортного средства

— только с типом устройства

— только с типом транспортного средства

-   — не связывать ни с одним из типов — такой шаблон считается универсальным
    

<table><tbody><tr><td><span></span></td><td><div>Если тип устройства не указан, шаблон можно использовать с любым устройством. Если не указан тип транспортного средства, шаблон подходит для всех типов транспортных средств.</div></td></tr></tbody></table>

### Чтобы настроить применимость:

-   В правой верхней части окна найдите инструменты для управления настройками экодрайвинга
    

![Шаблоны правил](images/drex_shablony_pravil_screen_3.png)

2.  Нажмите значок

### ![](images/drex_shablony_pravil_custom_15.png)

в верхней части вкладки «Качество вождения»

3\. В окне «Применимость шаблона» выберите:

-   Тип устройства
    
-   Тип ТС
    
-   Шаблон
    

![](images/drex_shablony_pravil_custom_16.png)

-   Тип устройства
    
-   Тип ТС
    
-   Шаблон
    
    3\. Нажмите «Привязать»
    

В поле «Тип устройства» можно выбрать конкретную модель оборудования.

![](images/drex_shablony_pravil_custom_17.png)

В поле «Тип ТС» можно выбрать конкретный тип транспортного средства или оставить значение «Для всех типов ТС».

![](images/drex_shablony_pravil_custom_18.png)

В поле «Шаблон» выберите шаблон, для которого настраивается применимость.

![](images/drex_shablony_pravil_custom_19.png)

Например, шаблон можно связать с устройством FleetGuide и типом транспортного средства «Легковой».

![](images/drex_shablony_pravil_custom_20.png)

Чтобы очистить выбранное значение, нажмите значок крестика в соответствующем поле.

После привязки PILOT учитывает тип устройства и тип транспортного средства при подборе доступных шаблонов. Шаблон не применяется автоматически: вы выбираете его и подтверждаете применение.

Последующие изменения самого шаблона также не изменят настройки транспортных средств, к которым он был применён ранее.</div></td></tr></tbody></table>

## Импорт и экспорт правил

Импорт и экспорт позволяют переносить правила между транспортными средствами или сохранять их копию.

В верхней части окна «Качество вождения» найдите инструменты экспорта и импорта.

![Шаблоны правил](images/drex_shablony_pravil_screen_4.png)

**Экспорт **![](images/drex_shablony_pravil_custom_21.png) — сохраняет текущие правила в файл JSON

Для этого:

1\. Нажмите кнопку экспорта

2\. Сохраните файл на компьютер

В файл JSON сохраняются все параметры правил.

**Импорт **![](images/drex_shablony_pravil_custom_22.png) — загружает  ранее сохранённый файл JSON

Для этого:

1\. Нажмите кнопку импорта

2\. Выберите файл

3\. Настройки автоматически загрузятся в таблицу

<table><tbody><tr><td><span></span></td><td><div>Импортированные правила заменяют текущий набор правил в таблице. При необходимости сохраните существующие настройки с помощью экспорта перед импортом нового файла.</div></td></tr></tbody></table>
