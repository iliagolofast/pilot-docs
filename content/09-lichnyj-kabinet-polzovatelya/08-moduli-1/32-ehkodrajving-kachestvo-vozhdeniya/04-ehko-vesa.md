ЭКО-веса (коэффициенты важности) определяют, насколько сильно различные типы нарушений влияют на итоговую оценку качества вождения.

![](images/drex_ehko_vesa_custom.png)

Когда система регистрирует событие качества вождения, она начисляет штрафные баллы. При расчёте итоговой оценки эти баллы учитываются с использованием ЭКО-весов.

Чем выше ЭКО-вес, тем сильнее нарушения этого типа влияют на итоговую оценку качества вождения.

<table><tbody><tr><td><span></span></td><td><div>Изменение ЭКО-весов не влияет на регистрацию событий и количество начисленных штрафных баллов. Меняется только их влияние на итоговую оценку в отчётах Eco Driving.</div></td></tr></tbody></table>

Настройки ЭКО-весов применяются ко всей учётной записи и используются при формировании отчётов Eco Driving.

![](images/drex_ehko_vesa_custom.png)

Для каждого показателя отображаются:

-   Числовой коэффициент — значение, которое используется системой при расчёте штрафных баллов
    
-   Ползунок — позволяет изменить важность соответствующего типа нарушения
    
-   Процент — показывает вклад данного типа нарушений в итоговую оценку
    

Общая сумма всех весов должна составлять 100%.

### Пример

Если увеличить ЭКО-вес для Speeding, превышение скорости будет сильнее влиять на итоговую оценку качества вождения, чем остальные типы нарушений. При этом сами события и начисленные штрафные баллы не изменятся.

## Как настроить ЭКО-веса

1\. Откройте окно «ЭКО-веса для вождения» ![](images/drex_ehko_vesa_custom_2.png)

![ЭКО-веса](images/drex_ehko_vesa_screen.png)

2\. Измените значения с помощью ползунков

![](images/drex_ehko_vesa_custom_3.png)

3\. Убедитесь, что сумма всех ЭКО-весов составляет 100%

4\. Нажмите «Сохранить», чтобы применить текущие значения ЭКО-весов. Они будут сохранены как рабочие настройки, которые система будет использовать при расчёте качества вождения

Чаще всего изменяют веса Harsh Brake и Harsh Accel, если необходимо усилить или уменьшить влияние резких манёвров на итоговую оценку качества вождения.

В нижней части окна эко-весов доступны дополнительные команды:

-   Update Defaults (Сохранить значения по умолчанию) — сохраняет текущие значения как значения по умолчанию
    
-   Load Defaults (Загрузить значения по умолчанию) — загружает ранее сохранённые значения по умолчанию
    
-   Reset Defaults (Восстановить стандартные значения по умолчанию) — возвращает стандартные настройки системы:
    

 — Speeding — 58.3%

 — Excess Idle — 10.4%

 — Harsh Brake — 6.9%

 — Harsh Accel — 13.9%

 — Harsh Corner — 10.4%
