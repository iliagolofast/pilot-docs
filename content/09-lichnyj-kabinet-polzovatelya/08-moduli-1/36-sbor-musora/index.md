**Назначение модуля**

-   В контейнеры устанавливаются датчики, сигнализирующие на платформу PILOT о наполненности контейнера до уровня датчика.
    
-    Датчик устанавливается на высоте около 80% от полного бака, для того чтобы еще осталось  время для приезда мусоросборщика.
    
-   Оператор компании по вывозу мусора видит на платформе PILOT в режиме реального времени информацию о том, что заполняемость нескольких  мусорных контейнеров приближается к верхней отметке и формирует задачу на построение оптимального маршрута, чтобы собрать раньше эти переполняющиеся контейнеры.
    
-   Водитель мусоровоза получает задание в приложение о необходимости забрать определенные контейнеры и оптимальный маршрут к ним.
    
-   Оператор видит выполнение задания онлайн в режиме реального времени.
    

В случае наступления экстренной ситуации, например пожара в мусорном контейнере, оператор также получает уведомление на платформе PILOT (а также через смс, пуш или email в зависимости от удобного ему способа) об инциденте и необходимости реагирования.

Более того, на платформе PILOT можно заранее настроить сценарий реагирования на экстренные ситуации

(пожар в мусорном баке, авария с мусоровозом, выезд автомобиля с маршрута следования) и тогда любой оператор сервисной компании по вывозу мусора будет знать что ему делать при наступлении той или иной ситуации.

-   Данные  модуль  не имеет  отдельной иконки  и его работа состоит из двух подключенных  модулей .
    
     Модуль логистика и Модуль ПТМ.
    
-   Модуль  работает и с  одним из этих  Модулей, но рекомендовано использовать  два выше перечисленных  модуля одновременно.
    
-   Настройка  модуля   отображается  в контекстном  меню  только с типом мусорный контейнер.

**Создать  задание для ПТМ.**

Для того, что бы создать задание, необходимо выбрать  **Сreate a task in PTM**.

Создавать  задания  по сбору мусора    необходимо  только из **контекстного меню  объекта мусорного бака.**

При  подключенном  модуле   Логистика  будет доступно  название  Клиента.

По умолчанию  устанавливается текущее время,  которое можно  изменять к примеру будущим  периодом.

Указанное  плановое  время, будет учтено при выполнении задания.

![](images/drex_sbor_musora_custom_3.png)

Если требуется  выбрать  большее  количество баков  на  одну  машину, следует выбрать   первый  и последний контейнер   и зажать **shift.**

![](images/drex_sbor_musora_custom_4.png)

Далее данные о выполнение  задания по  сбору мусора,  можно отследить в  модуле  ПТМ.

Модуль ПТМ  в  данном  случае предусмотрен  для  просмотра, а не создания  заданий.

![](images/drex_sbor_musora_custom_5.png)

**Создать  задание  для  Логистики**

 Для  создания  заданий необходимо выбрать второе  меню  **Create a task in Logistic**.

![](images/drex_sbor_musora_custom_6.png)

Важно учесть, что модуль Логистики берет учет настроек с графика работы  объекта и  учет  настроек работы  склада.

Настройка планового времени сборки мусора.

![](images/drex_sbor_musora_custom_7.png)

Для  объектов  так же  следует   заполнять  параметры для Логистики.

![](images/drex_sbor_musora_custom_8.png)

Задание создавать  в Логистике не предусмотрено, задание по сбору мусора  создается  только  из  контекстного меню, как  показано выше.

Созданные задания можно  найти через  фильтр дат.
