Модуль подключает администратор системы или обслуживающий партнёр.

Для поиска штрафов PILOT использует интеграцию с сервисом ELPAS. Сервис проверяет начисления по реквизитам организации, данным транспортных средств и водительским удостоверениям.

### 1\. Включите модуль

Включите модуль «Штрафы»:

-   для партнёра
    
-   для субпартнёра
    
-   для договора
    

![Как подключить модуль](images/drex_kak_podklyuchit_modul_screen.png)

Модуль должен быть включён на всех уровнях. Если он отключён хотя бы на одном из них, система не сможет получать сведения о штрафах.

### 2\. Добавьте конфигурацию ELPAS

1\. Перейдите в Настройки договора → Конфиги

2\. Нажмите «Добавить»

3\. В поле «Ключ» укажите fine\_api

4\. В поле «Значение» укажите elpas

5\. Нажмите «Сохранить»

**![](images/drex_kak_podklyuchit_modul_custom.png)**

Конфигурация  должна быть включена для партнёра, субпартнёра и аккаунта. Только после этого система сможет получать сведения о штрафах.

### 3\. Настройте тариф

Модуль является платным, поэтому для его работы требуется настроить тариф.

1\. Перейдите в настройки договора во вкладку «Сервисы»

2\. Нажмите «Добавить»

3\. В списке сервисов выберите «Модуль штрафов»

4\. Выберите тариф для модуля

5\. Нажмите «Сохранить»

![](images/drex_kak_podklyuchit_modul_custom_2.png)

<table><tbody><tr><td><span></span></td><td><div>Если вы не знаете, какой тариф необходимо использовать, обратитесь в техническую поддержку.</div></td></tr></tbody></table>

### 4\. Заполните реквизиты организации

В карточке договора укажите:

-   ИНН
    
-   КПП.
    

Сервис ELPAS выполняет поиск по сочетанию ИНН и КПП, поэтому необходимо заполнить оба поля.

![Как подключить модуль](images/drex_kak_podklyuchit_modul_screen_2.png)

### 5\. Заполните данные транспортных средств

Для каждого транспортного средства необходимо указать номер СТС.

Для этого:

1\. Откройте в личном кабинете карточку объекта

2\. Перейдите на вкладку «Инфо»

3\. Укажите серию и номер свидетельства о регистрации транспортного средства

**![Как подключить модуль](images/drex_kak_podklyuchit_modul_screen_3.png)**

4\. Сохраните изменения

Повторите эти действия для каждого транспортного средства.

Перепишите серию и номер точно так, как они указаны в свидетельстве. Даже одна неверная цифра может помешать найти штраф и связать его с нужным объектом.

![Как подключить модуль](images/drex_kak_podklyuchit_modul_screen_4.png)

### 6\. Заполните данные водителей

Откройте карточку каждого водителя и укажите номер водительского удостоверения.

**![Как подключить модуль](images/drex_kak_podklyuchit_modul_screen_5.png)**

Без номера водительского удостоверения сервис ELPAS не сможет проверить штрафы, выписанные на данного водителя.

Для поиска штрафов используются четыре идентификатора:

ИНН — определяет организацию, на которую могут быть выписаны штрафы

КПП — уточняет данные организации и используется вместе с ИНН

СТС — помогает найти штрафы по конкретному транспортному средству

ВУ — помогает найти штрафы по водительскому удостоверению

## Когда появляются штрафы

После завершения настройки дождитесь следующего обновления данных.

Каждую ночь один раз в сутки система автоматически обращается к сервису ELPAS, получает информацию о новых штрафах и обновляет список.

Во время каждого обновления загружаются сведения о штрафах за последние 30 дней.

Если сервис обнаружит новые штрафы, они автоматически появятся в личном кабинете после завершения обновления.
