Модули — это отдельные компоненты системы PILOT, каждый из которых отвечает за определённые функции.

Благодаря модульной организации вы можете:

— настраивать систему под конкретные задачи вашей компании

— оплачивать только те функции, которые вам действительно нужны

— добавлять новые модули в зависимости от ваших потребностей

### Как подключаются модули

Подключение модулей  выполняет администратор договора в [Панели администратора](../../panel-administratora/dogovor/moduli-2.html). Для некоторых модулей есть свои настройки, которые нужно правильно активировать.

### Отчёты по модулям

При включении модуля у вас появляются дополнительные отчёты, которые помогают анализировать работу.

Ознакомиться с ними можно в разделе [«Отчёты»](../otchyety-1/index.html).
