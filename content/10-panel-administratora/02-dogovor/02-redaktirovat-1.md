 **Основные настройки**

-   **Название -** название договора.
    
-   **Email -** адрес электронной почты договора (будет использован при автоматическом заведении нового пользователя).
    
-   **Телефон -** номер телефона договора.
    
-   **Баланс** - текущий баланс.
    
-   **Депозит -** оплата, которая может быть произведена клиентом в качестве аванса за предоставленные услуги.
    
-   **ИИН**\- индивидуальный идентификационный номер.
    
-   **КПП -** регистрационный код.
    
-   **Партнер -** партнер, с которым будет привязан договор (выберите из списка).
    
-   **Валюта**\- выбор списка валют.
    
-   **Тариф -** тарифный план для договора (выберите из списка).
    
-   **Тип организации -** Тип организации, заключаемой договор (выберите из списка).
    
-   **Тип счета-** выберите из выпадающего списка\*.
    
           **Постоплата -** оплата производится после предоставления услуги. При ограниченном балансе клиент
    
           будет получать уведомления по электронной почте о сумме платежа.
    
           **Предоплата -** оплата**,** произведенная до предоставления услуги. Если баланс отрицательный,
    
           контракт блокируется.
    
           **Поcтоплата (лайт) -** при выборе типа счета, добавляется поле «Лимит  блокировки» в котором
    
          устанавливается сумма платежа, когда срабатывает автоматическая блокировка счета.
    
-    **Код 1С -** код для синхронизации с программой 1С.
    
-   **Активный —** флажок для создания контракта в активном состоянии.
    
-   **Складской  аккаунт** - эта учетная запись, в которой хранятся заблокированные объекты без абонентской платы.
    

Складской аккаунт имеет такие же права как и обычный аккаунт. Такой аккаунт можно использовать для объектов которые занесены в базу в тестовом режиме и пока не введены в эксплуатацию на платной основе.

Перенести объекты, может только администратор через панель администратора.

-   **Пароли  пользователей** - создание пароля сложного  или простого. Отображение пароля  в  настройка пользователя.
    
    Показать  пароли  пользователя **-** это действие, которое позволяет просмотреть пароли в личной карточке пользователя. Пароли пользователей могут  быть скрыты или  оставаться доступными.
    
-   **Мастер-пароль -**  возможность отправлять команды на устройства, используя мастер- пароль

**Тарифы**

Данная  вкладка предназначена для прайсов на видеоустройства.

**Сервисы**

Платные сервисы позволяют администраторам  предоставлять  модули на платной основе.

Для того, чтобы модуль был платным, необходимо его активировать  в настройках,  а  затем  выбрать во вкладке Сервисы +.
