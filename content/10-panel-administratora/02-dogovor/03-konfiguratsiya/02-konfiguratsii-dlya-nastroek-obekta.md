Настройки, которые отражаются в [карточке объекта](../../../lichnyj-kabinet-polzovatelya/obekty-1/kartochka-obekta/index.html#Настройки_карточка_объекта), задаются с помощью специальных конфигураций.

![](images/drex_konfiguratsii_dlya_nastroek_obekta____custom.png)

<table><tbody><tr><td><span></span></td><td><div>Настройки, которые заданы с помощью конфигурации, автоматически применяются ко всем объектам в договоре.</div></td></tr></tbody></table>

### Как добавить конфигурации для настроек объекта:

-   # В панели администратора перейдите в раздел «Договоры»
    
-   Выберите договор
    
-   Кликните правой кнопкой мыши на выбранный договор — откроется контекстное меню
    

![](images/drex_konfiguratsii_dlya_nastroek_obekta____custom_2.png)

4\. Выберите в меню «Редактировать»

5\. В открывшемся окне настроек договора выберите вкладку «Конфигурация».

![](images/drex_konfiguratsii_dlya_nastroek_obekta____custom_3.png)

6\. Чтобы добавить новую конфигурацию, нажмите кнопку «Добавить».

7\. В раскрывающемся списке выберите нужную конфигурацию для настроек объекта и укажите значение для неё.

![](images/drex_konfiguratsii_dlya_nastroek_obekta____custom_4.png)
