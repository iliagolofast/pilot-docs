Конфигурация — это набор параметров и настроек системы, которые настраивают работу системы под конкретные задачи. Каждая конфигурация состоит из ключа — уникального идентификатора, и значения, которое может быть числом, текстом или более сложной структурой данных.

### Как добавить конфигурацию к договору:

-   # В панели администратора перейдите в раздел «Договоры»
    
-   Выберите договор
    
-   Кликните правой кнопкой мыши на выбранный договор — откроется контекстное меню
    

![](images/drex_konfiguratsiya_custom.png)

4\. Выберите в меню «Редактировать»

5\. В открывшемся окне настроек договора выберите вкладку «Конфигурация»

# ![Конфигурация](images/drex_konfiguratsiya_screen.png)

# 6\. Чтобы добавить новую конфигурацию, нажмите кнопку «Добавить».

# 7\. В раскрывающемся списке выберите нужную конфигурацию и укажите значение для неё. 

# ![Конфигурация](images/drex_konfiguratsiya_screen_2.png)

8\. Сохраните изменения

Воспользуйтесь иконками, чтобы изменить конфигурацию ![](images/drex_konfiguratsiya_custom_2.png)или удалить ![](images/drex_konfiguratsiya_custom_3.png).

Используйте кнопку «Экспорт» для сохранения настроек текущего договора в файл формата JSON. Чтобы применить ранее сохранённые настройки к другому договору, используйте кнопку «Импорт» и выберите сохранённый JSON-файл.
