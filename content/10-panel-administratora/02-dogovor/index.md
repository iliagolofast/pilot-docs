Договор это и есть учетная запись, которая предназначена, для работы в пользовательском  интерфейсе.

Процесс создания учетной записи обычно включает ввод личных данных, название договора, выбор  типа организации,  типа счета, тариф и другие параметры.

![](images/drex_dogovor_custom.png)

**Окно Договоры содержит настройки:**

• [Кнопка добавить договор +.](redaktirovat-1.html)

• **Кнопка экспорта договоров** - кнопка для скачивания договоров в  excel формате.

• **Фильтры поиска** - это инструмент, которые позволяет пользователям выполнять поиск по заданным критериям.

-   **Основное рабочее окно состоит из**: уникальный номер id договора, название, тип организации, тип счета, дата создания  договора, количество объектов и другие поля).
    

Для удобства работы с договорами в системе, предусмотрено отображать или скрывать колонки в шапке настроек.

-   Отметить договора
    
-   Применить загрузку.

-   Отчеты можно скрыть отобразить  обычным способом через Лист Отчетов.
