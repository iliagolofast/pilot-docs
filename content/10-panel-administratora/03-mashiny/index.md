Вкладка используется для мониторинга существующих  транспортных средств.

-   **Agent ID -**  идентификатор объекта мониторинга.
    
-   **Название —** имя объекта мониторинга в системе.
    
-   **Папка -** папка объекта мониторинга в системе.
    
-   **Объем данны**х -объем данных.
    
-   **Дата создания -** дата создания объекта мониторинга.
    
-   **Тип -** тип устанавливаемого блока.
    
-   **Тариф -** тарифный план и цена в месяц.
    
-   **Партнерский тариф  -** тарифный план для партнера.
    
-   **Unique -** единица IMEI.
    
-   **Msisdn -** номер SIM-карты на устройстве.
    
-   **Договор -** номер договора в системе, к которому относится объект мониторинга.
    
-   **Владелец -** наименование договора, к которому принадлежит объект мониторинга.
    
-   **Партнер -** партнер, которому принадлежит объект мониторинга.
    
-   **Сам -** блокировка объекта мониторингом пользователем.
    
-   **Администратор -** блокировка объекта мониторинга администратором.
    
-   **Последнее обновление -** дата последнего объекта точки мониторинга.
    
-   **На связи -** текущее состояние объекта мониторинга.
