Конфигурация — это набор параметров и настроек системы, которые настраивают работу системы под конкретные задачи. Каждая конфигурация состоит из ключа — уникального идентификатора, и значения, которое может быть числом, текстом или более сложной структурой данных.

### Как добавить конфигурацию к партнёру:

-   # В панели администратора перейдите в раздел «Партнёры»

В списке отображаются все конфигурации, которые вы можете добавить в системе.

![](images/drex_kak_dobavit_konfiguratsiyu_k_partnyeru_custom_5.png)

## Конфигурации партнёра

В системе предусмотрен список доступных конфигураций, которые можно задать для партнёра.

Каждая конфигурация состоит из:

-   Название — имя настройки
    
-   Ключ (значение) — техническое имя параметра, которое используется системой
    

Если партнёру требуется особая логика работы (например, подключение SMS-провайдера, изменение отображения баланса, интеграция с Helpdesk, Twilio, Here Maps и т.д.), соответствующая конфигурация добавляется с нужным значением.

Пример:

-   Для отображения баланса в днях вместо денег используется ключ balance\_in\_days = 1
    
-   Для подключения Telegram-бота указывается адрес бота, например: @PilotGpsBot
    
-   Для подключения SMTP или SMS-провайдера указываются параметры авторизации в виде объекта (логин, пароль, ключ API и т.п.)
