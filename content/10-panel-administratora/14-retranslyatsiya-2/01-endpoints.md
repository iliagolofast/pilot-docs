## Что такое endpoint

Endpoint — это направление передачи данных во внешнюю систему. В нём настраиваются параметры подключения: адрес сервера, порт, протокол передачи данных и параметры авторизации.

После создания endpoint к нему можно подключить один или несколько объектов.

## Список endpoints

Чтобы открыть список endpoint, перейдите в раздел «Ретрансляция» → «Endpoints».

![](images/drex_endpoints_custom.png)

В этой вкладке отображаются все доступные направления передачи данных и их текущее состояние.

**![](images/drex_endpoints_custom_2.png)**

Здесь вы можете:

— создавать новые endpoints

— изменять настройки существующих endpoints

— подключать объекты

— настраивать автоматическое подключение новых объектов

— просматривать статистику передачи данных

— включать, отключать и удалять endpoints

### Верхняя панель

На верхней панели доступны следующие действия:

1\. Добавить — создание нового endpoint

2\. Statistics — выбор периода для отображения статистики

3\. Искать — поиск endpoint в таблице

4\. Очистить фильтры — сброс всех фильтров

![Endpoints](images/drex_endpoints_screen.png)

### Выбор периода отображения статистики

![](images/drex_endpoints_custom_3.png)

Параметр Statistics влияет на отображение мини-графиков в колонках:

-   Err — ошибки
    
-   Отправка (Send) — отправка данных
    
-   Ack — подтверждённые пакеты
    

![Endpoints](images/drex_endpoints_screen_2.png)

Мини-графики помогают быстро оценить состояние ретрансляции за выбранный период.

На графике отображаются:

— динамика показателя

— общее количество событий за выбранный период

При наведении курсора отображается информация по выбранной точке графика.

Доступны следующие периоды:

![](images/drex_endpoints_custom_3.png)

-   12 hours — последние 12 часов
    
-   Day — последние сутки
    
-   Week — последняя неделя
    
-   2 weeks — последние две недели
    
-   Month — последний месяц

### Как создать endpoint

1\. Нажмите на верхней панели «Добавить»

## ![Endpoints](images/drex_endpoints_screen_4.png)

2\. Заполните параметры подключения

![](images/drex_endpoints_custom_14.png)

Основные параметры

Название — название endpoint

Хост — адрес внешнего сервера, на который будут отправляться данные

Порт — порт подключения внешней системы

Формат — протокол или формат передачи данных

Путь — дополнительный путь или URL-маршрут, если он требуется используемым протоколом

Uspw — данные авторизации для подключения к внешней системе

Time zone — часовой пояс, который будет использоваться по умолчанию для объектов данного endpoint

Speed Limit — максимальная скорость, которая будет передаваться во внешнюю систему

Галочка «Включено» — включение или отключение endpoint

Testing — позволяет создать тестовый endpoint. Параметр доступен только администраторам

Json config — дополнительные настройки подключения в формате JSON

Комментарий — произвольный комментарий для пользователей системы

Mapping fields — настройки сопоставления полей для специальных форматов передачи данных

Расписание — расписание, в течение которого разрешена передача данных через данный endpoint

3\. Нажмите «Сохранить»

После сохранения endpoint станет доступен для подключения объектов.

### Как редактировать endpoint

1\. Нажмите кнопку «Редактировать»  ![](images/drex_endpoints_custom_9.png) в колонке действий или дважды щёлкните по строке endpoint

## ![Endpoints](images/drex_endpoints_screen_3.png)

2\. Измените необходимые параметры

![](images/drex_endpoints_custom_15.png)

3\. Нажмите «Сохранить»

Изменения автоматически применяются ко всем объектам, которые используют этот endpoint.

Если система обнаружит endpoint с такими же параметрами, она предложит объединить их. Перед подтверждением внимательно проверьте настройки.

Если объединение не подтвердить, изменения не будут сохранены.

![](images/drex_endpoints_custom_16.png)

### Как включить или отключить endpoint

Чтобы временно остановить или возобновить передачу данных:

1\. Нажмите кнопку включения ![](images/drex_endpoints_custom_8.png) или отключения  ![](images/drex_endpoints_custom_7.png)  в колонке действий

![Endpoints](images/drex_endpoints_screen_5.png)

Если endpoint отключён, все объекты, подключённые к нему, перестают передавать данные во внешнюю систему.

### Как удалить endpoint

1\. Нажмите кнопку удаления ![](images/drex_endpoints_custom_13.png) в колонке действий

2\. Подтвердите удаление

Перед удалением система покажет количество объектов, которые используют этот endpoint.

После удаления передача данных через endpoint будет полностью остановлена.

## Объекты endpoint

Чтобы посмотреть объекты, подключённые к endpoint:

1\. Найдите нужный endpoint

2\. Нажмите кнопку «Машины/Объекты»  ![](images/drex_endpoints_custom_12.png) в колонке действий

Откроется список объектов, которые передают данные через выбранный endpoint.

![](images/drex_endpoints_custom_17.png)

Из этого окна можно:

— подключать новые объекты

— изменять параметры ретрансляции отдельных объектов

— временно отключать передачу данных

— удалять объекты из endpoint

### Колонки списка объектов

![](images/drex_endpoints_custom_17.png)

Agent ID — идентификатор объекта

Машина — название объекта мониторинга

IMEI — уникальный идентификатор устройства

Договор — договор объекта

External ID — идентификатор объекта во внешней системе

On/off — включена или выключена ретрансляция объекта

Err — мини-график ошибок по объекту

Отправка (Send) — мини-график попыток отправки по объекту

Ack — мини-график принятых пакетов по объекту

Действия с объектами:

![](images/drex_endpoints_custom_7.png) и ![](images/drex_endpoints_custom_8.png)  — включить или выключить объект в этом endpoint

![](images/drex_endpoints_custom_18.png) — удалить объект из этого endpoint

### Как добавить объекты

1\. Нажмите в окне «Объекты/Машины» кнопку «Добавить»

![Endpoints](images/drex_endpoints_screen_6.png)

2\. Выберите один или несколько объектов

![](images/drex_endpoints_custom_19.png)

3\. При необходимости измените External ID. По умолчанию в качестве External ID используется IMEI устройства

4\. Нажмите «Добавить», чтобы подключить выбранные объекты к endpoint

Если список объектов большой, воспользуйтесь поиском сверху в поле «Искать» —  введите название или номер объекта.

### Как редактировать объект

1\. Дважды щёлкните по объекту в списке

![](images/drex_endpoints_custom_17.png)

2\. Внесите изменения в форму редактирования объекта

![](images/drex_endpoints_custom_20.png)

В форме можно изменить объектные параметры ретрансляции:

-   Endpoint — направление передачи данных, через которое объект отправляет информацию во внешнюю систему
    
-   External ID — идентификатор объекта во внешней системе
    
-   Чекбокс «Включено» — включает или отключает передачу данных только для выбранного объекта
    
-   Ограничение скорости — максимальная скорость, которая будет передаваться во внешнюю систему для этого объекта
    
-   Временная зона — часовой пояс, используемый для передачи данных этого объекта
    
-   Uspw — данные авторизации для данного объекта
    
-   Json config — дополнительные настройки ретрансляции в формате JSON
    
-   Расписание — расписание передачи данных для объекта.
    

Параметры Host, Port, Format и Path в этой форме изменить нельзя. Они наследуются от endpoint.

Если необходимо изменить подключение к внешней системе, откройте настройки endpoint или выберите другой endpoint.

3\. Сохраните настройки

## Автоматическое подключение объектов к endpoint

Функция Auto add  позволяет автоматически подключать новые объекты к endpoint.

Эту функцию используют, если все объекты определённого договора должны автоматически передавать данные в одну внешнюю систему. После настройки правила новые объекты будут подключаться автоматически без дополнительных действий пользователя.

### Как настроить Auto add

1\. Нажмите кнопку Auto add  ![](images/drex_endpoints_custom_10.png)в колонке действий

## ![Endpoints](images/drex_endpoints_screen_7.png)

2\. Откроется окно, для включения автоматического добавления объектов список договоров. Нажмите «Добавить»

![](images/drex_endpoints_custom_21.png)

3\. Выберите один или несколько договоров

![](images/drex_endpoints_custom_22.png)

4\. Нажмите «Добавить»

После сохранения все новые объекты выбранных договоров будут автоматически подключаться к данному endpoint.
