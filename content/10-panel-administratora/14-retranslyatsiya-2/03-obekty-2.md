Во вкладке «Объекты» отображаются все ретрансляции объектов, доступные текущему пользователю.

## Список объектов

Чтобы открыть список объектов, перейдите в раздел «Ретрансляция» → «Объекты».

![](images/drex_obekty_2_custom.png)

Здесь вы можете:

— найти нужный объект

— посмотреть, через какой endpoint передаются данные

— включить или отключить ретрансляцию объекта

— открыть настройки ретрансляции

— просмотреть статистику передачи данных по объекту

![](images/drex_obekty_2_custom_2.png)

### Верхняя панель

На верхней панели доступны следующие действия:

-   Конфиги — настройки конфигураций ретрансляции
    
-   Экспорт — выгрузка списка объектов
    
-   Statistics — выбор периода отображения мини-графиков
    
-   Искать — поиск по таблице
    
-   Очистить фильтры — очистка фильтров
    

![](images/drex_obekty_2_custom_2.png)

### Колонки таблицы

-   Actions — доступные действия с ретрансляцией объекта.
    
-   ID — идентификатор записи ретрансляции.
    
-   Agent id — идентификатор объекта.
    
-   Хост —  IP-адрес или доменное имя внешнего сервера.
    
-   Порт — порт внешнего сервера
    
-   Формат — используемый протокол передачи данных.
    
-   Статистика / Err — мини-график ошибок
    
-   Статистика / Отправка (Send) — мини-график попыток отправки за выбранный период
    
-   Статистика / Ack — мини-график принятых пакетов за выбранный период
    
-   Last id — идентификатор последнего обработанного пакета.
    
-   Uspw — данные авторизации
    
-   Временная зона — временная зона ретрансляции объекта
    
-    ![](images/drex_obekty_2_custom_3.png) ![](images/drex_obekty_2_custom_4.png) — состояние ретрансляции объекта (включена или отключена).
    

### Действия с объектом

В колонке Actions доступны следующие действия:

![Объекты](images/drex_obekty_2_screen.png)

![](images/drex_obekty_2_custom_5.png) ![](images/drex_obekty_2_custom_6.png)   — включить или отключить ретрансляцию объекта

![](images/drex_obekty_2_custom_7.png) Редактировать — открыть настройки ретрансляции объекта Также форму редактирования можно открыть двойным щелчком по строке объекта.

В форме редактирования можно изменить параметры, относящиеся только к выбранному объекту:

![](images/drex_obekty_2_custom_8.png)

Если необходимо изменить адрес сервера, порт, протокол передачи данных или путь подключения, откройте настройки соответствующего endpoint во вкладке [Endpoints](endpoints.html).

## Работа с ретрансляциями из раздела «Машины»

Управлять ретрансляциями можно не только через вкладку «Объекты» в разделе «Ретрансляция», но и напрямую из списка объектов в разделе «Машины».

Для этого:

1\. Перейдите в раздел «Машины»

![](images/drex_obekty_2_custom_9.png)

2\. Выберите одну или несколько машин

3\. Нажмите правой кнопкой мыши

4\. В контекстном меню выберите пункт «Ретрансляции»

![](images/drex_obekty_2_custom_10.png)

### Ретрансляции одной машины

Если выбрана одна машина, откроется окно ретрансляций выбранного объекта.

![](images/drex_obekty_2_custom_11.png)

Окно состоит из двух секций:

**Конфигурация — с**одержит список настроенных ретрансляций объекта.

Здесь можно:

— добавить новую ретрансляцию

— изменить существующую

— удалить ретрансляцию

— включить или отключить передачу данных

**Resend requests** — содержит запросы на повторную передачу исторических данных за выбранный период.

### Ретрансляции нескольких машин

Если выбрано несколько машин, пункт меню отображается как «Ретрансляция (N)», где N — количество выбранных объектов.

![](images/drex_obekty_2_custom_12.png)

После открытия окна можно создать одинаковую ретрансляцию сразу для нескольких машин.

![](images/drex_obekty_2_custom_13.png)

В этом случае система создаст отдельную запись ретрансляции для каждого выбранного объекта с использованием одного выбранного endpoint.

### Как добавить ретрансляцию

1\. В разделе «Машины» выберите один или несколько объектов

2\. Откройте контекстное меню правой кнопкой мыши

3\. Выберите пункт «Ретрансляции»

![](images/drex_obekty_2_custom_10.png)

4\. В секции «Конфигурация» нажмите кнопку ![](images/drex_obekty_2_custom_14.png)

![](images/drex_obekty_2_custom_11.png)

Откроется форма создания ретрансляции.

![](images/drex_obekty_2_custom_15.png)

Заполните необходимые параметры:

-   Endpoint — направление передачи данных
    
-   External ID — идентификатор объекта во внешней системе
    
-   Ограничение скорости — ограничение скорости передачи
    
-   Временная зона — часовой пояс
    
-   Uspw — данные авторизации
    
-   Галочка «Включено»— включение или отключение ретрансляции
    
-   Json config — дополнительные параметры в формате JSON
    
-   Расписание  — расписание передачи данных
    

Поля хост, порт, формат, путь определяются настройками endpoint и в этой форме не редактируются. Для изменения этих параметров необходимо изменить настройки соответствующего [endpoint](endpoints.html).

После сохранения объект начнёт передавать данные через выбранный endpoint.

### Resend requests

Секция Resend requests предназначена для повторной отправки ранее сохранённых данных за указанный период.

![Объекты](images/drex_obekty_2_screen_2.png)

Эта функция используется, если данные по какой-либо причине не были переданы во внешнюю систему или требуется повторная выгрузка исторической информации.

Как создать запрос:

1\. В секции Resend requests нажмите кнопку ![](images/drex_obekty_2_custom_14.png)

2\. Укажите дату начала периода

3\. Укажите дату окончания периода

![](images/drex_obekty_2_custom_16.png)

4\. Нажмите «Добавить»

После создания запрос появится в таблице.

![](images/drex_obekty_2_custom_17.png)

### Колонки таблицы Resend requests

-   Время начала — начало периода повторной передачи
    
-   Время остановки  — окончание периода повторной передачи
    
-   Create at — дата и время создания запроса
    
-   Update at — дата и время последнего изменения запроса
    
-   Status — текущее состояние запроса:
    
-   New — запрос создан и ожидает обработки
    
-   In Process — выполняется повторная отправка данных
    
-   Complete — обработка завершена
    

После завершения запроса данные за указанный период будут повторно переданы через выбранную ретрансляцию.
