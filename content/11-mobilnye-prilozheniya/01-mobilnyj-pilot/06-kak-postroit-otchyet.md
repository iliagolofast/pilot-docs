В разделе «Отчёты» вы можете сформировать отчёт по выбранным объектам и параметрам.

![](images/drex_kak_postroit_otchyet__custom.png)

-   Выберите объект
    

В поле «Объекты» выберите один или несколько объектов, для которых нужно сформировать отчёт.

![](images/drex_kak_postroit_otchyet__custom_2.png)

2.Выберите тип отчёта

Укажите, какой отчёт вы хотите получить, например:

— по пробегу

— по времени в движении и на стоянке

— по расходу топлива

— по датчикам

![](images/drex_kak_postroit_otchyet__custom_3.png)

Доступные типы отчётов зависят от [настроек](../../lichnyj-kabinet-polzovatelya/otchyety-1/kak-nastroit-dostup-k-otchyetam-1.html) в вашем аккаунте.

3\. Задайте временной диапазон

Выберите начальную и конечную дату для отчёта. При необходимости укажите точное время (часы и минуты).

Отчёт будет построен только за этот период.

4\. Настройте разбивку отчёта

В поле «Разбивать» выберите, как разделить отчёт на интервалы:

-   По суткам — данные будут разбиты по дням
    
-   По неделям — суммарные показатели по неделям
    
-   Не разбивать — отчёт за весь период в одном блоке
    
    ![](images/drex_kak_postroit_otchyet__custom_4.png)
    

5\. Выберите группировку

Определите, как сгруппировать строки отчёта:

-   По датам — для анализа изменений по времени (каждый день или неделя отдельной строкой)
    
-   По объектам — для сравнения разных объектов (каждый объект в отдельной строке)
    

![](images/drex_kak_postroit_otchyet__custom_5.png)

6\. Укажите группы датчиков

Выберите одну или несколько групп датчиков, по которым нужен отчёт.

![](images/drex_kak_postroit_otchyet__custom_6.png)

7\. Скачайте отчёт

После настройки всех параметров нажмите «Скачать отчёт». Приложение создаст отчёт, который вы сможете открыть.

![](images/drex_kak_postroit_otchyet__custom_7.png)

### Дополнительные параметры

Некоторые отчёты могут включать дополнительные настройки. Например, в отчёте по парковкам можно указать минимальное и максимальное время парковки (в секундах).
