Мобильное приложение PILOT — это приложение для мониторинга транспорта и управления объектами прямо с вашего смартфона. В нём доступны все основные функции системы мониторинга PILOT.

![](images/drex_mobilnyj_pilot_custom.png)

С помощью приложения вы можете:

— отслеживать местоположение объектов на карте в реальном времени

— просматривать историю перемещений и статистику по транспортным средствам

— строить отчёты за выбранный период

— просматривать уведомления по событиям

— контролировать параметры работы устройств
