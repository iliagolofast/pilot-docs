Чтобы самостоятельно создать телеграм-бота, вам понадобится официальный сервис @BotFather — это главный бот Telegram, через которого создаются и настраиваются все остальные боты.

1\. Перейдите по ссылке: [https://t.me/BotFather](https://t.me/BotFather)

2\. Нажмите Start, чтобы открыть меню

               ![](images/drex_kak_sozdat_svoj_telegram_bot_custom.png)

3\. Введите команду: /newbot

              ![](images/drex_kak_sozdat_svoj_telegram_bot_custom_2.png)

4\. Придумайте имя для бота

BotFather попросит вас указать название бота — это отображаемое имя, которое видят люди.

5\. Придумайте username для бота —  его адрес в Telegram

Здесь есть важное правило — username должен заканчиваться на \_bot. Например, mycompany\_bot, skyelectronics\_helper\_bot

               ![Как создать свой Telegram-бот](images/drex_kak_sozdat_svoj_telegram_bot_screen.png)

6\. Получите токен

После того как BotFather создаст бота, появится сообщение с поздравлением. Сразу под ним вы увидите:

-   Token to access the HTTP API — токен бота
    

<table><tbody><tr><td><div><img alt="3. " src="images/drex_kak_sozdat_svoj_telegram_bot_control_3.png" data-full-src="drex_kak_sozdat_svoj_telegram_bot_control_3.png" data-full-width="506" data-full-height="95"></div></td></tr><tr><td><div><a href="#top"></a></div></td></tr></tbody></table>

-   Username — имя пользователя вашего бота
    

7\. Передайте токен и username вашего бота  в службу технической поддержки для подключения бота к PILOT

<table><tbody><tr><td><span></span></td><td><div>Договор в системе должен быть активным, иначе бот не сможет отправлять или получать данные.</div></td></tr></tbody></table>
