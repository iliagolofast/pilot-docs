Во вкладке «Активные» отображаются задания, которые вы уже приняли и выполняете в данный момент. Здесь можно отслеживать прогресс выполнения, работать с маршрутными точками и завершать задания.

![](images/drex_aktivnye_zadaniya__custom.png)

Каждое задание представлено в виде карточки, содержащей основную информацию:

— название и номер задания

— прогресс выполнения — количество пройденных точек из общего числа

— плановое время начала и завершения

— индикатор прогресса, который показывает, какая часть маршрута уже выполнена

## Сортировка заданий

Если в списке много заданий, вы можете изменить порядок их отображения.

Для этого:

1\. Откройте вкладку «Активные»

2\. Нажмите значок настройки списка в правом верхнем углу

![Активные задания ](images/drex_aktivnye_zadaniya__screen.png)

3\. В окне «Настройка списка» выберите вариант сортировки:

![](images/drex_aktivnye_zadaniya__custom_2.png)

-   Сначала новые — сначала отображаются более новые задания
    
-   Сначала старые — сначала отображаются более ранние задания
    
    4\. Нажмите «Применить»
    

Список будет автоматически обновлён в соответствии с выбранной сортировкой.

## Просмотр задания

Чтобы открыть задание, нажмите на его карточку.

![](images/drex_aktivnye_zadaniya__custom_3.png)

В карточке задания отображаются:

— плановое время начала и завершения

— тип задания

— дополнительная информация (контактные данные, сведения о грузе и другие данные)

— маршрут со списком точек посещения

Если задание было принято, нажмите кнопку «Начать задание», чтобы приступить к его выполнению.

![Активные задания ](images/drex_aktivnye_zadaniya__screen_2.png)

### Работа с маршрутными точками

После начала выполнения задания на экране отображается блок «Следующая точка» — адрес, который необходимо посетить следующим.

Для выбранной точки доступны следующие действия:

-   Маршрут — построить маршрут в установленном на устройстве навигационном приложении
    
-   Прибыл — отметить прибытие на точку
    

После нажатия кнопки «Прибыл» точка становится активной.

![](images/drex_aktivnye_zadaniya__custom_4.png)

 Для неё становятся доступны дополнительные действия:

![](images/drex_aktivnye_zadaniya__custom_5.png)

— добавить комментарий

— завершить точку

— открыть меню «Другие действия»

Комментарий можно использовать для фиксации дополнительной информации о выполнении работ, доставке или других событиях.

**Другие действия**

Для текущей точки доступны дополнительные операции:

![Активные задания ](images/drex_aktivnye_zadaniya__screen_3.png)![](images/drex_aktivnye_zadaniya__custom_6.png)

-   Копировать адрес — скопировать адрес в буфер обмена
    
-   Показать на карте — открыть расположение точки на карте
    
-   Отложить точку — временно перенести выполнение точки
    

Функция отложенной точки может быть полезна в следующих случаях:

— получатель временно отсутствует

— выполнение точки невозможно по внешним причинам

— необходимо сначала посетить другую точку маршрута

После откладывания точка получает статус «Отложено», а приложение предлагает перейти к следующей точке маршрута. К отложенной точке можно вернуться позже.

![](images/drex_aktivnye_zadaniya__custom_7.png)

### Прогресс выполнения

Текущий прогресс задания отображается:

— в списке активных заданий

![](images/drex_aktivnye_zadaniya__custom_8.png)

 — в карточке задания в разделе «Прогресс»

![](images/drex_aktivnye_zadaniya__custom_7.png)

### Меню задания

В правом верхнем углу карточки задания находится кнопка меню.

![Активные задания ](images/drex_aktivnye_zadaniya__screen_4.png)

Через неё доступны следующие действия:

![](images/drex_aktivnye_zadaniya__custom_9.png)

-   Завершить задание — завершить выполнение задания
    
-   Показать весь маршрут — открыть карту со всеми точками маршрута
    

![](images/drex_aktivnye_zadaniya__custom_10.png)

Подробнее о работе с картой см. статью [«Карта маршрута»](karta-marshruta.html).

## Завершение задания

После выполнения всех необходимых работ и прохождения маршрутных точек нажмите «Завершить задание».

![Активные задания ](images/drex_aktivnye_zadaniya__screen_5.png)

После завершения задание автоматически переместится во вкладку [«Завершённые»](zavershyennye-zadaniya.html), где будет доступно для просмотра.
