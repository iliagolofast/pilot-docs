---
title: "Как построить отчёт"
source: kak_postroit_otchyet_3.html
---

Во вкладке «Отчёты» вы можете сформировать отчёт по выбранным объектам и параметрам.

![](images/drex_kak_postroit_otchyet_3_custom.png)

1\. Выберите машины

В поле «Машины» выберите один или несколько объектов, по которым нужно получить отчёт.

2\. Выберите тип отчёта

Укажите нужный тип отчёта, например:

— по пробегу

— по времени в движении и на стоянке

— по расходу топлива

— по датчикам

3\. Задайте период

Выберите начальную и конечную дату. При необходимости укажите точное время (часы и минуты) — отчёт будет сформирован только за выбранный период.

4\. Выберите группировку

Определите, как будут сгруппированы данные:

-   По датам — чтобы отследить изменения во времени
    
-   По объектам — чтобы сравнить разные машины
    

5\. Укажите группы датчиков

Выберите одну или несколько групп датчиков, если они нужны для отчёта.

6\. Скачайте отчёт

Нажмите «Скачать отчёт». Файл сформируется автоматически — его можно будет открыть или сохранить.
