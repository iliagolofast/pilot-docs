PILOT Guarda — приложение для безопасности и мониторинга автотранспорта. Оно помогает контролировать состояние автомобиля, управлять доступом к нему и отслеживать его перемещения. Приложение подходит как для личного пользования, так и для работы с автопарком.

![](images/drex_pilot_guarda_custom.png)

С помощью приложения вы можете:

— Контролировать состояние автомобиля

Просматривать текущий статус, заряд, события и другие параметры

— Управлять доступом

Открывать и закрывать автомобиль без использования ключей

— Отслеживать перемещения

Смотреть текущее местоположение и историю поездок

### Способы управления

Доступ к автомобилю возможен:

-   Через GSM (мобильную связь) — на любом расстоянии
    
-   Через Bluetooth — при нахождении рядом с автомобилем
