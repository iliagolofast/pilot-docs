Этот раздел поможет вам подключиться и начать работать с мобильными инструментами системы PILOT:

-   Мобильное приложение PILOT — приложение для мониторинга транспорта и работы с объектами
    

![](images/drex_mobilnye_prilozheniya_custom.png)

• Telegram-бот — помощник, с помощью которого вы можете работать со списком транспорта, получать информацию по объектам и использовать телефон как виртуальный GPS-трекер

![](images/drex_mobilnye_prilozheniya_custom_2.png)

-   Мобильное приложение PTM (PILOT Task Manager) — приложение для водителей и курьеров, где отображаются задания и маршруты
    

![](images/drex_mobilnye_prilozheniya_custom_3.png)

-   PILOT Guarda — это приложение для безопасности и мониторинга автотранспорта. С помощью него вы можете контролировать состояние автомобиля, управлять доступом и отслеживать перемещения
    

![](images/drex_mobilnye_prilozheniya_custom_4.png)

С помощью приложения вы можете:

— контролировать состояние автомобиля

— управлять доступом к автомобилю

— отслеживать перемещения

PILOT Трекер — это приложение, которое превращает ваш смартфон в GPS-трекер. С его помощью можно отслеживать местоположение устройства в реальном времени и отправлять данные на сервер

![](images/drex_mobilnye_prilozheniya_custom_5.png)

В этом разделе мы расскажем, как пользоваться функциями мобильных приложений.
