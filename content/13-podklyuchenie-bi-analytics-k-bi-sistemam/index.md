BI Analytics позволяет подключить данные системы мониторинга к внешним BI-платформам для создания собственных отчётов, графиков, дашбордов и аналитических панелей.

![](images/drex_podklyuchenie_bi_analytics_k_bi_sistemam_custom.png)

С помощью BI Analytics API можно получать данные о транспортных средствах, водителях, поездках, расходе топлива, нарушениях «Экодрайвинга» и других показателях, а затем использовать их в любой BI-системе, поддерживающей работу с REST API.

BI Analytics подходит как для создания простых отчётов, так и для построения корпоративной аналитики с использованием собственных показателей, фильтров и визуализаций.

Полученные данные можно использовать в таких BI-системах, как:

-   Microsoft Power BI
    
-   Tableau
    
-   Qlik Sense
    
-   Apache Superset
    
-   Grafana
    
-   других платформах, поддерживающих REST API
    

## Что необходимо для подключения

Перед подключением убедитесь, что:

— на партнёрском аккаунте [включён модуль аналитики](kak-vklyuchit-dostup-k-bi-analytics.html#Включение_модуля_аналитики_на_партнёрском_аккаунте)

— на договоре пользователя также [включён модуль аналитики](kak-vklyuchit-dostup-k-bi-analytics.html#Включение_модуля_аналитики_на_договоре_пользователя)

— в конфигурации партнёра [установлен параметр bi\_analytics = 1](kak-vklyuchit-dostup-k-bi-analytics.html#Подключение_конфигурации)

— известны [логин и парол](podklyuchenie-k-bi-analytics-api.html#Где_взять_логин_и_пароль)ь партнёрского аккаунта

 — выбран правильный [адрес сервера](podklyuchenie-k-bi-analytics-api.html#Как_выбрать_адрес_сервера)

После выполнения этих настроек можно подключаться к BI Analytics API из любой поддерживаемой BI-платформы.
