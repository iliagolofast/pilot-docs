Чтобы добавить объект в договор, используйте этот API.

## Как получить данные

### Метод

POST

### Адрес запроса

Для получения данных используйте адрес:  https://<server\_address>/backend/api.php?

### Параметры запроса

Чтобы получить нужные данные, добавьте к адресу запроса параметры. Параметры указываются после знака вопроса «?» и разделяются знаком «&».

Обязательные:

-   cmd = vehadd — команда для добавления транспортного средства
    
-   account\_id — номер договора в системе
    
-   vehmodel — модель устройства мониторинга. ID модели берётся из ответа команды vehmodellist
    
-   imei — уникальный номер устройства мониторинга
    
-   type — тип транспортного средства. ID типа транспортного средства берётся из ответа команды vehtypelist. Если требуемый тип отсутствует в списке, можно указать новый ID
    
-   name — государственный номер или название транспортного средства
    
-   msisdn — номер основной SIM-карты устройства
    
-   msisdn2 — номер второй SIM-карты устройства
    
-   mac — MAC-адрес, идентификатор устройства автокондуктора.  Если указан параметра mac система автоматически создаст запись об объекте во вкладке «Автобусы» в панели администратора. 
    
-   node — номер узла, на котором нужно выполнить команду
    

Дополнительные:

-   folder — название папки для добавления транспорта. Если указанной папки нет — будет создана. Если папка не указана, транспорт будет добавлен в общий список — корневую папку
    
-   info — дополнительная информация о транспорте
    
-   summer\_fuel — расход топлива в летний период
    
-   winter\_fuel — расход топлива в зимний период
    
-   fuel\_type — тип используемого топлива . 50-дизель, 80-92-95-98-бензин, 100-газ. Если параметр не указан, система автоматически установит дизель
    
-   lost\_connection\_time — время, после которого фиксируется потеря связи (в секундах)
    
-   time\_zone — часовой пояс транспорта. По умолчанию устанавливается Europe/Moscow
    
-   initial\_motor\_hours — начальные показания моточасов
    
-   driver\_id — идентификатор водителя
    
-   initial\_mileage — начальный пробег транспорта. Если не указан, считается с нуля
    
-   speed\_limit — максимально допустимая скорость. Если не указана, контроль скорости отключён
    
-   minsat — минимальное количество спутников. По умолчанию установлено 4
    
-   maxhdop — максимальный HDOP. По умолчанию установлено 21
    
-   mintime — минимальное время стоянки для разбития треков. По умолчанию установлено 3600 секунд
    
-   maxspeed — максимально возможная скорость. По умолчанию установлено 250
    
-   minspeed — минимальная скорость для детектирования начала движения. По умолчанию установлено10 км/ч
    
-   minparking — минимальное время парковки на маршруте. По умолчанию установлено 300 секунд
    
-   model — марка и модель транспорта
    
-   year — год выпуска транспорта. Если год выпуска не указан, по умолчанию он будет считаться 1900 годом
    
-   vin — идентификационный номер транспорта
    
-   engine\_horse: — мощность двигателя
    
-   organization — название организации-владельца
    
-   column — номер колонки
    
-   subdivision — подразделение
    

### Пример запроса

<table><tbody><tr><td><span></span></td><td><div><span>https://</span>&lt;server_address&gt;<span>/backend/api.php?cmd=vehadd&amp;account_id=4019&amp;type=1&amp;name=testveh&amp;imei=80987898789987&amp;vehmodel=13&amp;msisdn=7903&amp;node=1</span></div></td></tr></tbody></table>

Ответ

<table><tbody><tr><td><span></span></td><td><div><span>{</span></div><div><span>&nbsp;"code": 0,</span></div><div><span>&nbsp;"msg": "OK",</span></div><div><span>&nbsp;"agent_id": "20518",</span></div><div><span>&nbsp;"veh_id": "18994"</span></div><div><span>}</span></div></td></tr></tbody></table>

В ответ на API-запрос возвращается:

-   code — код ответа, который показывает, как запрос был обработан
    
-   msg — сообщение с текстовым описанием результата операции
    
-   agent\_id — идентификатор агента, который обработал запрос
    
-   veh\_id — идентификатор транспортного средства, к которому относится этот ответ
