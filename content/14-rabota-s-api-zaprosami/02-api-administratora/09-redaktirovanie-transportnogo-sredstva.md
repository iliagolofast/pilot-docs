Этот API используется для редактирования данных транспортного средства. Можно изменить информацию о транспорте, включая тип, модель, госномер, VIN, год выпуска, мощность двигателя, начальный пробег и моточасы, а также привязку к папке, водителю или подразделению.

## Как получить данные

### Метод

POST

### Адрес запроса

Для получения данных используйте адрес: https://<server\_address>/backend/api.php?

### Параметры запроса

Обязательные:

-   cmd=vehedit — команда для изменения информации о ТС
    
-   agentid— идентификатор транспорта или imei — уникальный ID устройства
    
-   node — номер узла, на котором нужно выполнить команду
    

Дополнительные:

-   type — тип ТС, ID берется из команды vehtypelist
    
-   veh\_number — отображаемое имя/госномер машины
    
-   veh\_type — пользовательский тип машины (строка)
    
-   folder\_id — папка, в которую помещается объект; если папки нет — папка создается автоматически. По умолчанию — корневая папка
    
-   model — модель транспортного средства
    
-   initial\_motor\_hours — начальные моточасы
    
-   driver\_id — ID водителя
    
-   initial\_mileage — первоначальный пробег (по умолчанию 0)
    
-   year — год выпуска машины (по умолчанию 1900)
    
-   vin — VIN транспортного средства
    
-   engine\_horse — мощность двигателя
    
-   organization — организация
    
-   column — колонна
    
-   subdivision — подразделение
