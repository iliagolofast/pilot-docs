API администратора — это специальный набор команд, который даёт расширенные возможности, недоступные обычным пользователям. Он предназначен для управления системой и выполнения административных задач.

С помощью API администратора вы можете:

-   Создавать, изменять или удалять учётные записи пользователей
    
-   Настраивать права доступа и роли
    
-   Получать информацию о состоянии объектов
    
-   Настраивать параметры системы и модулей
