Этот API получает список всех доступных отчётов в аккаунте с их идентификаторами, названиями и группами, к которым они относятся.

## Как получить данные

### Адрес запроса

Для получения данных используйте адрес: https://<server\_address>/api/api.php?

### Метод запроса

GET или POST

### Параметры запроса

-   cmd=reports\_list — команда для получения списка отчетов
    
-   node — номер узла, на котором выполняется команда
    

### Пример GET-запроса

<table><tbody><tr><td><span></span></td><td><div>https://&lt;server_address&gt;/api/api.php?cmd=reports_list&amp;node=1</div></td></tr></tbody></table>

Ответ

В ответ на API-запрос возвращается:

-   code — код результата (0 — успешная операция)
    
-   data — массив отчётов, где каждый отчёт содержит:
    
-   id — уникальный идентификатор отчёта
    
-   name — название отчёта
    
-   group — группа, к которой относится отчёт
