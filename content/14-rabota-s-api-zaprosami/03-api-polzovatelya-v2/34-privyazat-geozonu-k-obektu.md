Этот API позволяет привязать существующую геозону к транспортному средству, задав параметры контроля, такие как ограничение скорости, время бездействия и оповещения.

## Как получить данные

### Метод

GET

### Адрес запроса

Для выполнения запроса используйте адрес: https://<server\_address>/api/api.php?

### Параметры запроса

-   cmd=geofencelink — команда для привязки геозоны
    
-   zone\_id — идентификатор геозоны (обязательный, если external\_id не задан)
    
-   external\_id — внешний идентификатор геозоны (необязательно, игнорируется, если указан zone\_id)
    
-   agent\_id — идентификатор агента (транспортного средства)
    
-   idle — контроль бездействия в геозоне в минутах (необязательно)
    
-   speedlimit — ограничение скорости в геозоне в км/ч (необязательно)
    
-   alerts — оповещения:
    
-   0 — не отправлять
    
-   1 — бездействие
    
-   2 — пересечение границ
    
-   3 — границы и погранпереходы
    
-   node — номер узла, на котором нужно выполнить команду
