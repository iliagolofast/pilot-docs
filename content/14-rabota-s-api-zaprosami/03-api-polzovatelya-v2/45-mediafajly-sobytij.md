Этот API используется для получения медиафайлов выбранных объектов за указанный период. С его помощью можно получить ссылки на фото и видео, связанные с событиями, в том числе ADAS и DMS.

## Как получить данные

### Метод

GET

### Адрес запроса

Для получения данных используйте адрес: https://<server\_address>/api/api.php?

### Параметры запроса

-   cmd=get\_media — команда для получения медиафайлов
    
-   agent\_id — идентификатор объекта или идентификаторы нескольких объектов, перечисленные через запятую
    
-   start — время начала выборки в формате Unix timestamp
    
-   stop — время окончания выборки в формате Unix timestamp
    

### Пример запроса

<table><tbody><tr><td><span></span></td><td><div>https://&lt;server_address&gt;/api/api.php?cmd=get_media&amp;agent_id=1234,5678&amp;start=1724623200&amp;stop=1724709600</div></td></tr></tbody></table>

В ответ на успешный API-запрос возвращаются сведения о медиафайлах выбранных объектов за указанный период и ссылки для их просмотра. При переходе по ссылке связанное с событием изображение или видео открывается в браузере.
