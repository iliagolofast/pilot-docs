API пользователя даёт доступ к функциям и данным PILOT, которые разрешены для обычного пользователя.

С его помощью вы можете:

— просматривать свои отчёты и статистику по поездкам, объектам и расходам

— получать информацию о своих настройках и персональных данных

— запрашивать данные, связанные только с вашим аккаунтом и вашей деятельностью в системе

Через эти API нельзя получить доступ к данным других пользователей или администраторов. Вы видите и работаете только с информацией своего аккаунта.
