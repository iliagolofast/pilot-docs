Для работы с **API Пользователя v3** используйте Swagger-интерфейс: [https://pilot-swagger.pilot-gps.com/](https://pilot-swagger.pilot-gps.com/)

В данной версии API доступны обновлённые и структурированные методы для работы с системой.

В Swagger вы можете:

— просмотреть список всех доступных методов

— изучить параметры запросов и ответы

— протестировать API прямо в браузере
