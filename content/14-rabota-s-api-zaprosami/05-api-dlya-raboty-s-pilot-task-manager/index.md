PILOT Task Manager ([Диспетчер задач](../../lichnyj-kabinet-polzovatelya/moduli-1/pilot-task-manager/index.html)) — это модуль системы PILOT для управления заданиями.

С помощью API этого модуля вы можете:

— создавать, редактировать и удалять задания

— назначать задания исполнителям

— получать статус выполнения и сроки

 — получать информацию о текущих и завершённых заданиях
