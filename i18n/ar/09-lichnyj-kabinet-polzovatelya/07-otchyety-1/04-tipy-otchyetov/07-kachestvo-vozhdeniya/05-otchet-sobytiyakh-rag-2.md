**يتضمّن التقرير:**

-   # الكائن  -
    
    الكائن المراقَب الذي سُجّلت عليه جودة القيادة؛
    
-   # إجمالي المسافة (كم) -
    
    المسافة التي ارتُكبت خلالها المخالفة؛
    
-   # مدة الرحلة -
    
    المدة التي ارتُكبت خلالها المخالفة؛
    
-   # السرعة القصوى-
    
    أعلى سرعة سُجّلت أثناء الرحلة.
    
-   # منطقة تجاوز السرعة - **مقطع من الطريق حُدّد فيه حد أقصى لسرعة حركة المركبات**;
    
-   # معدل تجاوز السرعة - **حركة المركبة بسرعة تتجاوز الحدود المنصوص عليها في القانون أو في إشارات الطريق**;
    
-   # نطاق مدة تجاوز السرعة -  **مدة  تجاوز  السرعة;**
    
-   # مدة تجاوز السرعة العادية-**الوقت الذي تتحرك فيه المركبة بسرعة تتجاوز حد السرعة المحدد**;
    
-   # إجمالي مدة تجاوز السرعة -**الوقت الذي تتحرك فيه المركبة بسرعة تتجاوز حد السرعة المحدد**;
    
-   # تقييم السرعة -  **قيمة تقييم السرعة;**
    
-   # إجمالي التسارع -  **قيمة  إجمالي التسارع خلال الفترة المحددة;**
    
-   # تقييم التسارع -**قيمة تقييم التسارع;**
    
-   # إجمالي عدد حالات التباطؤ - **قيمة  إجمالي التباطؤ خلال الفترة المحددة;**
    
-   # تقييم التباطؤ  - **قيمة تقييم التباطؤ;**
    
-   # الوقت دون حزام الأمان- **وقت  الرحلة دون  حزام  الأمان  خلال  فترة  التقرير;**
    
-   # تقييم مخالفات حزام الأمان - **قيمة مخالفات عدم ربط  حزام  الأمان;**
    
-   # دوران المحرك الزائد دون حمل **\-يدور محرك السيارة دون حمل مدة أطول مما يلزم;**
    
-   # مدة التوقف - **قيمة مدة التوقف;**
    
-   # النتيجة الإجمالية - **التقييم النهائي للرحلة.**
