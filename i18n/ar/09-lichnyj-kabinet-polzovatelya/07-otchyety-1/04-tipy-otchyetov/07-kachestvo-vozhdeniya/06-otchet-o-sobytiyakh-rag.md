# **تقرير أحداث RAG هو تقرير يتضمّن نظرة عامة على أهم الأحداث** **المتعلقة بجودة القيادة.**

**يتضمّن التقرير:**

-   # السائق -
    
    السائق المعيَّن لهذا الكائن؛
    
-   # إجمالي المسافة (كم) -
    
    المسافة التي ارتُكبت خلالها المخالفة؛
    
-   # إجمالي التسارع -  **القيمة الإجمالية لتقييم التسارع;**
    
-   # تقييم التسارع - **قيمة تقييم التسارع;**
    
-   # إجمالي عدد حالات التباطؤ- **القيمة الإجمالية لتقييم التباطؤ;**
    
-   # تقييم التباطؤ -**قيمة تقييم التباطؤ;**
    
-   # السرعة القصوى (كم/س) -
    
    أعلى سرعة سُجّلت أثناء الرحلة.
    
-   # إجمالي وقت تجاوز السرعة -
    
    إجمالي الوقت الذي جرى خلاله تجاوز السرعة؛
    
-   # تقييم السرعة - **قيمة تقييم السرعة;**
    
-   # الوقت دون حزام الأمان - **الوقت الذي قاد فيه السائق دون حزام الأمان;**
    
-   # تقييم مخالفات حزام الأمان - **قيمة تقييم القيادة دون حزام الأمان;**
    
-   # النتيجة -
    
    تُحسب على أساس مجموع حالات الانعطاف والكبح والتسارع الحادة.
