#  **سجل المركبات هو سجل للمركبات.**

 **يحتوي التقرير على :**

-   # رقم المركبة -   **كائن في نظام المراقبة؛**
    
-   # الماركة - **ماركة الكائن؛**
    
-   # الطراز - **طراز الكائن؛**
    
-   # سنة الصنع - **سنة صنع الكائن؛**
    
-   # نوع المركبة  -   **نوع المركبة في النظام ؛**
    
-   # رقم المحرك - **رقم المحرك؛**
    
-   # سعة المحرك - **سعة المحرك**؛
    
-   # VIN - **رمز VIN للهيكل؛**
    
-   # ترخيص المركبة **\- بيانات الترخيص؛**
    
-   # تاريخ إصدار وثيقة المركبة - **تاريخ إصدار وثيقة (جواز) المركبة.**
