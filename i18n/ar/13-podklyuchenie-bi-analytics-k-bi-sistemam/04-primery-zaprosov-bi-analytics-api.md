يقدّم هذا المقال أمثلة على الطلبات للعمل مع BI Analytics API. يمكنك استخدامها أساسًا للربط مع Power BI أو أي نظام BI آخر يدعم العمل مع REST API.

بحسب المهمة، يمكنك اختيار أحد خيارين:

-   المثال الأساسي — مناسب للتعرّف على API واختبار الاتصال وإنشاء تكاملات بسيطة. يعرض الحد الأدنى من الخطوات اللازمة للمصادقة وتنفيذ الطلب والحصول على البيانات.
    
-   المثال المتقدم — موصى به للتكاملات العاملة والتحديث المنتظم للبيانات. إضافةً إلى المصادقة والحصول على البيانات، يتضمن معالجة أخطاء API والتحقق من بنية الاستجابة ومعالجة النتائج الفارغة والتحويل التلقائي للبيانات إلى صيغة مناسبة لـ Power BI.
