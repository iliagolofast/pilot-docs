لإضافة كائن إلى عقد استخدم هذا API.

## كيفية الحصول على البيانات

### الطريقة

POST

### عنوان الطلب

للحصول على البيانات استخدم العنوان:  https://<server\_address>/backend/api.php?

### معاملات الطلب

للحصول على البيانات المطلوبة أضف معاملات إلى عنوان الطلب. تُكتب المعاملات بعد علامة الاستفهام «?» وتُفصل بينها بالعلامة «&».

المعاملات الإلزامية:

-   cmd = vehadd — أمر إضافة مركبة
    
-   account\_id — رقم العقد في النظام
    
-   vehmodel — طراز جهاز المراقبة. يؤخذ معرّف ID الطراز من استجابة الأمر vehmodellist
    
-   imei — الرقم الفريد لجهاز المراقبة
    
-   type — نوع المركبة. يؤخذ معرّف ID نوع المركبة من استجابة الأمر vehtypelist. إذا لم يكن النوع المطلوب موجودًا في القائمة، يمكنك تحديد معرّف ID جديد
    
-   name — رقم لوحة المركبة أو اسمها
    
-   msisdn — رقم شريحة SIM الأساسية في الجهاز
    
-   msisdn2 — رقم شريحة SIM الثانية في الجهاز
    
-   mac — عنوان MAC، معرّف جهاز مراقب الحافلة. إذا حُدّد المعامل mac فسيُنشئ النظام تلقائيًا سجلًّا للكائن في تبويب «الحافلات» في لوحة المسؤول.
    
-   node — رقم العقدة التي يجب تنفيذ الأمر عليها
    

المعاملات الاختيارية:

-   folder — اسم المجلد الذي تُضاف إليه المركبة. إذا لم يكن المجلد المحدد موجودًا فسيتم إنشاؤه. وإذا لم يُحدَّد مجلد فستُضاف المركبة إلى القائمة العامة — المجلد الجذر
    
-   info — معلومات إضافية عن المركبة
    
-   summer\_fuel — استهلاك الوقود في الفترة الصيفية
    
-   winter\_fuel — استهلاك الوقود في الفترة الشتوية
    
-   fuel\_type — نوع الوقود المستخدم. 50 — ديزل، 80-92-95-98 — بنزين، 100 — غاز. إذا لم يُحدَّد المعامل فسيضبط النظام الديزل تلقائيًا
    
-   lost\_connection\_time — المدة التي يُسجَّل بعدها فقدان الاتصال (بالثواني)
    
-   time\_zone — المنطقة الزمنية للمركبة. الافتراضي Europe/Moscow
    
-   initial\_motor\_hours — القراءة الأولية لساعات تشغيل المحرك
    
-   driver\_id — معرّف السائق
    
-   initial\_mileage — المسافة المقطوعة الأولية للمركبة. إذا لم تُحدَّد فيبدأ الحساب من الصفر
    
-   speed\_limit — السرعة القصوى المسموح بها. إذا لم تُحدَّد فإن مراقبة السرعة معطّلة
    
-   minsat — الحد الأدنى لعدد الأقمار الصناعية. الافتراضي 4
    
-   maxhdop — أقصى قيمة لـ HDOP. الافتراضي 21
    
-   mintime — الحد الأدنى لمدة التوقف لتقسيم المسارات. الافتراضي 3600 ثانية
    
-   maxspeed — أقصى سرعة ممكنة. الافتراضي 250
    
-   minspeed — الحد الأدنى للسرعة لاكتشاف بدء الحركة. الافتراضي 10 كم/س
    
-   minparking — الحد الأدنى لمدة التوقف على المسار. الافتراضي 300 ثانية
    
-   model — ماركة المركبة وطرازها
    
-   year — سنة صنع المركبة. إذا لم تُحدَّد سنة الصنع فستُعتبر افتراضيًا 1900
    
-   vin — رقم تعريف المركبة
    
-   engine\_horse: — قدرة المحرك
    
-   organization — اسم المؤسسة المالكة
    
-   column — رقم الرتل
    
-   subdivision — القسم

تعيد استجابة طلب API ما يلي:

-   code — رمز الاستجابة الذي يوضح كيف تمت معالجة الطلب
    
-   msg — رسالة بوصف نصي لنتيجة العملية
    
-   agent\_id — معرّف الوكيل الذي عالج الطلب
    
-   veh\_id — معرّف المركبة التي تتعلق بها هذه الاستجابة
