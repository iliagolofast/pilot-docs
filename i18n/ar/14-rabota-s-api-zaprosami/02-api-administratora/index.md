---
title: "API المسؤول"
---

API المسؤول هو مجموعة خاصة من الأوامر توفر إمكانات موسعة غير متاحة للمستخدمين العاديين. وهو مخصص لإدارة النظام وتنفيذ المهام الإدارية.

باستخدام API المسؤول يمكنك:

-   إنشاء حسابات المستخدمين أو تعديلها أو حذفها
    
-   ضبط صلاحيات الوصول والأدوار
    
-   الحصول على معلومات عن حالة الكائنات
    
-   ضبط معاملات النظام والوحدات البرمجية
