---
title: "عمليات التزود بالوقود بالبطاقات الوقودية"
---

استخدم هذا API للحصول على بيانات عمليات تزود المركبة بالوقود عن الفترة المحددة. وبه يمكنك:

— عرض المعاملات بالبطاقات الوقودية (عمليات شراء الوقود ورصيد البطاقة ونوع الوقود ومحطة الوقود)

— الحصول على بيانات التزود بالوقود وتصريفه بحسب حساس المركبة (الإحداثيات وكمية الوقود وموقع الحدث)

— مراقبة أرصدة الوقود في بداية اليوم ونهايته لكل مركبة

## كيفية الحصول على البيانات

### الطريقة

GET

عنوان الطلب

للحصول على البيانات استخدم العنوان: https://<server\_address>/api/api.php?

### معاملات الطلب

-   cmd=fuel — أمر الحصول على بيانات التزود بالوقود
    
-   imei — معرّف المركبة في النظام
    
-   start — وقت بداية العينة (Unix timestamp)
    
-   stop — وقت نهاية العينة (Unix timestamp)
    
-   addr — عنوان محطات الوقود
    
-   node — رقم العقدة التي يجب تنفيذ الأمر عليها
