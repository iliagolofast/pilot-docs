---
title: "الملفات الوسائطية للأحداث"
---

تُستخدم واجهة API هذه للحصول على الملفات الوسائطية للكائنات المختارة خلال فترة محددة. وباستخدامها يمكنك الحصول على روابط الصور ومقاطع الفيديو المرتبطة بالأحداث، بما في ذلك أحداث ADAS وDMS.

## كيفية الحصول على البيانات

### الطريقة

GET

### عنوان الطلب

للحصول على البيانات، استخدم العنوان: https://<server\_address>/api/api.php?

### معلمات الطلب

-   cmd=get\_media — أمر الحصول على الملفات الوسائطية
    
-   agent\_id — معرّف كائن أو معرّفات عدة كائنات مفصولة بفواصل
    
-   start — وقت بداية العينة بصيغة Unix timestamp
    
-   stop — وقت نهاية العينة بصيغة Unix timestamp
    

### مثال على طلب

<table><tbody><tr><td><span></span></td><td><div>https://&lt;server_address&gt;/api/api.php?cmd=get_media&amp;agent_id=1234,5678&amp;start=1724623200&amp;stop=1724709600</div></td></tr></tbody></table>

عند نجاح طلب API تُعاد معلومات عن الملفات الوسائطية للكائنات المختارة خلال الفترة المحددة، مع روابط لعرضها. وعند الانتقال عبر الرابط تُفتح الصورة أو الفيديو المرتبط بالحدث في المتصفح.
