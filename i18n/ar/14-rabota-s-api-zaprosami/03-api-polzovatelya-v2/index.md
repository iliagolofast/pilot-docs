---
title: "واجهة API للمستخدم v2"
---

تتيح واجهة API للمستخدم الوصول إلى وظائف PILOT وبياناته المسموح بها للمستخدم العادي.

وباستخدامها يمكنك:

— عرض تقاريرك وإحصاءاتك حول الرحلات والكائنات والمصروفات

— الحصول على معلومات عن إعداداتك وبياناتك الشخصية

— طلب البيانات المرتبطة بحسابك ونشاطك في النظام فقط

لا يمكن عبر واجهات API هذه الوصول إلى بيانات المستخدمين الآخرين أو المسؤولين. فأنت ترى وتعمل مع معلومات حسابك فقط.
