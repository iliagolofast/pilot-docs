---
title: "واجهة API للعمل مع PILOT Task Manager"
---

PILOT Task Manager ([مدير المهام](../../lichnyj-kabinet-polzovatelya/moduli-1/pilot-task-manager/index.html)) وحدة في نظام PILOT لإدارة المهام.

باستخدام واجهة API لهذه الوحدة يمكنك:

— إنشاء المهام وتعديلها وحذفها

— إسناد المهام إلى المنفّذين

— الحصول على حالة التنفيذ والمواعيد النهائية

 — الحصول على معلومات عن المهام الحالية والمكتملة
