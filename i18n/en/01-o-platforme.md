PILOT is a monitoring system that collects data from sensors and shows the location and status of objects.

The system runs on protected servers, and only authorized users can access the information.

PILOT works with different types of sensors and video cameras and combines them into a single network. The system analyzes the data it receives, helps you make decisions, and warns you about possible problems.

With PILOT you can:

— track objects in real time

— view reports at different levels of detail

— study the history of events

— view photos and videos from objects

## Access levels

The system has two access levels: the user account and the admin panel.

The [user account](lichnyj-kabinet-polzovatelya/index.html) is the basic interface without administrator rights. In this account, users can track vehicles, equipment, people, and other objects.

![](images/drex_o_platforme_custom.png)

The [admin panel](panel-administratora/index.html) provides full access to the system settings. Administrators manage accounts, users, system objects, and the overall structure of the system, configuring the platform for the company's tasks.

![](images/drex_o_platforme_custom_2.png)

## Modular architecture

PILOT is built on a modular architecture. [Modules](lichnyj-kabinet-polzovatelya/moduli-1/index.html) are separate components of the system, each responsible for specific functions.

Thanks to the modular design, you can:

— configure the system for your company's specific tasks

— pay only for the features you actually need

— add new modules as your needs change

You can enable the modules you need through the contract administrator or by contacting technical support.
