To work in the monitoring system you need an internet connection with a speed of at least 1 Mbit/s. The connection must be stable and able to support several users working at the same time.

### Supported mobile operating systems

• Android: version 10 and later

-   iOS: version 14 and later

### If the platform is slow

-   Close unnecessary tabs and programs
    
-   Turn off unnecessary map elements: objects, geofences, tracks
    
-   Use clusters to group markers on a map with many objects for better readability
    
-   Enable only the elements you need
