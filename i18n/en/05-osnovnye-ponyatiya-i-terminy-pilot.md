---
title: "Basic PILOT concepts and terms"
---

Before you start working in PILOT, we recommend getting familiar with the basic concepts and terms:

### Authorization

— determining a user's access rights to the functions and data of the system after a successful login.

### Administrator

— a user of the admin panel who is responsible for configuring and managing the monitoring system.

### Account

— a person's personal account in the monitoring system. Through the account, the user gets access to their data and the system's features. The account stores the user's personal data, login, password, contact information, and individual interface settings.

### Alerts

— system notifications about important events or deviations from set parameters, sent to the user by e-mail, SMS, or messengers.

### Authentication

— confirming a user's identity at login with a username and password.

### Software version

— the release number of the software, which shows which variant of the program is currently in use. Each new version contains updates, fixes, or new features.

### Geofence

— a virtual bounded area on a geographic map.

### Geocoder

— a system tool that converts GPS coordinates into ordinary addresses.

### Sensor

— a device that collects and transmits data about a specific parameter or state of an object.

### Dashboard

— a control panel that presents the main working information in a clear form. The dashboard shows key indicators, charts, and quick access to important functions.

### Contract

— the main element of the system, which combines all monitored objects, users, and available features for one client or company. The contract specifies which devices the system tracks and who can access them.

### History

— the history of an object's movement or the history of a sensor's operation.

### Object card

— the place where you can edit information about an object and configure its parameters.

### Cache

— a place for temporary data storage.

### Mapping contract

— a type of contract in the system that combines data from several accounts or contracts in one interface. It acts as a “mirror”, reflecting information from other accounts without changing them directly. With it, a user can track information from different user accounts without switching between them. A mapping contract does not contain physical data; it only reflects data from other accounts. For example, a company's security service can create such a contract to track all of the company's vehicles in one place without logging in to each account separately.

### Object menu

— a list of available actions you can perform with the selected object.

### Module

— a separate part of the system with a set of specific functions. Modules connect to the main system and can work independently or together with other modules.

### Object

— a vehicle, equipment, person, animal, or other moving or stationary object that is being monitored.

### Report

— collected information about monitored objects for a selected period of time.

### Data transmission

— the process of collecting and transporting information from devices installed on objects to the central server over mobile networks. Data on location, speed, and other parameters is processed, filtered, and stored in a database for further analysis and use.

### User

— a person who works with the PILOT monitoring system. Each user has a certain level of [access](roli-i-prava-dostupa.html), which depends on their role in the system. Some users can see only basic information, while others have access to system settings.

### Push, push notification

— a notification about an event sent to a phone.

### Events

— changes in a vehicle's parameters, for example speeding, leaving a geofence, start of movement, or fuel drain.

### Tag

— a special label for searching for objects.

### Token

— a unique access code.

### Tracker

— a compact electronic device for tracking the movement of an object. Once switched on, it automatically determines its current location and establishes an internet connection to transmit data. A tracker is configured by connecting it directly to a computer and using special software to set all the device's operating parameters.

### API

— a set of rules and tools for programs to interact with each other. The API is used to exchange data between systems, services, applications, and the PILOT platform.

### AccountID

— a unique identifier of a user's account in the system. The system uses it to identify a specific user at login and during work in the system.

### AgentID

— a unique number of a device or monitored object in the system, for example a GPS tracker on a car.

### Device ID

— the unique number of the device installed on an object.

### SMS tracker setup

— a method of configuring a tracker remotely with SMS commands. A text message with a specific instruction is sent to the number of the SIM card installed in the device. Each SMS changes only one tracker parameter. After executing the command, the device sends a reply message confirming the change.

### Unixtimestamp

— a numeric time format that shows the number of seconds since January 1, 1970.
