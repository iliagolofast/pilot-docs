After signing in, you land on the main page.

Let’s get to know the main interface elements that will help you find your way around the system quickly.

<div class="demo" data-demo="overview"></div>

## 1. Top bar

The top bar holds the main controls:

- The main menu with the key sections of the system for navigation
- Object statuses showing the state of your objects
- User name and balance: your personal details and available funds
- The notifications icon, which opens the list of all notifications
- Contract configuration settings
- AI assistant
- The extra settings menu: interface color theme, language, news, technical support and sign-out

## 2. Workspace

In the workspace you interact with the elements of the section and tab you selected in the navigation menu.

## 3. Map

The map shows where your objects are in real time, with precise GPS coordinates. Here you can monitor how objects move and follow their routes.

The map has extra settings and [tools](../lichnyj-kabinet-polzovatelya/interfejs-lichnogo-kabineta/karta/index.html) for working with it.

For a detailed description of the interface, see [“User account interface”](../lichnyj-kabinet-polzovatelya/interfejs-lichnogo-kabineta/index.html).
