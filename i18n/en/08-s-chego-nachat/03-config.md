---
title: "How to add an object"
---

An object is a vehicle, machine, person, animal or any other moving or stationary item you monitor.

### To add an object

1. Click the “Add object” (+) button above the object list.
2. Fill in the required fields in the object card:
   - **Vehicle number**: the license plate or the object’s name;
   - **Device ID**: the unique ID of the device. You can use the device’s [IMEI](https://en.wikipedia.org/wiki/International_Mobile_Equipment_Identity), which is usually printed on its case;
   - **Device type**: the type of device installed on the object.
3. Click “Save”, and the object appears in the object list in the workspace.

> The GPS device installed on the object must be on the list of [supported hardware](../oborudovanie-2/spisok-podderzhivaemogo-oborudovaniya.html).

To add a different kind of object, choose it in the “Vehicle type” field: animal, special machinery, trailer or another type.

You can fill in the rest of the object’s details later, whenever it suits you. To learn how, see the [“Objects”](../lichnyj-kabinet-polzovatelya/obekty-1/index.html) section.
