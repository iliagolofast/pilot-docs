---
title: "How to add a sensor"
---

A sensor is a device that collects and transmits data about a specific parameter or state of the monitored object.

### To add a sensor

1. Open the object menu: right-click the object in the object list on the “Online” tab.
2. Go to the “Sensors” tab in the object menu.
3. In the window that opens, click the button to add a sensor.
4. Choose the type of sensor to add, for example an ignition sensor.
5. Fill in the required fields: enter a name and choose the device field that carries the values for this sensor. Set thresholds, the update rate and other parameters.
6. Click “Save”. Check that the sensor appears in the list of active sensors and reports data correctly.
