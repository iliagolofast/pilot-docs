The indicators in the top panel help you quickly assess the state of objects: how many of them are moving, parked, or inactive. The number on each indicator shows the number of objects in the corresponding state.

![](images/drex_statusy_obektov_custom.png)

## Which statuses are displayed

By default the panel uses the following indicators:

![](images/drex_statusy_obektov_custom_2.png) All objects: the total number of objects

![](images/drex_statusy_obektov_custom_3.png) Moving: the number of moving objects

![](images/drex_statusy_obektov_custom_4.png) Parked: the number of parked objects

![](images/drex_statusy_obektov_custom_5.png) Idle in zone: the number of objects that are idle in a zone

![](images/drex_statusy_obektov_custom_6.png) Inactive: the number of objects that are not sending current data

## How to view objects with a given status

Click a status indicator and the object list is filtered automatically.

For example, click the “moving” status and only moving objects remain in the list.

![](images/drex_statusy_obektov_custom_7.png)

![](images/drex_statusy_obektov_custom_8.png)

## Inactive objects

When you click the inactive objects indicator, a separate window opens with a list of objects and how long they have been inactive.

In this window you can:

— see which objects are not sending current data

— check how long each object has been inactive

— download the list to Excel for further checking or to pass it to the responsible specialist

![](images/drex_statusy_obektov_custom_9.png)
