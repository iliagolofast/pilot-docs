---
title: "Map"
---

The map is a tool that clearly shows what is happening with objects.

The map displays:

-   Monitored objects
    
-   Their current location
    
-   Movement routes
    
-   Significant geographic points and places
    
-   Geofences
    
-   Additional information about objects, for example status, speed, and direction
    

The map is available when you work with tabs and sections. Most often it takes up most of the screen.

If you want the maximum view of the map, you can hide the work area. To do this, click the screen [divider](../rabochaya-oblast.html#Разделитель_экрана).

![](images/drex_karta_custom.png)

If you want to see only the map and remove all panels, titles, and browser buttons, press F11, and the screen expands to the full size of the monitor.

### Searching for objects on the map

When you select objects in the list, they are displayed on the map automatically.

![Map](images/drex_karta_screen.png)

1 — Selecting an object in the list. To select an object, select the checkbox next to it

2 — The object on the map

### Moving around the map

To move around the map, press the left mouse button and, without releasing it, drag in the direction you need. The map moves with the cursor. If you want to see another area, just drag the mouse.
