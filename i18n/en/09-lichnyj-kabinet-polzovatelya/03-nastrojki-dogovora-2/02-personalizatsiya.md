## General display settings

Display settings help you personalize the interface. You can choose how information is displayed on the map and in other interface elements.

### Available display settings:

-   Show geofence names: display text labels with geofence names on the map
    
-   Show global tags: display labels shared by all users for sorting object information
    
-   Show tag labels: display additional labels on objects
    
-   Show global service templates: display ready-made maintenance schemes available to all users
    
-   Show object tree tooltips: enable pop-up tooltips when you hover over objects in the list
    

• Show LRS radius: display the coordinate accuracy radius when the device determines its location by LBS (cell towers)

-   Group markers on the map: combine closely located objects into groups, making the map more readable
    
-   Marker animation: add movement to icons on the map
    
-   Full-screen map: display the map at full screen
    

How to set up:

-   In the “Personalization” tab, find the “Settings” section
    

2\. In this section you will see a list of options

3\. To enable an option, select its checkbox

![](images/drex_personalizatsiya__custom_2.png)

4\. After selecting the options you need, click the “Save settings” button in the “Personalization” tab

## Tooltips

In the “Tooltip elements” section you can choose what additional information is displayed when you hover the cursor over an object icon on the map.

![](images/drex_personalizatsiya__custom_3.png)

How to set up:

-   In the “Personalization” tab, find the “Tooltip elements” and “Additional tooltip elements” sections
    
-   Select the elements you need by selecting the checkbox in the required field
    

![](images/drex_personalizatsiya__custom_4.png)

3\. Click “Save settings” in the “Personalization” tab

## Measurement system

### Here you can configure:

1\. The measurement system:

-   Metric: kilograms, liters, kilometers
    
-   Imperial: pounds, gallons, miles
    
    2\. The number format
    
    3\. The first day of the week for the calendar and reports
    

![](images/drex_personalizatsiya__custom_5.png)

### How to set up:

-   In the “Personalization” tab, find the “Measurement system” section
    
-   Select the options you need from the drop-down lists
    
-   Click “Save settings” in the “Personalization” tab
    

Now all data will be displayed in a format convenient for you, and the calendar and reports will match your work schedule.
