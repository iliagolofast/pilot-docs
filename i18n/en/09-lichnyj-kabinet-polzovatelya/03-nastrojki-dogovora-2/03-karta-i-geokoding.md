## Address display

You can configure which address components are visible in the system, for example in reports or in pop-up windows on the map.

![](images/drex_karta_i_geokoding_custom_2.png)

-   Hide the address if there is a geofence: the system shows only the geofence name if the address is inside it
    
-   Reverse address order: display the address in reverse order, from the country to the house number
    

### How to set up:

-   In the “Map and geocoding” tab, find the “Address display settings” section
    

2\. In this section you will see a list of address components

3\. To enable a component, select its checkbox

4\. After selecting the settings you need, click the “Save settings” button in the “Map and geocoding” tab

## Displaying events on the map

In the “Display of events on the map” section you can configure which event types are displayed in the object's history.

![](images/drex_karta_i_geokoding_custom_3.png)

When you go to the “Events” tab in the “History” section, you will see the list of events you selected for display.

![](images/drex_karta_i_geokoding_custom_4.png)

The places where these events occurred are also marked on the map with markers. For example, you see “Parking” events in the list and select a record you are interested in. When you click the event record, the exact place where it was recorded appears on the map.

![](images/drex_karta_i_geokoding_custom_5.png)

### How to set up:

-   In the “Map and geocoding” tab, find the “Display of events on the map” section
    
-   Select the event type to display in the object's history by selecting the checkbox in the required field
    
-   Click “Save settings” in the “Map and geocoding” tab
    
    This way, in the “Display of events on the map” section you can select event types and then view them in the list and on the map in the “History” section.
    

## Color indication of speed

Color indication of speed shows speed changes in different colors. On the track in the movement history, you will see how fast the object was moving at each moment.

![](images/drex_karta_i_geokoding_custom_6.png)

### How to set up:

-   In the “Map and geocoding” tab, go to the “Speed in color” section
    
    2\. Select the checkbox next to the “Speed in color” function to display the track in the history in color.
    

![](images/drex_karta_i_geokoding_custom_7.png)

Color indication of speed is already set up in the system by default:

Gray: the vehicle is stationary

Green: slow driving, up to 60 km/h

Yellow: medium speed, up to 90 km/h

Red: fast driving, over 90 km/h

### If you want to change the color of the standard indication:

-   Double-click the color field you want to change
    
    2\. Select the color you need from the list
    

![](images/drex_karta_i_geokoding_custom_8.png)

3\. Click the “Update” button

4\. Click the “Save” button in the “Speed in color” section

### If you want to add a new color field:

-   Click the button for adding a new color ![](images/drex_karta_i_geokoding_custom_9.png)
    

2\. In the new field, select a color and set the speed

3\. Click the “Save” button

![](images/drex_karta_i_geokoding_custom_10.png)

To delete a color field, click the icon ![](images/drex_karta_i_geokoding_custom_11.png) next to it.
