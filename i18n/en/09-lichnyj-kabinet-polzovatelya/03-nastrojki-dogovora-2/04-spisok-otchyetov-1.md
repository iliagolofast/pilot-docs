In the “Report list” tab you choose which report types you want to use. The types selected here will be available when you create a new report.

![](images/drex_spisok_otchyetov_1_custom.png)

### How to set up:

-   Go to the “Report list” tab
    
-   Select the report types by selecting the checkbox next to the report name you need
    

![](images/drex_spisok_otchyetov_1_custom_2.png)

3\. Click the “Save settings” button

<table><tbody><tr><td><span></span></td><td><div>The selected report types are displayed the same way in both the web version and the mobile app.</div></td></tr></tbody></table>
