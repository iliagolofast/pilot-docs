title: "KML settings"
---

KML/KMZ is a special file that lets you put additional geographic data on the map:

 — points

— lines

— areas

— images

This file works like an additional transparent layer that can be overlaid on the main map. Such a layer helps display the information you need: mark important objects, show boundaries, or plot a route.

The main map stays visible, and the additional information is overlaid on top.

You can upload a KML/KMZ file to PILOT and see the additional geographic data on the map.

### Where to get a KML/KMZ file:

1\. Create one yourself:

-   In Google Earth
    
-   Edit a text document manually
    
    2\. Download ready-made files:
    
-   From specialized sites with geographic data
    
-   From open map databases
    
-   From specialized communities and forums
    

### How to upload a file to PILOT:

-   Go to the “KML settings” tab
    

![](images/drex_nastrojki_kml_custom.png)

2\. In the “KML/KMZ upload” section, select the data source for uploading

“URL”: if the file is on the internet

“File”: if the file is on your computer

3\. Add a link to the file or select the file on your computer

4\. Enter the file name that will be displayed in PILOT

![](images/drex_nastrojki_kml_custom_2.png)

5\. Click the “Save KML/KMZ” button

If you want all users of the contract to see the file, select the “For all” checkbox.

To delete an uploaded KML, click ![](images/drex_nastrojki_kml_custom_3.png) next to it.

After a KML file is uploaded, the “Object layers” tool appears on the map.

### How to display layers on the map:

1\. Find the “Object layers” panel: a list with checkboxes for selection. It is located in the upper right part of the map

![KML settings](images/drex_nastrojki_kml_screen.png)

2\. Expand the list and select the checkboxes next to the layers you need. You can select one or several layers at the same time

3\. The selected layers are displayed on the map, and the main map stays visible.
