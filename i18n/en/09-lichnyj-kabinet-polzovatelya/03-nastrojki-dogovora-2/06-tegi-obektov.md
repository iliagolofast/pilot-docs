title: "Object tags"
---

An object tag is a short label with information that helps you quickly understand what an object is. Think of a tag as a name sticker for each object.

The sticker displays information:

-   A short name
    
-   A color code
    
-   A description
    
    In the tag information you can specify, for example, the type of object, its role, or its state.
    

Tags are needed to:

— quickly find the object you need

— tell one object from another

— track and group objects

— organize objects in the list

### How to add object tags:

-   Go to the “Object tags” tab in the contract settings
    

![](images/drex_tegi_obektov_custom.png)

2\. Click the “Add label” button ![](images/drex_tegi_obektov_custom_2.png)

3.  In the window that opens, fill in the tag information:

-   Come up with a name
    
-   Choose a color
    
-   Write a short description
    
-   Select with checkboxes the objects that will have the label
    

![Object tags](images/drex_tegi_obektov_screen.png)

4\. Click the “Save” button

After you fill in the tag information, a record for it appears in the “Object tags” tab.

![](images/drex_tegi_obektov_custom_4.png)

This is how objects with tags look in the list. When you view the object list, in the “Labels” column you will see color markers that correspond to the objects' tags.

![](images/drex_tegi_obektov_custom_5.png)

You can add several tags to one object to describe it by different criteria.

![Object tags](images/drex_tegi_obektov_screen_2.png)
