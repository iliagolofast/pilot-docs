---
title: "Creating a user"
---

Users can be created and configured by an administrator. When creating an account, enter the login details, and then define which objects, tags, modules, and actions will be available to the employee.

## How to create a user

1\. Open “Contract settings” and go to the “Staff and groups” tab

2\. Click the “Add user” button ![](images/drex_sozdanie_polzovatelya_1_custom.png) in the upper right corner

![Creating a user](images/drex_sozdanie_polzovatelya_1_screen.png)

3\. In the card that opens, fill in the user data on the “Settings” tab

![](images/drex_sozdanie_polzovatelya_1_custom_2.png)

Required fields are outlined in red:

-   Login: the name the user will enter to log in to PILOT
    
-   Password: the password for logging in. Click the edit icon ![](images/drex_sozdanie_polzovatelya_1_custom_3.png) in the field to set the password
    
-   Name: the employee's name or another clear name for the account
    
-   Type: the user's access level. PILOT has two user types:
    
-   Administrator: can add users and objects, work with drivers, and manage the rights of the contract's users
    
-   User: works only with the objects, data, and functions assigned to them. The available capabilities are determined by their rights
    
-   Email: the e-mail address. Click the send icon ![](images/drex_sozdanie_polzovatelya_1_custom_4.png) in the field to send the user an e-mail with a link to log in to PILOT
    
-   Mobile phone: the employee's contact number
    
-   Information: additional details about the user. Fill in this field if necessary
    
    4\. Click “Save”
    

![](images/drex_sozdanie_polzovatelya_1_custom_5.png)

The created account appears in the list in the “Staff and groups” tab.

![](images/drex_sozdanie_polzovatelya_1_custom_6.png)

After creating the user, open their [card](kartochka-polzovatelya/index.html) and configure access on the corresponding tabs. Depending on the connected modules, you can assign here:

— [vehicles](kartochka-polzovatelya/transport-1.html)

— [drivers](kartochka-polzovatelya/voditeli-1.html)

— [object tags](kartochka-polzovatelya/tegi-obekta.html)

— [rights to view and change data](kartochka-polzovatelya/prava.html)

— [access to modules](kartochka-polzovatelya/prava.html)

— [interface parameters](kartochka-polzovatelya/interfejs.html)

— other available functions

The set of tabs depends on the contract configuration and the administrator's rights.

## How to edit a user

1\. Open the “Staff and groups” tab

2\. Find the user in the list

3\. Double-click the user's row

4\. Make changes in their card

5\. Click “Save”

## How to delete a user

Find the user in the “Staff and groups” tab and click the trash icon ![](images/drex_sozdanie_polzovatelya_1_custom_7.png) in their row.

After deletion, the user loses access to PILOT. Before deleting, make sure the account is no longer needed.

![Creating a user](images/drex_sozdanie_polzovatelya_1_screen_2.png)

The account owner and the user you are currently logged in as cannot be deleted in the PILOT interface. This restriction protects the account from losing access.

The account owner is highlighted in green in the list.

![](images/drex_sozdanie_polzovatelya_1_custom_8.png)

If you need to delete the owner, first assign another contract owner in the admin panel. After the owner is changed, deletion becomes available.

If you don't have access to the admin panel, contact the administrator or technical support.
