The “Rights” tab configures the actions the user can perform in PILOT. For example, you can allow them to view reports and edit objects but forbid creating or deleting data.

![](images/drex_prava_custom.png)

Rights are combined into thematic groups. The set depends on the connected modules and the account configuration. Here there may be permissions for:

— working with vehicles

—  creating and editing objects

—  managing sensors and tags

—  viewing and building reports

— working with geofences

—  access to financial data

— changing contract settings

— using additional modules

## Configuring rights

To grant rights to a user:

1\. Open the user's card

2\. Go to the “Rights” tab

3\. Expand the group you need

4\. Select the checkboxes next to the allowed actions

![](images/drex_prava_custom.png)

5\. Click “Save”

The checkbox next to a group enables all the rights nested in it. If the user needs only certain capabilities, expand the group and select them manually.

To find the right you need faster, enter its name in the search field.

![](images/drex_prava_custom_2.png)

Grant only the rights the employee needs for work. Access to objects, drivers, and tags is configured separately in the corresponding tabs of the card.

## Rights templates

A template saves a configured set of rights and helps you quickly assign the same permissions to several users. For example, you can create the templates “Dispatcher”, “Manager”, or “Reports specialist”.

### How to create a template

1\. Open the card of a user with a suitable set of rights

2\. Go to the “Rights” tab

3\. Click the save template icon ![](images/drex_prava_custom_3.png)

![Rights](images/drex_prava_screen.png)

4\. In the “Saving a template” window, enter a clear name

![](images/drex_prava_custom_4.png)

5\. Click “Save”

The template appears in the list of saved templates. To open this list, click the icon ![](images/drex_prava_custom_5.png) in the “Rights” tab.

![Rights](images/drex_prava_screen_2.png)

In the list you can view and delete templates you no longer need.

![](images/drex_prava_custom_6.png)

### How to apply a template

To assign saved rights to another user:

1\. Create a user or open their card

2\. On the “Settings” tab, expand the “Type” field

![](images/drex_prava_custom_7.png)

3\. Select the option marked “(template)”

4\. Fill in the rest of the user's data

5\. Click “Save”

The selected set of rights will be applied to the user.
