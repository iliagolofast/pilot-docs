---
title: "“Situation center” event groups"
---

The “Situation center event groups” tab (Control Room event groups) configures which event groups are available to the user when working with the “Situation center” module.

![](images/drex_gruppy_sobytij__situatsionnogo_tsentra__custom.png)

The event groups themselves are created and configured for the whole contract in “Contract settings”, in the [“Control Room” (“Situation center”)](../../../moduli-1/situatsionnyj-tsentr-2/kak-nastroit-parametry-sobytij.html) tab. In the user's card you can only grant or close access to groups that already exist.

# ![](images/drex_gruppy_sobytij__situatsionnogo_tsentra__custom_2.png)

### To configure access:

1\. Open the user's card

2\. Go to the “Situation center event groups” tab

3\. Select the checkboxes next to the event groups the user should see

![](images/drex_gruppy_sobytij__situatsionnogo_tsentra__custom.png)

4\. Click “Save”

If you clear a checkbox, the corresponding event group stops being displayed for the user.
