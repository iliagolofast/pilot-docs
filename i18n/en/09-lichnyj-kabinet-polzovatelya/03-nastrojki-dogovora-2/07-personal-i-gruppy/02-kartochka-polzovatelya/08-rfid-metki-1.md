title: "RFID tags"
---

The “RFID tags” tab configures the user's access to the contract's RFID tags. The user will be able to see and use only the tags marked in their card.

The tab is displayed in the user's card if the [RFID](../../../moduli-1/rfid-metki-2/index.html) module is connected for the contract.

![](images/drex_rfid_metki_1_custom.png)

The list shows:

-   ID: the RFID tag identifier
    
-   Name: the tag name
    
-   Description: additional information about the tag
    
-   Contract: the contract the tag belongs to
    

## How to assign RFID tags to a user

1\. Open the user's card

2\. Go to the “RFID tags” tab

3\. Find the tags you need using search ![](images/drex_rfid_metki_1_custom_2.png) or a filter ![](images/drex_rfid_metki_1_custom_3.png)

4\. Select the checkboxes next to the tags that should be available to the user

![](images/drex_rfid_metki_1_custom.png)

5\. Click “Save”

To assign all available RFID tags to the user at once, click the checkmark icon ![](images/drex_rfid_metki_1_custom_4.png)in the upper right corner. The checkboxes are selected next to all tags in the list.

![](images/drex_rfid_metki_1_custom_5.png)

To close access to an individual tag, clear the checkbox next to it and save the changes.

If the list of tags has changed, click the refresh icon ![](images/drex_rfid_metki_1_custom_6.png) to load current data.
