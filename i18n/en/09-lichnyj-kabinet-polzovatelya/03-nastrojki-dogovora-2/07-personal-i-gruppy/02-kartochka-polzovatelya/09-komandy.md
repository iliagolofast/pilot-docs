The “Commands” tab is displayed in the user's card if the [“Commands”](../../../moduli-1/komandy-1.html) module is connected for the contract. Here you configure which commands the user can use to control hardware.

Commands are grouped by device type. The list shows the command name and the hardware compatible with it.

![](images/drex_komandy__custom.png)

### To grant access:

1\. Open the user's card

2\. Go to the “Commands” tab

3\. Select the checkboxes next to the commands available to the user

![](images/drex_komandy__custom.png)

4\. Click “Save”

To select all commands, select the checkbox in the list header.

![Commands ](images/drex_komandy__screen.png)

![](images/drex_komandy__custom_2.png)

The edit icon ![](images/drex_komandy__custom_3.png) next to a command opens its settings.

In the editor you can change the command parameters, select objects, set restrictions by geofences and time, and configure other available execution conditions.

![](images/drex_komandy__custom_4.png)
