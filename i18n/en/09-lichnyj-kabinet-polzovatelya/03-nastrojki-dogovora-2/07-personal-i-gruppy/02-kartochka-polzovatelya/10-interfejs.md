The “Interface” tab configures which sections and modules are displayed to the user. If the checkbox is selected, the corresponding element is available in the interface. If you clear the checkbox, the element is hidden.

![](images/drex_interfejs_custom.png)

## Example: hiding the object tree

The **Online Tree** parameter controls the display of the object tree in the “Online” tab.

To hide the object tree:

1\. Open the user's card

2\. Go to the “Interface” tab

3\. Expand the “Main” group

4\. Clear the Online Tree checkbox

![](images/drex_interfejs_custom_2.png)

5\. Click “Save”

6\. Refresh the page in the user's account

**Object tree enabled**

If the **Online Tree** checkbox is selected, a tree with folders and vehicles is displayed on the left side of the work area.

![](images/drex_interfejs_custom_3.png)

**Object tree hidden**

If the checkbox is cleared, the object tree is not displayed. Instead, another available tab opens on the left side of the work area, for example “Counterparties”. The map and the other permitted modules remain available.

![](images/drex_interfejs_custom_4.png)
