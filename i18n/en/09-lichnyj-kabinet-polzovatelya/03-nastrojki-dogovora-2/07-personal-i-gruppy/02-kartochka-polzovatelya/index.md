---
title: "User card"
---

The user card configures the employee's credentials and rights in PILOT. Here you can define which objects, drivers, tags, reports, and modules will be available to them, and which actions they can perform.

![](images/drex_kartochka_polzovatelya_custom.png)

The card may contain the following tabs:

-   [Settings](nastrojki-polzovatelya.html): login, password, contact details, user type, and additional account parameters
    
-   [Climate chambers](klimaticheskie-kamery.html): access to the modes, objects, and data of the “Climate” module
    
-   [Vehicles](transport-1.html): selecting the objects the user can view and use
    
-   [Drivers](voditeli-1.html): selecting the drivers available to the user
    
-   [Object tags](tegi-obekta.html): assigning the tags the user can use to find and filter objects
    
-   [Rights](prava.html): permissions to view, create, change, and delete data, as well as access to individual functions and modules
    
-   [Interface](interfejs.html): configuring the available sections and interface elements
    
-   [“Situation center” event groups](gruppy-sobytij-situatsionnogo-tsentra.html): access to event groups and “Situation center” functions
    

<table><tbody><tr><td><span></span></td><td><div>The set of tabs depends on the connected modules, the contract configuration, and the rights of the user who performs the configuration. Therefore user cards in different accounts may differ.</div></td></tr></tbody></table>
