---
title: "Login history"
---

The authentication history helps you check when and from which device a user logged in to PILOT.

To open the log:

1\. Go to the “Staff and groups” tab

2\. Find the user you need

![](images/drex_istoriya_vkhodov_custom.png)

3\. Click the login history icon in their row ![](images/drex_istoriya_vkhodov_custom_2.png)

4\. In the window that opens, specify the start and end of the period

5\. Click the search icon

![](images/drex_istoriya_vkhodov_custom_3.png)

For each login the following is displayed:

— user ID

— login

— role

— login time

— last activity time

— IP address

— browser

— operating system

To save the log on your computer, click the download icon ![](images/drex_istoriya_vkhodov_custom_4.png). The data is exported in CSV format.

To reload current information, click the refresh icon ![](images/drex_istoriya_vkhodov_custom_5.png).
