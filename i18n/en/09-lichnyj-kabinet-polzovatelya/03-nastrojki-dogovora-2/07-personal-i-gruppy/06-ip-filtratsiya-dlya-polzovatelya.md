---
title: "IP filtering for a user"
---

IP filtering restricts account login by IP address. After you enable it, the user can log in to PILOT only from allowed addresses.

### To set up IP filtering:

1\. In the “Staff and groups” tab, find the user you need

![](images/drex_ip_filtratsiya_dlya_polzovatelya_custom.png)

2\. Click the filter icon ![](images/drex_ip_filtratsiya_dlya_polzovatelya_custom_2.png) next to their name

3\. In the window that opens, select the “Enable filtering” checkbox

![](images/drex_ip_filtratsiya_dlya_polzovatelya_custom_3.png)

4\. Specify the allowed IP addresses, one address per line

![](images/drex_ip_filtratsiya_dlya_polzovatelya_custom_4.png)

5\. Click “Save IP list”

When filtering is enabled, the current IP address is added to the list automatically. If necessary, add other addresses from which the user will log in to PILOT.
