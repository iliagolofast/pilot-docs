---
title: "Blocking and unblocking a user"
---

Blocking temporarily prevents a user from logging in to PILOT but keeps their account and access settings. In the “Status” column, the user's state is indicated by color:

![](images/drex_blokirovka_i_razblokirovka_polzovatelya_custom.png)green icon: the user is active

![](images/drex_blokirovka_i_razblokirovka_polzovatelya_custom_2.png) red icon: the user is blocked

![](images/drex_blokirovka_i_razblokirovka_polzovatelya_custom_3.png)

## How to block a user

1\. In the “Staff and groups” tab, find the user you need

![](images/drex_blokirovka_i_razblokirovka_polzovatelya_custom_4.png)

2\. Click the green icon![](images/drex_blokirovka_i_razblokirovka_polzovatelya_custom.png) in the “Status” column

3\. In the confirmation window, click “Yes”

![](images/drex_blokirovka_i_razblokirovka_polzovatelya_custom_5.png)

The status changes to red ![](images/drex_blokirovka_i_razblokirovka_polzovatelya_custom_2.png). After blocking, the user cannot log in to PILOT

![](images/drex_blokirovka_i_razblokirovka_polzovatelya_custom_3.png)

## How to unblock a user

1\. Find the blocked user in the list

![](images/drex_blokirovka_i_razblokirovka_polzovatelya_custom_3.png)

2\. Click the red icon ![](images/drex_blokirovka_i_razblokirovka_polzovatelya_custom_2.png) in the “Status” column

3\. In the confirmation window, click “Yes”

The status changes to green![](images/drex_blokirovka_i_razblokirovka_polzovatelya_custom.png), and the user can log in to the system again with their previous credentials.

![](images/drex_blokirovka_i_razblokirovka_polzovatelya_custom_4.png)
