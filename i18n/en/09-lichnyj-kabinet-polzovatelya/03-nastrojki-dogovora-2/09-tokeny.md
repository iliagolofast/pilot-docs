title: "Tokens"

A token is a unique access code that lets other users see the location of objects without having access to your account.

Put simply, a token is like a temporary pass. It gives limited access to specific information without revealing your personal data or password.

On the “Tokens” tab you can create two types of tokens:

-   [Monitor token](tokeny.html#Токен_для_просмотра_\(Monitor_token\)) — for viewing the location of selected objects via a public link
    
-   [Access token](tokeny.html#Токен_для_входа_\(Access_token\)) — for signing in to PILOT without entering a password
    

![](images/drex_tokeny_custom.png)

## View token (Monitor token)

A Monitor token gives another person access to a map with the selected objects and their movements. The recipient of the link does not get a login, a password, or full access to the account.

### Rights to manage view tokens

Separate rights are used to manage Monitor tokens:

-   Edit Tokens — allows you to create and edit monitoring tokens and location sharing links.
    
-   Delete Tokens — allows you to delete monitoring tokens.
    

For a regular user to be able to create, edit, or delete a link in the PILOT web version, an administrator or master must grant them the right to edit and delete tokens.

### How to grant rights to a user

-   In “Contract settings”, open the [“Staff and groups”](personal-i-gruppy/index.html) tab
    

2\. Double-click the user in the list to open their card

3\. Go to the [“Rights”](personal-i-gruppy/kartochka-polzovatelya/prava.html) tab

4\. Expand the “Tokens” group

5\. Select the required rights:

-   Edit Tokens — to create and edit tokens
    
-   Delete Tokens — to delete tokens
    

![](images/drex_tokeny_custom_2.png)

6\. Click “Save”

### How to create a view token

-   In the “Monitor tokens” section, click the “Add token” button ![](images/drex_tokeny_custom_3.png)
    
    2\. In the window that opens, fill in the token information:
    

![](images/drex_tokeny_custom_4.png)

-   Specify the validity period — select the date and time when the token starts and stops working
    
-   Select which map to use to display the objects
    
-   Specify whether to display object markers or sensors on the map
    
-   From the list, select the objects to track with this token
    
    3\. Click “Save”
    
    4\. The system creates a unique link or an iframe — an embed code
    
    5\. Copy the link or code and send it to whoever needs access to the information
    

## Access token

This type of token is used to sign in to the system without a password. When you follow the special link, PILOT signs you in as the user, the same way as with a login and password. A token can have a limited validity period or be unlimited.

### How to create an access token

-   In the “Access tokens” section, click the “Add token” button ![](images/drex_tokeny_custom_3.png)
    
-   In the new window, specify the date and time when the token starts and stops being valid. If you do not specify an end, the token works indefinitely. 
    
-   Click “Save”
    

![](images/drex_tokeny_custom_5.png)

To edit a token, click the pencil icon ![](images/drex_tokeny_custom_6.png), and to delete it, click the trash can icon ![](images/drex_tokeny_custom_7.png).

![](images/drex_tokeny_custom_8.png)
