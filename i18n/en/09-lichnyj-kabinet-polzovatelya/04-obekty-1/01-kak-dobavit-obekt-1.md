To create objects, you must have [rights](../nastrojki-dogovora-2/personal-i-gruppy/index.html#права_доступа) to create and edit objects.

In PILOT, you can add an object manually or import it from a WLP file.

## Adding an object manually

-   On the “Online” tab, click the “Add object” button![](images/drex_kak_dobavit_obekt__1_custom.png)
    

![How to add an object ](images/drex_kak_dobavit_obekt__1_screen.png)

2\. In the card that opens, fill in the required fields. They are highlighted with a red frame:

-   Vehicle number — enter the registration number or a descriptive name for the object
    
-   Device type — select the model of the GPS tracker or other terminal installed on the object
    

<table><tbody><tr><td><span></span></td><td><div>The GPS device installed on the object must be in the list of&nbsp;<a href="../../oborudovanie-2/index.html" target="_blank"><span>supported hardware</span></a><span>.</span></div></td></tr></tbody></table>

-   Device ID/IMEI — enter the unique identifier of the hardware. It is usually printed on the device body, the packaging, or in the manufacturer's documentation
    

![](images/drex_kak_dobavit_obekt__1_custom_2.png)

3\. Click the “Save” button — the object appears in the object list

You can fill in the remaining details right away or add them later when editing. A detailed description of all tabs and parameters is given in the article [“Object card”](kartochka-obekta/index.html).

## Transferring objects from a WLP file

In PILOT, the function for transferring data from a WLP file is designed to help customers who previously used the Wialon system.

Before you start transferring objects, let's look at the file types you will use:

WLP files store the basic information about an object: its name, type, and characteristics.

WLN files contain the entire history of an object's movements and sensor readings for a certain period.

### How to transfer objects from the Wialon system:

-   Download the list of objects with parameters from Wialon
    
    2\. Upload the objects to PILOT:
    

![How to add an object ](images/drex_kak_dobavit_obekt__1_screen_2.png)

-   Upload the WLP file with the object using the button ![](images/drex_kak_dobavit_obekt__1_custom_3.png)
    
-   Select the checkbox if you want to transfer sensor readings
    

![](images/drex_kak_dobavit_obekt__1_custom_4.png)

-   Click “Upload”
    
-   The objects are added to the system automatically
    

### How to upload a group of Wialon objects:

-   Export the group of objects from Wialon to WLP files
    
-   Pack the WLP files into a single ZIP archive
    
-   Upload the archive using the button ![](images/drex_kak_dobavit_obekt__1_custom_3.png)
    

### To transfer an object's history:

-   In Wialon, select the object and parameters, then download the file in WLN format
    
    2\. In PILOT, find the object you want to transfer the history to in the object list
    
    3\. Right-click the object — the object menu opens
    
    4\. In the object menu, select “Import WLN”
    

**![](images/drex_kak_dobavit_obekt__1_custom_5.png)**

5\. In the import window, upload the required WLN file using the “Choose file” button

6\. Specify how to process the uploaded data:

• Select the “Recalculate routes” checkbox if you need to restore the object's routes

• Select the “Recalculate sensors” checkbox if you need to restore sensor readings

![](images/drex_kak_dobavit_obekt__1_custom_6.png)

7\. Click “Upload”
