On this tab you can attach documents and files to the object so that the necessary information is at hand. Upload files in doc, png, txt, excel, and pdf formats.

This tab is available right after the object is created.

![](images/drex_fajly_custom.png)

### How to add a file

-   On the tab, click the “Add file” button ![](images/drex_fajly_custom_2.png)
    
    2\. In the pop-up window, enter a description of the file
    

![](images/drex_fajly_custom_3.png)

3\. Upload a file from your computer using the “Choose file” button

4\. Click “Save”

The uploaded files appear on the tab.
