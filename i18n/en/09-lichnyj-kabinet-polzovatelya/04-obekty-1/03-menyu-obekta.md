The object menu is a list of actions you can perform with the selected object.

To open the object menu, right-click the object in the object list.

![](images/drex_menyu_obekta_custom.png)

## Follow object

Click the “Follow object” function — and you see its location on the map.

![Object menu](images/drex_menyu_obekta_screen_2.png)

To cancel following, click the cross.

If you click the object icon, an [information tooltip](dopolnitelnaya-informatsiya-ob-obekte.html) about it appears.

![](images/drex_menyu_obekta_custom_4.png)

## Map

The map is a tool for viewing objects in detail.  When you use this function, a mini window with a map opens; you can move it around the screen and resize it as you like.

![](images/drex_menyu_obekta_custom_5.png)

You can view the locations of several objects in turn. Select several objects in the list at the same time — each object is shown in close-up one after another. This way, the location of all selected objects is always available. Open mini maps are saved in the browser and are restored automatically after the page is refreshed

![](images/drex_menyu_obekta_custom_6.png)

## Edit

To change the object information, select the edit function. The [object card](kartochka-obekta/index.html) opens, where you can make changes.

To quickly open the object card for editing, simply double-click the object in the list with the left mouse button.

## Highlight with color

Highlight with color is a quick way to highlight important objects in the list so that you notice them right away.

![](images/drex_menyu_obekta_custom_7.png)

## Sensors

When you click this item of the object menu, you go to the [sensor settings](../datchiki-1/dobavlenie-datchika.html) window. Here you can add and configure the object's sensors.

![](images/drex_menyu_obekta_custom_8.png)

## Points

The “Points” item takes you to a window with information about raw points.

Raw points are unprocessed information that sensors collect from the device in real time.

What raw points include:

-   The exact time the data was received
    
-   Location — latitude, longitude, altitude
    
-   Driving speed
    
-   Direction
    
-   Number of satellites
    
-   Readings of additional sensors, for example temperature, fuel level, battery charge, and pressure sensors
    

View the object's status data in a table or on a chart.

![Object menu](images/drex_menyu_obekta_screen_3.png)

1 — Select the period for building the points report. In this report you can select data for only one day for one object

2 — Build the report

3 — Build a chart. Select sensors, and their values are displayed on the chart

![](images/drex_menyu_obekta_custom_9.png)

To download the raw points data, click ![](images/drex_menyu_obekta_custom_10.png).

## Temporary blocking

Temporary blocking is a pause mode for an object in the system. When the equipment is not in use, for example in winter, you can suspend data collection and the deduction of the subscription fee. This function suits, for example, seasonal equipment that operates only part of the year.

![](images/drex_menyu_obekta_custom_11.png)

## Clone

When you have similar objects with small differences, use cloning. It is a quick way to create a copy of an existing object.

![](images/drex_menyu_obekta_custom_12.png)

 The system automatically copies all settings, but in the card you need to enter a new name for the object and change the unique identifier.

![Object menu](images/drex_menyu_obekta_screen_4.png)

## Import WLN

This function transfers objects from the Wialon system to PILOT. To learn how to work with this function, see [here.](kak-dobavit-obekt-1.html#Из_Виалон_)

## History

When you click “History” in the object menu, you go to the [“History”](../istoriya/index.html) section, where you can view all the information about this object's past movements and status.

![](images/drex_menyu_obekta_custom_13.png)

## Delete object

When you delete an object, all its data and history disappear. If you need to restore the information, contact the system administrator.

![](images/drex_menyu_obekta_custom_14.png)

## Menu for working with several objects

-   In the object list, select several objects while holding the Ctrl key on the keyboard
    

2\. Right-click the objects — the menu for working with several objects opens

![](images/drex_menyu_obekta_custom_15.png)

### Edit

The “Edit” button is activated only when you select objects with the same device type.

![](images/drex_menyu_obekta_custom_16.png)

<table><tbody><tr><td><span></span></td><td><div>Select objects with the same device type for bulk editing.</div></td></tr></tbody></table>

When you click “Edit”, a window with [settings](kartochka-obekta/index.html#Настройки_карточка_объекта) for the selected objects opens. In this window you can configure parameters for all the selected objects at once.

![](images/drex_menyu_obekta_custom_17.png)

### Sensor templates

The [“Sensor templates”](../datchiki-1/shablony-datchikov.html#Шаблоны_датчиков) button opens a window with ready-made sensor settings. When you apply a template, the ready-made sensor parameters appear in each object.

<table><tbody><tr><td><span></span></td><td><div>A sensor template can be applied only to objects with devices of the same type.</div></td></tr></tbody></table>

![](images/drex_menyu_obekta_custom_18.png)

### Export agents

The “Export agents” function saves information about the selected objects to a separate file in JSON format. It contains information about the vehicle, the device, and the sensors.

### Follow object

Click the “Follow object” function — and you see their location on the map.

### History

When you click “History”, you go to the [“History”](../istoriya/index.html) section, where you can view all the information about the past movements and status of the selected objects.

### Move to group

This function moves the selected objects to a group. In the “Move to group” window, select a group and click the “Move” button. [How to create and work with an object group](spisok-obektov.html#группы_объектов) is described in the next article.

![](images/drex_menyu_obekta_custom_19.png)
