## Configuring the object list

Configure the object list table the way you like. Select which parameter columns to display, and configure their sorting and filters.

### How to configure the object list table:

1\. In the header of any column, click the arrow ![](images/drex_spisok_obektov_custom_15.png). A menu with the column settings appears:

-   Sorting data in ascending or descending order
    
-   Selecting columns to display
    
-   Filtering data by the selected column
    
    2\. To configure which columns to show:
    
-   Click “Columns” — a list of parameters available for display in the table column opens
    
-   Select the checkboxes next to the parameters you want to see
    
    If you need to add new parameters to display in the columns, contact the administrator. Additional parameter fields are created [in the vehicle field editor](../../panel-administratora/dogovor/redaktor-polej-transportnogo-sredstva.html) in the admin panel.
    

![](images/drex_spisok_obektov_custom_16.png)

### Filtering data by the selected column

The table columns have filters that help you quickly find the objects you need by specified parameters.

Types of column filters:

-   Selection list — select one or more values from the list with checkboxes.
    

For example, to filter objects by type, open the filter in the “Type” column and select the required value from the drop-down list. The table immediately shows only the objects that match the selected type.

![](images/drex_spisok_obektov_custom_17.png)

-   Search bar — start typing a value, and the table filters the objects by the query.
    

For example, to filter objects by geofences, open the filter in the “Geofences” column and enter a value in the search field. The table shows the objects that match the query.

![](images/drex_spisok_obektov_custom_18.png)

## Object groups

Objects can be combined into groups by any criteria to organize the list. Groups can also be used to grant [access rights](../nastrojki-dogovora-2/personal-i-gruppy/index.html#права_доступа) to several objects at once.

![](images/drex_spisok_obektov_custom_19.png)

### How to create a group:

-   Click the “Add group” button in the workspace ![](images/drex_spisok_obektov_custom_20.png)
    
-   In the window that opens, enter the group name
    

![](images/drex_spisok_obektov_custom_21.png)

3\. Click “Save”

If you mark the group as private, it is visible only to the user who created it.

### How to work with groups

To add an object to a group, drag it to the required group.

To perform an action with a group:

-   Right-click the group
    

![](images/drex_spisok_obektov_custom_22.png)

2\. And select an action:

-   Rename
    
-   Highlight with color in the list
    
-   Import objects — upload objects as a list
    
-   Delete
