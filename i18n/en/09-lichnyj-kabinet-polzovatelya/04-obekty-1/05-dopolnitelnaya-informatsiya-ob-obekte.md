## Tooltip in the object list

In the object list you can find additional information about an object in a pop-up tooltip. The additional information may include mileage, location, presence in geofences, speed, the object icon, sensor values,  and custom fields configured by the user.

To view the information in the tooltip, hover over the object in the list.

![](images/drex_dopolnitelnaya_informatsiya_ob_obekte_custom.png)

For the tooltip to be displayed in the object list, select the “Show object tree tooltips” option in [“Personalization”](../nastrojki-dogovora-2/personalizatsiya.html#общие_настройки_отображения).

![](images/drex_dopolnitelnaya_informatsiya_ob_obekte_custom_2.png)

## Tooltip on the map

 When you select objects in the list with a checkbox, they are automatically displayed on the map.

 To open the tooltip, left-click the object icon on the map.

![](images/drex_dopolnitelnaya_informatsiya_ob_obekte_custom_3.png)

### How to configure the contents of the tooltip:

-   Go to “Contract settings”
    
-   Go to the “Personalization” tab
    
-   Find the “Tooltip elements” and “Additional tooltip elements” sections
    
    4\. Select the elements to display in the object tooltip — select the checkbox in the required field
    

![](images/drex_dopolnitelnaya_informatsiya_ob_obekte_custom_4.png)

5\. Click “Save settings” on the “Personalization” tab
