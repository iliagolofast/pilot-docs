An object is a vehicle, machinery, person, animal, or any other moving or stationary object that is being monitored.

To track an object, a special device that sends data to our system is installed on it.

To set up object tracking, go to the “Online” tab. Here you can add objects for monitoring and, if you wish, combine them into groups.  After you add objects, you see the object list on the same tab
