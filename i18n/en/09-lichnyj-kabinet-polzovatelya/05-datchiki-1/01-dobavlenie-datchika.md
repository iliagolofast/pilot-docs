### To add a sensor:

-   Open the object menu. To do this, right-click the object in the object list
    

![](images/drex_dobavlenie_datchika_custom.png)

2\. Click the “Sensors” tab in the object menu

3\. In the window that opens, on the “Sensors” tab, click the button for adding a sensor

![Adding a sensor](images/drex_dobavlenie_datchika_screen.png)

4.  In the window that appears, select the sensor type by purpose. For example, a battery charge sensor

![](images/drex_dobavlenie_datchika_custom_2.png)

5.  Fill in the required fields for adding a sensor — enter the name and description, and select the field in which the device sends the values the sensor needs. Configure the necessary parameters

![](images/drex_dobavlenie_datchika_custom_3.png)

6\. Click the “Save” button. Check that the sensor appears in the list of active sensors

![](images/drex_dobavlenie_datchika_custom_4.png)

To check that the sensor works correctly and transmits data:

1\. Open the [object menu](../obekty-1/menyu-obekta.html)

2\. Go to the [“Points”](../obekty-1/menyu-obekta.html#сырые_точки) tab

![](images/drex_dobavlenie_datchika_custom_5.png)

3\. Here you see the values transmitted by all sensors

![](images/drex_dobavlenie_datchika_custom_6.png)

![](images/drex_dobavlenie_datchika_custom_7.png)
