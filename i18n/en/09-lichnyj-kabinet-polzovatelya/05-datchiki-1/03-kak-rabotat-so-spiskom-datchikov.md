---
title: "How to work with the sensor list"
---

Added sensors appear in the list on the “Sensors” tab.

![](images/drex_kak_rabotat_so_spiskom_datchikov_custom.png)

The list has columns with the same names as the sensor parameters.

Configure the sensor list table the way you like. Select which parameter columns to display and configure their sorting.

![](images/drex_kak_rabotat_so_spiskom_datchikov_custom_2.png)

### How to configure the sensor list table:

1\. In the header of any column, click the arrow ![](images/drex_kak_rabotat_so_spiskom_datchikov_custom_3.png). A menu with the column settings appears:

-   Sorting data in ascending or descending order
    
-   Selecting columns to display
    
    2\. To configure which columns to show:
    
-   Click “Columns” — a list of parameters available for display in the table column opens
    
-   Select the checkboxes next to the parameters you want to see.
    

### How to delete a sensor

To delete a sensor, click ![](images/drex_kak_rabotat_so_spiskom_datchikov_custom_4.png) in the sensor list.
