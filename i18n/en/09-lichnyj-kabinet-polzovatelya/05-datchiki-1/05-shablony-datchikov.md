---
title: "Sensor templates"
---

Templates are a ready-made set of parameters used to quickly configure devices of the same type.

<table><tbody><tr><td><span></span></td><td><div>A sensor template can be applied only to objects with devices of the same type.</div><div>For example, a template from Teltonika FMB120 suits only Teltonika FMB120</div></td></tr></tbody></table>

There are two types of templates:

-   Local templates — your own settings that you create yourself on an object
    
-   Global templates — ready-made settings that any user can use
    

### How to create a local template:

![Sensor templates](images/drex_shablony_datchikov_screen.png)

-   Configure the sensors the way you need
    
    2\. On the “Sensors” tab, click the “Save template” button
    

3\. Enter the template name and description

![](images/drex_shablony_datchikov_custom.png)

4\. Click “Save as new”

![](images/drex_shablony_datchikov_custom_2.png)

### How to apply a template to one object:

-   Go to the object you want to apply the template to
    
    <table><tbody><tr><td><span></span></td><td><div>Sensor templates suit only objects with the same type of GPS device. If you created a template for one object, it works only on other objects with the same device.</div></td></tr></tbody></table>
    
-   Open the sensors window through the object menu
    
-   On the “Sensors” tab, select the saved template from the drop-down list of templates
    

![Sensor templates](images/drex_shablony_datchikov_screen_2.png)

1 — Apply template

2 — Delete template

4\. Click the “Apply template” button

5\. If necessary, delete the old sensors

![](images/drex_shablony_datchikov_custom_3.png)

6\. Click “Apply” — the sensors from the template appear on the “Sensors” tab  

To remove a template from the list, click the cross.

### How to apply a template to several objects:

-   In the object list, select several objects while holding the Ctrl key on the keyboard
    

2\. Right-click the objects — the menu for working with several objects opens

3\. In the menu, select “Sensor templates”

![](images/drex_shablony_datchikov_custom_4.png)

4\. In the window that opens, select the saved template

![](images/drex_shablony_datchikov_custom_5.png)

5\. Click “Apply template”

### Where to find global templates:

-   On the “Sensors” tab in the drop-down list of templates
    

![](images/drex_shablony_datchikov_custom_6.png)

2\. In the [“Sensor templates”](shablony-datchikov.html#Шаблоны_датчиков_для_нескольких_объектов) window when working with several objects

![](images/drex_shablony_datchikov_custom_7.png)
