title: "Sensor groups"
---

Sensor groups are a way to organize sensors the way that suits you. You can create groups by any criteria that matter for your work.

For example:

 — by measurement type: temperature, pressure, speed

— by location: sensors in the cabin, in the engine, on the outer part of the object

![](images/drex_gruppy_datchikov_custom.png)

## How to add a sensor group:

-   Click the “Add group” button ![](images/drex_gruppy_datchikov_custom_2.png)
    

2\. In the window that opens, enter a name for the new group

3\. If necessary, add a description of the group

![](images/drex_gruppy_datchikov_custom_3.png)

4\. Click “Save”

To assign a group to a sensor, open the sensor edit window and select the name in the “Group” field.

![](images/drex_gruppy_datchikov_custom_4.png)

In the sensor list, sensor groups are displayed in a separate column.

![](images/drex_gruppy_datchikov_custom_5.png)
