Tags are a tool for grouping sensors by certain parameters.

## How to create a tag for sensors:

1\. Click “Add tag” ![](images/drex_metki_datchikov_custom_2.png)

2\. Enter the tag name

3\. Select the sensor type from the drop-down list

![](images/drex_metki_datchikov_custom_3.png)

4\. If you wish, add a description.

5\. Select an icon and a color for the tag. Selecting a color is required.

![](images/drex_metki_datchikov_custom_4.png)

6\. Click “Save”

To assign a tag to a sensor, open the sensor edit window and select the name in the “Tags” field.

![](images/drex_metki_datchikov_custom_5.png)

You can use tags when creating [reports](../otchyety-1/index.html), configuring [notifications](../moduli-1/uvedomleniya/index.html), and defining [events](../moduli-1/sobytiya.html).
