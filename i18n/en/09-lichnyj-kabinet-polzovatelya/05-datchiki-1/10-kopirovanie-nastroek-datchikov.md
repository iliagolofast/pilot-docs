---
title: "Copying sensor settings"
---

If you have several similar monitoring objects, you can copy sensor settings from one object to another.

![Copying sensor settings](images/drex_kopirovanie_nastroek_datchikov_screen.png)

<table><tbody><tr><td><div><strong>1. Export sensors</strong></div><div>Copying sensor settings from the current object</div></td></tr><tr><td><div><a href="#top"></a></div></td></tr></tbody></table>

1.  Open the sensors window of the object you want to copy settings from

2.  Click the “Export” button

3\. Select with checkboxes which sensor settings you want to copy

![](images/drex_kopirovanie_nastroek_datchikov_custom.png)

4\. Click “Export” — the file with the settings is saved to your computer

<table><tbody><tr><td><div><strong>2. Import sensors</strong></div><div>Transferring sensor settings to a new object</div></td></tr><tr><td><div><a href="#top"></a></div></td></tr></tbody></table>

<table><tbody><tr><td><span></span></td><td><div>Before importing sensors, make sure you are working with the right object.&nbsp; To do this, check the object's AgentID in the sensors window.</div></td></tr></tbody></table>

<table><tbody><tr><td><div><strong>3. AgentID</strong></div><div>The unique identification number of the object.</div></td></tr><tr><td><div><a href="#top"></a></div></td></tr></tbody></table>

-   Open the sensors window for the object you want to copy the settings to
    
    2\. Click the “Import” button
    
    3\. Find and select the previously saved settings file
    

![](images/drex_kopirovanie_nastroek_datchikov_custom_2.png)

If necessary, configure the import parameters — click the text “Select import parameters”. A window with settings opens

![](images/drex_kopirovanie_nastroek_datchikov_custom_3.png)

4\. Click “Import”
