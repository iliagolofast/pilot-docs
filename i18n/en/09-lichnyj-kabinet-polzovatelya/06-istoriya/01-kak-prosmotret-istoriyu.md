title: "How to view history"
---

The “History” section helps you track the movements of vehicles and other monitoring objects. Here you can view routes, analyze events, track sensor readings, and get detailed information about trips for a selected period.

## How to view an object's movement history:

1\. Go to the “History” section on the top navigation panel

The “Last report” button opens the most recently built history.

![How to view history ](images/drex_kak_prosmotret_istoriyu__screen.png)

2.  Select an object from the list by checking its checkbox

3.  Specify the time period in one of the following ways:

![How to view history ](images/drex_kak_prosmotret_istoriyu__screen_2.png)

1 — Use the calendar to select specific dates

2 — Use the quick buttons: “Yesterday”, “Today”, “Week”

3 — Select working days only, if necessary

4 — Add parking information to the history

4\. Click the “Search” button

5\. In the search results, select with checkboxes the track records of the object that you want to view

A track is a line on the map that shows the path of an object's movement. A track consists of points marking the places where the object was at different times.

![How to view history ](images/drex_kak_prosmotret_istoriyu__screen_3.png)

After you select the tracks you are interested in, the following elements are displayed on the screen:

![How to view history ](images/drex_kak_prosmotret_istoriyu__screen_4.png)

1 — List of selected tracks

2 — Player — a tool for playing back and controlling the viewing of tracks

3 — Events —  significant events or changes related to the object

4 — Route on the map

5 — Chart showing the speed or sensor readings of the object during the selected period
