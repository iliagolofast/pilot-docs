title: "How to work with history"

In this article we look at the history functions that help you track an object's movement and parameters and work with the obtained data.

## Track list

After you select the time period and the parameters for building the history, the list of tracks is displayed in the search results.

A track is a line on the map that shows the path of an object's movement. A track consists of points marking the places where the object was at different times.

![How to work with history](images/drex_kak_rabotat_s_istoriej_screen.png)

The list consists of track records with the following parameters: track date, start, stop, duration, distance, and the object's maximum speed.

Configure the track list the way you like. Select which parameter columns to display, for example, the duration of parking or stops.

How to configure the list of track records:

1\. In the header of any column, click the arrow ![](images/drex_kak_rabotat_s_istoriej_custom.png). A menu with the column settings appears, where you can:

• Sort the data in ascending or descending order

• Select which columns to show on the screen

• Group the records by the selected parameter

2\. To configure which columns to show:

-   Click “Columns” — a list of parameters available for display in the list opens
    
-   Select the checkboxes next to the parameters you want to see
    

![](images/drex_kak_rabotat_s_istoriej_custom_2.png)

## Player

Use the player to view how the object moved in the past.

![](images/drex_kak_rabotat_s_istoriej_custom_6.png)

Click the “Start” button ![](images/drex_kak_rabotat_s_istoriej_custom_7.png) to start viewing.

Watch the object's movement on the map and on the speed chart at the bottom of the screen.

![](images/drex_kak_rabotat_s_istoriej_custom_8.png)

Next to the player you see the date, time, and current speed of the object at a given moment.

To speed up viewing, click the speed-up button — it helps you review long routes faster.

![](images/drex_kak_rabotat_s_istoriej_custom_9.png)

## Track on the map

When you select a record in the track list, the system displays the object's route on the map. You can add several tracks to the map at once, for example, to compare the routes of one or several objects over different periods.

Tracks can be displayed in different colors depending on the selected parameters.

### Track color by speed

The speed color is configured in the [“Speed in color”](../nastrojki-dogovora-2/karta-i-geokoding.html#скорость_по_цвету) section on the “Map and geocoding” tab. Sections of the route are colored depending on the driving speed.

![](images/drex_kak_rabotat_s_istoriej_custom_10.png)

### Track color by sensor readings

The track is colored according to the readings of the selected [multi-position](../datchiki-1/tipy-datchikov/index.html#Многопозиционный_датчик) sensor along the entire route.

To display a track with color indication of sensor readings:

1\. Make sure the sensor is [configured](../datchiki-1/dobavlenie-datchika.html) and has colors set in the [calibration](../datchiki-1/dobavlenie-datchika.html#тарировочная_таблица) table

![](images/drex_kak_rabotat_s_istoriej_custom_11.png)

![](images/drex_kak_rabotat_s_istoriej_custom_12.png)

2\. Build the object's movement history by selecting tracks in “History”

3\. After the track is displayed, find the panel with the list of sensors at the bottom of the map

![](images/drex_kak_rabotat_s_istoriej_custom_13.png)

4\. Select the required sensor from the list

5\. Click the palette button that appears

![](images/drex_kak_rabotat_s_istoriej_custom_14.png)

6\. The track on the map is colored according to the sensor readings at each point of the route

![](images/drex_kak_rabotat_s_istoriej_custom_15.png)

To enlarge the map area, collapse the bottom panel with the chart by clicking the button ![](images/drex_kak_rabotat_s_istoriej_custom_16.png)

![How to work with history](images/drex_kak_rabotat_s_istoriej_screen_3.png)

### Event markers

Important events that occurred during movement, such as fuel drains, speeding, and parking, are marked on the map with special icons. For detailed information about an event, simply click the corresponding marker on the map.

![](images/drex_kak_rabotat_s_istoriej_custom_17.png)

![](images/drex_kak_rabotat_s_istoriej_custom_18.png)

## Events

Events in “History” are actions that occurred with the object. They are displayed on the “Events” tab.

![](images/drex_kak_rabotat_s_istoriej_custom_19.png)

On the [“Map and geocoding”](../nastrojki-dogovora-2/karta-i-geokoding.html#отображение_событий) tab you can configure which types of events are displayed in “History”.

![](images/drex_kak_rabotat_s_istoriej_custom_20.png)

To view events in “History”:

1\. Build the object's history and select tracks

![](images/drex_kak_rabotat_s_istoriej_custom_21.png)

2\. Go to the “Events” tab. All the object's actions on the selected track are displayed here

![](images/drex_kak_rabotat_s_istoriej_custom_22.png)

3\. Select the checkboxes next to all the events in the list that you want to see on the map

![](images/drex_kak_rabotat_s_istoriej_custom_23.png)

4\. Go to the map to view the selected events on the track

![](images/drex_kak_rabotat_s_istoriej_custom_24.png)

## Chart

The chart shows the driving speed and sensor readings.

When you select a track, only the speed is displayed on the chart automatically.

![](images/drex_kak_rabotat_s_istoriej_custom_25.png)

 To add sensor readings, select the required sensors in the sensor panel. Their values then appear on the chart.

![](images/drex_kak_rabotat_s_istoriej_custom_26.png)

![](images/drex_kak_rabotat_s_istoriej_custom_27.png)

To temporarily hide the data of a sensor, click its name to the left of the chart. The name becomes crossed out, and the line with this parameter disappears from the chart. Clicking again restores the display.

![](images/drex_kak_rabotat_s_istoriej_custom_28.png)

Click the “Select all sensors” button to display all available readings.

![](images/drex_kak_rabotat_s_istoriej_custom_29.png)

![](images/drex_kak_rabotat_s_istoriej_custom_30.png)

To clear the chart of all selected readings, click the “Clear” button ![](images/drex_kak_rabotat_s_istoriej_custom_31.png).
