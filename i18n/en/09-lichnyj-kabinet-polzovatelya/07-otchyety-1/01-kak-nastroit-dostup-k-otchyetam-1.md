---
title: "How to set up access to reports"
---

To set up access to the reports you need, complete three main steps:

-   Select the available reports in the admin panel
    

2\. Assign report rights to specific users

3\. Configure how reports are displayed in the general list

## Setting up reports through the admin panel

If you have administrator access:

1\. Sign in to the admin panel

2\. Go to the “Contracts” tab

3\. Select a contract

4\. Right-click the selected contract — the context menu opens

5\. In the context menu, select “Report list”

![](images/drex_kak_nastroit_dostup_k_otchyetam_1_custom.png)

6\. In the list that appears, select with checkboxes the reports that you want to make available to the contract's users

![](images/drex_kak_nastroit_dostup_k_otchyetam_1_custom_2.png)

If necessary, change the report name. To do this, click the field in the “Alternative name” column and enter a more familiar name.

![](images/drex_kak_nastroit_dostup_k_otchyetam_1_custom_3.png)

## Setting up reports in the user account

Now it is important to specify which reports are available to specific users:

1\. In the contract configuration, go to the [“Staff and groups”](../nastrojki-dogovora-2/personal-i-gruppy/index.html) tab

2\. Select a user in the list and click the icon ![](images/drex_kak_nastroit_dostup_k_otchyetam_1_custom_4.png)

3\. A window with the list of reports opens

4\. Select with checkboxes the reports you are assigning access to for this user

You can either grant access to all reports or limit the list to only the ones needed.

![](images/drex_kak_nastroit_dostup_k_otchyetam_1_custom_5.png)

## Displaying reports in the list

To configure which report types are available when creating a new report:

![](images/drex_kak_nastroit_dostup_k_otchyetam_1_custom_6.png)

-   In the contract configuration, go to the [“Report list”](../nastrojki-dogovora-2/spisok-otchyetov-1.html) tab
    
-   Select the report types — select the checkbox next to the required report name
    

![](images/drex_kak_nastroit_dostup_k_otchyetam_1_custom_7.png)

3\. Click the “Save settings” button

After you configure report display and access rights, you will be able to:

-   View reports in the list
    
-   Select the report you need to view
    
-   Work only with the reports you have access to
