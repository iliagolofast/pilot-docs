### To build a report:

-   In the main menu, go to the “Reports” section and select an object by checking it in the object list
    

![How to build a report](images/drex_kak_postroit_otchyet_2_screen.png)

2\. Select the time interval for the report by clicking the calendar icon

3\. Select the report type

Specify the report parameters:

4\. Report breakdown by days, weeks, or no breakdown into intervals

5\. Report grouping by dates, to analyze changes in indicators over time, or by monitoring objects, to compare indicators between different objects

6\. Sensor groups the report is generated for

7\. Click the “Build report” button
