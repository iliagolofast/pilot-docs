## Interactive map

Some reports contain an interactive map that helps you see the report data visually.

To enlarge the map area, click the screen divider.

![](images/drex_kak_rabotat_s_otchyetom_custom.png)

For example, the map is useful in reports on object movement. In the trip report, you can select a specific record, and the map shows the corresponding route with marks for the start and end of the movement.

![](images/drex_kak_rabotat_s_otchyetom_custom_2.png)

When viewing an idle report, select the required record, and a stop marker appears on the map. Click it to get all the details about this idle period.

![How to work with a report](images/drex_kak_rabotat_s_otchyetom_screen_2.png)

1 — Marker on the map

2 — Report settings

When you finish working with the map, click the “Clear” button  ![](images/drex_kak_rabotat_s_otchyetom_custom_3.png)in the upper right corner of the map to remove all displayed data.

## Additional parameters

Some reports support additional parameters. They help display more data or filter the results when building. The set of parameters depends on the selected report type.

### Where to set the parameters:

-   Open the “Reports” tab and select the report type
    
    2\. A block with additional settings appears below. Set the required parameters and click “Build report”.
    

### Which parameters exist:

1\. Switches (checkboxes)

Show or hide additional columns and report elements. To show the information, select the checkbox. To hide it, clear the checkbox.

For example, the “Trips and parking” report has the following additional parameters: columns with drivers and vehicle type, and a chart.

![](images/drex_kak_rabotat_s_otchyetom_custom_4.png)

![](images/drex_kak_rabotat_s_otchyetom_custom_5.png)

2\. Numeric parameters

Used for filtering by values and setting a range. Enter numbers; the units of measurement are shown next to the field (sec, min, temperature, etc.).

If you do not need an upper threshold, in some reports you can leave it empty or set it to 0.

For example, in the parking report, specify “Minimum time (sec)” and, if necessary, “Maximum time (sec)” — the parking duration in seconds.

![](images/drex_kak_rabotat_s_otchyetom_custom_6.png)

## Report settings

Most reports can be customized:

-   After the report is built, click the button ![](images/drex_kak_rabotat_s_otchyetom_custom_7.png)
    

2\. Select the required parameters with checkboxes — for example, object, geofences, sensors, etc.

3\. Click “Build report” to update the report with the selected parameters

In the “Idle events on the route” report, all parameters are displayed by default.

## Downloading and printing a report

A built report can be downloaded in CSV, Excel, or PDF format, and also sent to print. To do this, click the button for the required format or the printer icon at the bottom of the report.

![How to work with a report](images/drex_kak_rabotat_s_otchyetom_screen_3.png)

### Downloading as PDF

When you select PDF, the PDF export window opens, where you can configure the page size and orientation:

![](images/drex_kak_rabotat_s_otchyetom_custom_12.png)

1\. In the Page size field, select the page size: A5, A4, A3, or A2

![](images/drex_kak_rabotat_s_otchyetom_custom_13.png)

2\. In the Orientation field, select the orientation:

-   Portrait — vertical page layout
    
-   Landscape — horizontal page layout
    

![](images/drex_kak_rabotat_s_otchyetom_custom_14.png)

3\. Click “Export” to download the file

For reports with many columns, select landscape orientation and, if necessary, a larger page size — this makes the table easier to read.

## Report scheduler

Use the report scheduler to set up automatic sending of reports to your e-mail.

The report scheduler is a tool that sends reports automatically on a schedule.

![](images/drex_kak_rabotat_s_otchyetom_custom_15.png)

How to work with the report scheduler:

-   Configure which reports you need
    
    2\. Select the time when it is convenient for you to receive them
    
    3\. Reports are sent to your e-mail automatically
    

For more information about setting up the scheduler, read this [article](../nastrojki-dogovora-2/planirovshchik-otchyetov.html).
