---
title: "Administrative actions"
---

The “Administrative actions” report shows the history of user actions in the system for the selected period. It lets you find out who made which changes to the data, and when.

Each row of the report corresponds to one registered user action.

![](images/drex_administrativnye_dejstviya_custom.png)

### What the report displays

-   User name — the name of the user who performed the action
    
-   Role — the user's role in the system, for example “Administrator”
    
-   User activity — the action performed and information about the changes
    
-   Date — the date and exact time the action was performed
    

The data in the report may be split by days. The names of some actions are displayed using system designations. For example, UPDATE means a data change.
