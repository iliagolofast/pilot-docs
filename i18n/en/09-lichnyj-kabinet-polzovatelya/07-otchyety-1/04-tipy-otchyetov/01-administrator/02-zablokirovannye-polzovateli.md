---
title: "Blocked users"
---

The “Blocked users” report contains information about users whose access to the system was blocked during the selected period. It lets you find out the date and method of blocking, and also check the number of allowed and incorrect login attempts.

![](images/drex_zablokirovannye_polzovateli_custom.png)

### What the report displays

-   Role — the role of the blocked user in the system
    
-   Login — the user's login for signing in to the system
    
-   Block date — the date and time the account was blocked
    
-   Block method — the way the user was blocked, for example blocking by an administrator
    
-   Allowed login attempts — the permitted number of login attempts
    
-   Incorrect attempts — the number of failed attempts to sign in to the system
