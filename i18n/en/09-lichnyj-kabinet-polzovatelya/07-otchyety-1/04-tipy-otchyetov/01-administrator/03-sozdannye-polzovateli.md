---
title: "Created users"
---

The “Created users” report contains information about the accounts created in the system. It lets you check the user's creation date, role, account status, and validity period.

![](images/drex_sozdannye_polzovateli_custom.png)

### What the report displays

-   Login — the user's login for signing in to the system
    
-   Creation time — the date and time the account was created
    
-   User role — the user's role in the system, for example “Administrator” or “User”
    
-   Display name — the user name displayed in the system
    
-   Last password set — the date and time the password was last set
    
-   Account expires — the account expiration date. If no period is set, the value “unlimited” is displayed
    
-   Status — the current state of the account, for example active or blocked
    
-   Created by — the user who created the account
