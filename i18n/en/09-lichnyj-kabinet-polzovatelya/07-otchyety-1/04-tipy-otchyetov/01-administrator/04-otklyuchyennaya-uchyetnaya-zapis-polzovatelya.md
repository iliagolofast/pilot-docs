---
title: "Disabled user account"
---

The “Disabled user account” report contains information about accounts whose access was disabled during the selected period.

After blocking, the user cannot sign in to the system with their account. Access remains closed until the administrator unblocks the account.

![](images/drex_otklyuchyennaya_uchyetnaya_zapis_polzovatelya_custom.png)

### What the report displays

-   Login — the login of the user whose access to the system was disabled
    
-   Changed date — the date and exact time the account state was changed
    
-   Current status — the current state of the account. The value “block” means the user is blocked and cannot sign in to the system
    
-   Changed by — the name of the user or administrator who changed the account state
