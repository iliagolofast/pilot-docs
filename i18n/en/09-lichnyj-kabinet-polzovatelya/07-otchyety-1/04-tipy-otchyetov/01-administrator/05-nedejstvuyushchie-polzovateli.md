---
title: "Inactive users"
---

The “Inactive users” report contains information about accounts that were disabled during the selected period. It lets you find out when the account was created and disabled, who disabled it, and what state it is in now.

![](images/drex_nedejstvuyushchie_polzovateli_custom.png)

### What the report displays

-   User name — the user's login for signing in to the system
    
-   Display name — the user name specified in the account settings
    
-   User creation date — the date and time the account was created
    
-   User disable date — the date and time the account was disabled
    
-   Disabled by — information about the initiator or method of disabling, for example by the system administrator
    
-   Account state — the current status of the user's account
