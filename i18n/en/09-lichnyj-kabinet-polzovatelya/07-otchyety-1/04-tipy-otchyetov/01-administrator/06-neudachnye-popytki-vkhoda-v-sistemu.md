---
title: "Failed login attempts"
---

The “Failed login attempts” report contains information about unsuccessful authorization attempts during the selected period.

![](images/drex_neudachnye_popytki_vkhoda_v_sistemu_custom.png)

### What the report displays

-   User name — the name or login of the user on whose behalf the login attempt was made
    
-   Number of attempts — the number of registered login attempts
    
-   Failed attempt time — the date and time of the unsuccessful authorization
    
-   Possible login attempts — the number of login attempts
    

If the system could not identify the user or obtain certain details of the login attempt, the corresponding fields may remain empty.
