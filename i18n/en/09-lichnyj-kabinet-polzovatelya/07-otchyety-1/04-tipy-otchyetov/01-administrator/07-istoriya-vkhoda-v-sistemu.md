---
title: "Login history"
---

The “Login history” report contains information about users' logins to the system for the selected period. It lets you find out who signed in to the system and when, from which IP address, and how long the session lasted.

![](images/drex_istoriya_vkhoda_v_sistemu_custom.png)

### What the report displays

-   Name — the user's display name
    
-   Login — the user's login for signing in to the system
    
-   Email — the user's e-mail address
    
-   Date — the date and time of login to the system
    
-   Role — the user's role in the system
    
-   IP — the IP address from which the user signed in
    
-   Duration — the length of the registered user session
