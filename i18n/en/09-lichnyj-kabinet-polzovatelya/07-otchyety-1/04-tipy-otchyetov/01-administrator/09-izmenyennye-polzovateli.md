---
title: "Modified users"
---

The “Modified users” report contains information about account changes for the selected period. It lets you find out which account was changed, when it happened, what data changed, and who made the changes.

![](images/drex_izmenyennye_polzovateli_custom.png)

### What the report displays

-   User name — the login of the user whose account was changed
    
-   Modified time — the date and time the changes were made
    
-   Modified attributes — the name of the changed account parameter, for example lang — interface language
    
-   Modified by — the login of the user who made the changes
    
-   User role — the user's role after the changes
    
-   Old role — the user's role before the changes
