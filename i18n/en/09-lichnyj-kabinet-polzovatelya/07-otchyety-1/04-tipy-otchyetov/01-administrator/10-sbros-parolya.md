---
title: "Password reset"
---

The “Password reset” report contains information about user password changes for the selected period. It lets you find out for which account the password was changed, when it happened, and who performed the action.

![](images/drex_sbros_parolya_custom.png)

### What the report displays

-   User name — the login of the user whose password was changed
    
-   Password change date — the date and time the password was reset or a new one was set
    
-   Changed by — the login of the user or administrator who changed the password
