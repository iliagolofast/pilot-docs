---
title: "User activity report"
---

The user activity report contains the history of actions performed by users in the system for the selected period. It lets you find out which user, with which role, performed a certain action, when it was performed, and from which IP address.

![](images/drex_otchyet_ob_aktivnosti_polzovatelej_custom.png)

### What the report displays

-   User name — the display name of the user who performed the action
    
-   Role — the user's role in the system
    
-   User activity — the action performed and information about the object it relates to
    
-   Date — the date and exact time the action was performed
    
-   IP — the IP address from which the action was performed
    
-   Location — the user's location
