---
title: "User actions report"
---

The user actions report contains information about actions performed by users in the system for the selected period. It lets you find out which user, under which login, performed an action and when it was performed, and also determine the user's IP address and location.

**![](images/drex_otchyet_o_dejstviyakh_polzovatelya_custom.png)**

### What the report displays

-   Name — the display name of the user who performed the action
    
-   Login — the user's login for signing in to the system
    
-   Description — the action performed and information about the object it relates to
    
-   Date — the date and exact time the action was performed
    
-   IP — the IP address from which the action was performed
    
-   Location — the user's location, determined by the IP address
