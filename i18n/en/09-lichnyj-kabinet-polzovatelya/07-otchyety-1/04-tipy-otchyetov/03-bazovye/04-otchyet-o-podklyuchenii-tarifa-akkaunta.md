---
title: "Account Plan Activation Report"
---

The Report contains information about plan activation for the monitored Objects in the account. Use it to check the activation cost of each Object, the billing start date, the hardware identifier, and information about the installed SIM cards.

![](images/drex_otchyet_o_podklyuchenii_tarifa_akkaunta_custom.png)

### What the report shows

-   № — row sequence number
    
-   License plate (fleet number) — the state registration or fleet number of the Object specified in the system
    
-   IMEI — unique identifier of the installed hardware
    
-   SIM card 1 — number of the first SIM card
    
-   SIM card 2 — number of the second SIM card, if installed
    
-   Plan installation date — date the plan was activated and billing for the Object began
    
-   Price — activation cost with the currency
