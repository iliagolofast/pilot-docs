---
title: "Offline Devices"
---

The “Offline Devices” report contains a list of selected Objects with which there is no connection at the time the report is generated. Use it to find out which device is not transmitting data, how long the connection has been missing, and when the last Event was received from it.

The Report shows the current state of the Objects and is built for the current day only. If you select several vehicles, only those that are offline at the time of generation are included in the report.

![](images/drex_ustrojstva_oflajn_custom.png)

### What the report shows

-   Group — the group the monitored Object belongs to
    
-   Object — name or number of the vehicle
    
-   Message — connection status information, for example, how long the connection has been missing or a message that the device has never connected
    
-   Device type — type of the monitored Object, for example, car or bus
    
-   Last event — date and time of the last Event received from the device
    

The “Total” row shows the total number of Objects that are offline.
