---
title: "Events Report"
---

The Events Report contains information about the Events recorded by the system for the selected monitored Objects over the specified period. Use it to find out which Event occurred, when and where it was recorded, how fast the Object was moving, and which Driver was assigned to it.

![](images/drex_otchyet_po_sobytiyam_custom.png)

### What the report shows

-   Object — name or number of the monitored Object
    
-   Date and time — date and time the Event was recorded
    
-   Event — Event type and additional details
    
-   Speed — the Object’s speed at the time of the Event. If speed is not determined for the Event, the field may be empty
    
-   Drivers — the Driver assigned to the Object at the time of the Event
    
-   Geofences — the Geofence where the Event was recorded
    
-   Place — address or description of the Object’s location at the time of the Event
    

The content of the report depends on the Events, Sensors, and Notifications configured for the selected Objects.
