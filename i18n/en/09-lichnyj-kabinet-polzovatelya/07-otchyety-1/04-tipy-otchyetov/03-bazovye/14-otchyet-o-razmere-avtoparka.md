---
title: "Fleet Size Report"
---

The Fleet Size Report contains information about the number of vehicles in the User’s groups and about changes in the fleet during the reporting period. Use it to assess the initial fleet size, track new arrivals and vehicles taken out of service, and determine the current number of Objects.

![](images/drex_otchyet_o_razmere_avtoparka_custom.png)

### What the report shows

• Object or User group — name of the User group the figures are calculated for

• Existing fleet — number of vehicles in the group at the start of the reporting period

• Removed from fleet — number of vehicles removed from the group or taken out of service during the reporting period

• New deliveries — number of vehicles added to the group during the reporting period

• Current fleet — number of vehicles in the group at the end of the reporting period

The bottom total row shows the total number of vehicles in the existing fleet, the total number of removed Objects and new deliveries, and the current size of the entire fleet.
