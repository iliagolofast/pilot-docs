---
title: "GLONASS Report"
---

The GLONASS Report contains summary information about organizations’ vehicles for the selected period. Use it to compare the number of registered vehicles with their actual deployment, and to identify Objects with zero Mileage, missing navigation data, or repair status.

![](images/drex_otchyet_po_glonass_custom.png)

### What the report shows

-   Organization name — the organization the vehicles belong to
    
-   Registered in GLONASS — number of vehicles registered in the GLONASS system
    
-   Actual deployment — number of vehicles that actually operated on the given day
    
-   Zero mileage — number of vehicles with no Mileage recorded for the day
    
-   No navigation — number of vehicles from which no navigation data was received
    
-   Vehicles under repair — number of vehicles marked as under repair
    

At the bottom of each block, the totals are shown:

-   Total table count — total number of records in the table
    
-   Total vehicles — total number of vehicles
    

If there is no data for the selected day, 0 is shown in the corresponding columns.
