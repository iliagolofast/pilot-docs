---
title: "Refrigerator Report No. 2"
---

The report is designed to monitor refrigerator unit operation while the vehicle is moving and parked.

It helps you track temperature, equipment state, speed, and Object location over the selected period.

![](images/drex_otchyet_o_refrizheratore__2_custom.png)

When generating the report, you can set the minimum recording interval (in seconds). This parameter determines how often the system records data and adds rows to the report. For example, if you set the interval to 900 seconds (15 minutes), information about temperature, ignition, and other parameters is shown in the report at 15-minute steps over the selected period.

![Refrigerator Report No. 2](images/drex_otchyet_o_refrizheratore__2_screen.png)

### What the report shows

GPS date/time — date and time the data was recorded

Latitude / Longitude — coordinates of the Object at the time of recording

Place — address or detected location of the Object

Speed — travel speed at the time the data was recorded

Ignition sensor — ignition state (on / off)

AC unit status — Sensor showing whether the refrigerator unit is on or off

Back door — rear door state (open / closed)

Ground — state of the connection to the “ground” of the vehicle’s on-board network (power circuit monitoring)

RFID — radio-frequency identification data (if tag-based authorization is used)
