title: "Trips"
---

The “Trips” report contains information about the Trips of the selected vehicles over the specified period. Use it to find out when and where each Trip started and ended, its duration, the distance traveled, the speed, and the coordinates of the start and end points.

![](images/drex_poezdki_custom.png)

To view individual Trips, click the ![](images/drex_poezdki_custom_2.png) icon to the left of the Object name. After it expands, detailed data for each Trip appears under the summary row. To collapse the list, click the ![](images/drex_poezdki_custom_3.png) icon.

![](images/drex_poezdki_custom_4.png)

### What the report shows

-   Object — name or number of the vehicle
    
-   Begin — date and time the Trip started
    
-   Start — address or description of the Trip start location
    
-   End — date and time the Trip ended
    
-   Stop — address or description of the Trip end location
    
-   Duration — Trip duration
    
-   Distance (km) — distance traveled during the Trip
    
-   Avg. speed (km/h) — average travel speed
    
-   Max. speed (km/h) — maximum speed recorded during the Trip
    
-   Start coordinates — latitude and longitude of the Trip start location
    
-   End coordinates — latitude and longitude of the Trip end location
    

### Fuel data

Before generating the report, you can check the “Fuel” box.

![Trips](images/drex_poezdki_screen.png)

In this case, the following columns are added to the table:

-   Fuel level at start — fuel Sensor reading at the start of the Trip
    
-   Fuel level at end — fuel Sensor reading after the Trip ended
    
-   Fuel consumption — amount of fuel used during the Trip
    
-   Average fuel consumption per 100 km — fuel consumption based on Sensor readings, converted to 100 km
    
-   Fuel consumption by norm — calculated fuel consumption according to the norm set for the Object
    
-   Fuel consumption by norm/100 km — the set fuel consumption norm per 100 km
    

The actual fuel level and consumption figures are generated when a fuel Sensor is present and correctly configured.

![](images/drex_poezdki_custom_5.png)

### Viewing a Trip on the Map

You can expand the “Map” block above the report. To see the route of a specific Trip, first expand the Trip list using the ![](images/drex_poezdki_custom_2.png) icon, and then click the row you need.

The Map shows:

— the vehicle’s route

— the start and end points of the Trip

— the direction of movement along the route

— the vehicle’s position

— the sections of the route corresponding to the selected Trip

![](images/drex_poezdki_custom_6.png)
