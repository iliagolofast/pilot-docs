---
title: "Mileage Plus"
---

The “Mileage Plus” report contains information about the Trips of the selected vehicles over the specified period. Use it to find out the time and place movement started and ended, the Trip duration, the distance traveled, the speed, and the coordinates of the start and end points.

![](images/drex_probegi_plyus_custom.png)

### What the report shows

• Object/Event — name of the vehicle or the Event associated with it

• Begin — date and time the Trip started

• Begin/Message — address or description of the place where movement started

• End — date and time the Trip ended

• Stop — address or description of the place where movement ended

• Duration — Trip duration

• Distance (km) — distance traveled during the Trip

• Avg. speed (km/h) — average travel speed

• Max. speed (km/h) — maximum speed recorded during the Trip

• Start coordinates — latitude and longitude of the Trip start location

• End coordinates — latitude and longitude of the Trip end location

• Agent ID — identifier of the monitored Object

The total row shows the duration, distance, and average and maximum speed for the corresponding interval.

![](images/drex_probegi_plyus_custom_2.png)

### Fuel data

Before generating the report, you can check the “Fuel” box.

![Mileage Plus](images/drex_probegi_plyus_screen.png)

In this case, the following columns are added to the table:

• Fuel level at start — fuel Sensor reading at the start of the Trip

• Fuel level at end — fuel Sensor reading after the Trip ended

• Fuel consumption — amount of fuel used during the Trip

• Average fuel consumption per 100 km — actual fuel consumption converted to 100 km

• Fuel consumption by norm — calculated consumption according to the norm set for the Object

• Fuel consumption by norm/100 km — the set fuel consumption norm per 100 km

The actual fuel level and consumption figures are shown when a fuel Sensor is present and correctly configured.
