---
title: "Shifts Summary"
---

The “Shifts Summary” report contains summary information about vehicle operation relative to a base working Geofence, for example “Office”. Use it to find out when the vehicle started work and first arrived in the base Geofence, how long it stayed there, the number of departures, daily Mileage, and odometer readings.

For each vehicle, data is generated by day for the selected period.

For the report to be generated correctly, you need to assign one base Geofence to the vehicle and set the “Working” option for it. The system uses this Geofence to record entries and exits.

![](images/drex_svodka_po_smenam_custom.png)

### What the report shows

• Vehicle — name, registration, or fleet number of the vehicle

• Start date — the date the figures are calculated for

• Start time — time the vehicle began work

• Arrival time in the “Office” base Geofence — time of the vehicle’s first arrival in the working Geofence

• Idle duration in the base Geofence during the day — total time the vehicle was stationary in the working Geofence

• Number of departures from the base Geofence during the day — number of recorded exits from the working Geofence

• Time of last entry into the base Geofence during the day — time of the last recorded entry

• Time of last exit from the base Geofence during the day — time of the last recorded exit

• Odometer reading at start of day — odometer value at the start of the counted period

• Odometer reading at end of day — odometer value at the end of the counted period

• Mileage — distance traveled by the vehicle during the day

Idle duration is determined according to the Parking settings of the corresponding vehicle.
