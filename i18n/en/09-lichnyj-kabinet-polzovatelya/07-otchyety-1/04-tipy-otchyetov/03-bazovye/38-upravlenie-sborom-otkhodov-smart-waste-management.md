---
title: "Waste Collection Management (Smart Waste Management)"
---

The Smart Waste Management Report is designed to analyze [waste container servicing](../../../moduli-1/sbor-musora/index.html) over the selected period. Use it to assess the intensity of waste collection, identify areas where containers fill up regularly, and adjust collection schedules and routes.

![](images/drex_upravlenie_sborom_otkhodov__smart_waste_management__custom.png)

The Report consists of two blocks.

### Collections Chart

The chart shows the number of recorded servicing operations for each selected Object. Object names or numbers are shown on the left, and the values on the bars show the number of servicing operations during the reporting period.

The chart lets you:

— assess the intensity of work for each Object

— compare the number of servicing operations

— identify Objects with high or low workload

— check compliance with the waste collection schedule

![](images/drex_upravlenie_sborom_otkhodov__smart_waste_management__custom_2.png)

### Bins Statistics Map

The Map shows the places where the system recorded waste containers being full. The number on a marker shows the number of such Events at the corresponding point.

When you select a marker, the Bins Statistics window opens with the following information:

-   Coordinates — latitude and longitude of the point
    
-   Address — address or description of the location
    
-   Total full alerts — total number of fullness Notifications
    
-   Bin full alerts list — list of Objects for which Notifications were recorded, and the number of Events for each
    

![](images/drex_upravlenie_sborom_otkhodov__smart_waste_management__custom_3.png)

The Map lets you identify zones where containers regularly fill up or overflow, determine areas that may need more frequent collection, and plan vehicle routes based on the actual load.

The Report data is generated from recorded servicing Events and container fullness Notifications. For the information to be displayed correctly, the corresponding Sensors and Notifications must be configured for the selected Objects.
