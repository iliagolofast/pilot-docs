---
title: "Trip and Parking (with Maps)"
---

The “Trips and Parking (with Maps)” report contains information about the Trips and Parking of the selected vehicle over the specified period. Use it to analyze the time and place movement started and ended, the duration of operation and Parking, the distance traveled, and speed indicators.

The Report includes summary indicators for the selected period and detailed information for each Trip. When Maps are enabled, the vehicle’s route is displayed graphically.

![](images/drex_poezdka_i_parkovki__s_kartami__custom.png)

### What the report shows

• Object — name, registration, or fleet number of the vehicle

• Work start time — date and time the vehicle began work

• Work start place — address where the work started

• Work end time — date and time the vehicle ended work

• Work end place — address where the work ended

• Duration — duration of the counted Event

• Operating duration — total vehicle operating time

• Parking duration — total Parking time for the corresponding period

• Driver — the Driver assigned to the vehicle during the Trip

• Mileage — distance traveled by the vehicle

• Maximum speed — maximum speed recorded during the Trip

• Average speed — the vehicle’s average speed during the Trip

![](images/drex_poezdka_i_parkovki__s_kartami__custom_2.png)

### Report parameters

Before generating the report, you can select the Map type and configure additional display options:

• Show odometer — adds the odometer readings at the start and end of the Trip to the table

• Show maps — adds a Map with the vehicle’s route to the report

• Show parking — shows Parking locations on the Map; this option becomes available after Maps are enabled

![Trip and Parking (with Maps)](images/drex_poezdka_i_parkovki__s_kartami__screen.png)

### Show odometer

If you enable the “Show odometer” option, additional columns appear in the summary and detailed parts of the report:

![](images/drex_poezdka_i_parkovki__s_kartami__custom_3.png)

1 — Odometer at start — odometer reading at the moment work or the Trip began

2 — Odometer at end — odometer reading at the moment work or the Trip ended

![Trip and Parking (with Maps)](images/drex_poezdka_i_parkovki__s_kartami__screen_2.png)

### Show maps

If you enable the “Show maps” option, a Map with the vehicle’s route for the selected period appears below the table part of the report.

Before generating the report, you can select in the “Map type” field the base map to be used to display the route.

![Trip and Parking (with Maps)](images/drex_poezdka_i_parkovki__s_kartami__screen_3.png)

![](images/drex_poezdka_i_parkovki__s_kartami__custom_4.png)

### Show parking

If you enable both “Show maps” and “Show parking”, Parking location markers are shown on the Map along with the route.

![](images/drex_poezdka_i_parkovki__s_kartami__custom_5.png)

When you select a Parking marker, a tooltip opens with the following data:

• Start — date and time the Parking began

• End — date and time the Parking ended

• Duration — total Parking duration

![](images/drex_poezdka_i_parkovki__s_kartami__custom_6.png)
