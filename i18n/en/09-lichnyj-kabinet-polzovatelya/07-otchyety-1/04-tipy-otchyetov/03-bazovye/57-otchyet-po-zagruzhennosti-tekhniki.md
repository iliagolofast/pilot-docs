---
title: "Equipment Utilization Report"
---

The Equipment Utilization Report contains information about the use of the selected monitored Objects over the specified period. It lets you compare the time machinery spent idling and under load, and determine the total engine hours and the distance traveled.

Use the Report to assess the efficiency of equipment operation, identify long operation without useful load, reduce downtime, and allocate resources more efficiently.

![](images/drex_otchyet_po_zagruzhennosti_tekhniki_custom.png)

### Report structure

The information is presented in several sections:

-   “Totals for the period” — summary indicators for all selected Objects
    
-   “Equipment use for the period” — a pie chart showing the ratio of Parking, idling, and operation under load
    
-   Breakdown by Object — indicators for each Object, split by date
    

### Totals

-   Object — name, registration, or fleet number of the monitored Object
    
-   Description — additional information about the Object. If no description is set, the field stays empty
    
-   Days — number of calendar days included in the analyzed period
    
-   Idling — engine operating time without recorded useful load. The indicator is shown in two columns:
    
-   % — the share of idling calculated by the system
    
-   hh:mm — idling duration in hours and minutes
    
-   Operation under load — time during which the equipment performed useful work. The indicator is shown in two columns:
    
-   % — the share of operation under load calculated by the system
    
-   hh:mm — duration of operation under load in hours and minutes
    
-   Total engine hours — total engine operating time for the corresponding period in “hh:mm” format
    
-   Distance, km — distance traveled by the Object over the specified period
    

![](images/drex_otchyet_po_zagruzhennosti_tekhniki_custom_2.png)

### Equipment use chart

Below the totals table, in the “Equipment use for the period” section, a pie chart is shown. It shows the ratio of the main equipment states:

-   Parking — time when the equipment was neither working nor moving
    
-   Idling — time the engine ran without useful load
    
-   Operation under load — time the equipment performed useful work
    

The chart lets you visually compare the states and determine what part of the selected period was actual work, idling, and Parking.

![](images/drex_otchyet_po_zagruzhennosti_tekhniki_custom_3.png)

### Breakdown by Object

Below the chart, separate blocks split by date are shown for each Object. Each daily block contains:

-   Description — additional description of the Object
    
-   Idling — percentage and duration of idling
    
-   Operation under load — percentage and duration of operation under load
    
-   Total engine hours — total engine operating time for the day
    
-   Distance, km — the Object’s Mileage for the corresponding date
    

This breakdown lets you compare the indicators of one Object by day and find periods of high load, long idling, or no work.
