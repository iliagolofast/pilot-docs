---
title: "Driver’s License Expiring"
---

This report shows which Drivers have a driver’s license that is about to expire.

![](images/drex_voditelskoe_udostoverenie_istekaet_custom.png)

For a Driver to appear in the report, the following fields must be filled in on the Driver’s card:

1\. Driver’s license / ID number — license number

2\. License validity / Expiry date — expiration date

![](images/drex_voditelskoe_udostoverenie_istekaet_custom_2.png)

### How to generate the report

1\. Go to the Driver reports section

2\. Select the “Driver’s License Expiring” report

3\. Specify the check period — the range of months during which a driver’s license may expire

![Driver’s License Expiring](images/drex_voditelskoe_udostoverenie_istekaet_screen.png)

1 — License check period

2 — Select Drivers

4\. Select the Drivers

5\. Start generating the report

### What the report shows

Each row is a separate Driver whose license expiration falls within the selected period.

![](images/drex_voditelskoe_udostoverenie_istekaet_custom_3.png)

-   Driver — the Driver’s full name
    
-   Group the Driver belongs to
    
-   ID number — driver’s license number
    
-   Contact number — contact phone number
    
-   Registration — the Object the Driver is assigned to
    
-   Expiry date — driver’s license expiration date
