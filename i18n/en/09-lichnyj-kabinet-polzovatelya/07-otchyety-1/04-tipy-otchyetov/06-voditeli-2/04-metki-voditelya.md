title: "Driver Tags"
---

This report shows which identifiers are linked to each Driver — RFID cards, iButtons, passes, and other access keys.

![](images/drex_metki_voditelya_custom.png)

### What the report shows

-   Group — the group the Driver belongs to
    
-   Driver — the Driver’s name or full name
    
-   Identification number  — ID specified on the Driver’s card
    
-   ID —  ID received by the system from the device when a tag is used
    
-   Date — date the ID was last used
    
-   Difference — field showing discrepancies between the data
