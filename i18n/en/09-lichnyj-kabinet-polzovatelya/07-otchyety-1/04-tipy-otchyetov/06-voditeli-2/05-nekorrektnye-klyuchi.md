---
title: "Invalid Keys"
---

This report shows cases when iButtons that are not in the system were used during the specified period.

An iButton is an electronic Driver identification key. It is used to control access to monitored Objects. For the system to recognize the Driver correctly, the iButton must be registered in the system and compatible with the reader.

### What the report shows

-   Object — the vehicle or monitored Object in which the key was used.
    
-   Date — date and time the Trip started.
    
-   iButton — identifier of the key that is not registered in the system
