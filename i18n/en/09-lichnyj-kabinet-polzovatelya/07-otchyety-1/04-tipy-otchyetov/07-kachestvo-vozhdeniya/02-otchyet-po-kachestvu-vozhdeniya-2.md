title: "Driving Quality Report No. 2"
---

Driving Quality Report No. 2 is a log of all violations. This report breaks the data down to each individual Event: when, where, and which violation occurred.

![](images/drex_otchyet_po_kachestvu_vozhdeniya__2_custom.png)

### What the report shows

Each row in the table is one recorded violation.

The report contains the following columns:

-   Object — the vehicle in which the violation was recorded
    
-   Driver — the Driver assigned to this Object at the time of the Event
    
-   Time — exact time the violation was committed
    
-   Type — violation category (for example, speeding, harsh braking, etc.)
    
-   Message — text description of the violation, set when the rule was created in the [driving quality control](../../../moduli-1/ehkodrajving-kachestvo-vozhdeniya/index.html) Module
    
-   Value — the actual measured value at which the rule was triggered (for example, speed, idling duration, acceleration value)
    
-   Penalty — number of penalty points assigned for the Event
    
-   Place — address where the violation occurred — a link that lets you open the point on the Map
    

![](images/drex_otchyet_po_kachestvu_vozhdeniya__2_custom_2.png)

When you select a specific violation, its type and the place on the Map where it occurred are shown.
