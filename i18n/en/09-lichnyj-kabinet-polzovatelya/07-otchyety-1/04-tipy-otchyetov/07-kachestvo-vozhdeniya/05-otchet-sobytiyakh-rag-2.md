**The Report contains:**

-   # Object  -
    
    the monitored Object on which driving quality was recorded;
    
-   # Total distance (km) -
    
    the distance over which the violation was committed;
    
-   # Trip duration -
    
    the duration over which the violation was committed;
    
-   # Max. speed-
    
    the maximum speed recorded during the Trip.
    
-   # Speeding zone - **a section of road on which a maximum speed limit for vehicles is set**;
    
-   # Speeding norm - **vehicle movement at a speed exceeding the limits set by law or road signs**;
    
-   # Speeding duration range -  **duration of the speeding;**
    
-   # Normal speeding duration-**the time during which the vehicle moves above the set speed limit**;
    
-   # Total speeding duration -**the time during which the vehicle moves above the set speed limit**;
    
-   # Speed score -  **speed score value;**
    
-   # Total acceleration -  **value of total acceleration for the specified period;**
    
-   # Acceleration score -**acceleration score value;**
    
-   # Total number of decelerations - **value of total deceleration for the specified period;**
    
-   # Deceleration score  - **deceleration score value;**
    
-   # Time without seat belt- **Trip time without a seat belt during the reporting period;**
    
-   # Seat belt violation score - **value for violations of driving without a seat belt;**
    
-   # Excessive idling **\-the vehicle engine idles longer than necessary;**
    
-   # Idling duration - **value for idling duration;**
    
-   # Total score - **overall Trip score.**
