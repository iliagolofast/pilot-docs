# **The RAG Events Report is a report that gives an overview of the main driving quality Events.**

**The Report contains:**

-   # Driver -
    
    the Driver assigned to this Object;
    
-   # Total distance (km) -
    
    the distance over which the violation was committed;
    
-   # Total acceleration -  **total acceleration score value;**
    
-   # Acceleration score - **acceleration score value;**
    
-   # Total number of decelerations- **total deceleration score value;**
    
-   # Deceleration score -**deceleration score value;**
    
-   # Maximum speed (km/h) -
    
    the maximum speed recorded during the Trip.
    
-   # Total speeding time -
    
    the total time during which the speed was exceeded;
    
-   # Speed score - **speed score value;**
    
-   # Time without seat belt - **the time during which the Driver drove without a seat belt;**
    
-   # Seat belt violation score - **score value for driving without a seat belt;**
    
-   # Score -
    
    calculated from the sum of harsh turns, braking, and acceleration events.
