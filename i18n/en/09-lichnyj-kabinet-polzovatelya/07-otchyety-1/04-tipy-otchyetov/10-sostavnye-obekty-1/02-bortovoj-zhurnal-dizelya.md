---
title: "Diesel Logbook"
---

The “Diesel Logbook” report shows the fuel balance of the selected composite object for the selected period. Use it to control the opening and closing fuel balance, receipts, consumption, dispensing via outputs and possible discrepancies.

The report is built for one composite object only. For the calculation to be correct, tanks, flow meters and the links between the elements of the composite object must be configured on the Object.

![](images/drex_bortovoj_zhurnal_dizelya_custom.png)

### What the report shows

• Start — the fuel balance at the start of the selected period

• Receipts — the volume of fuel received by the composite object

• Consumption — the volume of fuel consumed during the period

• Dispensed via outputs — the volume of fuel dispensed through output elements or flow meters

• Discrepancy — the difference between calculated and actual values

• Closing balance — the fuel balance at the end of the selected period
