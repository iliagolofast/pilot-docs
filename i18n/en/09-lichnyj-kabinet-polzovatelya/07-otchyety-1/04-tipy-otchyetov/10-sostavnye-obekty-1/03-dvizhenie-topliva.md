---
title: "Fuel Movement"
---

The “Fuel Movement” report shows fuel movement across a composite object for the selected period. Use it to analyze receipts, consumption, fuel balances, output readings and fuel level changes based on sensor data.

 The report can be displayed as a table or a chart. To build the report, select a composite object and the required sensors. If necessary, you can use a breakdown by days and grouping by dates or Objects.

![](images/drex_dvizhenie_topliva_custom.png)

### What the report shows

• Start — the fuel balance at the start of the selected period

• Receipts — the volume of fuel received by the composite object

• Consumption — the volume of fuel consumed during the period

• By outputs — the volume of fuel dispensed through output elements or flow meters

• Discrepancy — the difference between calculated and actual values

• End — the fuel balance at the end of the selected period

• Sensor readings — the values of the selected fuel sensors in chart mode

• Fuel level change events — events related to changes in the fuel level
