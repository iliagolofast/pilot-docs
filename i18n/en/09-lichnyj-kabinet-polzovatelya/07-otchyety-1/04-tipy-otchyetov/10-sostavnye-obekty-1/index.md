title: "Composite Objects"
---

This section contains reports related to the [“Composite Objects”](../../../moduli-1/sostavnye-obekty-3.html) module. They help you control fuel movement and see receipts, consumption and balances across the entire fuel scheme that combines several tanks and sensors.

With these reports you can:

— track the fuel balance by day

— analyze consumption and identify discrepancies between level and flow meter readings

— control balances and fuel deliveries across the entire scheme

sensors.

For the reports to be generated correctly, the related elements and sensors must be configured on the composite object: the main tank, input or output flow meters, additional tanks and the links between them. The set of required sensors depends on the scheme of the particular composite object.

**Diesel Logbook**

The **“Diesel Logbook”** report shows the fuel balance of the selected composite object for the period. The report displays the opening balance, receipts, consumption, dispensing via outputs, discrepancy and closing balance.

The report is built for one composite object only. For the calculation to be correct, tanks, flow meters and the links between the elements of the composite object must be configured on the Object.

**Fuel Movement**

The **“Fuel Movement”** report shows fuel movement across a composite object for the selected period. It can be displayed as a table or a chart.

In table view, the report shows the fuel balance: opening balance, receipts, consumption, output readings and discrepancy. In chart view, you can view the sensor reading series and fuel level change events.

To build the report, select a composite object and the required sensors. If necessary, you can use a breakdown by days and grouping by dates or Objects.
