---
title: "Events"
---

The “Events” report shows all events recorded by the system during the selected period. It helps you understand what happened, when, and how operators handled these events.

![](images/drex_sobytiya_custom.png)

The main part of the report is a table. It displays the following fields:

-   Group — the group of Objects the Object belongs to.
    
-   Object — the monitored object that generated the event
    
-   Time — the date and time the event occurred
    
-   Type — the event description (for example, speeding, Alarm → Lane deviation, etc.).
    
-   [Group](../../../moduli-1/situatsionnyj-tsentr-2/kak-nastroit-parametry-sobytij.html#группы_событий) (on the right) — the event category (for example, Alarms).
    
-   Status —  the event processing state: unprocessed or processed
    
-   Operator — the system user who processed the event
    
-   Processing time — the date and time when the operator finished processing the event
    
-   Comments — additional notes the operator added during processing
