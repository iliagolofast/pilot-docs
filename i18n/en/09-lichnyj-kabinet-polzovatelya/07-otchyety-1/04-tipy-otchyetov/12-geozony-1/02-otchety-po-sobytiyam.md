---
title: "Event Reports"
---

This report displays actions of an Object over a specific period of time.

**The report contains:**

-   **Event -**   the sensor event type;
    
-   **Event start -** the time and date the sensor started operating;
    
-   **Event end -** the time and date the sensor stopped operating;
    
-   **Duration  -**  the operating time;
    
-   **Distance  -** the monitored object's mileage in km on the specified date;
    
-   **Address** of event start -  the event address;
    
-   **Address** of event end -  the event address at the end;
