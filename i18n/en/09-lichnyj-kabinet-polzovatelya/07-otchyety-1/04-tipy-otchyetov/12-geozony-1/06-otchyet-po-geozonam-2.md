**Geofences Report No. 2**

The geographic zones report 2 displays data as a table showing the Object name, time, the message about arrival (entry) in and departure (exit) from a particular zone, and the duration of stay in the specified zone, with the option of setting a time filter (set in the Object settings on the “Geofences” tab, in the idling control field).

**The report contains:**

-   **Object** - the monitored object for which the idling table is generated.
    
-   **Date** - the time period for which the idling table is generated for the specified Object.
    
-   **Zone**\- the geographic zone in which idling was recorded.
    
-   **Start -** the date and time the monitored object entered the geographic zone.
    
-   **End** - the date and time the monitored object exited the geographic zone.
    
-   **Duration -** the time the monitored object spent in the geographic zone, equal to the difference between the entry and exit times.

If necessary, you can hide certain parts of the report by clicking the icon ![](images/drex_otchyet_po_geozonam__2_custom_2.png). A menu opens in which you can turn individual fields on or off.
