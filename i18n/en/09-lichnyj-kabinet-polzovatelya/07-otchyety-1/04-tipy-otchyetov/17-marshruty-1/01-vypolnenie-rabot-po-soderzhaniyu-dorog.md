---
title: "Road Maintenance Work Completion"
---

This report belongs to the Routes module.

After linking an Object to a route, build the Road Maintenance Work Completion report.

A recalculation is available for this report.

If a route is configured and linked to an Object and the report then turns out to be empty, you will need to recalculate it.

If recalculation through the interface does not recalculate the data and resets the recalculation, contact support to have it recalculated.

 **The report contains:**

-   **License plate (garage number) -**  the Object in the system**;**
    
-   **Vehicle type -**  the vehicle type in the system;
    
-   **Start time -** the date and time work started;
    
-   **End time-** the date and time work ended;
    
-   **Route name -** the route name;
    
-   **Route length -** the route length;
    
-   **Mileage (Work cycle), km -** the work cycle is a parameter showing how long, in km, the machine can work without a break.
    
-   **Area (Work cycle) ㎡ -** the total area treated during one work cycle of the machine.
    
-   **Mileage (Idle cycle) km -** the distance in km that the vehicle drives without a load.
    
-   **Mileage on other roads, km** - the mileage on other roads.
