#  **The vehicle register is a register of vehicles.**

 **The report contains:**

-   # Vehicle number -   **the Object in the monitoring system;**
    
-   # Make - **the make of the Object;**
    
-   # Model - **the model of the Object;**
    
-   # Year of manufacture - **the year of manufacture of the Object;**
    
-   # Vehicle type  -   **the type of vehicle in the system;**
    
-   # Engine number - **the engine number;**
    
-   # Engine displacement - **the engine displacement**;
    
-   # VIN - **the VIN of the body;**
    
-   # Vehicle license **\- license details;**
    
-   # Vehicle registration certificate issue date - **the issue date of the vehicle registration certificate.**
