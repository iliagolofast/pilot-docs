# **A tachograph report is a document that contains information about the driver's work, speed, route, time, and work and rest mode**.

# To get a tachograph report, you will need to:

 Install a tachograph in the vehicle and connect it to a GPS tracker.

 Insert the driver card into the tachograph and select the operating mode.

#  **Monitor changes in the operating mode and comply with driving and rest time limits.**

 **The report contains:**

-   # Vehicle number - **the Object in the system**
    
-   # Activity type -   **the type of the driver's activity**
    
-   # Start -  **the date and time the activity started;**
    
-   # End - **the date and time the activity ended;**
    
-   # Location - **the location of the activity;**
    
-   # End position - **the address of the end of the journey;**
    
-   # Duration - **information on the duration of activities;**
    
-   # Driver **- information about drivers.**
