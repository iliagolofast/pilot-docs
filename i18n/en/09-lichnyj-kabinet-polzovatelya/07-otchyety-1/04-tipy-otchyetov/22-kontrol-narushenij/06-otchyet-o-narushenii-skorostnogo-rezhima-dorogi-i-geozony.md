---
title: "Speed Limit Violation Report (Roads and Geofences)"
---

The report on speed violations in geofences and on roads helps you monitor where and when vehicles exceeded the speed limit, both on ordinary roads and inside geofences (for example, on the territory of a warehouse, a construction site or in a particular district).

This report combines data from two modules: “Violations Control” and “Geofences”. As a result, you see all cases of speeding both on ordinary roads and inside the specified geofences in one common report.

When building the report, select the required Object and geofence to see all cases of speeding.

![](images/drex_otchyet_o_narushenii_skorostnogo_rezhima__dorogi_i_geozony__custom.png)

### How to set a speed threshold for a geofence

You can set a separate speed threshold for each geofence:

-   Open the [card](../../../obekty-1/kartochka-obekta/index.html) of the required Object
    
-   Go to the [“Geofences”](../../../moduli-1/geozony-2/geozony-v-kartochke-obekta.html) tab
    

![Speed Limit Violation Report (Roads and Geofences)](images/drex_otchyet_o_narushenii_skorostnogo_rezhima__dorogi_i_geozony__screen.png)

3\. Set the geofence speed threshold for this Object:

![Speed Limit Violation Report (Roads and Geofences)](images/drex_otchyet_o_narushenii_skorostnogo_rezhima__dorogi_i_geozony__screen.png)

1) Click the required geofence

2) Use the arrows to set the speed limit for this zone

3) Click “Save”

If a vehicle is in a geofence, the limit set for that zone is applied.

The report shows:

-   A list of all vehicles and drivers that violated the speed limit
    
-   The date, time and place of each violation
    
-   The set speed limit and the maximum recorded speed
    
-   By how many km/h the speed limit was exceeded
    
-   How long and how many kilometers the vehicle drove while speeding
    
-   The type of road or geofence where the violation occurred
    
-   Map links for quickly viewing the location of the violation
