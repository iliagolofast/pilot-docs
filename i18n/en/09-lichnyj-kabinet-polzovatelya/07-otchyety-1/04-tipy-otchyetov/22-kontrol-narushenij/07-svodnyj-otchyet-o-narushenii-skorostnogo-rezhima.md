---
title: "Speed Limit Violation Summary Report"
---

The Speed Limit Violation Summary Report shows which vehicles exceeded the speed you set, and when, during the selected period. This report helps you monitor compliance with speed limits.

![](images/drex_svodnyj_otchyet_o_narushenii_skorostnogo_rezhima_custom.png)

Before using the report, be sure to set the speed threshold for each vehicle:

1\. Open the [card](../../../obekty-1/kartochka-obekta/index.html#Настройки_карточка_объекта) of the required Object

2\. Go to the “Settings” tab

3\. In the “Additional” section, enter a value in the “Speed control, km/h” field. For example, if you set 90 km/h, all trips faster than this speed will be considered a violation.

![Speed Limit Violation Summary Report](images/drex_svodnyj_otchyet_o_narushenii_skorostnogo_rezhima_screen.png)

If the threshold is not set, speeding will not be recorded, and the report may be empty.

Once you have set the speed threshold, the system tracks all trips on its own and flags cases of speeding.

The report shows:

-   How many vehicles there are in the group in total
    
-   How many of them violated the speed limit
    
-   Speeding penalties — points for each speed limit violation
    
-   How long the vehicle was on the road while speeding
    
-   How long the vehicle drove faster than the set threshold
    
-   The maximum recorded speed
    
-   The average of the maximum speeds across all trips
