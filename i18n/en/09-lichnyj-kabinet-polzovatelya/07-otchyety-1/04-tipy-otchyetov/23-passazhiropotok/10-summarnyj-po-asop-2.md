title: "ASOP Summary #2"
---

This report is active when the Convenient Route module is enabled.

**The report contains:**

-   **Vehicle -** the monitored object in the system.
    
-   **Carried -** the number of passengers
    
-   **Validator data-** the number of readings of various ticket types.
    
-   **Difference -** the difference.
    
-   **Trips -** the number of trips.
    

![](images/drex_summarnyj_po_asop__2_custom.png)

If necessary, you can hide certain parts of the report by clicking the icon ![](images/drex_summarnyj_po_asop__2_custom_2.png). A menu opens in which you can turn individual fields on or off.
