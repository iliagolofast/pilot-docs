---
title: "ASOP Summary #4"
---

This report is active when the Convenient Route module is enabled.

The report is generated by drivers, with the driver's personnel number specified.

If no driver is found by the personnel number, the driver field in the report will be empty.

Configure an additional driver field in which the personnel number will be stored (at the partner).

![](images/drex_summarnyj_po_asop__4_custom.png)

**The report contains:**

-   **Vehicle**\- the monitored object in the system.
    
-   **Driver -** the driver's name in the system.
    
-   **Video -** the video.
    
-   **Validator data -** the reader of various ticket types.
    
-   **ASOP total -** the total amount.
    
-   **Difference -** the number of passengers and the difference in amounts.
    
-   **Trips-** the number of trips per shift.
    

![](images/drex_summarnyj_po_asop__4_custom_2.png)

If necessary, you can hide certain parts of the report by clicking the icon ![](images/drex_summarnyj_po_asop__4_custom_3.png). A menu opens in which you can turn individual fields on or off.

![](images/drex_summarnyj_po_asop__4_custom_4.png)
