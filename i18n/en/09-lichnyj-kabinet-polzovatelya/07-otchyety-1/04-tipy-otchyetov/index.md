---
title: "Report Types"
---

In PILOT, all reports are divided into types depending on what they are for and what data they use.

Each report is generated as a table. Tables are the main way of displaying data in reports. Each report type has its own set of columns, calculation logic and separate display settings.

![](images/drex_tipy_otchyetov_custom.png)

The system provides basic reports used to analyze standard monitoring data: trips, mileage, time in motion, events and other universal indicators. These reports are available regardless of the connected modules.

The system also has reports for [modules](../../moduli-1/index.html). They are designed to work with specific system modules (for example, “Drivers”, “Fuel”, “Geofences”, etc.) and use additional data and settings available only when the module is active.
