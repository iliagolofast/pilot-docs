When you create a report, you first select the report type and then add columns with data.

![](images/drex_kolonki_s_dannymi_dlya_raznykh_tipov_otchyetov_custom.png)

The set of available data depends on the selected report type:

1\. You select the report type

2\. The system automatically loads the available categories and data fields

3\. In the “Columns” section, you add the data you need

4\. When the report is built, only the selected columns are displayed

### Example: the “RFID tags” report type

If you select the “RFID tags” type, RFID-related data becomes available.

This kind of report helps you analyze:

-   which RFID tags were recorded
    
-   when the event occurred
    
-   where it occurred
    
-   which object or device the record belongs to
    

![](images/drex_kolonki_s_dannymi_dlya_raznykh_tipov_otchyetov_custom_2.png)

When you create a report, you specify the main settings:

-   Name: the report name
    
-   Sorting: the field by which the data is ordered
    
-   Desc: sort in descending order
    
-   Columns: the data to be displayed
    
-   Configuration: additional parameters and filters
    

After that, you can proceed to adding columns:

1\. Click the add button in the “Columns” section ![](images/drex_kolonki_s_dannymi_dlya_raznykh_tipov_otchyetov_custom_3.png)

2\. In the “Data” field, select the parameter you need from the list

The available fields depend on the selected report type.

![](images/drex_kolonki_s_dannymi_dlya_raznykh_tipov_otchyetov_custom_4.png)

Example of available data (RFID)

In addition to the general data (vehicle, device, ID, group, and so on), specialized fields appear:

-   RFID Time: the time the tag was read
    
-   RFID Name: the tag name (for example, an employee name or an object)
    
-   RFID Location: the place where it was read
    
-   RFID UID: the unique tag code
    
-   RFID Group: the tag group
    

Add the columns you need to build the report structure.
