---
title: "Which devices can be connected"
---

The PILOT system supports different types of video devices. Each type has its own connection parameters:

### Howen

-   Server 1 (telematics): Server URL, port 20009
    
-   Server 2 (video): video.pilot-gps.com, port 33000
    
    Howen uses a separate key, url\_howen, in [“Module settings”](nastrojka-modulej-v-paneli-administratora.html#Настройка_модуля)
    
    No password is required to connect.
    

![](images/drex_kakie_ustrojstva_mozhno_podklyuchat_custom.png)

### CMS

-   Server address (Host): video.pilot-gps.com
    
-   Port: 6608
    

### Cipia

-   Server address (Host): video.pilot-gps.com
    
-   Port: 1883
    

### Teltonika DualCam

-   Server address (Host): video.pilot-gps.com
    
-   Port: 20233
    

### Hikvision

How Hikvision devices are connected depends on the specific model.

Some models use the standard connection to the video.pilot-gps.com server.

For example, for Hikvision G40:

• Server address (Host): video.pilot-gps.com

• Port: 6608

Other Hikvision models that can be connected to PILOT:

-   DS-MCW407 (BWS): a body camera for video and audio with online transmission.
    
-   AE-MN5043 (DVR): a mobile dash cam with GPS for vehicles.
    
-   AE-VC583I-IS/P(H): a high-resolution vehicle IP camera (license plate recognition).
    

Different Hikvision models may use different connection parameters. Contact support to find out which ones apply.
