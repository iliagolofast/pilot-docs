All recordings and photos from devices are available for viewing in your account, either in the [“History”](kak-rabotat-s-mediafajlami.html#История_медиа) section or on the [“Media”](kak-rabotat-s-mediafajlami.html#Медиа_в_меню_объекта) tab of the selected object.

## Media files in “History”

In the “History” section you can not only view an object’s tracks but also work with video: watch recordings, download clips, or review recorded violations.

1\. In the top panel, go to the “History” section

2\. Select the object you need from the list by selecting its check box

3\. Specify the time period

4\. Click the “Search” button

5\. In the search results, select the check boxes next to the track records you want to view

6\. A “Media” tab appears in the bottom panel (next to “Events”)

![](images/drex_kak_rabotat_s_mediafajlami_custom.png)

The “Media” tab is divided into two parts:

-   Device: recordings stored on the device itself (a dash cam or camera)
    
-   Storage Server: recordings stored on the server (for example, DMS/ADAS events: seat belt not fastened, fatigue, smoking, and so on)
    

###  Device tab

This tab shows everything that is still stored on the device.

![](images/drex_kak_rabotat_s_mediafajlami_custom_2.png)

How to view a recording:

1\. Click the ![](images/drex_kak_rabotat_s_mediafajlami_custom_3.png) icon next to the recording in the list

2\. A player opens with the video for the selected time interval

![](images/drex_kak_rabotat_s_mediafajlami_custom_4.png)

The video shows basic information:

-   channel number
    
-   date and time
    
-   vehicle speed and/or coordinates
    

In the player you can use the following functions:

![](images/drex_kak_rabotat_s_mediafajlami_custom_5.png)  Play / ![](images/drex_kak_rabotat_s_mediafajlami_custom_6.png) Pause: start or pause playback

![](images/drex_kak_rabotat_s_mediafajlami_custom_7.png) Stop: end playback

![](images/drex_kak_rabotat_s_mediafajlami_custom_8.png) Seek: move through the recording

![](images/drex_kak_rabotat_s_mediafajlami_custom_9.png) Screenshot: capture a frame from the video

![](images/drex_kak_rabotat_s_mediafajlami_custom_10.png) Sound: adjust the volume (if the recording contains audio)

![](images/drex_kak_rabotat_s_mediafajlami_custom_11.png) Playback speed: slow down or speed up the recording

![](images/drex_kak_rabotat_s_mediafajlami_custom_12.png) Full screen: expand the player to full screen

How to download a video:

1\. Click the download button

### ![](images/drex_kak_rabotat_s_mediafajlami_custom_13.png)

next to the recording

2\. A window for downloading the video opens

![](images/drex_kak_rabotat_s_mediafajlami_custom_14.png)

3\. You can download either the entire video or only the segment you need.

-   To select a segment, specify the start and end time in the calendar ![](images/drex_kak_rabotat_s_mediafajlami_custom_15.png)
    

### ![](images/drex_kak_rabotat_s_mediafajlami_custom_16.png)

3\. Click “Start”

![](images/drex_kak_rabotat_s_mediafajlami_custom_17.png)

Wait while the system prepares the file (the device must be turned on and the recording must still be on the memory card).

While the file is being prepared, a progress indicator is displayed in the window. It contains:

— the amount of data already transferred and the total file size

— the completion percentage

— the current data transfer speed

— the estimated time to completion

For example, the value 7.5 MB / 136.3 MB (5.5%) • 266 KB/s • 8 min means that 7.5 MB of 136.3 MB has been transferred, the download is 5.5% complete, the current speed is 266 KB/s, and about 8 minutes remain.

![](images/drex_kak_rabotat_s_mediafajlami_custom_18.png)

3\. Once the file is prepared, you can download it to your computer: click “Save”

![](images/drex_kak_rabotat_s_mediafajlami_custom_19.png)

### Storage Server tab

This tab contains recordings from the server. Safety-related events (DMS and ADAS) are uploaded to the server, for example:

-   the driver was not wearing a seat belt
    
-   smoking while driving
    
-   lane departure
    
-   signs of fatigue
    

A description is stored for each event, for example: “Seat belt not fastened”, “Driver fatigue”

![](images/drex_kak_rabotat_s_mediafajlami_custom_20.png)

### How to work with media on the server

To view the photo of an event, click the icon![](images/drex_kak_rabotat_s_mediafajlami_custom_21.png) .

![](images/drex_kak_rabotat_s_mediafajlami_custom_22.png)

### Where violations in Storage Server come from

All violations you see on the Storage Server tab are detected by the device itself.

When you create an object and apply a global settings template (for example, for CMS devices), a multi-position Alarm sensor appears in the object.

![](images/drex_kak_rabotat_s_mediafajlami_custom_26.png)

The device sends violation codes, and PILOT automatically maps these codes to the sensor’s calibration table of values.

![](images/drex_kak_rabotat_s_mediafajlami_custom_27.png)

The table translates technical codes into clear statuses, for example:

-   talking on the phone
    
-   unsafe following distance
    
-   smoking while driving
    
-   fatigue
    
-   lane departure
    
-   and other violations
    

![](images/drex_kak_rabotat_s_mediafajlami_custom_28.png)

When the driver commits one of these violations, the device sends the code to the system along with a photo or video. A basic set of violation codes is already built into the calibration table, so the main events are recorded right away, with no additional setup.

## Media files in the object menu

The object menu has a separate “Media” tab.

To open it:

1\. Find the object you need in the list

2\. Right-click it

3\. In the menu that appears, select “Media”

![](images/drex_kak_rabotat_s_mediafajlami_custom_29.png)

The “Media” tab is divided into two parts:

-   Device: recordings stored on the device itself (a dash cam or camera)
    

![](images/drex_kak_rabotat_s_mediafajlami_custom_30.png)

-   Storage Server: recordings stored on the server (for example, recordings of violations)
    

![](images/drex_kak_rabotat_s_mediafajlami_custom_31.png)

For details on what these sections contain and how to work with video, see [above](kak-rabotat-s-mediafajlami.html#Медиа_на_две_части).
