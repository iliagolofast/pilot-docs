The “Drivers” tab in the “Main” section is used to manage drivers in the system.

Here you can:

 — [work with the driver list](kak-rabotat-s-voditelyami-1.html#Как_работать_со_списком_водителей)

— [manage the assignment of drivers to vehicles](kak-rabotat-s-voditelyami-1.html#Как_настроить_привязку_водителей_к_машинам)

## How to work with the driver list

All drivers are displayed as a list on the “Drivers” tab.

![](images/drex_kak_rabotat_s_voditelyami_1_custom.png)

The table shows:

-   Driver name
    
-   Labels (tags)
    
-   The vehicle the driver is currently assigned to
    
-   iButton identification key (if used)
    
-   Other data, depending on the table column settings
    
    ### How to configure table columns
    

You can customize the driver list: select the columns you need and enable sorting and filters.

![](images/drex_kak_rabotat_s_voditelyami_1_custom_2.png)

1\. In the header of any column, click the arrow ![](images/drex_kak_rabotat_s_voditelyami_1_custom_3.png) to open the settings menu

![](images/drex_kak_rabotat_s_voditelyami_1_custom_4.png)

2\. The menu offers:

— sorting data in ascending or descending order

— filtering by the selected column

— selecting the columns to display

3\. To choose which columns to show:

— click “Columns”

— select the check boxes next to the parameters you need; the table updates automatically

### How to open the driver card

To open the driver card for viewing or editing:

1\. Find the driver you need in the list

2\. Double-click the row with the driver’s name

The driver card opens in a separate window.

![](images/drex_kak_rabotat_s_voditelyami_1_custom_5.png)

### Driver groups

![](images/drex_kak_rabotat_s_voditelyami_1_custom_6.png)

![](images/drex_kak_rabotat_s_voditelyami_1_custom_2.png)

The main actions are at the top of the list:

![](images/drex_kak_rabotat_s_voditelyami_1_custom_7.png) Driver assignment: bulk [configuration of driver assignment](kak-rabotat-s-voditelyami-1.html#Как_настроить_привязку_водителей_к_машинам) to vehicles

![](images/drex_kak_rabotat_s_voditelyami_1_custom_8.png) Export drivers: export the list to a file

![](images/drex_kak_rabotat_s_voditelyami_1_custom_9.png) Import drivers: load drivers from a file

![](images/drex_kak_rabotat_s_voditelyami_1_custom_10.png) Add driver: [create a new driver](kak-sozdat-voditelya.html)

![](images/drex_kak_rabotat_s_voditelyami_1_custom_11.png) Refresh list: refresh the data

## How to configure driver assignment to vehicles

To link drivers to vehicles, open the DriversLink window. To do this, on the “Drivers” tab, click the “Assign driver to object” button at the top of the list.

![How to work with drivers](images/drex_kak_rabotat_s_voditelyami_1_screen.png)

In this window you can:

— assign drivers to vehicles

 — configure access to vehicles by ID / iButton

DriversLink lets you not only link a driver and a vehicle but also create an assignment group.

Such a group stores:

— the list of vehicles

— the list of drivers

— the selected access mode

![How to work with drivers](images/drex_kak_rabotat_s_voditelyami_1_screen_2.png)

1\. Select the access mode

![How to work with drivers](images/drex_kak_rabotat_s_voditelyami_1_screen_3.png)

At the top of the window, select the mode you need:

**\[0\] Off**

ID control is disabled. The vehicle is available without driver identification.

**\[1\] Only authorized ID can unlock the vehicle**

Only assigned drivers can use the vehicle.

**\[2\] Any ID can unlock the vehicle**

Any ID can start driving. The system only records who got behind the wheel.

2\. In the “Objects” block, select the check boxes next to the vehicles to which the setting should apply

![](images/drex_kak_rabotat_s_voditelyami_1_custom_12.png)

3\. In the “Drivers” block, select the drivers who are allowed access to the selected vehicles.

If mode \[0\] Off is selected, you do not need to select drivers.

If mode \[1\] or \[2\] is selected, you must assign drivers.

4\. Create an assignment group

After selecting vehicles and drivers:

1) Click “Save”.

2) In the window that appears, enter a group name and click OK.

![](images/drex_kak_rabotat_s_voditelyami_1_custom_13.png)

The group appears in the list on the left. It stores:

— the selected access mode

— the list of vehicles

— the list of drivers

For the selected vehicles, the group name appears in the “Group” column.

![](images/drex_kak_rabotat_s_voditelyami_1_custom_14.png)

5\. Click the “Save” button at the bottom of the window.

The selected settings are then applied to all vehicles in the group.
