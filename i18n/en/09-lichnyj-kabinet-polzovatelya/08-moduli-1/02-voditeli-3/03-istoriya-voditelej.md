title: "Driver history"
---

You can view drivers’ work history in two ways:

— [through the driver card](istoriya-voditelej.html#через_карточку_водителя)

— [through the object menu](istoriya-voditelej.html#через_меню_объекта)

## History in the driver card

In the driver card you can see which vehicles the driver worked on and when.

How to open the history:

1\. In the driver card, go to the “Vehicle” tab

2\. Click the “Show history” button

![Driver history](images/drex_istoriya_voditelej_screen.png)

In the history window you will see:

**![](images/drex_istoriya_voditelej_custom.png)**

-   Period: you can select dates in the calendar and click “Refresh” to see the range you need
    
-   Object: the vehicle the driver is assigned to
    
-   Driver: the driver’s name
    
-   Date and time the assignment started and ended (if the assignment is still active, the “To” field is empty)
    
-   iButton: the code of the key the driver used (if identification is used)
    

![](images/drex_istoriya_voditelej_custom_2.png)  : export the history to a file

![](images/drex_istoriya_voditelej_custom_3.png) : reload the data

![](images/drex_istoriya_voditelej_custom_4.png): delete a specific assignment record

## Driver history through the object menu

This method lets you view the driver history for a specific vehicle and manage the list of drivers allowed to work on it.

How to open the history:

1\. Go to the “Online” tab

2\. Select the object you need

3\. Right-click the object

4\. In the menu that opens, select “Drivers”

## ![](images/drex_istoriya_voditelej_custom_5.png)

The DriversLink window opens. The window is divided into two parts: the left shows the history, the right shows the allowed drivers.

![](images/drex_istoriya_voditelej_custom_6.png)

The left part shows the history of driver assignments to the selected object.

In the history you can see:

-   Period: select dates in the calendar and click “Refresh” to show the range you need.
    
-   Object: the vehicle the driver was assigned to
    
-   Driver: the driver’s name
    
-   Date and time the assignment started and ended (if the assignment is still in effect, the “To” field is empty)
    
-   iButton: the code of the key the driver used (if identification is used)
    

![](images/drex_istoriya_voditelej_custom_2.png)  : export the history to a file

![](images/drex_istoriya_voditelej_custom_3.png) : reload the data

![](images/drex_istoriya_voditelej_custom_4.png): delete a specific assignment record

The right part shows the list of drivers allowed to work on this object.

Select the check boxes next to drivers; they will be considered authorized for this vehicle.

![](images/drex_istoriya_voditelej_custom_7.png)

After selecting, click “Save” to apply the changes.
