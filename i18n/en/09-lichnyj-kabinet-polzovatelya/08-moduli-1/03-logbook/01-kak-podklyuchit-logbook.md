---
title: "How to connect LogBook"
---

To connect LogBook, you need to complete two steps:

-   Activate the LogBook module in the admin panel
    

2\. Connect LogBook in the user interface

## Connecting the LogBook module in the admin panel

-   Log in to the admin panel with your login and password
    
-   Select the contract to which you are connecting the module
    
-   Right-click the contract to open the context menu
    
-   In the menu, select “Edit”
    

![](images/drex_kak_podklyuchit_logbook__custom.png)

 5. In the contract settings window that opens, select the “Module settings” tab

![](images/drex_kak_podklyuchit_logbook__custom_2.png)

6\. Select the drivers module and set the key for it: logbook = 1

7\. After adding the key, click “Update” and save the contract settings.

## Connecting LogBook in the user account interface

-   Go to the user account
    
-   In the “Main” section, go to the “Drivers” tab
    

![](images/drex_kak_podklyuchit_logbook__custom_3.png)

3\. Select the driver you need and open the driver card by double-clicking the driver in the list

![](images/drex_kak_podklyuchit_logbook__custom_4.png)

4\. Enable the LogBook module for the selected driver by selecting the **LogBook Acces** check box

5\. Set the login for the driver’s access to the portal

6\. Click the “Send to driver” button. An email with a link to access the LogBook portal is sent to the address specified in the driver card.
