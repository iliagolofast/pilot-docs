This article explains how to use settings in the LogBook portal. You will be able to:

— configure a [calendar](kak-rabotat-s-nastrojkami-v-logbook.html#календарь_LogBook) with days off for working time tracking

— go to and view the portal [user guide](kak-rabotat-s-nastrojkami-v-logbook.html#Руководство_LogBook_ссылка_на_него)

— [change your password](kak-rabotat-s-nastrojkami-v-logbook.html#смена_пароля_LogBook)

— view the user’s [action history](kak-rabotat-s-nastrojkami-v-logbook.html#Аудит_истории_LogBook) on the portal

![](images/drex_kak_rabotat_s_nastrojkami_v_logbook_custom.png)

## Setting up days off and holidays

So that LogBook correctly identifies trips on days off (for example, marking them as private), you can configure the calendar.

![](images/drex_kak_rabotat_s_nastrojkami_v_logbook_custom_2.png)

### Importing a production calendar

1\. Go to the **Settings** section and select **Holidays**.

2\. In the window that opens, select **Import** ![](images/drex_kak_rabotat_s_nastrojkami_v_logbook_custom_3.png) to automatically load the calendar for the year you need

3\. Enter the following data:

-   **Year**: specify the year for which you want to load the list of holidays
    
-   **Country code (2 letters)**: for example, ZA for South Africa
    

![](images/drex_kak_rabotat_s_nastrojkami_v_logbook_custom_4.png)

4\. Click **Save** to save the data

### Adding a day off manually

1\. Open **Settings** and select **Add** ![](images/drex_kak_rabotat_s_nastrojkami_v_logbook_custom_5.png)

![](images/drex_kak_rabotat_s_nastrojkami_v_logbook_custom_6.png)

2\. Enter information about the day off:

-   **Date**: select the date of the holiday
    
-   **Name**: specify the official name of the holiday
    
-   **Local Name**: what the holiday is called in your language or in your company
    
-   **Type**: the type of holiday (national, regional, corporate, and so on)
    
-   **Launch Year**: specify the year from which this holiday is taken into account
    
    3\. Click **Save**
    

![](images/drex_kak_rabotat_s_nastrojkami_v_logbook_custom_7.png)

## Changing your password

To change your password for logging in to the LogBook portal:

1\. In Settings, select Change password

2\. Enter a new password and repeat it for confirmation

![](images/drex_kak_rabotat_s_nastrojkami_v_logbook_custom_9.png)

3\. Click Save to save the new password

## Viewing the action history

With the Audit function, you can view the history of actions on the portal.

### How to view the action history:

1\. In the Audit window, select:

![](images/drex_kak_rabotat_s_nastrojkami_v_logbook_custom_10.png)

-   Start Date: specify the date from which to show events
    
-   End Date: select the date up to which to show events
    
-   Driver: select the driver or user whose activity you want to track.
    
    2\. Click Show
    

You will then see a list of all actions in the specified period:

-   Date: when the event occurred
    
-   Driver: who performed the action
    
-   Login: which account the action was performed under
    
-   Operation: what exactly was done
    
-   IP: which IP address the action was performed from
    
-   Browser: which browser was used to perform the operation
