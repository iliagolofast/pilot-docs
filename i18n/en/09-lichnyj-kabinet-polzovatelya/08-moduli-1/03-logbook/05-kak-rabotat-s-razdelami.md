## Automatic trip processing

The Auto Process function helps automatically split trips into business and private.

How to set up automatic processing:

-   Click **Auto Process** in the “Trips” section
    

2\. In the window that appears, select the period to which you want to apply automatic processing:

-   Current Month: if you select this option, the system automatically processes trips for the current calendar month
    

![](images/drex_kak_rabotat_s_razdelami_custom_2.png)

-   Select date range: if you want to process trips for a specific period, select the dates using the calendar.
    

![](images/drex_kak_rabotat_s_razdelami_custom_3.png)

Specify:

-   **Start Date**: the date from which to start automatic processing
    
-   **End Date**: the date up to which to apply it
    

3\. Specify the standard working hours in the fields:

-   **Start Work**: specify the time from which trips are considered business trips. For example, 08:00.
    
-   **End Work**: specify the time after which trips are considered private. For example, 19:00.
    

All trips that take place between Start Work and End Work are automatically marked as Business

Trips before **Start Work**, after **End Work**, and on days off (if configured) are automatically classified as Private

4\. When all settings are specified, click **Save** to apply automatic processing

## Current object position

The Show current position function displays the object’s current location on the map.

![](images/drex_kak_rabotat_s_razdelami_custom_4.png)

When working with the map, you can use the following tools:

### Changing the zoom

There are several ways to change the map zoom:

1\. Buttons on the map toolbar ![](images/drex_kak_rabotat_s_razdelami_custom_5.png) and ![](images/drex_kak_rabotat_s_razdelami_custom_6.png)

In the upper-left part of the map there are buttons for quickly zooming in and out. When you click the buttons, the map zooms in or out, but the point that was in the center stays in place. 

2\. Mouse scroll wheel

Scroll the mouse wheel: away from you to zoom in, toward you to zoom out. The cursor indicates which area you want to look at in more detail.

3\. Double-click

Double-click the left mouse button at any point on the map, and it zooms in right away.

### Printing the map

This function prints the current map view. When you click the print button ![](images/drex_kak_rabotat_s_razdelami_custom_7.png), four print orientation options are offered:

1\. Landscape: the map is printed in horizontal orientation. This orientation is convenient for displaying extended areas or objects arranged horizontally.

2\. Portrait: the map is printed in vertical orientation. This format suits areas that are elongated vertically.

3\. Auto: the system automatically selects the optimal print orientation depending on the current map view and its proportions.

4\. Custom area: select this option if you want to print only a specific area of the map. To do this, select the part of the map you need with the mouse, and it is sent to print.

### Measuring the distance between points

This tool helps you calculate distances between any points on the map.

 How to use it:

-   Click on the map to mark the first point
    
    2\. Click again to mark the second point
    
    3\. A line with the distance appears between the points
    
    If you need to measure several segments, keep clicking on the map to add new points. The length of each segment is shown next to it.

### Street view

The street view function lets you see panoramic photos of the area.

Available viewing options:

-   GSV: panoramic images from Google with high image quality and wide coverage
    
-   OSC: panoramas created by the user community. They may contain more recent images in some areas
    

To enable street view:

1\. Select the check box for this option in the upper-right part of the map

2\. Drag the yellow figure on the map to the place you want

3\. Select the viewing option you want: GSV or OSC

![](images/drex_kak_rabotat_s_razdelami_custom_9.png)

4\. After you select one of the options, the corresponding panorama service opens, where you can view interactive panoramas of the selected area.

### Traffic view

The traffic view function shows current road congestion using color coding:

-   Green: free-flowing traffic
    
-   Yellow: moderate congestion
    
-   Red: heavy congestion
    

To enable traffic display, select the check box for this option in the upper-right part of the map.

![](images/drex_kak_rabotat_s_razdelami_custom_10.png)

### Selecting a map

You can choose from several map types to display the area in the LogBook interface. The map type is the base layer of the map image used in the monitoring system to display spatial data. To change the map, click the map selection button ![](images/drex_kak_rabotat_s_razdelami_custom_11.png).

![](images/drex_kak_rabotat_s_razdelami_custom_12.png)

### Object tooltip

The tooltip appears when you have enabled the Show current position function and clicked an object on the map. It is intended to provide information about the vehicle’s state in real time.

![](images/drex_kak_rabotat_s_razdelami_custom_13.png)

## Editing locations

The **Edit locations** function lets you refine the addresses of the trip start and end and set the type of these points.

![How to work with sections](images/drex_kak_rabotat_s_razdelami_screen_2.png)

How to edit a location:

1\. Select a trip from the list in the Trips section

2\. Click the Edit locations button

3\. Select the check box for what you want to edit: **Start Location** or **End Location**

-   Start Location – the address where the trip starts
    
-   End Location – the address where the trip ends
    
    Edit the address.
    

![](images/drex_kak_rabotat_s_razdelami_custom_14.png)

3\. Select **Type** (the place type): in this field you can specify what kind of place is at the start or end of the trip, for example: Home, Office, Client,

4\. If necessary, set **Radius**. It defines the area around the place (in meters) within which the vehicle is considered to be at the specified point.

5\. Click Save to save all changes

## Reports

With the Reports function you can save information about trips for the selected period to PDF or Excel.

How to create a report:

1\. In the “Trips” section, select the **Reports** function

![](images/drex_kak_rabotat_s_razdelami_custom_15.png)

2\. Click the down arrow to open the format selection menu.

3\. Select the file format to save: PDF or Excel

## Selecting the trip type

In the “Trips” section you can manage which trips are shown in the list.

To do this, select the check boxes next to the Business or Private types to filter the list display for your tasks.

-   Business – the trip is related to work tasks
    
-   Private – the trip was personal

### How to change the trip type

You can change the purpose of any trip: business or private.

To change the type:

1\. Find the trip you need in the list

2\. Click the change type button ![](images/drex_kak_rabotat_s_razdelami_custom_16.png)

![](images/drex_kak_rabotat_s_razdelami_custom_17.png)

3\. The trip type is updated; for example, a private trip becomes a business trip

### How to edit a business trip

Extended editing is available for business trips:

-   To open the details, click the edit icon next to the trip you need ![](images/drex_kak_rabotat_s_razdelami_custom_18.png)
    

2\. At the top of the window you will see the trip date and time

![](images/drex_kak_rabotat_s_razdelami_custom_19.png)

This form helps you describe the business trip in detail:

-   Reason for trip: select a reason, for example: work, delivery, repair
    
-   Reason Desc: you can briefly describe the purpose of the trip
    
-   Contact Name: the person you were traveling to see
    
-   Contact Details: phone, email, or other contact information.
    
-   Company Name: the name of the client’s or partner’s organization
    
-   Reference number: the task number
    
-   Assign same reason to all end locations: if you select the check box, the selected reason and the entered data are automatically applied to all trips that end at the same point
    

3\. Click **Save** to apply the changes

## Events

In the **Events** section you can track events related to trips, such as:

— when the object left on a route or returned

— when a refuel took place

— when speeding occurred, a sensor was triggered, and so on

Events can be not only viewed as a list but also displayed directly on the map, which helps you better understand where and under what conditions they occurred.

![](images/drex_kak_rabotat_s_razdelami_custom_20.png)

### How to view events

-   Go to the Events section.
    
    On the left you will see a list of event groups (Battery, Eco Driving, Fillings, Speed violations, and others); these are the available event types
    
    2\. Select the events you need using the check boxes, for example, Fillings (refuels), Speed violations, Ignition (ignition on/off).
    
    ![How to work with sections](images/drex_kak_rabotat_s_razdelami_screen_4.png)
    
    3\. Click the **Show** button ![](images/drex_kak_rabotat_s_razdelami_custom_21.png)
    
    ### How to view events on the map
    
-   Select one or more events in the list
    
-   Click **Show on map**
    
    ![How to work with sections](images/drex_kak_rabotat_s_razdelami_screen_4.png)
    

The selected events appear on the map as icons at the places where they occurred.

![How to work with sections](images/drex_kak_rabotat_s_razdelami_screen_5.png)

At the bottom of the map there is a player that you can use to view the route and events that occur during trips.

# Fuel

The **Fuel** section displays all fuel-related transactions for the selected vehicle and period.

Here you can:

-   see the total fuel expenses for the selected period
    
-   view fuel card transactions:
    
    — refuel date and time
    
    — fuel volume
    
    — the amount charged for each operation
    
    — refuel location (gas station)
    

### How to view fuel transactions

1\. In the left LogBook panel, select the **From / To** period and **Vehicle**

2\. Go to the **Fuel** section

3\. Click **Refresh** to load all fuel operations for the specified period. All transactions are displayed in the list

![](images/drex_kak_rabotat_s_razdelami_custom_26.png)

# Media

The Media section is for working with video and photos from the vehicle’s on-board cameras.

To search for media files, you can use the filters at the top of the screen:

-   Evidence Type
    

— All – all media files are shown without restriction

— Investigate – materials for reviews and investigations (accidents)

— Trainable – recordings that can be used to train drivers

— Vault – important materials placed in the “archive” that require long-term storage

— Custom – custom materials with an arbitrary category

-   Sub Category: select a subcategory to filter by (for example, NTF, FTI, and so on).
    
-   Description: enter part of the text found in the Description column of the media files
    

After selecting the values you need in the filters, click **Refresh** to load the list of media matching your parameters.

For each media file, the list shows:

-   Date: when the recording was made
    
-   Group
    
-   Vehicle: the number or ID of the vehicle the file was received from
    
-   Driver: who was driving the vehicle at the time of recording
    
-   Channel: which camera the file came from (front, cabin, and so on)
    
-   Alarm: the event for which the file was saved (for example, hard braking, speeding, SOS press).
    
-   Type: the material format
    
-   Category
    
-   Description: a brief explanation of what is shown in the recording or why it was made
    
-   Location: where the recording was made: an address or coordinates on the map
