title: "Points of interest"
---

The “Points of interest” module helps you mark places that are important to you on the map. These can be offices, warehouses, service points, parking lots, anything you need to monitor.

### How to work with the module:

• Mark important places on the map with exact GPS coordinates

• Use different icons to see the type of object at a glance

• Add descriptions to each point

• Group points by purpose

• Save and load data in Excel

![](images/drex_tochki_interesa_custom.png)

### Access rights

To work with the module, you can configure access rights for each user. This lets you separate employee roles and protect points of interest from unwanted changes.

To configure rights:

1\. Go to “Contract settings”

2\. Open the [“Personnel and groups”](../nastrojki-dogovora-2/personal-i-gruppy/index.html) tab

3\. Select the user you need and double-click the user

4\. In the user card, go to the [“Rights”](../nastrojki-dogovora-2/personal-i-gruppy/index.html#права_доступа) tab

5\. Find the “Points of interest” (PoI) module and select the check boxes for the permissions you need:

![](images/drex_tochki_interesa_custom_2.png)

-   Add own POI: create your own points of interest, available only to this user
    
-   Read non-own POI: view points created by other users
    
-   Edit non-own POI: edit points created by other users
    
-   Delete non-own POI: delete points created by other users
    

Each user can create private POIs and at the same time work with shared points according to the assigned rights, which keeps work with the map organized.

### How to add a point:

1\. Click the “Add point” button ![](images/drex_tochki_interesa_custom_3.png)

2\. In the window that opens, fill in the information:

![](images/drex_tochki_interesa_custom_4.png)

— enter the point name

— write a description

— select a suitable icon and color

— specify the group the point will belong to

— set the latitude and longitude, or click on the map to specify the point’s location

![](images/drex_tochki_interesa_custom_5.png)

3\. Click “Save”

### How to edit a point:

1\. Double-click the point’s entry in the list

2\. In the window that opens, edit the information you need

![](images/drex_tochki_interesa_custom_6.png)

3\. Click “Save”

### Saving and loading data

• To save all points to an Excel file, click the download button ![](images/drex_tochki_interesa_custom_7.png)

• To load points from an Excel file, click the upload button ![](images/drex_tochki_interesa_custom_8.png)

• To refresh the list of points, click the refresh button ![](images/drex_tochki_interesa_custom_9.png)

### Working with the map

Select points in the list, and they are displayed on the map with the icons you chose.

![](images/drex_tochki_interesa_custom_10.png)

Click a point to see its description.

![](images/drex_tochki_interesa_custom_11.png)

Use the map tools to work with points. For example, measure distances between them or calculate road distances to plan routes.

![](images/drex_tochki_interesa_custom_12.png)
