You can configure how events are displayed in the “Control room”: set groups, colors, and processing statuses.

1\. Go to “Contract settings”

2\. Open the “Control room” tab

## Event group settings

On the left is the list of event groups coming from the “Control room” (for example: Observation, Arming/Disarming, RFID Antenna, and others).

![](images/drex_kak_nastroit_parametry_sobytij_custom_2.png)

Each row is a separate event group. For it you can configure:

-   Group color: select a color from the list. The color helps you identify the event type, for example, blue for observation, red for alarms
    
-   “Alarm” type: select the check box if events of this group should be considered alarms
    

The trash icon ![](images/drex_kak_nastroit_parametry_sobytij_custom_3.png) deletes a group if it is no longer needed.

How to add an event group:

-   Click the “Add” button at the bottom of the event list
    
-   Select a color for the new group
    
-   If necessary, select the “Alarm” type
    

After saving, the new group immediately appears in the list and starts being used in the “Control room”.

## Stage color settings

On the right you choose the color used to show the event state. The color helps you understand what is currently happening with the event.

![](images/drex_kak_nastroit_parametry_sobytij_custom_4.png)

-   In progress: the event is being processed
    
-   Unprocessed: a new event
    
-   Processed: events that the algorithm and the operator have already handled
    
-   Unprocessed (timer expired): the event was not processed in time
    

To set a color, select it from the drop-down list.
