title: "Control room"
---

The “Control room” module is designed for monitoring and managing object parameters in the system. It helps you track events related to objects and simplifies working with notifications and event-handling algorithms. With this module you can not only receive notifications about events but also configure exactly what the system should do when such an event occurs.

<table><tbody><tr><td><span></span></td><td><div>The module was previously called GARM. This name may still appear in some places in the interface.</div><div>The new name, “Control room”, is now in use and will eventually replace the old one completely.</div></td></tr></tbody></table>

## Main functions of the module:

### Event monitoring

The system tracks events related to objects and notifies you about them, for example, when parameters deviate or a state changes.

### Event-handling algorithms

You can configure action scenarios that the system performs automatically when an event occurs, for example, sends a notification, records data, creates a command, and so on.

### Notification management

You define which events trigger notifications, who they are sent to, and which handling algorithm is used.
