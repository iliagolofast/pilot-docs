---
title: "How to view the history of Velavu objects"
---

On the “History” tab, you can view the history of Velavu objects for a selected period.

You can:

— see where an object was at a specific moment

— see which room it was in

— trace the movement of the object on the map

## How to open the Velavu history

1\. Go to the “History” tab

![](images/drex_kak_prosmotret_istoriyu_obektov_velavu_custom.png)

2\. In the “View” field, select Velavu mode

![](images/drex_kak_prosmotret_istoriyu_obektov_velavu_custom_2.png)

3\. Specify:

-   Period from
    
-   Period to
    
    4\. In the “Objects” field, select one or more Velavu objects whose history you want to view
    

![](images/drex_kak_prosmotret_istoriyu_obektov_velavu_custom_3.png)

After that, records for the selected objects appear in the table below.

![](images/drex_kak_prosmotret_istoriyu_obektov_velavu_custom_4.png)

The following columns are usually displayed for each record:

-   Name — the Velavu object name
    
-   RFID — if RFID data is available
    
-   Type — the object type, for example: Anchor (ANCHOR) or tag (TAG)
    
-   Date — the date and time of the record
    
-   Building — the building the record relates to
    
-   Floor — the floor where the object was located
    
-   Duration — how long the object stayed in this state or place
    
-   Sensor — related sensor data, if any
    
-   Actions — buttons for viewing and playback
    

You can customize which columns are displayed:

1\. In the header of any column, click the arrow ![](images/drex_kak_prosmotret_istoriyu_obektov_velavu_custom_5.png). A menu with column settings appears, where you can:

• Sort the data in ascending or descending order

• Choose which columns to show on the screen

2\. To choose which columns to show:

-   Click “Columns” — a list of parameters available for display in the list opens
    
-   Select the check boxes next to the parameters you want to see
    

![](images/drex_kak_prosmotret_istoriyu_obektov_velavu_custom_6.png)

## What you can do in the history

### 1\. View records by object

The history is grouped by each selected object.

For each object, you can expand the list of records and view its history over time.

### 2\. View the object on the map

If you select a record in the list, a map is displayed on the right. On the map, you will see the position of the object at the time of the record

![](images/drex_kak_prosmotret_istoriyu_obektov_velavu_custom_7.png)

### 3\. Play back movements

Next to each device there is a player — a play button ![](images/drex_kak_prosmotret_istoriyu_obektov_velavu_custom_8.png) and a slider.

With the player, you can see how the device moved around the site over time

### 4\. View the device card

Next to each record there is an icon ![](images/drex_kak_prosmotret_istoriyu_obektov_velavu_custom_9.png). Click it to open the Velavu device card.

The card opens with exactly the data that was present when the record was created.

![](images/drex_kak_prosmotret_istoriyu_obektov_velavu_custom_10.png)
