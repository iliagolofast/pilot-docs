# Statistics are displayed for the last 24 hours.

-   Open the Dashboard tab.
    
-   Select an object from the list.
    
-   Select a date.
    
-   View the vehicle info block.
    

Reports are not provided in the Analytics module.

![](images/drex_analitika__custom.png)

<table><tbody><tr><td><span></span></td><td><div>&nbsp;</div><div><span>Important! Depending on the connected modules, for example Eco-driving, the PTM module, or geofence violations, these values will also be shown in charts on the corresponding topics.</span></div></td></tr></tbody></table>

![](images/drex_analitika__custom_2.png)

From the geofence block, you can jump to the “Online” tab, where the vehicles located in the specified geofences are highlighted in the object tree.

**How do I display the objects?**

-   Click the bar representing the geofence.
    
-   Right-click to open the menu. “Show vehicles on the main map”.
    
    • Only the objects located in this zone will be highlighted in the object tree.
    

Return to the module in the usual way.

![](images/drex_analitika__custom_3.png)

In this example, all 6 objects that the system highlighted for this geofence are displayed.

![](images/drex_analitika__custom_4.png)

Data refresh button.

![](images/drex_analitika__custom_5.png)

Select a template

A user can create their own profile and set it as the default.

The system administrator can create a profile and set it as the default for a partner account. In this case, all users will see this profile as the default profile.

![](images/drex_analitika__custom_6.png)

Create a template

After selecting the additional parameters, click “Save as new”.

![](images/drex_analitika__custom_7.png)

 Right-click a chart, and the system will offer several reports to generate.

![](images/drex_analitika__custom_8.png)

To return to Analytics, click “Back”.

![](images/drex_analitika__custom_9.png)

<table><tbody><tr><td><span></span></td><td><div><span>Generate reports on the corresponding topics, for example, reports related to mileage, fuel consumption, and machinery operation.</span></div></td></tr></tbody></table>

**For example, for the Mileage chart you can generate the following reports:**

-   Mileage report.
    
-   Mileage report No. 2.
    
-   Mileage with drivers.
    

![](images/drex_analitika__custom_10.png)

The reports will be generated on the regular “Reports” tab with all the details on duration, distance, address, and other fields.

![](images/drex_analitika__custom_11.png)
