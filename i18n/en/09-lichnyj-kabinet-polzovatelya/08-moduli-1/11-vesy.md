title: "Scales"
---

The “Scales” module automatically determines the weight of cargo using sensors installed on vehicles.

With the module, you can:

— monitor the weight of vehicles

— add and configure weighing checkpoints

— see the history of all weighings

— keep records of transported materials

— export weighing data for reports

![](images/drex_vesy_custom.png)

## How it works

1\. Scale sensors that transmit data to PILOT are installed on the vehicle

2\. A weighing checkpoint is created on the map

3\. When an empty vehicle crosses the checkpoint, PILOT records the current weight

4\. After a material, for example crushed stone, sand, or grain, is loaded, the object crosses the checkpoint again

5\. The system records the new weight and calculates the cargo mass

## How to add scales

1\. Go to the “Main” section and select the “Scales” tab

![Scales](images/drex_vesy_screen.png)

2\. Click the “Add” button

3\. Fill in the fields in the window that appears:

![](images/drex_vesy_custom_2.png)

-   ID — the unique identifier of the scales
    
-   Scales name
    
-   Description — additional information about the scales
    
-   Latitude and longitude  — the coordinates of the scales location
    
    4\. Click “Save”
    

![](images/drex_vesy_custom_3.png)

The new scales are added to the scales list. If the new scales do not appear in the list, click “Refresh”.

![Scales](images/drex_vesy_screen_2.png)

To change the scales parameters, double-click the scales in the list with the left mouse button — a window with the parameters opens. Edit the required fields and save the changes.

## Weighing history

To view the weighing history for specific scales, click the “History” icon in the scales list.

![Scales](images/drex_vesy_screen_3.png)

Here you will see data on all weighings with information about vehicles and cargo:

![Scales](images/drex_vesy_screen_4.png)

-   Vehicle number
    
-   Vehicle type
    
-   First time and second time — entry and exit time
    
-   First weight and second weight — the weight before and after weighing
    
-   Cargo type, for example, “Crushed stone 5-20”
    
-   Client name
    
    To save the weighing information, click the “Export” button ![](images/drex_vesy_custom_4.png) — the data is saved in CSV format.
