---
title: "Importing and exporting zones in KML format"
---

For convenient work with geofences, you can load them into the monitoring system from files or, conversely, save the geofences you created to a file to copy or transfer to other devices.

![Importing and exporting zones in KML format](images/drex_import_i_ehksport_zon_v_formate_kml_screen.png)

### Importing geofences

With import, you can add to the system geofences that were created in advance or obtained from other sources.

1\. Go to the “Geofences” tab

2\. Click the “Import” button ![](images/drex_import_i_ehksport_zon_v_formate_kml_custom.png)

3\. Select a KML or KMZ file on your computer

<table><tbody><tr><td><span></span></td><td><div>KML or&nbsp;KMZ&nbsp; is a special file format for storing geographic data such as points, lines, and areas on a map.</div></td></tr></tbody></table>

4\. Specify the group to load the geofences into

5\. Confirm the import — the selected geofences appear in the list and are displayed on the map

### Exporting geofences

Export saves geofences to a file so you can use them in other systems.

-   On the “Geofences” tab, select the check boxes next to the geofences you want to save
    
    2\. Click the “Export” button ![](images/drex_import_i_ehksport_zon_v_formate_kml_custom_2.png)
    
    3\. Select the file format — KML or KMZ
    
    4\. Specify the group the geofences will be exported from
    
    5\. Save the resulting file to your device
