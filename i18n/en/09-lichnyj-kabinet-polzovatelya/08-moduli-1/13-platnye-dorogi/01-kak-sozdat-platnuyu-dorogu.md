---
title: "How to create a toll road"
---

If the route of a monitoring object includes sections with tolls, you can account for them in the system using the “Toll roads” function.

How to create a toll road:

1\. Create a geofence of the “Polyline” type

![](images/drex_kak_sozdat_platnuyu_dorogu_custom.png)

2.  Draw on the map the road section that will be tolled. Mark two or more points on the map to build the segment or route you need.

![](images/drex_kak_sozdat_platnuyu_dorogu_custom_2.png)

3\. Select the “Toll road” check box

When creating the zone, select the “Toll road” option so that the system knows this road section is tolled.

![How to create a toll road](images/drex_kak_sozdat_platnuyu_dorogu_screen.png)

3\. Configure the line color and width

4\. Click “Save” — the toll road appears in the zone list
