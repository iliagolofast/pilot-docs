---
title: "Settings"
---

-   Default value - these parameters set the loading and unloading parameters.
    
-   Geocoder settings - this setting lets you select the geocoder.
    
-   Task type setting - in this parameter, select the default task type from the drop-down list.
    
-   Speed coefficients - this field is used to specify the speed coefficient by day of the week and time.
