**Data retransmission**.

This is the process of transferring data from one source to another in real time, often through intermediate servers or nodes.

Here you can create any number of relays that forward messages from selected objects to other systems. A relay can be paused or resumed at any time.

• Open the Online tab.

• Open the object's context menu.

• Select **Relay list**.

-   \+ Start filling in the fields.
    

![](images/drex_retranslyatsiya_obektov_custom.png)

![](images/drex_retranslyatsiya_obektov_custom_2.png)

-   **Host** - the host address for retransmitting data over the specified protocol (as an IP address or a domain name).
    
-   **Port** - the port to which data is retransmitted over the specified protocol.
    
-   **Format** \- the retransmission format (select from the drop-down list).
    
-   **External ID** \- the retransmission identifier of a single monitoring object (the imei block is usually used).
    
-   **Path -** when a domain name is used, this field contains additional parameters.
    
-   **USPW** - if authentication is required, this field contains the user name and password.
    
-   **Time zone** - specifies the time zone in GMT format.
    
-   **Speed control** - speed control in km/h.
    
-   **Enabled** - the current status.
    
-   **Json conf** - a window for adding a configuration.
    
-   **Comment** - additional information about the retransmission.

**SAW retransmission**

SAW retransmission is a system used to forward alarm signals and warnings from one device to another. This kind of retransmission ensures reliable delivery of critical notifications, especially in situations where a direct connection may be unreliable or impossible.

-   Activate the module through the Admin panel.
    

**![](images/drex_retranslyatsiya_obektov_custom_3.png)**

• Go to the user interface, to the object menu.

![](images/drex_retranslyatsiya_obektov_custom_4.png)

-    Open and fill in the retransmission window.
