On the “Services” tab, you can keep records of all service work, and create templates and reminders. Let's see how to work with it:

![](images/drex_servisy_custom.png)

-   [All services](servisy.html#Все_сервисы)
    

All created service records are displayed here. You can:

— work with the list of service records

— create a new service record

— add service objects

— add completed works and parts

— create a service reminder

— add files

— use additional functions in a service record

-   [Templates](servisy.html#Шаблоны_сервисов)
    

Templates help you quickly create standard service records. Here you will learn:

— where saved service templates are stored

— how to create and apply a template

-   [Reminders](servisy.html#Напоминания_вкладка)
    

Keep track of upcoming services and do not miss important dates. You can:

— edit reminders

— change their status

### How to create a service record

1\. Click the “Create service” button![](images/drex_servisy_custom_10.png)

2\. In the window that opens, fill in the service information

![](images/drex_servisy_custom_11.png)

 General information:

-   Template — select a template to fill in the fields automatically. To learn how to create a service template, see [here](servisy.html#Шаблоны_сервисов)
    
-   Event type — specify whether this maintenance is one-time or recurring
    
-   Service name — enter the name
    
-   Supplier — select from the drop-down list. To learn how to add a supplier, see [below](servisy.html#добавить_поставщика)
    
-   Maintenance status — mark whether it is completed or not
    
-   Invoice number — enter a number, for example, an invoice or an internal document number
    
-   Service type — select from the list
    
-   Date and time — specify when the maintenance was or will be performed
    
-   Comment — add an explanation if necessary
    

![](images/drex_servisy_custom_12.png)

### Creating reminders

In the “Reminders” section, set up automatic service reminders.

![](images/drex_servisy_custom_31.png)

How to create a reminder:

1\. Go to the “Reminders” section

2\. Click “Add reminder” ![](images/drex_servisy_custom_16.png)

3\. In the new window, specify:

![](images/drex_servisy_custom_32.png)

-   Reminder name
    
-   Service date
    

Optionally, you can specify:

-   Repeat interval — how often the reminder should repeat
    
-   How many days before the event to remind — for example, 2 days before
    
-   Mileage or engine hours
    
-   Mileage or engine hours interval 
    
-   Reminder delivery method — email and others
    

<table><tbody><tr><td><span></span></td><td><div>To receive reminders by email, confirm it in <a href="../../nastrojki-dogovora-2/privatnost.html#Электронная_почта"><span>“Privacy”</span></a>.</div></td></tr></tbody></table>

-   Reminder text:
    
    — specify the reminder subject — what exactly the notification should be about
    
    — write a title for your reminder — what will be written at the top of the message
    
    — create the reminder text with automatic data substitution. To do this, use variables:    
    

%current\_time% — current time 

%reminder\_name% — reminder name

%current\_moto% — current mileage

%current\_mil% — current mileage in miles

%agent\_id% — account number

%vehicle\_name% — vehicle name

%driver\_name% — driver name

These variables are automatically replaced with real data when the message is sent.

For example: Scheduled maintenance of %vehicle\_name% is set for %current\_time% 

4\. Click “Save” — the reminder is created and appears in the general list

![](images/drex_servisy_custom_33.png)

## Templates

The “Templates” tab stores all saved service maintenance templates. Templates help you quickly create new service records without filling in all the information again.

![](images/drex_servisy_custom_46.png)

### How to create a template

1\. [Create](servisy.html#как_создать_сервисную_запись) a new service maintenance record or open an existing one

2\. In the service record, click the three-dot menu ![](images/drex_servisy_custom_44.png) and select “Create template”

![](images/drex_servisy_custom_47.png)

3\. In the new window, enter the template name

![](images/drex_servisy_custom_48.png)

4\. If you wish, select from the list the make, model, and modification of the vehicle the template will apply to.

![](images/drex_servisy_custom_49.png)

If the make you need is not in the list, you can add it: click ![](images/drex_servisy_custom_50.png), enter the make name, and click “OK”.

![](images/drex_servisy_custom_51.png)

5\. Click “Save” — the template appears on the “Templates” tab

### How to edit a template

To change a template:

1\. Go to the “Templates” tab

2\. Double-click the template you need

![](images/drex_servisy_custom_52.png)

3\. In the window that appears, edit the name, make, or model of the vehicle

![](images/drex_servisy_custom_53.png)

4\. Click “Save”

### How to delete a template

To delete a template, click the icon ![](images/drex_servisy_custom_54.png) next to the template record in the list.

![](images/drex_servisy_custom_46.png)

### How to apply a template

1\. On the “All services” tab, click the “Create service” button

![](images/drex_servisy_custom_55.png)

2\. In the new record creation window, select the template you need

![](images/drex_servisy_custom_56.png)

3\. After you select the template, all saved details are automatically added to the record: parts, works, reminders (if they were specified in the template)

4\. All that remains is to select the objects and the date and time of the service

5\. Click “Save” — the new service record created from the template appears in the service list

![](images/drex_servisy_custom_57.png)
