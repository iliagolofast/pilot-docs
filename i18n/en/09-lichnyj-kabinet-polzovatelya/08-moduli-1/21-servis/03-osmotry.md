Inspections are a tool for convenient and systematic checks of vehicle condition:

— create inspection templates with the questions you need

— plan and carry out inspections

— record what was checked and in what condition

— identify problems in advance to prevent downtime

![](images/drex_osmotry_custom.png)

The tab consists of two parts:

-   Forms — create inspection templates
    
-   Completed — carry out inspections and view the results
    
    ## Forms
    

Here you create inspection templates — blanks with questions that the check will follow.

You can create forms for:

-   Scheduled technical inspection
    
-   Pre-trip check
    
-   Acceptance inspection
    
-   Unscheduled check
    

You can have as many forms as you like, one for each case.

![](images/drex_osmotry_custom_2.png)

### How to create an inspection form

-   Click the “Create form” button ![](images/drex_osmotry_custom_3.png)
    
    2\. You go to the form creation window. Here you need to fill in two blocks:
    
-   General information
    
-   Questions
    
    3\. When everything is ready, click the “Save” icon in the upper-right corner
    

To edit an inspection form, double-click the form in the list. A window opens where you can change the general information and questions.

To delete a form from the list, click ![](images/drex_osmotry_custom_4.png).

### General information

This is the form header. Fill it in as follows:

1\. Inspection name — for example, “Pre-trip inspection”

2\. Comment — write when and how to use the form. Example: “The inspection is carried out before departure. Pay special attention to the brakes and lighting”

3\. Signature — select the check box if you want the inspector (the person carrying out the inspection) to sign the form to certify the inspection.

![](images/drex_osmotry_custom_5.png)

![](images/drex_osmotry_custom_6.png)

### Questions

Now let's add the questions the inspection will follow.

### How to add a question

1\. Click “Create question” ![](images/drex_osmotry_custom_3.png)

2\. In the window that opens, fill in:

![](images/drex_osmotry_custom_7.png)

-   Question title — brief and clear (for example, “Brake operation”)
    
-   Comment — an explanation of what exactly needs to be checked
    
    3\. Configure the additional functions:
    
-   Add comment — if you need to leave a text comment when answering
    
-   Allow skip — if the question may be left unanswered
    
-   Add photo — if you need to attach a photo to the question
    
-   Photo required — if a photo is required for the answer
    
-   Button names:
    
-   For a positive answer (for example, “Yes”, “OK”)
    
-   For a negative answer (for example, “No”, “Not working”)
    
-   If skipping is allowed, also specify a name for the skip button (for example, “Skip”)
    

![](images/drex_osmotry_custom_8.png)

4\. Click “Save”

For example, a completed question may look like this

![](images/drex_osmotry_custom_9.png)

As soon as you save the question, it appears in the new inspection form.

![](images/drex_osmotry_custom_10.png)

To edit a question, double-click it. To delete it, click ![](images/drex_osmotry_custom_4.png) next to the question.

## Completed

All inspections that have been carried out are displayed here.

You can see:

-   Which object was inspected
    
-   Which form was used
    
-   Who carried out the inspection
    
-   When it was carried out
    
-   How many questions were completed
    
-   Which ones were skipped
    

![](images/drex_osmotry_custom_13.png)

To work with completed inspections, use the icons in the list:

![](images/drex_osmotry_custom_14.png)  — delete the inspection record

![](images/drex_osmotry_custom_15.png) — print the completed inspection form

![](images/drex_osmotry_custom_16.png) — download the inspection form

### How to view details

Double-click the inspection you need — the completed form opens.

![](images/drex_osmotry_custom_17.png)

Here you can:

-   View all answers
    
-   If necessary, correct erroneous answers
    

### How to carry out an inspection

-   On the “Completed” tab, click “Create inspection” ![](images/drex_osmotry_custom_3.png)
    
    2.  In the window that opens, select:
    
    ![](images/drex_osmotry_custom_18.png)
    
-   The inspection form (created earlier)
    
-   The object (vehicle)
    

![](images/drex_osmotry_custom_19.png)

3\. Click “Continue” — the form with questions opens

![](images/drex_osmotry_custom_20.png)

4\. Answer the questions:

-   Select an answer
    
-   If necessary, add a photo and a comment
    
    5\. Sign the inspection:
    
-   Use the mouse or a stylus to sign
    
-   If it did not work, click “Clear” ![](images/drex_osmotry_custom_21.png) and try again
    

![](images/drex_osmotry_custom_22.png)

6\. Click “Done” — the inspection appears in the list of completed ones
