title: "Directories"
---

Directories are a tool similar to a database that you can use when creating service records.

Instead of entering the same data manually each time, you save it here once in advance and then simply select it from a list.

You can create and store information about:

-   [Suppliers and manufacturers](spravochniki-1.html#поставщики)
    
-   [Service types](spravochniki-1.html#тип_сервсиного_обслуживания_как_создать)
    
-   [Works](spravochniki-1.html#работы_в_сервисе)
    
-   [Parts](spravochniki-1.html#запчасти)
    
    ## Suppliers
    

This is where data about parts suppliers or manufacturers is stored. You decide how to use this information — for yourself, for accounting, for contact.

![](images/drex_spravochniki_1_custom.png)

### How to add a supplier

1\. Go to the “Suppliers” tab

2\. Click  ![](images/drex_spravochniki_1_custom_2.png)

3\. In the window that opens, enter:

-   Company name
    
-   Phone
    
-   Email
    
-   Address
    

![](images/drex_spravochniki_1_custom_3.png)

![](images/drex_spravochniki_1_custom_4.png)

4\. Click “Save” — the supplier appears in the general list

### How to edit or delete a supplier

To edit, double-click the record, change the data, and save.

To delete, click the icon ![](images/drex_spravochniki_1_custom_5.png) next to the record.

## Service types

Here you create service maintenance types.

## ![](images/drex_spravochniki_1_custom_6.png)

### How to add a service maintenance type

1\. Go to the “Service types” tab

2\. Click ![](images/drex_spravochniki_1_custom_2.png)

3\. In the new window:

-   Enter the type name (for example, “Maintenance-2”)
    
-   Select a category:
    
-   Service (for example, scheduled maintenance)
    
-   Work (an action — replacement, repair)
    
-   Material (consumables, parts)
    

![](images/drex_spravochniki_1_custom_7.png)

![](images/drex_spravochniki_1_custom_8.png)

4\. Click “Save” — the service type appears in the general list

### How to edit or delete

Double-click the record to edit it.

Click the icon ![](images/drex_spravochniki_1_custom_5.png) to delete the service type record from the list

## Works

On the “Works” tab, create and store a list of all works that you can quickly select when adding a service record.

![](images/drex_spravochniki_1_custom_9.png)

### How to add a work item

1\. Go to the “Works” tab

2\. Click ![](images/drex_spravochniki_1_custom_2.png)

3. In the window that opens, fill in:

![](images/drex_spravochniki_1_custom_10.png)

-   Work name — for example, “Brake pad replacement”
    
-   Maintenance type — select from those created earlier
    
-   Cost — specify the price for performing the work
    
-   Comment — add an explanation if necessary
    
    4\. Select the “Finished” check box if the work has already been done
    

![](images/drex_spravochniki_1_custom_11.png)

5\. Click “Save”

### How to edit or delete

Double-click the work to change it.

Click ![](images/drex_spravochniki_1_custom_5.png) next to the record to delete it.

## Parts

All the parts you have added that are used in maintenance are displayed here.

![](images/drex_spravochniki_1_custom_12.png)

### How to add a part

1\. Go to the “Parts” tab

2\. Click ![](images/drex_spravochniki_1_custom_2.png)

3\. In the new window, enter:

### ![](images/drex_spravochniki_1_custom_13.png)

-   Part name — for example, “Oil filter”
    
-   Maintenance type — select from the list
    
-   Supplier or manufacturer — select from those added earlier
    
-   Part code — if available
    
-   Cost
    
-   Comment — if necessary
    
    4\. Select the “Finished” check box if the part has already been installed
    
    ![](images/drex_spravochniki_1_custom_14.png)
    
    5\. Click “Save”
    

### How to edit or delete

To change, double-click the record in the list.

To delete, click ![](images/drex_spravochniki_1_custom_5.png) in the row of the part you need.
