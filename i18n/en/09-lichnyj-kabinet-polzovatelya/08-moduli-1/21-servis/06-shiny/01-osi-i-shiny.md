---
title: "Axles and tires"
---

In this article, we will look at how to configure the axle and tire layout for a selected object.

First add axles, then install tires on them. After configuration, the system can display the number of axles and tires, their location, mileage, as well as pressure and temperature readings if sensors are connected to the tires.

## How to add an axle

An axle can be added in two ways: through the axle and tire layout or through the object menu.

To add an axle through the layout:

1\. Select the object in the list

![](images/drex_osi_i_shiny__custom.png)

2\. Go to the axle and tire layout

3\. Click the “Add axle” button

![](images/drex_osi_i_shiny__custom_2.png)

4\. In the window that opens, specify:

• Axle name — for example, front axle or rear axle

• Location number — the order of the axle in the diagram

![](images/drex_osi_i_shiny__custom_3.png)

5\. Click “Save”

The new axle appears on the object layout.

![](images/drex_osi_i_shiny__custom_4.png)

An axle can also be added through the object menu. To do this, right-click the object in the list and select “Add axle”. The same axle settings window opens.

![](images/drex_osi_i_shiny__custom_5.png)

## How to add a tire

After adding axles, you can install tires.

-   Click the “Add tire” button on the layout
    

![](images/drex_osi_i_shiny__custom_6.png)

2\. In the window that opens, fill in the tire parameters:

![](images/drex_osi_i_shiny__custom_7.png)

-   Tire name
    
-   Installation date and time — select using the calendar
    
-   Mileage at installation
    
-   Threshold mileage — for wear control
    
-   Installation side — right or left
    
-   Location number
    
-   Serial number
    
-   Pressure and temperature sensors — select from the list of available ones
    

![](images/drex_osi_i_shiny__custom_8.png)

3. Click the “Save” button — the tire appears on the layout

![](images/drex_osi_i_shiny__custom_9.png)

After you have added axles and tires, the following information appears for the object in the list:

-   Number of axles — how many axles are configured for the object
    
-   Number of tires — the total number of installed tires
    
-   Tire location — exactly where they are installed (by sides and positions)
    
-   Pressure — current values from the sensors
    
-   Temperature — the temperature of each tire
    
-   Mileage — the mileage of the object and the mileage of each installed tire
    
    ![](images/drex_osi_i_shiny__custom_10.png)
    

This data helps you detect deviations, such as pressure drops or overheating, extend tire life, and avoid unscheduled repairs.
