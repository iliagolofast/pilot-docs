---
title: "Tire templates"
---

Tire templates let you save a ready-made axle and tire layout of one object and apply it to other objects. Use templates if several vehicles have the same axle and wheel configuration.

You can open templates from the object menu on the “Tires” tab. To do this, right-click the object and select “Template”.

![](images/drex_shablony_shin__custom.png)

<table><tbody><tr><td><span></span></td><td><div>Before creating a template, the object must have axles and tires added. If there is no tire data, the system shows an error message.</div></td></tr></tbody></table>

### To create a new template:

1\. Open the object menu and select “Templates”

![](images/drex_shablony_shin__custom.png)

2\. In the “Templates” window, click “Create new”

![](images/drex_shablony_shin__custom_2.png)

3\. Enter the template name

![](images/drex_shablony_shin__custom_3.png)

4\. If necessary, specify the make, model, and modification

![](images/drex_shablony_shin__custom_4.png)

5\. Click “Save”

<table><tbody><tr><td><span></span></td><td><div>The “Name” field is required. The “Make”, “Model”, and “Modification” fields can be left empty.</div></td></tr></tbody></table>

### To apply a template to an object:

1\. Open the menu of the object you want to apply the template to

![](images/drex_shablony_shin__custom_5.png)

2\. In the list, select the appropriate template

![](images/drex_shablony_shin__custom_6.png)

3\. Click “Use”

![](images/drex_shablony_shin__custom_7.png)

After the template is applied, the system replaces the object's current axle and tire layout with the data from the selected template.

![](images/drex_shablony_shin__custom_8.png)

<table><tbody><tr><td><span></span></td><td><div>If the object already had axles and tires configured, they will be deleted and replaced with data from the template.</div></td></tr></tbody></table>

If a template is no longer needed, select it in the list and click “Delete”.
