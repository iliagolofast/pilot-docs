On this tab, track the condition of vehicle tires. Here you monitor pressure and temperature readings and manage information about axles and tires.

![](images/drex_shiny__custom.png)

## Tab overview

When you open the “Tires” tab, you see three main blocks:

### Object list

All the vehicles you are monitoring are displayed here.

![](images/drex_shiny__custom_2.png)

You can quickly find the object you need using:

**![Tires ](images/drex_shiny__screen.png)**

1 — Search for objects in the list. Enter a name or number and the search highlights the result in the list

2 — [Filter by object type](../analitika.html#фильтр_по_типам_объектов). Select specific object types to view, for example, only passenger cars or special equipment

3 — [Filter in the table header](../analitika.html#фильтры_в_шапке_таблицы_). Use filters with conditions:

— Contains

— Equals

— Not equal

— Empty / Not empty

— Greater than / Greater than or equal to

— Less than / Less than or equal to

### Axle and tire layout

After you click an object in the list, you see its axle and tire layout. This is a visual diagram where you can:

-   Add axles and tires
    
-   See where and which tire is installed
    
-   Monitor the condition of each tire
    

![](images/drex_shiny__custom_3.png)

### Readings chart

The chart shows the history of parameters for the selected object:

-   Driving speed
    
-   Tire temperature
    
-   Tire pressure
    

On the chart, you can select a date to see how the readings changed over time — this helps you notice overheating or a pressure drop in time.

![](images/drex_shiny__custom_4.png)
