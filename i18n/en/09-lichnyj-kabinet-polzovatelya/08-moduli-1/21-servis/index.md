The “Service” module is designed for managing vehicle maintenance.

With the module:

— monitor the condition of vehicles

— plan maintenance

— keep records of tires

— record breakdowns and problems

— set up reminders about service activities

![](images/drex_servis_custom.png)

### Module structure

The module consists of the following tabs:

-   [Analytics](analitika.html)
    
-   [Services](servisy.html)
    
-   [Inspections](osmotry.html)
    
-   [Directories](spravochniki-1.html)
    
-   [Downtime](prostoi.html)
    
-   [Tires](shiny/index.html)
    

The “Service”, “Inspections”, and “Directories” tabs have additional submenus that help you configure the module's functionality in more depth.

Go to the articles about the module to understand each tab in detail.

## Access rights

To work with the module, you can flexibly configure access rights for each user. This lets you separate employee roles and protect service data from unwanted changes.

To configure the rights:

1\. Go to “Contract settings”

2\. Open the [“Personnel and groups”](../../nastrojki-dogovora-2/personal-i-gruppy/index.html) tab

3\. Select the user you need and double-click them

4\. In the user card, go to the [“Rights”](../../nastrojki-dogovora-2/personal-i-gruppy/index.html#права_действия) tab

5\. Find the “Service” module and select the check boxes for the necessary permissions

![](images/drex_servis_custom_2.png)

The administrator can separately configure access to the following sections:

• Services

• Inspections

• Directories (Suppliers, Service types, Works, Parts)

• Downtime

• Tires

For each section, you can set the allowed actions:

• Add — can create new records

• Edit — can edit existing records

• Delete — can delete records

You can configure access according to the employee's role: for example, give a manager full access and leave other users with view-only access.
