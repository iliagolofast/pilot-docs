The “Events” module helps you find events related to vehicles and other monitoring objects and view the places where they occurred on the map.

With the module, you can:

— find events for a selected period

— view speeding, downtime, refuels, fuel drains, service reminders, and other events

— select only the objects and event types you need

— see the location of an event on the map

— view notifications

![](images/drex_sobytiya__custom.png)

In this article you will learn how to:

— [find events for a selected period](sobytiya.html#Как_найти_события)

— [open and view the events found](sobytiya.html#Как_открыть_список_событий)

— [change how the event list is displayed](sobytiya.html#Как_изменить_вид_списка)

— [view where events occurred on the map](sobytiya.html#Просмотр_событий_на_карте)

— [change the display color of event types](sobytiya.html#Изменение_цвета_событий)

## How to find events

1\. In the top menu, open the “Events” section

2\. In the “From date” and “To date” fields, specify the period for which you need to find events

![Events ](images/drex_sobytiya__screen.png)

3\. In the left part of the window, select monitoring objects

![Events ](images/drex_sobytiya__screen_2.png)

4\. In the right part, select the event types you want to view

You can select:

— an entire event group, for example, “Notifications” or “Events”

— individual events within a group, for example, “Speed”, “Downtime”, or “Inspections”

To expand or collapse an event group, click the arrow next to its name ![](images/drex_sobytiya__custom_2.png).

![Events ](images/drex_sobytiya__screen_3.png)

5\. Click “Search”

![Events ](images/drex_sobytiya__screen_4.png)

After the search is completed, the events found appear in the list.

## How to open the event list

The results are grouped first by object and then by event type. The number in parentheses shows the number of records found.

![](images/drex_sobytiya__custom_3.png)

To open the event list, expand in sequence:

1\. The monitoring object

2\. The event type you need

![](images/drex_sobytiya__custom_4.png)

For each event, the following are displayed:

— the event name

— the date and time of registration

— a [color label](sobytiya.html#Изменение_цвета_событий)

## How to change the list view

By default, the events found are grouped by object and event type. To change the list view, click the button ![](images/drex_sobytiya__custom_5.png) in the upper-right corner of the panel.

![Events ](images/drex_sobytiya__screen_5.png)

The events are displayed as a single list without grouping.

![](images/drex_sobytiya__custom_6.png)

Each record shows:

— the object the event relates to

— date and time

— the event name or description

Events are ordered by time: newer records are displayed higher. The colored square next to the description corresponds to the event type.

To return to the list view grouped by object and event type, click the button ![](images/drex_sobytiya__custom_5.png) again.

## Viewing events on the map

To see where an event occurred:

1\. Click the event row in the list

2\. The map shows the place where the event was recorded — a colored marker appears. Its color corresponds to the color label next to the event in the list

![](images/drex_sobytiya__custom_7.png)

To open the event tooltip, click the marker.

![](images/drex_sobytiya__custom_8.png)

 The tooltip shows:

— the date and time of the event

— the monitoring object

— the event name and description

— additional parameters (if available)

To close the tooltip, click the cross in its upper-right corner or select another marker.

If several events are close to each other, the map combines them into one common marker with a number. The number shows how many events are in this area.

Zoom in on the map to see individual events.

![](images/drex_sobytiya__custom_9.png)

Some events do not contain coordinates. In this case, no marker is displayed on the map. For example, this may apply to certain service reminders. The event itself remains available in the list, and you can view it.

To display all events found on the map, click ![](images/drex_sobytiya__custom_10.png) in the upper-right corner of the events panel.

![Events ](images/drex_sobytiya__screen_6.png)

To remove all displayed events from the map, click ![](images/drex_sobytiya__custom_11.png).

## How to change event colors

Each event type has its own color. It is used both in the event list and on the map. If necessary, you can change the color.

To do this:

1\. In the “Event types” panel, find the event type you need

2\. Click the color label next to its name

![Events ](images/drex_sobytiya__screen_7.png)

3\. In the palette that opens, select a new color

![](images/drex_sobytiya__custom_12.png)

After you select it, the new color is immediately used for this event type both in the list and on the map.
