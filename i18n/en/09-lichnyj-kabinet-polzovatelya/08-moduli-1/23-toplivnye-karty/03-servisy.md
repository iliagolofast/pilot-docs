On this tab, you can enable or disable transaction notifications and manually upload fuel card data.

## How to manage alerts

1\. In the “Transaction notifications” section, select or clear the check box for the notification type you need. Email and SMS notifications are available.

<table><tbody><tr><td><span></span></td><td><div>If you plan to receive SMS notifications, make sure an SMS package is connected and paid for.</div></td></tr></tbody></table>

![](images/drex_servisy__custom.png)

2\. Click “Save”

<table><tbody><tr><td><span></span></td><td><div>Notifications are sent only for automatically loaded transactions. No alerts are sent for manually uploaded transactions.</div></td></tr></tbody></table>

## How to upload transactions manually

1\. In the “Card transaction upload” section, select the file format you need

2\. Click “Choose file”

If the transactions were exported from the operator in Excel format, first save the file as CSV.

When preparing the file, make sure that:

-   the CSV format is used
    
-   a comma is used as the delimiter
    
-   the file structure matches the selected upload format
    
    3\. To see a sample file, click the icon ![](images/drex_servisy__custom_2.png) next to the format you need
    

![](images/drex_servisy__custom_3.png)

4\. Click “Upload” to import the data

![](images/drex_servisy__custom_4.png)
