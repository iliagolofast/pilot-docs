title: "How to view notifications"
---

When an event configured in the system occurs, you receive a notification. It appears in the “Notifications” window.

![](images/drex_kak_prosmatrivat_uvedomleniya_custom.png)

The first time you sign in, this window may open automatically. If you closed or minimized it, open it again by clicking the notifications icon on the top bar.

![](images/drex_kak_prosmatrivat_uvedomleniya_custom_2.png)

![How to view notifications](images/drex_kak_prosmatrivat_uvedomleniya_screen.png)

## What the notifications window shows

The window shows the list of all notifications. For each event it displays:

— the date and time it was triggered

— the object

— the notification text describing the event

![](images/drex_kak_prosmatrivat_uvedomleniya_custom_3.png)

Click a notification to expand it and see the details. The expanded view may show:

— a more detailed description of the event

— [additional information](kak-sozdat-uvedomlenie.html#Дополнительная_информация_в_уведомлении) — for example: address, geofence, a direct link to the event

The following functions are available at the bottom of the window:

-   “Clear” — remove the list of notifications from the window
    
-   “Mute” — turn off the sound for new notifications
    
-   “OK” — close the notifications window
