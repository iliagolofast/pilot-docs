title: "Trip tools"
---

You can use the following tools to work with trips:

![Trip tools](images/drex_instrumenty_dlya_raboty_s_rejsami_screen.png)

![](images/drex_instrumenty_dlya_raboty_s_rejsami_custom.png) — route monitor

Use this tool to view all routes of the selected trips in live mode. Check the route you need in the list and click this tool.

![](images/drex_instrumenty_dlya_raboty_s_rejsami_custom_2.png)

![](images/drex_instrumenty_dlya_raboty_s_rejsami_custom_3.png)— add a trip group

Create a new group, enter its name, and click “Save”. The group appears in the trip list. To organize trips, simply drag them into the groups you need with the mouse.

![](images/drex_instrumenty_dlya_raboty_s_rejsami_custom_4.png)

![](images/drex_instrumenty_dlya_raboty_s_rejsami_custom_5.png)— add a trip

Use this tool to create a new trip. To learn how to add a trip, read [this article](kak-sozdat-rejs.html).

![](images/drex_instrumenty_dlya_raboty_s_rejsami_custom_6.png)— clear the map

Clears the map of all routes, stops, and objects.

![](images/drex_instrumenty_dlya_raboty_s_rejsami_custom_7.png) — refresh the trip list

Refreshes the data in the trip list so you see the latest changes and up-to-date information. Use this button if you added or edited trips and the updates did not appear right away.
