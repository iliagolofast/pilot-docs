---
title: "How to create a route from a track in History"
---

You can create a route not only through the routes module, as described in the previous [article](kak-sozdat-marshrut.html), but also from a track in the “History” section:

### How to create a route in “History”

-   Go to the [“History”](../../istoriya/kak-prosmotret-istoriyu.html) section and select an object from the list by checking the box next to it
    
-    Specify the time interval for the track search and click the “Search” button
    

![](images/drex_kak_sozdat_marshrut_cherez_trek_v_istorii_custom.png)

3\. The search results list shows the object's track records

![](images/drex_kak_sozdat_marshrut_cherez_trek_v_istorii_custom_2.png)

4\. Find the row with the track for the day you need. Right-click it and open the track menu

5\. In the menu, select “Create route”

6\. The route opens, displayed in gray on the map

![](images/drex_kak_sozdat_marshrut_cherez_trek_v_istorii_custom_3.png)

7\. If you want to create a route from part of the track, just mark the start and end of the segment you need by clicking points on the track line

![](images/drex_kak_sozdat_marshrut_cherez_trek_v_istorii_custom_4.png)

![](images/drex_kak_sozdat_marshrut_cherez_trek_v_istorii_custom_5.png)

8\. After marking the segment, click the “Go to route builder” button to set the [route parameters](kak-sozdat-marshrut.html#Параметры_маршурута)

![](images/drex_kak_sozdat_marshrut_cherez_trek_v_istorii_custom_6.png)

9\. In the route builder, set the required parameters and click “Save”

![](images/drex_kak_sozdat_marshrut_cherez_trek_v_istorii_custom_7.png)

Your route is now saved and appears in the route list.

![](images/drex_kak_sozdat_marshrut_cherez_trek_v_istorii_custom_8.png)
