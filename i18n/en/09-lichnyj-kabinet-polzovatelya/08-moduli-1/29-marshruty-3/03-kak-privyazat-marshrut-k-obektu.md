---
title: "How to link a route to an object"
---

For the system to track route events and build reports for a specific object, you need to link the route to the vehicle:

-   Go to “Main” → “Online”
    
-   Find the object you want to link a route to
    
-   Right-click the object and select “Route”
    

![](images/drex_kak_privyazat_marshrut_k_obektu_custom.png)

4\. In the window that opens, select the routes you want to link to the selected object

![](images/drex_kak_privyazat_marshrut_k_obektu_custom_2.png)

5\. Click “Save” to link the route to the object

After saving, the system offers to recalculate reports, because the routes for this object were changed or relinked. Recalculation is needed so that all data is up to date and reports correctly reflect the route changes.

![](images/drex_kak_privyazat_marshrut_k_obektu_custom_3.png)

If you want to recalculate reports, click “Yes”. Specify the recalculation period (start and end dates) and click “Start recalculation”.

![](images/drex_kak_privyazat_marshrut_k_obektu_custom_4.png)

Report recalculation runs in the background, and once it finishes, the data is updated.

![](images/drex_kak_privyazat_marshrut_k_obektu_custom_5.png)
