title: "How to work with a route"

In this article we explain how to work with a route in the system, what actions you can perform, and which tools are available for them.

## Route menu 

On the “Routes” tab you see all created routes. To open the menu and perform actions on a route, right-click the route you need.

## ![](images/drex_kak_rabotat_s_marshrutom_custom.png)

## Route actions

Let's look at the actions you can perform on a route in the menu.

### Move the map to the route center

If you want to focus on the route, select this option. The map automatically opens on the route

### Edit route

Click “Edit” in the menu to open the route builder. In this mode you can change the route parameters, add or delete points, and change other settings.

![](images/drex_kak_rabotat_s_marshrutom_custom_2.png)

### Route recalculation

To recalculate a route and analyze its data, open the “Recalculations” menu. It shows all objects linked to the route.

![](images/drex_kak_rabotat_s_marshrutom_custom_3.png)

For each object in this window you can start a recalculation or view the recalculation history. To do this, right-click the object — a menu with actions opens.

![](images/drex_kak_rabotat_s_marshrutom_custom_4.png)

When you click “Start recalculation”, a window opens for selecting the period. Specify the start and end dates, and the system recalculates the route passage for this period.

![](images/drex_kak_rabotat_s_marshrutom_custom_5.png)

When you click “List of recalculated”, you see the recalculation history — when and which recalculations were performed for the selected route.

# ![How to work with a route](images/drex_kak_rabotat_s_marshrutom_screen.png)

If you want to recalculate the route again, select the recalculation you need and click “Start recalculation”.

The “Go to vehicle track” button displays the vehicle's track, where you can see how the object passed the route in that recalculated period. This button is active when at least one recalculation has been completed.

### Delete

If the route is no longer needed, you can delete it. Confirm the deletion, and the route with all its linked points and objects is deleted.

## Viewing a route and points

On the “Routes” tab you can see all created routes in a list. To expand a route and see its points, click ![](images/drex_kak_rabotat_s_marshrutom_custom_6.png)

# ![](images/drex_kak_rabotat_s_marshrutom_custom_7.png)

When you select a route, it is displayed on the map. If you click a route point in the list, the map automatically focuses on that point so you can see its exact location.

![](images/drex_kak_rabotat_s_marshrutom_custom_8.png)

If you want to see individual route points on the map, check the “Show points” box.

![How to work with a route](images/drex_kak_rabotat_s_marshrutom_screen_2.png)

To view the route without points, uncheck this box.

![](images/drex_kak_rabotat_s_marshrutom_custom_9.png)

To rename a route point, right-click the point in the list and select “Rename”. Enter the new name and click “OK”.

![](images/drex_kak_rabotat_s_marshrutom_custom_10.png)
