After signing in to the PTM electronic dispatch center, you land on the main page. It gathers the tools for working with tasks, users, and settings. Below is a brief overview of the main interface elements.

![](images/drex_obzor_interfejsa__custom.png)

## Left menu

The left menu contains the main sections of PILOT Task Manager.

![Interface overview ](images/drex_obzor_interfejsa__screen.png)

Main menu sections:

-   Dashboard
    
    Shows the tasks you are working with: you can view, open, and manage them.
    
-   Acts
    
    The list of acts related to tasks — for example, completion certificates or transfer-acceptance certificates.
    
-   Users
    
    Management of system users: roles, access rights, and settings.
    
-   Queue
    
    Tasks that have not been assigned yet or require processing.
    
-   Reference books
    
    Auxiliary data and settings used when creating tasks.
    
-   Settings
    
    General settings of the PTM module.
    
-   Calendar / Calendar v2
    
    View tasks as a calendar
    
-   User account
    
    Settings of the current user and access to personal information.
    

The left menu can be collapsed or expanded to free up more screen space. To do this, click the arrow at the bottom of the menu ![](images/drex_obzor_interfejsa__custom_2.png).

The left arrow collapses the menu to icons, the right arrow expands it and shows the section names.

### User account

To go to the user account, click the profile icon ![](images/drex_obzor_interfejsa__custom_12.png) in the upper right corner.

![Interface overview ](images/drex_obzor_interfejsa__screen_4.png)

In the user account you can view and edit your profile data:

-   Name
    
-   Email
    
-   Password
    
-   Date of birth
    
-   Phone numbers
    
-   Additional information: address, position, department, description
    

To change the data, click ![](images/drex_obzor_interfejsa__custom_13.png), make the changes, and click “Save”.

![Interface overview ](images/drex_obzor_interfejsa__screen_5.png)

## Workspace

The workspace is in the center of the screen. It shows the main content of the selected section: task lists, the calendar, users, and so on.

The workspace content changes depending on which section you selected in the left menu.
