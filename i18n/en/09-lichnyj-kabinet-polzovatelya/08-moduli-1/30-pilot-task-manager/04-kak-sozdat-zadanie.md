title: "How to create a task"
---

To create a new task in PTM, click the “Add” button above the task table on the dashboard — the task card opens.

![How to create a task](images/drex_kak_sozdat_zadanie_screen.png)

The task card is a form where you set all the important trip parameters. It is divided into several blocks:

![](images/drex_kak_sozdat_zadanie_custom.png)

![](images/drex_kak_sozdat_zadanie_custom_2.png)

### Upper part (left)

![](images/drex_kak_sozdat_zadanie_custom_3.png)

-   Template — [select the task type](spravochniki-2.html#параметры_шаблонов_PTM) that determines the field structure for this task
    
-   Vehicle — select the vehicle that will perform the trip
    
-   Driver and Driver phone — enter the driver's full name and contact number
    
-   Trailer Plate — the trailer number, if a trailer is used for transportation
    
-   Route Name — internal route identification
    
-   Cargo Name — enter the cargo name
    
-   Minimum / Maximum Temperature — if the transportation requires a temperature regime, enter the minimum and maximum temperatures
    

### Upper part (right)

![](images/drex_kak_sozdat_zadanie_custom_4.png)

Task information — shows the main route data here:

-   Address list — the main address/route, with the ability to edit, delete, or add new route points.
    
    Details:
    
-   Route point coordinates
    
-   Redirect this point — use the point as a redirect address
    
-   Visit time — planned arrival time
    
-   Warehouse — the name of the warehouse or point
    
-   Stay time — how long the vehicle must spend at the point
    
-   Radius — allowed deviation from the route point (in meters)
    
-   Add address — a button to add another route point
    
-   Start time and End time — specify the time frame for completing the task
    
-   Description — a field for a free-form comment on the task
    

### Completion certificate

If a [completion certificate template](spravochniki-2.html#Как_создать_акт_выполненных_работ_для_шаблона:_) has been created in advance for the task template, it can be linked to the task. In this case, in the Pilot Driver mobile app the driver can not only complete the task but also fill in the completion certificate as a report.

Two setup options are available:

-   Certificate for a route point — lets you assign a separate certificate template to a specific route point. Select the template you need from the list of previously created completion certificate templates.
    

![How to create a task](images/drex_kak_sozdat_zadanie_screen_2.png)

-   Main task certificate — a certificate template assigned to the whole task. It is selected in the lower part of the task card.
    

![How to create a task](images/drex_kak_sozdat_zadanie_screen_3.png)

If no separate certificate template is selected for a route point, the main task certificate is used.

After the task is created, the selected certificates are available to the driver in the Pilot Driver app. The driver can fill them in either for individual route points or for the task as a whole — depending on the settings specified when the task was created.

### Map

![](images/drex_kak_sozdat_zadanie_custom_5.png)

The map shows the route with all the points included in the task marked.

### Lower part

![](images/drex_kak_sozdat_zadanie_custom_6.png)

Counterparties — in this block you can select the company that will be linked to the task

Certificate template — select the completion certificate forms, if such a template has been set up in the system

### Control buttons at the bottom of the card:

-   Back — if you changed your mind about saving the task, you can return to the task table without saving the changes
    
-   Save — when you have entered all the data, click this button to save the task and put it into work
    
-   Forecast — use this button to calculate the route forecast
    

## How to create a task from a template

To quickly create a new task based on an existing one, use the “Create from template” function:

1\. Right-click the task row in the task table.

2\. In the task menu that appears, select “Create from template”

![](images/drex_kak_sozdat_zadanie_custom_7.png)

3\. The system automatically creates a new task with all the main data copied from the original task (for example, client, route, cargo, parameters).

4\. After that you can edit the task by selecting “Edit” in the menu. You go to the task card, where you can make the necessary changes.

![](images/drex_kak_sozdat_zadanie_custom_8.png)
