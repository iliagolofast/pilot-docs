title: "Users"
---

In the “Users” section you can manage all system users: dispatchers, logisticians, drivers, administrators, and other employees. Here you see the list of all users and can configure system access for each of them.

![](images/drex_polzovateli_1_custom.png)

Each row in the users table is a separate user. You will see:

-   Login — the user name for signing in to the system
    
-   Email — the work email address
    
-   Full name — the full name
    
-   Phone — the contact number
    
-   Role — for example, logistician, dispatcher, administrator
    
-   Driver — a mark if the account is linked to a driver
    

### Actions with users

Above the table there are several buttons for managing users:

![](images/drex_polzovateli_1_custom_2.png)

-   Add — create a new user by specifying a login, password, contact details, and access rights
    
-   Edit — change the information of the selected user
    
-   Delete — delete the user account
    
-   Download — export user information to Excel
    
-   Upload — upload user information from a previously prepared file
    
-   Update drivers — update the data of driver users
    
-   Show drivers — if you check this box, driver accounts are also shown in the list
    

### How to add a user

1\. Click the “Add” button at the top of the screen to open the new user card

![](images/drex_polzovateli_1_custom_3.png)

2\. Fill in the main information:

![](images/drex_polzovateli_1_custom_4.png)

-   Login — the name the user will use to sign in to the system
    
-   Email — work email for notifications and access
    
-   Password — create a password and confirm it
    
-   Full name — the employee's full name
    
-   Phone — contact number
    
-   Address — work address, if needed
    
-   Signatories — select a signatory template if this user will sign documents
    
-   Permission templates — select a ready-made set of rights for the user (for example, Administrator, Logistician, Driver) 
    
-   Position — specify the position (logistician, driver, dispatcher, etc.)
    
-   Passport — enter passport details if required
    
-   User color — select the color that will be used to highlight this user in the system
    
-   Description — add a comment or note
    
    3\. Configure access rights
    

On the right of the user card there is a block with check boxes where you can configure exactly which actions are allowed for this user. Check the rights you need, and they are activated for this account.

![](images/drex_polzovateli_1_custom_5.png)

4\. Save the user card

When all data is filled in and the rights are configured, click “Save”. The new user appears in the list and can sign in to the system with the specified login and password.

![Users](images/drex_polzovateli_1_screen.png)

If you changed your mind, click “Cancel” and the changes are not saved.

### How to edit a user

To edit user data, select the user in the list and click the “Edit” button at the top of the table. The card opens, where you can make the necessary changes. You can also double-click the user's row, and the card opens automatically.

![Users](images/drex_polzovateli_1_screen_2.png)

![](images/drex_polzovateli_1_custom_6.png)

After editing the user card, click the “Save” button to save your changes.
