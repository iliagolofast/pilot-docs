title: "Queue"
---

The “Queue” section shows tasks that are waiting to be sent to the driver for execution.

![](images/drex_ochered_custom.png)

The table shows information for each task:

-   Task ID — the unique task number
    
-   Task name — a short task description
    
-   Driver — who will perform the task
    
-   Time sent for execution — when the task was put in the queue
    

While tasks are in the queue, you can select a task and click “Delete” to remove it from the queue.

![Queue](images/drex_ochered_screen.png)

If the queue is empty, it means there are currently no tasks waiting to be sent for execution.
