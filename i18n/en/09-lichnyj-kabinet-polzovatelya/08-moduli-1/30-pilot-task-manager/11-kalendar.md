The calendar shows all tasks as a schedule and helps you plan work by date.

![](images/drex_kalendar_custom.png)

Main calendar elements:

The center of the screen shows the calendar grid, where you can switch between different views:

![](images/drex_kalendar_custom_2.png)

-   Day — for a detailed view of tasks for a specific day
    
-   Week — to view all tasks for one week
    
-   Month — for a general overview of all tasks for the month
    
    The calendar cells show tasks with the time and task number.
    
    In the filter on the left you can select which task types to show in the calendar. For example, you can filter only logistics, delivery, loading, repair, or other task types. Each task type is assigned its own color in the calendar.
    

![](images/drex_kalendar_custom_3.png)

Main buttons and actions:

-   Create — create a new task from the calendar
    
-   Today — return to the current day in the calendar
    
-   Arrows ![](images/drex_kalendar_custom_4.png)  — switch to the previous or next period.
    
-   “Day / Week / Month” switches — select the display scale you need in the calendar
    

![](images/drex_kalendar_custom_2.png)

-   Search by task ID — enter the task number in the search field to find it in the calendar and click ![](images/drex_kalendar_custom_5.png)
    
-   Icon ![](images/drex_kalendar_custom_6.png) — opens additional calendar display settings
    

![](images/drex_kalendar_custom_7.png)

### How to create a task in the calendar

1\. Click the day you need in the calendar grid

2\. A window for creating a new task appears on the screen

![](images/drex_kalendar_custom_8.png)

3\. Enter the data needed for the task

4\. Click “Submit” to save and launch the task

## Calendar V2

Calendar V2 is a schedule for managing tasks distributed across vehicles. In this version of the calendar you can see which task is assigned to each vehicle on a specific day.

![](images/drex_kalendar_custom_9.png)

Calendar structure:

-   The left column shows the list of all vehicles used to perform tasks.
    
-   The top row shows the days of the week with dates. This way, in one row you see which tasks are assigned to each vehicle on each day.
    
-   The cells show the tasks assigned to a specific vehicle on the selected day.
    

![](images/drex_kalendar_custom_10.png)

Main actions and buttons:

-   Refresh — click this button to reload the calendar and pull in the latest task changes
    
-   Settings — open additional calendar display settings
    

![](images/drex_kalendar_custom_7.png)

-   Arrows ![](images/drex_kalendar_custom_11.png) —  use the arrows to page the calendar forward and back to view tasks for future or past days
    

If you want to view a task or make changes to it, double-click the cell — the task card opens, where you can edit all the necessary parameters.

![](images/drex_kalendar_custom_12.png)
