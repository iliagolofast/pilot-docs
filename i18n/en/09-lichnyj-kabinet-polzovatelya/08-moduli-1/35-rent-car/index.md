title: "Rent Car"
---

To work with the module, you need to enable three modules.

-   Violation control module.
    
-   Rent Car.
    
-   Eco-driving module.
    

To work with the module, you need to fill in the data on the Contract, date, cost and Driver.

Configuration in the admin panel

-   **Max\_fee** — if a Trip scores more points than this, the Driver will receive a Notification. 
    
-   **Trips\_warning** — if the Driver's number of unsuccessful Trips is greater than this value, a Garm Notification to the dispatch office will be activated.
    
-   **link\_host** — the host name of the link with Trip information that will be sent to the Driver.
    
-   **Garm\_notification\_id** - the identifier of the Notification configuration from the Notifications module that will fire in case of a Trips warning.
    

![](images/drex_rent_car_custom.png)

**Speeding settings on the road graph**

Speed\_delta — the default delta value, which can be changed for each vehicle in the account.
