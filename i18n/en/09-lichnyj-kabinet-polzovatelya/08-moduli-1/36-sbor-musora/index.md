**Purpose of the module**

-   Sensors are installed in containers and signal the PILOT platform when the container is filled up to the Sensor level.
    
-   The Sensor is installed at a height of about 80% of the full tank, so that there is still time for the garbage truck to arrive.
    
-   The waste removal company's operator sees in real time on the PILOT platform that several waste containers are approaching the upper mark, and creates a task to build an optimal route so these overflowing containers are collected sooner.
    
-   The garbage truck Driver receives a task in the app to pick up specific containers, along with the optimal route to them.
    
-   The operator sees the task being completed online in real time.
    

In an emergency, for example a fire in a waste container, the operator also receives a Notification on the PILOT platform (as well as by SMS, push or e-mail, depending on the method they prefer) about the incident and the need to respond.

Moreover, on the PILOT platform you can set up in advance a response scenario for emergencies

(a fire in a waste bin, an accident involving a garbage truck, a vehicle leaving its route), and then any operator of the waste removal service company will know what to do when a particular situation occurs.

-   This module has no separate icon, and it works through two connected modules.
    
     The Logistics module and the PTM module.
    
-   The module also works with just one of these modules, but it is recommended to use both of the modules listed above at the same time.
    
-   The module settings are shown in the context menu only for the waste container type.

**Create a task for PTM.**

To create a task, select **Сreate a task in PTM**.

Waste collection tasks must be created only from the **context menu of the waste bin Object.**

When the Logistics module is connected, the Client name will be available.

The current time is set by default; you can change it, for example to a future period.

The specified planned time will be taken into account when the task is completed.

![](images/drex_sbor_musora_custom_3.png)

If you need to select more bins for one vehicle, select the first and the last container and hold **shift.**

![](images/drex_sbor_musora_custom_4.png)

Next, you can track the progress of the waste collection task in the PTM module.

In this case the PTM module is intended for viewing, not for creating tasks.

![](images/drex_sbor_musora_custom_5.png)
