title: "Panel"
---

To launch the **admin panel**, enter the platform address in the address bar**.**

As a result, a start page with a login form is displayed.

The login and password are issued by the company manager.

![](images/drex_panel_custom.png)

**The graphical panel contains the following information:**

-   Number of Objects in the system.
    
-   Object statuses.
    
-   Names of organizations.
    
-   Balance.
    
-   Tariff.
    
-   Log out button.
    

![](images/drex_panel_custom_2.png)

**The tab bar** \- is intended for working with Contracts, Objects,

# **Reports, recalculations and other actions.**

**The work area** -  displays the graphical interface with Objects.

**User personal settings**

# **\- include a number of steps that let you personalize your data.**

-   Add a photo
    
-   Change name
    
-   Change password
    

![](images/drex_panel_custom_3.png)
