 **Main settings**

-   **Name -** the name of the Contract.
    
-   **Email -** the Contract's e-mail address (it will be used when a new User is created automatically).
    
-   **Phone -** the Contract's phone number.
    
-   **Balance** - the current balance.
    
-   **Deposit -** a payment that the client can make as an advance for the services provided.
    
-   **TIN**\- individual identification number.
    
-   **KPP -** registration code.
    
-   **Partner -** the Partner the Contract will be linked to (select from the list).
    
-   **Currency**\- selection from the list of currencies.
    
-   **Tariff -** the tariff plan for the Contract (select from the list).
    
-   **Organization type -** the type of organization entering into the Contract (select from the list).
    
-   **Account type-** select from the drop-down list\*.
    
           **Postpayment -** payment is made after the service is provided. When the balance is limited, the client
    
           will receive e-mail notifications about the payment amount.
    
           **Prepayment -** payment**,** made before the service is provided. If the balance is negative,
    
           the contract is blocked.
    
           **Postpayment (lite) -** when this account type is selected, the “Blocking limit” field is added, in which
    
          the payment amount at which automatic blocking of the account is triggered is set.
    
-    **1C code -** a code for synchronization with the 1C program.
    
-   **Active —** a checkbox for creating the Contract in the active state.
    
-   **Stock account** - this is an account in which blocked Objects without a subscription fee are stored.
    

A stock account has the same rights as a regular account. Such an account can be used for Objects that are entered in the database in test mode and not yet put into paid operation.

Only the administrator can transfer Objects, through the admin panel.

-   **User passwords** - creating a complex or simple password. Displaying the password in the User settings.
    
    Show User passwords **-** an action that lets you view passwords in the User's personal card. User passwords can be hidden or remain available.
    
-   **Master password -**  the ability to send commands to devices using the master password

**Services**

Paid services let administrators provide modules on a paid basis.

For a module to be paid, it must be activated in the settings, and then selected on the Services + tab.

![](images/drex_redaktirovat_1_custom_3.png)
