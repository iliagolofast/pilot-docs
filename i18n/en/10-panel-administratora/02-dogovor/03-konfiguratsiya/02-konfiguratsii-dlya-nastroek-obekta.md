title: "Configurations for Object settings"

The settings shown in the [Object card](../../../lichnyj-kabinet-polzovatelya/obekty-1/kartochka-obekta/index.html#Настройки_карточка_объекта) are set using special configurations.

![](images/drex_konfiguratsii_dlya_nastroek_obekta____custom.png)

<table><tbody><tr><td><span></span></td><td><div>Settings defined using a configuration are automatically applied to all Objects in the Contract.</div></td></tr></tbody></table>

### How to add configurations for Object settings:

-   # In the admin panel, go to the “Contracts” section
    
-   Select a Contract
    
-   Right-click the selected Contract — the context menu opens
    

![](images/drex_konfiguratsii_dlya_nastroek_obekta____custom_2.png)

4\. Select “Edit” in the menu

5\. In the Contract settings window that opens, select the “Configuration” tab.

![](images/drex_konfiguratsii_dlya_nastroek_obekta____custom_3.png)

6\. To add a new configuration, click the “Add” button.

7\. In the drop-down list, select the configuration you need for the Object settings and specify a value for it.

![](images/drex_konfiguratsii_dlya_nastroek_obekta____custom_4.png)
