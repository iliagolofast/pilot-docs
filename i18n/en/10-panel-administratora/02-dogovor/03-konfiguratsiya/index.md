title: "Configuration"
---

A configuration is a set of system parameters and settings that adapt the system's operation to specific tasks. Each configuration consists of a key — a unique identifier — and a value, which can be a number, text or a more complex data structure.

### How to add a configuration to a Contract:

-   # In the admin panel, go to the “Contracts” section
    
-   Select a Contract
    
-   Right-click the selected Contract — the context menu opens
    

![](images/drex_konfiguratsiya_custom.png)

4\. Select “Edit” in the menu

5\. In the Contract settings window that opens, select the “Configuration” tab

# ![Configuration](images/drex_konfiguratsiya_screen.png)

# 6\. To add a new configuration, click the “Add” button.

# 7\. In the drop-down list, select the configuration you need and specify a value for it.

Use the icons to edit a configuration ![](images/drex_konfiguratsiya_custom_2.png)or delete it ![](images/drex_konfiguratsiya_custom_3.png).
