---
title: "Modules"
---

**System modules** are separate components that together form a complex system, providing its functionality and interconnected operation.

Each module performs specific tasks or functions, and they can be developed and updated independently of each other.

Only the system administrator can manage activation, through the admin panel.

The list of modules in a Contract may vary depending on the Partner's settings.

![](images/drex_moduli_2_custom.png)

[CMS](../../lichnyj-kabinet-polzovatelya/moduli-1/video-i-cms/index.html) [and Video](../../lichnyj-kabinet-polzovatelya/moduli-1/video-i-cms/index.html) - a system component that lets you monitor the state and behavior of the driver and passengers inside the cabin.

[Drivers module](../../lichnyj-kabinet-polzovatelya/moduli-1/voditeli-3/index.html) - a system component used to manage and track the work of Drivers in the system.

[Counterparties module (Sales representative)](../../lichnyj-kabinet-polzovatelya/moduli-1/torgovyj-predstavitel.html) - intended for managing information about counterparties, including clients, suppliers, Partners and sales representatives. This module helps organize interaction with counterparties and improve the quality of service.

[Control room](../../lichnyj-kabinet-polzovatelya/moduli-1/situatsionnyj-tsentr-2/index.html) - a system component for tracking the location of a vehicle and scanning its condition.

[Climate control](../../lichnyj-kabinet-polzovatelya/moduli-1/klimat/index.html) - a system for automatically regulating climatic conditions in an enclosed space, for example in a vehicle, office or living space. The main goal is to maintain comfortable conditions for people, including optimal levels of temperature, humidity and air quality.

[RFID tags module](../../lichnyj-kabinet-polzovatelya/moduli-1/rfid-metki-2/index.html) - a module intended for monitoring the reading of RFID tags; a narrowly focused module created to control waste collection (there is a tag on the bin and a reader on the vehicle).

[Analytics module (Dashboard)](../../lichnyj-kabinet-polzovatelya/moduli-1/analitika.html)\- a system component that provides capabilities for collecting, processing and analyzing data from monitored Objects in order to obtain valuable information about them.

[Engine blocking module](../../lichnyj-kabinet-polzovatelya/moduli-1/blokirovka-dvigatelya.html) - a system component intended to prevent unauthorized access to and starting of the engine.

[Geofence module](../../lichnyj-kabinet-polzovatelya/moduli-1/geozony-2/index.html) - intended for territorial control of monitored Objects. It lets you record the fact that an Object is in a given zone, exceeding the permitted idle time in the zone, and leaving the zone.

[Commands module](../../lichnyj-kabinet-polzovatelya/moduli-1/komandy-1.html) - a system component that includes a set of commands that Users can send to devices.

[Time control module](../../lichnyj-kabinet-polzovatelya/moduli-1/kontrol-vremeni.html) - a system component intended for tracking, recording and managing working time.

[Violation control module](../../lichnyj-kabinet-polzovatelya/moduli-1/kontrol-narushenij.html)  - a system component used to track and detect violations using a set of predefined rules.

[Logistics module](../../lichnyj-kabinet-polzovatelya/moduli-1/logistika-2/index.html) - a system component intended for managing and optimizing logistics operations within the supply, storage and transportation of goods or services.

[Recalculation module](../../lichnyj-kabinet-polzovatelya/moduli-1/pereschyet-dannykh.html) - a system component used to perform recalculations and transformations of data in the system. Recalculation is possible for two types: Zones and Trips.

 [Trailers module](../../lichnyj-kabinet-polzovatelya/moduli-1/pritsepy.html) -  intended for monitoring the state of trailers and semi-trailers attached to main vehicles. This module lets you track the location, state and movement of trailers, as well as view the history of connections and disconnections with the vehicle.

[Retranslation module](../../lichnyj-kabinet-polzovatelya/moduli-1/retranslyatsiya/index.html) \- a system component used to forward data from one source to another or to several other sources at once. It acts as an intermediary between the sender and the recipient of the data.

[Service module](../../lichnyj-kabinet-polzovatelya/moduli-1/servis/index.html) - a system component intended for convenient planning or recording of vehicle technical inspections.

[Events module](../../lichnyj-kabinet-polzovatelya/moduli-1/sobytiya.html) - a system component intended for tracking and recording the various Events configured in the system. It plays a key role in monitoring Objects and analyzing User actions.

[Fuel cards module](../../lichnyj-kabinet-polzovatelya/moduli-1/toplivnye-karty/index.html)  - the choice of fuel depends on specific requirements, operating conditions and environmental factors.

[Notifications module](../../lichnyj-kabinet-polzovatelya/moduli-1/uvedomleniya/index.html) \- a system component intended for sending Notifications to Users about various Events, changes or states. It provides prompt information to the User and allows timely response to important Events.

[Trips module](../../lichnyj-kabinet-polzovatelya/moduli-1/rejsy-2/kak-dobavit-ostanovki.html)\- a system component intended for automating and optimizing the operation of bus routes, improving passenger service quality and ensuring the efficiency of the vehicle fleet.

[Routes module](../../lichnyj-kabinet-polzovatelya/moduli-1/marshruty-3/index.html) - a system component intended for passenger flow control.

[PILOT task manager](../../lichnyj-kabinet-polzovatelya/moduli-1/pilot-task-manager/index.html) - a module intended for monitoring, managing and coordinating the execution of tasks or processes in the system. It gives Users the ability to observe and manage current processes

[Schedule](../../lichnyj-kabinet-polzovatelya/moduli-1/raspisanie.html) - a module used to create, manage and optimize work schedules for vehicles and Drivers.

[Eco-driving](../../lichnyj-kabinet-polzovatelya/moduli-1/ehkodrajving-kachestvo-vozhdeniya/index.html) \- a component of the vehicle management system intended for monitoring, analyzing and improving driving style.

[Tachograph module](../../lichnyj-kabinet-polzovatelya/moduli-1/takhograf-2.html) - intended for monitoring and recording data on the work and rest regimes of Drivers, driving speed and other important parameters related to vehicle operation. Tachographs play a key role in ensuring road safety and compliance with regulatory requirements.

[Crash detected](../../lichnyj-kabinet-polzovatelya/moduli-1/obnaruzhenie-avarij.html) - a component of the vehicle management system intended for automatically detecting road accidents involving vehicles.  The module uses various Sensors to monitor movement parameters.

[Rent Сar](../../lichnyj-kabinet-polzovatelya/moduli-1/rent-car/index.html) \- a module intended for managing and automating vehicle rental processes.

[Waste collection module](../../lichnyj-kabinet-polzovatelya/moduli-1/sbor-musora/index.html) - intended for planning, optimizing and monitoring waste collection and removal operations.

[Agro module (Trailers module)](../../lichnyj-kabinet-polzovatelya/moduli-1/agro.html)\- intended for automating and optimizing the management of agricultural machinery and resources in the agro-industrial complex.

Hardware health monitoring module - a system component intended for monitoring the state of various components and systems of vehicles. This module helps identify faults, prevent breakdowns and optimize Maintenance.

[LogBook module](../../lichnyj-kabinet-polzovatelya/moduli-1/logbook/index.html) - a portal for Drivers where they can track their Trip statistics, eco-driving data, fuel costs, toll costs and their ratings.

Each Driver can access the portal and see only their own statistics, which are analyzed based on all Trips in all vehicles they have used.
