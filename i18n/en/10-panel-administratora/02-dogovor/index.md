A Contract is the account intended for working in the User interface.

The account creation process usually includes entering personal data, the Contract name, selecting the organization type, account type, tariff and other parameters.

![](images/drex_dogovor_custom.png)

**The Contracts window contains the following settings:**

• [The Add Contract + button.](redaktirovat-1.html)

• **The Contract export button** - a button for downloading Contracts in Excel format.

• **Search filters** - a tool that lets Users search by specified criteria.

-   **The main work window consists of**: the Contract's unique id number, name, organization type, account type, Contract creation date, number of Objects and other fields).
    

For convenience when working with Contracts in the system, columns in the settings header can be shown or hidden.
