---
title: "Machines"
---

The tab is used to monitor existing vehicles.

-   **Agent ID -**  the identifier of the monitored Object.
    
-   **Name —** the name of the monitored Object in the system.
    
-   **Folder -** the folder of the monitored Object in the system.
    
-   **Data volume** - the volume of data.
    
-   **Creation date -** the creation date of the monitored Object.
    
-   **Type -** the type of the installed unit.
    
-   **Tariff -** the tariff plan and the price per month.
    
-   **Partner tariff  -** the tariff plan for the Partner.
    
-   **Unique -** the IMEI unit.
    
-   **Msisdn -** the SIM card number in the device.
    
-   **Contract -** the number of the Contract in the system the monitored Object belongs to.
    
-   **Owner -** the name of the Contract the monitored Object belongs to.
    
-   **Partner -** the Partner the monitored Object belongs to.
    
-   **Self -** blocking of the monitored Object by the User.
    
-   **Administrator -** blocking of the monitored Object by the administrator.
    
-   **Last update -** the date of the last monitoring point of the Object.
    
-   **Connected -** the current state of the monitored Object.
