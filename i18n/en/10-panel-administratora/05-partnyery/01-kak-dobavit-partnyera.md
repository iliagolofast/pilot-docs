---
title: "How to add a Partner"
---

In the “Partners” section you can create a new Partner account.

-   Click the “Add” button in the “Partners” section
    

![How to add a Partner](images/drex_kak_dobavit_partnyera_screen.png)

2\. In the window that opens, go to filling in the “Main settings” tab

![](images/drex_kak_dobavit_partnyera_custom.png)

3\. Fill in the required Partner Contract data:

• Name — the name of the Contract or company (as it will be displayed in the system)

• Email — the Partner's e-mail address

• Phone — a contact phone number

• Deposit — the advance amount for services (if used)

• TIN — individual identification number

• KPP — the organization's registration code

-   VAT — specify the percentage
    

• 1C code — a code for synchronization with the 1C program (when integrated)

-   Region — select from the list
    

### Access and linking settings

• Partner blocking — completely blocks the Partner's access to the system

• Contract Users blocking — blocks sign-in for all Users created in this Partner's account

• Partner — the main Partner to which the Contract will be linked (if the sub-partner scheme is used)

### Financial and tariff parameters

• Currency — the main settlement currency

• Additional currencies — if necessary, you can select several currencies

• Tariff — the tariff plan for settlements under the Contract. Select the price list that will be applied to Objects. A tariff can be assigned to an account or to a Partner (then it applies to all of its accounts).

The tariff applies only to new Objects. Existing vehicles keep the price lists assigned previously.

• Partner tariff — an additional Partner program tariff

• Organization type — select the organization form from the list

• Account type — select the settlement model from the drop-down list

### Sign-in data

• Password for Users — select the password complexity level: simple or complex

• Show password for Users — choose whether to show or hide

• Login — specify the login used to sign in to the Partner's admin panel (required field)

• Password — the password of the administrator account

4\. After filling in all the required fields, click “Save”.

After saving, you will be able to assign Contracts to the Partner, connect Objects and create Users.
