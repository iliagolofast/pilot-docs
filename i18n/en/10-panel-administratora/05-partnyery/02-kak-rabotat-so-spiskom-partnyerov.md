---
title: "How to work with the Partner list"
---

The “Partners” section shows all Partner agreements that have been created. Here you can quickly find the Partner you need, check its status and manage its data.

![](images/drex_kak_rabotat_so_spiskom_partnyerov_custom.png)

The following actions are available at the top of the page:

![](images/drex_kak_rabotat_so_spiskom_partnyerov_custom_2.png)

• Add — create a new Partner agreement

• Export — export the list of Partners to a file

• Search — quick search by name, login, phone and other data

• Show deleted — display archived records

• Clear filters — reset the search parameters

### Partner table

Each row is a separate Partner agreement.

The table shows:

• Id — the unique number of the Contract in the system

• Name — the internal name of the agreement

• Tariff — the settlement tariff plan

• Balance — the current state of settlements (positive, zero or debt)

• Email and Phone — contact details

• Login — the Partner's sign-in data

• Number of Contracts — the number of contracts concluded

• Number of machines — the amount of connected equipment

• Partner — the main Partner is shown if this one is a sub-partner

• Comment — service information or cooperation terms

### Table settings

You can set up the list display the way that suits you best. Choose which columns with parameters to display, and set up their sorting and filters:

1\. In the header of any column, click the arrow ![](images/drex_kak_rabotat_so_spiskom_partnyerov_custom_3.png). A menu with column settings appears:

• sort ascending or descending

• filter by the selected column

• choose columns to display

2\. To choose which columns to show:

• click “Columns”

• check the parameters you need — the table updates automatically
