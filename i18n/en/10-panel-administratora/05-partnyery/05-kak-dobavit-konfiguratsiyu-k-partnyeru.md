A configuration is a set of system parameters and settings that adapt the system's operation to specific tasks. Each configuration consists of a key — a unique identifier — and a value, which can be a number, text or a more complex data structure.

### How to add a configuration to a Partner:

-   # In the admin panel, go to the “Partners” section

2\. Double-click the selected Partner — a window with settings opens

3\. Go to the “Configuration” tab and click the “Add” button

4\. In the drop-down list, select the configuration you need and specify a value for it

## Partner configurations

The system provides a list of available configurations that can be set for a Partner.

Each configuration consists of:

-   Name — the name of the setting
    
-   Key (value) — the technical name of the parameter used by the system
    

If a Partner needs special operating logic (for example, connecting an SMS provider, changing how the balance is displayed, integration with Helpdesk, Twilio, Here Maps, etc.), the corresponding configuration is added with the required value.

Examples:

-   To display the balance in days instead of money, the key balance\_in\_days = 1 is used
    
-   To connect a Telegram bot, the bot address is specified, for example: @PilotGpsBot
    
-   To connect SMTP or an SMS provider, the authorization parameters are specified as an object (login, password, API key, etc.)
