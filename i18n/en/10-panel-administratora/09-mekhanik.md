---
title: "Mechanic"
---

The tab is used to monitor existing settings and add new machines.

Rights of the Mechanic type allow limited actions in the system.

-   **ID -** the unique number in the system.
    
-   **Device ID -** the unique id number in the system.
    
-   **SIM  -** the SIM number linked to the Object.
    
-   **Machine number -** the name of the machine in the system.
    
-   **Contract -** the Contract number in the system and a window for viewing the machine settings.
    
-   **Client -** the name of the Contract.
