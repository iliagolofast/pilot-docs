---
title: "Account mapping"
---

**A function for mirroring an object to another account.**

-   **Id -** unique account number.
    
-   **User name -** user name.
    
-   **E-mail -** user’s e-mail address.
    
-   **Contract name -** name of the contract in the system.
    
-   **Contract ID -** unique number in the system.
    
    ![](images/drex_account_mapping_custom.png)
    

In the “Account mapping” section, select the user by name, ID or contract number.

This is the contract the object will be mirrored to.

![](images/drex_account_mapping_custom_2.png)

-   Double-click this user to open the settings.
    
-   Select the account the object should be mirrored from.
    
-   Then save the settings.
    

![](images/drex_account_mapping_custom_3.png)

Log in as the selected user to the account the object is mirrored to.

![](images/drex_account_mapping_custom_4.png)

Then, in the user settings, select the objects you want to display.

![](images/drex_account_mapping_custom_5.png)
