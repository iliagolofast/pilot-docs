List of rebrandings.

-   **ID -** unique identifier of the recast record.
    
-   **Contract ID** - number of the partner’s contract in the system.
    
-   **Organization name -** title displayed on the login page.
    
-   **Url -** alternative link to PILOT.
    
-   **Url PTM -** alternative link to PTM.
    
-   **Logo -** link to the logo image.
    
-   **Second logo -** link to the second logo image.
    
-   **Favicon** - website icon. It is displayed in the address bar before the page title.
    
-   **iOS -** link to the mobile app in the App Store.
    
-   **Android -** link to the mobile app on Google Play.
    
-   **Theme -** selected PILOT color theme.
