### Administrator

— a user of the admin panel who is responsible for configuring and managing the monitoring system.

Their main tasks include:

— creating and managing user accounts

— setting up access rights for different roles

— monitoring user activity in the system

— technical setup of hardware: servers, sensors, GPS devices

— configuring platform parameters for a specific company’s needs, for example, connecting modules and setting up contracts

Here you will find information on creating contracts, working with modules, using and working with the configuration, and making other settings for effective use of the system.
