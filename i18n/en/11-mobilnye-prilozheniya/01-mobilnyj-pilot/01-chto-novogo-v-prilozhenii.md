title: "What’s new in the app"

Here we have gathered the latest app updates — what has changed and which new features are now available.

## [Transport analytics](kak-prosmotret-analitiku.html)

The mobile app now has an “Analytics” tab for monitoring key transport performance indicators. It shows statistics for the last 24 hours: idle and working time, mileage and the number of vehicles.

Vehicle statuses, connection state, mileage, violations, geofences and other indicators are shown on charts. You can assess the situation and spot deviations right from your smartphone.

## [AI assistant](kak-rabotat-s-ii-podderzhkoj.html)

The PILOT AI assistant is now available in the mobile app. It helps you find the features you need and explains how to perform common tasks: build a report, set up an object, create a geofence or connect a device. Answers may contain links to the relevant documentation sections.

Chats are saved in the history — you can return to previous conversations to continue the discussion or view an answer again.

![](images/drex_chto_novogo_v_prilozhenii_custom_3.png)![](images/drex_chto_novogo_v_prilozhenii_custom_4.png)

## [Additional login protection](kak-ustanovit-i-vojti-v-prilozhenie.html#Вход_в_приложение_с_двухфакторной_аутентификацией_)

Login with two-factor authentication is now available in the app. After entering your login and password, confirm the login with a one-time code from an authenticator app or from e-mail.

The additional check protects your account even if someone else learns your password.

![](images/drex_chto_novogo_v_prilozhenii_custom_5.png)     ![](images/drex_chto_novogo_v_prilozhenii_custom_6.png)

## [Top up your balance via Stripe](menyu-i-nastrojki-polzovatelya.html#Финансы_)

You can now top up your organization’s balance via Stripe. On the “Finance” tab, enter the amount, proceed to payment and choose an available method on the Stripe page.

The feature is available for accounts with Stripe payment enabled. You can check the account status after payment right in the app.

![](images/drex_chto_novogo_v_prilozhenii_custom_7.png)

## [Viewing events and notifications](kak-prosmatrivat-uvedomleniya-i-sobytiya.html)

The “Events” section now has separate “Notifications” and “Events” tabs. The first collects triggered rules you have set up; the second collects changes in the state of objects and sensors.

For each tab you can separately choose the objects, data types and viewing period. You can open the place where a notification or event was registered on the map.

## [Address display](menyu-i-nastrojki-polzovatelya.html#Отображение_адреса)

You can now choose which parts of the address are displayed in the app — for example, in object cards, reports, history and other sections.

We added a new “Address display” tab to the app menu. Open it to turn the address components you need on or off.

![](images/drex_chto_novogo_v_prilozhenii_custom_10.png)   ![](images/drex_chto_novogo_v_prilozhenii_custom_11.png)

## [Updated “Info” tab](kak-rabotat-s-obektami.html#инфо)

Now, when you open an object card, the “Info” tab immediately shows a map with the vehicle’s current location.

![](images/drex_chto_novogo_v_prilozhenii_custom_12.png)

## [Object’s current track](kak-rabotat-s-obektami.html#текущий_трек)

The object menu now has a “Current track” tab.

Here you can see the object’s current location and its recent movement right on the map.

   **![](images/drex_chto_novogo_v_prilozhenii_custom_13.png)**![](images/drex_chto_novogo_v_prilozhenii_custom_14.png)

## [Viewing raw points](kak-poluchit-syrye-tochki.html)

Viewing raw data is now available in the mobile app.

You can see the unprocessed points that the device sends to the system.

![](images/drex_chto_novogo_v_prilozhenii_custom_15.png)   ![](images/drex_chto_novogo_v_prilozhenii_custom_16.png)

## [Arming an object](kak-postavit-obekt-na-okhranu.html)

You can now arm and disarm an object in the mobile app.

If a security sensor is set up, the object menu shows an “Arming” item, and the corresponding security status icons appear next to the object in the list.
