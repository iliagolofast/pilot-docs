## Installing the app

To start using the mobile version of PILOT, install the app on your smartphone.

### Method 1. Through the app store

1\. Open the app store on your phone:

-   Google Play, if you have an Android phone
    
-   App Store, if you use an iPhone
    
    2\. In the search bar, enter: ПИЛОТ
    
    3\. Find the app with the brand icon and tap “Install”
    

![](images/drex_kak_ustanovit_i_vojti_v_prilozhenie_custom.png)

### Method 2. Via a direct link

You can go straight to the app store using a link from your smartphone:

[Go to Google Play](https://play.google.com/store/apps/details?id=ru.octys.pilot) 

[Go to App Store](https://itunes.apple.com/us/app/pilot/id917533772?l=ru&ls=1&mt=8)

After following the link, install the PILOT app.

When installation is complete, the PILOT icon appears on your smartphone screen — tap it to open the app.

## Logging in to the app

To log in to the app, make sure you have:

-   A smartphone with the PILOT mobile app installed
    
-   An internet connection
    
-   The login and password for your PILOT account
    

### How to log in

1\. Open the PILOT app

2\. On the start screen, enter the login and password for your web account

![](images/drex_kak_ustanovit_i_vojti_v_prilozhenie_custom_2.png)

3\. Tap “Log in”

4\. If you want your details to be saved so you don’t have to enter them every time, select the “Remember me” checkbox

5\. Select the server to log in to

![](images/drex_kak_ustanovit_i_vojti_v_prilozhenie_custom_3.png)

After a successful login, you will go to the app’s main screen with its sections.

![](images/drex_kak_ustanovit_i_vojti_v_prilozhenie_custom_4.png)

### Logging in as an administrator

Administrators can log in to the app with their own login and immediately see the profiles of all users under the contract. You can quickly switch between accounts, help colleagues and manage settings in the mobile app.

1\. Enter the administrator login and password

![](images/drex_kak_ustanovit_i_vojti_v_prilozhenie_custom_5.png)

2\. Tap “Log in”

3\. Select the server to log in to

4\. The app shows a list of contracts assigned to the administrator

![](images/drex_kak_ustanovit_i_vojti_v_prilozhenie_custom_6.png)

5\. Tap the contract you need

6\. Select a specific user within the contract and go to their user account

![](images/drex_kak_ustanovit_i_vojti_v_prilozhenie_custom_7.png)

## Logging in to the app with two-factor authentication

Two-factor authentication (2FA) adds extra protection to your PILOT account. To log in, you need not only a login and password but also a one-time code. Even if someone else learns your password, they cannot log in to the account without this code.

PILOT offers two ways to confirm a login:

-   Code from an authenticator app (TOTP) — the code is generated in a connected app, for example, Google Authenticator or Microsoft Authenticator
    
-   Code by e-mail (Email 2FA) — the system sends a code to a verified e-mail address
    

Before logging in to the mobile app, you must [enable](../../lichnyj-kabinet-polzovatelya/nastrojki-dogovora-2/privatnost.html#Двухфакторная_аутентификация) the chosen 2FA method in the user profile in the PILOT web interface.

Both two-factor authentication methods can be enabled for an account at the same time. In this case, you must complete both verification steps in order when logging in: enter the code from the authenticator app, then the code received by e-mail.

### Logging in with a code from an authenticator app (TOTP)

This verification method uses a six-digit code from the authenticator app.

To learn how to enable TOTP authentication in the web interface, read [here](../../lichnyj-kabinet-polzovatelya/nastrojki-dogovora-2/privatnost.html#Как_подключить_двухфакторную_аутентификацию_TOTP:).

To log in to the mobile app:

1\. Open the PILOT app

2\. Enter your login and password

![](images/drex_kak_ustanovit_i_vojti_v_prilozhenie_custom_2.png)

3\. Tap “Log in”

4\. Open the authenticator app and find the code for your PILOT account

5\. Enter the six-digit code on the login confirmation screen

![](images/drex_kak_ustanovit_i_vojti_v_prilozhenie_custom_8.png)     ![](images/drex_kak_ustanovit_i_vojti_v_prilozhenie_custom_9.png)

6\. Tap “Log in”

After the code is verified successfully, the app opens

### Logging in with a code by e-mail (Email 2FA)

With this method, after your login and password are checked, PILOT sends a one-time code to the e-mail address specified in the user profile.

To learn how to enable e-mail login confirmation in the web interface, read [here](../../lichnyj-kabinet-polzovatelya/nastrojki-dogovora-2/privatnost.html#Как_подключить_Email_2FA:).

To log in to the mobile app:

1\. Open the PILOT app

2\. Enter your login and password

![](images/drex_kak_ustanovit_i_vojti_v_prilozhenie_custom_2.png)

3\. Tap “Log in”

4\. Check your e-mail and find the message with the code

5\. Enter the code you received on the login confirmation screen

![](images/drex_kak_ustanovit_i_vojti_v_prilozhenie_custom_10.png)   ![](images/drex_kak_ustanovit_i_vojti_v_prilozhenie_custom_11.png)

6\. Tap “Log in”

After the code is verified successfully, the app opens.

If the message does not arrive, check your “Spam” and “Junk” folders and make sure the correct address is specified in your profile. Do not share the one-time code with other people.

## Login settings

On the login screen, in the upper right corner, there is an icon ![](images/drex_kak_ustanovit_i_vojti_v_prilozhenie_custom_12.png) . Tap it to open “Login settings”.

![](images/drex_kak_ustanovit_i_vojti_v_prilozhenie_custom_13.png)

Here you can:

### Register using the

### [device QR code](../../panel-administratora/qr-kody.html)

—  the app reads a QR code that already contains the object data:

-   Scan the device QR code
    

Point your smartphone camera at the QR code on the device or in PILOT. Make sure the QR code is within the frame on the screen, and the app reads it automatically.

2\. Select an action:

-   Log in — if you already have an account in PILOT. In this case, the device is linked to your existing account automatically.
    
-   Register — if you do not have an account. The app offers to create a new account, and the device is added to the new account.
    

Registering a new user:

1\. Fill in the details:

— Email

— phone number

— password

— password confirmation

 Tap “Continue”.

2\. Confirm your e-mail

A confirmation code is sent to the e-mail address you specified. Enter the code on the confirmation screen. If the message does not arrive, you can request it again after the timer ends. Tap “Confirm”.

After successful confirmation, you are logged in to the app automatically, and the device scanned via the QR code is linked to your account in PILOT

### Change server

— enter the address of the server you need and save the changes by tapping “Accept”.

![](images/drex_kak_ustanovit_i_vojti_v_prilozhenie_custom_14.png)

### Go to system settings

— open your smartphone settings and grant the app the permissions it needs.

![](images/drex_kak_ustanovit_i_vojti_v_prilozhenie_custom_15.png)

To exit the “Login settings” section, tap “Cancel”.
