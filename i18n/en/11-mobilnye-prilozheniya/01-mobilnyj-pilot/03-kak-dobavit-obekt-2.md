title: "How to add an object"
---

In the mobile app, you can add an object by QR code or manually.

1\. Open the “Objects” tab

2\. Tap the plus icon in the upper right corner

![How to add an object ](images/drex_kak_dobavit_obekt__2_screen.png)

3\. Select how to add the object

-   “Scan QR code”
    
-   “Add manually”
    

 ![](images/drex_kak_dobavit_obekt__2_custom.png)

## Adding an object by QR code

1\. Select “Scan QR code”

![](images/drex_kak_dobavit_obekt__2_custom.png)

2\. If prompted, allow the app to access the camera

3\. Point your smartphone camera at the QR code placed on the device or [created in PILOT](../../panel-administratora/qr-kody.html). Make sure the code is fully inside the frame.

![](images/drex_kak_dobavit_obekt__2_custom_2.png)

After the QR code is recognized, the object is added automatically to the account that is open in the mobile app.

## Adding an object manually

Manual adding of objects is available only to users with administrator rights and consists of three steps:

###  1. Device

Enter the details of the device you are connecting:

-   Device ID — unique device identifier
    
-   Device type — device model
    
-   Device tags — if needed, select tags for grouping and search
    

![](images/drex_kak_dobavit_obekt__2_custom_3.png)    ![](images/drex_kak_dobavit_obekt__2_custom_4.png)

Tap “Next”.

### 2\. Vehicle

Fill in the vehicle details:

-   Vehicle number — registration number
    
-   Make
    
-   Model
    
-   Modification
    
-   Vehicle type
    
-   Color — determines the color of the object icon in the app
    

![](images/drex_kak_dobavit_obekt__2_custom_5.png)    ![](images/drex_kak_dobavit_obekt__2_custom_6.png)

Fields marked with an asterisk are required. Tap “Next”.

### 3\. Additional

If needed, specify additional parameters:

-   Group
    
-   Template
    
-   Time zone
    
-   Initial mileage
    
-   Initial engine hours
    
-   Description
    

![](images/drex_kak_dobavit_obekt__2_custom_7.png)    ![](images/drex_kak_dobavit_obekt__2_custom_8.png)

The set of available fields in the vehicle card depends on the connected modules. For example, the RFID and “Fuel representative ID” fields are shown if the corresponding modules are enabled for the account.

Tap “Add object”. After it is created successfully, the object appears in the general list.

![](images/drex_kak_dobavit_obekt__2_custom_9.png)    ![](images/drex_kak_dobavit_obekt__2_custom_10.png)
