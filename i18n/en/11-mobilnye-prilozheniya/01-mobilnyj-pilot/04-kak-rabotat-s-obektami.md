## Object list

The “Objects” section shows the list of all monitoring objects. Here you can see the status of objects and the time of last communication.

To find the object you need, use the “Search” field and enter the object’s name or number.

**![](images/drex_kak_rabotat_s_obektami_custom.png)**

Tap the ![](images/drex_kak_rabotat_s_obektami_custom_2.png) button to configure how the object list is displayed. You can choose which objects to show, as well as how objects are grouped — for example, by groups, geofences or tags.

![](images/drex_kak_rabotat_s_obektami_custom_3.png)

The object list shows a short summary for each object. From it you can tell where the object is, whether it is moving, and how much fuel and mileage it currently has.

**![How to work with objects](images/drex_kak_rabotat_s_obektami_screen.png)**

When you tap an object in the list, you go to the “Info” and “History” tabs with detailed information.

### “Info” tab

The “Info” tab shows all the main information about the object:

-   Location on the map
    
-   Statistics: data for the selected day — time in motion, mileage, maximum and average speed, fuel consumption and average consumption per 100 km.
    
-   Sensors: current state of the sensors and the time of their last update.
    
-   Additional information: vehicle model, current status, time of last communication, speed and mileage.
    

![](images/drex_kak_rabotat_s_obektami_custom_4.png)   ![](images/drex_kak_rabotat_s_obektami_custom_5.png)

The “Show on map” button opens a map with the object’s current location.

The “Get directions” block lets you build a route:

-   In PILOT — the route opens right in the app
    
-   On another map — an external map service opens
    

### “History” tab

The “History” tab shows exactly how the object moved during the selected period.

![How to work with objects](images/drex_kak_rabotat_s_obektami_screen_2.png)

The top of the screen shows a map with the object’s position and its track for the day.

Below the map is a short summary for the selected day: total mileage, maximum and average speed.

Just below is a date switcher — select the day you need, and the map, statistics and event list update for that date.

Next comes a detailed list of events for the selected day, in chronological order.

An event includes:

— start time

— event type (movement or parking)

— duration

— for movement events, the distance covered and the average or maximum speed

— the address where the movement started or ended, or the parking location

If you tap an event, the corresponding route appears on the map, and you can view it in the player.

![How to work with objects](images/drex_kak_rabotat_s_obektami_screen_3.png)

### Actions menu

Tap the three dots to open additional functions:

![](images/drex_kak_rabotat_s_obektami_custom_10.png)

![](images/drex_kak_rabotat_s_obektami_custom_11.png)

-   Show on map — return to displaying the object
    

![](images/drex_kak_rabotat_s_obektami_custom_12.png)

-   Create link — get a token that lets a third party view the object on the map
    

![](images/drex_kak_rabotat_s_obektami_custom_13.png)

-   Events — view notifications and events for the object: time, place, event type. With the settings  ![](images/drex_kak_rabotat_s_obektami_custom_14.png)you can select the objects for which events and notifications are shown, configure the types and specify the period — the dates and times for which you want to view the list of events that occurred.
