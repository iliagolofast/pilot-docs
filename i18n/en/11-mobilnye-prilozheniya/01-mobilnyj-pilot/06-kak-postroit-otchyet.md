---
title: "How to build a report"
---

In the “Reports” section, you can generate a report for selected objects and parameters.

![](images/drex_kak_postroit_otchyet__custom.png)

-   Select an object
    

In the “Objects” field, select one or more objects to generate the report for.

![](images/drex_kak_postroit_otchyet__custom_2.png)

2.Select the report type

Specify which report you want to get, for example:

— by mileage

— by time in motion and parking

— by fuel consumption

— by sensors

![](images/drex_kak_postroit_otchyet__custom_3.png)

The available report types depend on the [settings](../../lichnyj-kabinet-polzovatelya/otchyety-1/kak-nastroit-dostup-k-otchyetam-1.html) in your account.

3\. Set the time range

Select the start and end dates for the report. If needed, specify the exact time (hours and minutes).

The report is built only for this period.

4\. Set up the report breakdown

In the “Split” field, select how to divide the report into intervals:

-   By days — data is split by day
    
-   By weeks — totals by week
    
-   Do not split — the report for the whole period in one block
    
    ![](images/drex_kak_postroit_otchyet__custom_4.png)
    

5\. Select grouping

Determine how to group the report rows:

-   By dates — to analyze changes over time (each day or week in a separate row)
    
-   By objects — to compare different objects (each object in a separate row)
    

![](images/drex_kak_postroit_otchyet__custom_5.png)

6\. Specify sensor groups

Select one or more sensor groups to report on.

![](images/drex_kak_postroit_otchyet__custom_6.png)

7\. Download the report

After setting all the parameters, tap “Download report”. The app creates a report that you can open.

![](images/drex_kak_postroit_otchyet__custom_7.png)

### Additional parameters

Some reports may include additional settings. For example, in the parking report you can specify the minimum and maximum parking time (in seconds).  
   ![](images/drex_kak_postroit_otchyet__custom_2.png)   ![](images/drex_kak_postroit_otchyet__custom_8.png)
