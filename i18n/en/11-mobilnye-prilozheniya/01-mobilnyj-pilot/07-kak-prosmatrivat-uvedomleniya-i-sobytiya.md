title: "How to view notifications and events"
---

In the “Events” section, information is divided into two tabs:

-   [“Notifications”](../../lichnyj-kabinet-polzovatelya/moduli-1/uvedomleniya/index.html) — triggered rules that were set up in advance in the web interface. A notification is generated when the condition of a configured rule is met. For example, the system creates a “Speed control” notification if an object exceeded the specified speed and kept moving at that speed for longer than the set time.
    

# ![](images/drex_kak_prosmatrivat_uvedomleniya_i_sobytiya_custom.png)

-   [“Events”](../../lichnyj-kabinet-polzovatelya/moduli-1/sobytiya.html) — changes in the state of objects and sensors registered by the system, for example, ignition on, door opened, prolonged idling, sensor triggered.
    

![](images/drex_kak_prosmatrivat_uvedomleniya_i_sobytiya_custom_2.png)

## How to view notifications

Open the “Events” section and go to the “Notifications” tab.

# ![](images/drex_kak_prosmatrivat_uvedomleniya_i_sobytiya_custom.png)

Notifications are grouped by date. Each card shows:

— the object the notification relates to

— the time it was triggered

— the notification name

— a description of what happened

For example, a “Speed control” notification may contain the set limit, the maximum recorded speed and the duration of the violation.

Tap a card to open the map and see the place where the notification was triggered.

![](images/drex_kak_prosmatrivat_uvedomleniya_i_sobytiya_custom_3.png)

If push notifications are allowed for the account, the app alerts you about new triggers on your mobile device.

### How to configure the notification list

1\. Go to the “Notifications” tab

2\. Tap the settings icon in the upper right corner

# ![How to view notifications and events](images/drex_kak_prosmatrivat_uvedomleniya_i_sobytiya_screen.png)![](images/drex_kak_prosmatrivat_uvedomleniya_i_sobytiya_custom_4.png)

3\. In the “Objects” block, select groups or individual objects

# ![](images/drex_kak_prosmatrivat_uvedomleniya_i_sobytiya_custom_5.png)

4\. In the “Notification types” field, select one or more configured notifications, or leave the “All types” option

# ![](images/drex_kak_prosmatrivat_uvedomleniya_i_sobytiya_custom_6.png)

5\. Specify the start and end of the period

# ![](images/drex_kak_prosmatrivat_uvedomleniya_i_sobytiya_custom_7.png)

6\. Tap “Apply”

The list will show only the notifications that match all the selected conditions.

To clear the conditions you set and return to the initial settings, tap “Clear”.

## How to view events

Go to the “Events” tab. It shows the events that the system registered for objects and their hardware.

![](images/drex_kak_prosmatrivat_uvedomleniya_i_sobytiya_custom_2.png)

Each card shows:

— the object

— the event time

— the event type

— the description

For example, the list may show ignition on, idling, door opened or a service reminder.

Tap an event card to open the map and see the place where it was registered.

![](images/drex_kak_prosmatrivat_uvedomleniya_i_sobytiya_custom_8.png)

### How to configure the event list

1\. Go to the “Events” tab

2\. Tap the settings icon

![How to view notifications and events](images/drex_kak_prosmatrivat_uvedomleniya_i_sobytiya_screen_2.png)![](images/drex_kak_prosmatrivat_uvedomleniya_i_sobytiya_custom_9.png)

3\. In the “Objects” block, select the objects to display events for

![](images/drex_kak_prosmatrivat_uvedomleniya_i_sobytiya_custom_10.png)

4\. In the “Event types” field, select the categories you need, for example, “Route events”, “Agro”, “Battery” or “Complex events”. To avoid limiting the list by category, leave the “All types” option

![](images/drex_kak_prosmatrivat_uvedomleniya_i_sobytiya_custom_11.png)

5\. Specify the start and end of the period

![](images/drex_kak_prosmatrivat_uvedomleniya_i_sobytiya_custom_12.png)

6\. Tap “Apply”

To reset the selected conditions, tap “Clear”.

The set of available notification and event types depends on the account settings, connected modules and user rights.
