The “Menu” section contains the user profile, financial information and the main settings of the mobile app. Here you can switch between profiles, check the account status, top up your balance, configure address display, app parameters and the interface theme.

![](images/drex_menyu_i_nastrojki_polzovatelya_custom.png)

In this article:

-   [User profile](menyu-i-nastrojki-polzovatelya.html#Профиль_пользователя) — switching between saved profiles and logging out of the account
    
-   [Finance](menyu-i-nastrojki-polzovatelya.html#Финансы_) — information about the organization’s account and balance top-up via Stripe
    
-   [Address display](menyu-i-nastrojki-polzovatelya.html#Отображение_адреса) — choosing the address components displayed in the app
    
-   [Settings](menyu-i-nastrojki-polzovatelya.html#Настройки) — language, object refresh, map parameters and layer visibility
    
-   [Appearance](menyu-i-nastrojki-polzovatelya.html#Оформление) — choosing the light, dark or system theme
    

The set of tabs depends on the connected modules and the user’s rights.

The menu may also include [“Geofences”](kak-rabotat-s-geozonami-1.html), [“Drivers”](kak-rabotat-s-voditelyami-2.html), [“Inspections”](kak-rabotat-s-osmotrami.html), [“Analytics”](kak-prosmotret-analitiku.html), [“AI support”](kak-rabotat-s-ii-podderzhkoj.html), [“Commands”](kak-rabotat-s-komandami.html) and [“Video”](kak-prosmotret-video-1.html). Working with them is described in separate articles.

## User profile

The “User profile” block shows your name or login.

![Menu and user settings](images/drex_menyu_i_nastrojki_polzovatelya_screen.png)

If you want to switch to another account, tap your login — a list of profiles you have previously used in the app opens. If the “Remember” option was selected for these accounts, you can quickly switch to the profile you need without entering your details again.

# ![](images/drex_menyu_i_nastrojki_polzovatelya_custom_3.png)  ![](images/drex_menyu_i_nastrojki_polzovatelya_custom_4.png)

If you want to log out of the current account, go to the “Profiles” tab, where you will find the logout button.

![Menu and user settings](images/drex_menyu_i_nastrojki_polzovatelya_screen_2.png)

## Finance

The “Finance” tab shows information about the organization’s account status:

![Menu and user settings](images/drex_menyu_i_nastrojki_polzovatelya_screen_3.png)![](images/drex_menyu_i_nastrojki_polzovatelya_custom_5.png)

-   Organization — name of the organization
    
-   Account number — identifier of the settlement account in the system
    
-   Deposit — amount of the deposit made
    
-   Balance — current account status
    
-   Available balance — amount available for use
    
-   SMS balance — number of available SMS messages
    

### How to top up your balance via Stripe

Stripe is a payment service for secure payment by bank card and other available methods. If Stripe payment is enabled for your account, you can top up your balance in the mobile app:

1\. Open the “Finance” tab

2\. In the “Pay via Stripe” block, enter the amount

![Menu and user settings](images/drex_menyu_i_nastrojki_polzovatelya_screen_4.png)

3\. Tap “Pay”

4\. On the Stripe page, select a payment method and confirm the payment

5\. After the payment is processed successfully, return to the app and check your balance

## Address display

On this tab, you can configure which parts of the address are displayed in the system, for example, in object cards, reports or history.

![Menu and user settings](images/drex_menyu_i_nastrojki_polzovatelya_screen_5.png)

Go to the “Address display” tab and use the switches to select the address components you want to see. After configuring, tap the “Save” button at the bottom of the screen.

![Menu and user settings](images/drex_menyu_i_nastrojki_polzovatelya_screen_6.png) ![](images/drex_menyu_i_nastrojki_polzovatelya_custom_6.png)

You can turn the following elements on or off:

-   House number
    
-   Street
    
-   City
    
-   Postal code
    
-   Region
    
-   Country
    
-   Suburb
    
-   Info
    
-   Geofences
    
-   Hide address if there is a geofence — if enabled, when an object is inside a geofence, the system shows only the geofence name instead of the full address
    
-   Reverse address order — when this option is enabled, the address is displayed in reverse order — from the country down to the house number.
    

## Settings

On the “Settings” tab, you can configure how the app works and looks, including map and refresh parameters.

# ![](images/drex_menyu_i_nastrojki_polzovatelya_custom_7.png)

Main settings:

# ![](images/drex_menyu_i_nastrojki_polzovatelya_custom_7.png)

-   Language — select the app interface language
    
-   Object refresh period — set how often object location data is refreshed (for example, every 20 seconds)
    
-   High location accuracy — enable this option so the app uses more accurate location methods
    
-   Show the [“Change scale”](kak-rabotat-s-kartoj.html#изменить_масштаб_карты_мобпилот) button — if you enable this option, a separate zoom button is displayed on the map.
    
-   Group objects on the map — enable this setting if you want objects located close to each other to be grouped into “clusters” for easier viewing
    
-   Show geofence names — when this function is enabled, geofence names are displayed on the map
    

Layer visibility:

-   KML layer visibility — turn on or off the [KML/KMZ layers](../../lichnyj-kabinet-polzovatelya/nastrojki-dogovora-2/nastrojki-kml.html) uploaded in the web version (for example, additional outlines, objects or boundaries) that are displayed on the map
    
-   Tile layer visibility — this switch turns additional map layers on or off
    

Account management:

At the bottom of the screen you will find the button for deleting your account. However, to delete the account completely, you need to contact technical support.

# ![](images/drex_menyu_i_nastrojki_polzovatelya_custom_8.png)
