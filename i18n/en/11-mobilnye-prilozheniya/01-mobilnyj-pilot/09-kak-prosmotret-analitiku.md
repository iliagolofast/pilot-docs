On the “Analytics” tab, you can see your transport performance indicators at a glance. Here you can see overall statistics and detailed charts for various parameters.

![](images/drex_kak_prosmotret_analitiku_custom.png)  

## ![](images/drex_kak_prosmotret_analitiku_custom_2.png)

Statistics are shown for the last 24 hours.

At the top of the screen there are information blocks with the main indicators, for example:

-   Idle time
    
-   Mileage
    
-   Number of vehicles
    
-   Working time
    

Below are charts that help you assess the situation visually, for example, “Vehicle status”, “Connection”, “Mileage”, “Violation control”, “Geofences”, etc.

![](images/drex_kak_prosmotret_analitiku_custom_3.png)   ![](images/drex_kak_prosmotret_analitiku_custom_4.png)    ![](images/drex_kak_prosmotret_analitiku_custom_5.png)

### How to configure analytics

You can choose which information blocks and charts you want to see:

1\. Tap the settings button

## ![](images/drex_kak_prosmotret_analitiku_custom_6.png)

2\. In the “Transport info blocks” section, select the checkboxes for the indicators you need

![](images/drex_kak_prosmotret_analitiku_custom_7.png)

3\. In the “Charts” section, select the charts that matter to you

![](images/drex_kak_prosmotret_analitiku_custom_8.png)

All charts you created in the web version (including through templates) are also available in the mobile app.

### Configuring charts

Some charts have additional settings. For example, in the “Mileage” chart you can set a limit (for example, 100 km).

![](images/drex_kak_prosmotret_analitiku_custom_9.png)   ![](images/drex_kak_prosmotret_analitiku_custom_10.png)

The chart will then show:

-   How many vehicles traveled less than 100 km
    
-   How many vehicles traveled more than 100 km
    
    You can set any limit you need to understand the statistics.
