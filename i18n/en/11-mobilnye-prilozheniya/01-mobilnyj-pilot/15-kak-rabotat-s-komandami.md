---
title: "How to work with commands"
---

With the mobile app, you can send [commands](../../lichnyj-kabinet-polzovatelya/moduli-1/komandy-1.html) to objects to control them remotely:

1\. Go to the “Objects” section and select the object you want to send a command to

2\. Tap the object menu ![](images/drex_kak_rabotat_s_komandami_custom.png) and select the “Commands” tab

    **![](images/drex_kak_rabotat_s_komandami_custom_2.png)**![](images/drex_kak_rabotat_s_komandami_custom_3.png)

3\. On the “Commands” tab, you will see a list of commands that can be run for the selected object, for example, sending an SMS command to the device, requesting settings, etc.

Tap the command you need to send it to the device.

![](images/drex_kak_rabotat_s_komandami_custom_4.png)

In the “Command history” block, you can see all previously sent commands, their statuses and details:

-   Command name
    
-   Status
    
-   Command type
    
-   User who sent the command
    
-   Date the command was sent
    
-   Time of the last command status update
    
-   Vehicle the command was applied to
    

If you need to cancel a command, tap ![](images/drex_kak_rabotat_s_komandami_custom_5.png) and “Cancel command”.

![How to work with commands](images/drex_kak_rabotat_s_komandami_screen.png)![](images/drex_kak_rabotat_s_komandami_custom_6.png)

To see the command history for a specific period, use the filters. Tap ![](images/drex_kak_rabotat_s_komandami_custom_7.png) and select the date and time to filter commands by the period you need, then tap “Apply”.

 ![](images/drex_kak_rabotat_s_komandami_custom_4.png)   ![](images/drex_kak_rabotat_s_komandami_custom_8.png)
