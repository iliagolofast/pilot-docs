---
title: "How to get raw points"
---

Raw points are unprocessed data that the device sends directly to the system in real time. They show what values come from the sensors without filtering or processing.

### How to view raw points

1\. Open the object menu

2\. Go to the “Points” tab

![How to get raw points](images/drex_kak_poluchit_syrye_tochki_screen.png)![](images/drex_kak_poluchit_syrye_tochki_custom.png)

On this tab you will see the data that the device sends.

![How to get raw points](images/drex_kak_poluchit_syrye_tochki_screen_2.png)

To view the full set of unprocessed data:

— tap “Raw data”

— if needed, you can copy the data by tapping the “Copy” button

![](images/drex_kak_poluchit_syrye_tochki_custom_2.png)

### Viewing points on a chart

To view the data on a chart:

1\. Switch to chart mode

![How to get raw points](images/drex_kak_poluchit_syrye_tochki_screen_3.png)

2\. Select one or more parameters to display on the chart. To do this, turn on the switch next to the parameter you need

  ![How to get raw points](images/drex_kak_poluchit_syrye_tochki_screen_4.png)   ![](images/drex_kak_poluchit_syrye_tochki_custom_3.png)   ![](images/drex_kak_poluchit_syrye_tochki_custom_4.png)

The chart shows the values of the selected parameters. If you hover over a specific point, a tooltip appears with the exact time and value at that moment.

![](images/drex_kak_poluchit_syrye_tochki_custom_5.png)   ![](images/drex_kak_poluchit_syrye_tochki_custom_6.png)

### Configuring the display of point fields

On the “Points” tab, you can configure how data is displayed:

— select which parameters to show for each GPS point

![How to get raw points](images/drex_kak_poluchit_syrye_tochki_screen_5.png)   ![](images/drex_kak_poluchit_syrye_tochki_custom_7.png)

— filter the points you need by time range

![](images/drex_kak_poluchit_syrye_tochki_custom_7.png)   ![](images/drex_kak_poluchit_syrye_tochki_custom_8.png)
