---
title: "Mobile PILOT"
---

The PILOT mobile app is an application for monitoring vehicles and managing objects right from your smartphone. It offers all the main features of the PILOT monitoring system.

![](images/drex_mobilnyj_pilot_custom.png)

With the app you can:

— track object locations on the map in real time

— view movement history and vehicle statistics

— build reports for a selected period

— view event notifications

— monitor device operating parameters
