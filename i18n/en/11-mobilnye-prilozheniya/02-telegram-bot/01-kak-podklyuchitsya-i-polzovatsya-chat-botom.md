## How to connect to the chatbot

1\. Open Telegram and find the bot [@skyelectronics\_bot](https://t.me/skyelectronics_bot)

![](images/drex_kak_podklyuchitsya_i_polzovatsya_chat_botom_custom.png)

2\. Tap the “Start” button

3\. Select “Start authorization”

4\. Enter your account login and password

If you made a mistake, tap “Reset login” and start over.  

 ![](images/drex_kak_podklyuchitsya_i_polzovatsya_chat_botom_custom_2.png)

## How to use the bot menu

Tap the “Menu” button — the main functions appear:

  ![How to connect to and use the chatbot](images/drex_kak_podklyuchitsya_i_polzovatsya_chat_botom_screen.png)  ![](images/drex_kak_podklyuchitsya_i_polzovatsya_chat_botom_custom_3.png)

### Help

When you tap Help, you get a short welcome message from the bot.

In it, the bot explains what it can do:

— show the list of your vehicles

— give information on each vehicle

— provide your unique ID, which is needed for the tracker to work

### Advanced Menu

When you tap this command, an extended menu with buttons appears:

![How to connect to and use the chatbot](images/drex_kak_podklyuchitsya_i_polzovatsya_chat_botom_screen_2.png)

-   Vehicles — shows the list of all your vehicles
    
     ![](images/drex_kak_podklyuchitsya_i_polzovatsya_chat_botom_custom_4.png)
    
-   Get ID — the bot sends you your unique ID
    
     The ID is the number of a virtual GPS tracker. It works like a real [tracker](ispolzovanie-telegram-kak-gps-trekera.html) in a vehicle, except that the data is transmitted through Telegram from your phone.
    
     ![](images/drex_kak_podklyuchitsya_i_polzovatsya_chat_botom_custom_5.png)
    
-   Get user — shows which account you are currently logged in to
    
    ![](images/drex_kak_podklyuchitsya_i_polzovatsya_chat_botom_custom_6.png)
    
-   Log out — you log out of the account in the bot
    

### Change language

Use this button if you want to change the bot interface language.

![](images/drex_kak_podklyuchitsya_i_polzovatsya_chat_botom_custom_5.png)

### Version bot

Shows the current version of the bot.

![](images/drex_kak_podklyuchitsya_i_polzovatsya_chat_botom_custom_5.png)

## How to get the vehicle list

1\. Make sure you are logged in to the bot

2\. Go to Advanced Menu to open the extended menu

 ![](images/drex_kak_podklyuchitsya_i_polzovatsya_chat_botom_custom_3.png)

3\. Select “Vehicles” — the list of vehicles in the account is displayed

 ![](images/drex_kak_podklyuchitsya_i_polzovatsya_chat_botom_custom_4.png)

If you select a specific vehicle, the bot shows:

— a summary for the object

— a map link to view the location

 ![](images/drex_kak_podklyuchitsya_i_polzovatsya_chat_botom_custom_7.png)

When working with the vehicle list, you can search for the vehicle you need by typing text. Just write in the chat, for example: “Show vehicles” “Find vehicle 7009”

The bot recognizes the digits and letters of the number and picks all matching options. If there are matches in the list, it shows only the vehicles that fit your query.
