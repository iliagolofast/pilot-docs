---
title: "How to create your own Telegram bot"
---

To create a Telegram bot yourself, you need the official @BotFather service — the main Telegram bot through which all other bots are created and configured.

1\. Follow the link: [https://t.me/BotFather](https://t.me/BotFather)

2\. Tap Start to open the menu

               ![](images/drex_kak_sozdat_svoj_telegram_bot_custom.png)

3\. Enter the command: /newbot

              ![](images/drex_kak_sozdat_svoj_telegram_bot_custom_2.png)

4\. Come up with a name for the bot

BotFather asks you to specify the bot’s name — the display name that people see.

5\. Come up with a username for the bot —  its address in Telegram

There is an important rule here — the username must end with \_bot. For example, mycompany\_bot, skyelectronics\_helper\_bot

6\. Get the token

After BotFather creates the bot, a congratulations message appears. Right below it you will see:

-   Token to access the HTTP API — the bot token
    

<table><tbody><tr><td><div><img alt="3. " src="images/drex_kak_sozdat_svoj_telegram_bot_control_3.png" data-full-src="drex_kak_sozdat_svoj_telegram_bot_control_3.png" data-full-width="506" data-full-height="95"></div></td></tr><tr><td><div><a href="#top"></a></div></td></tr></tbody></table>

-   Username — your bot’s user name
    

7\. Send your bot’s token and username to technical support to connect the bot to PILOT
