---
title: "How to send statuses and media files via the Telegram bot"
---

The Telegram bot lets employees send information to PILOT directly from a mobile device. An employee can select the current status and also send a photo or video from the work site.

For example, an employee can send the statuses “On the way”, “Arrived at the site” and “Started work” in sequence, and after finishing, select the status “Work completed” and attach a photo of the result. Sent media files can be found and viewed in the PILOT web interface.

## Setting up Telegram statuses

Statuses are created separately for each PILOT account. In the Telegram bot, an employee sees only the options that the master added in the settings of the corresponding account.

Setup is done by a user with master rights:

1\. Log in to the PILOT web interface

2\. Open “Contract settings”

3\. Go to the “Telegram statuses” tab

![](images/drex_kak_peredavat_statusy_i_mediafajly_cherez_telegram_bot_custom.png)

4\. Click “+ Add”

![](images/drex_kak_peredavat_statusy_i_mediafajly_cherez_telegram_bot_custom_2.png)

5\. Enter the status name

![](images/drex_kak_peredavat_statusy_i_mediafajly_cherez_telegram_bot_custom_3.png)

6\. Click “OK”

The created status appears in the general list. The value in the “Order” column determines its position among the other statuses.

![](images/drex_kak_peredavat_statusy_i_mediafajly_cherez_telegram_bot_custom_4.png)

To delete a status, select it in the list and click “Delete”.

After the account is connected to the Telegram bot, the created statuses become available to authorized users.

## How to send a status

### Logging in to the Telegram bot

Before starting, an employee needs to link the Telegram bot to a PILOT account:

1\. Open the PILOT Telegram bot

2\. Start the bot with the **/start** command

3\. Enter the PILOT account login

4\. Enter the password

5\. Wait for the message confirming successful authorization

To log in, use the account in whose settings the master created the required statuses.

### How to send a status in the bot

1\. In the bot menu, tap “Status”

![How to send statuses and media files via the Telegram bot](images/drex_kak_peredavat_statusy_i_mediafajly_cherez_telegram_bot_screen.png)

3\. Select the status you need from the list provided

![](images/drex_kak_peredavat_statusy_i_mediafajly_cherez_telegram_bot_custom_5.png)

4\. Wait for the “Status sent” message

The bot has accepted the selected status. After that, you can continue working with the bot: select another status when the work stage changes, or send a photo or video.

## How to send a photo or video

Through the Telegram bot you can send materials that confirm completed work or show the condition of an object. For example, the work location, equipment before servicing, the result of the work, delivered cargo.

To send a file:

1\. Open the PILOT Telegram bot

2\. Tap the paperclip icon

![How to send statuses and media files via the Telegram bot](images/drex_kak_peredavat_statusy_i_mediafajly_cherez_telegram_bot_screen_2.png)

3\. Select a photo or video on your mobile device

![](images/drex_kak_peredavat_statusy_i_mediafajly_cherez_telegram_bot_custom_6.png)

4\. Send the file

   ![](images/drex_kak_peredavat_statusy_i_mediafajly_cherez_telegram_bot_custom_7.png)

5\. Wait for the “Media saved” message

![](images/drex_kak_peredavat_statusy_i_mediafajly_cherez_telegram_bot_custom_8.png)

The message confirms that the file has been received and saved in PILOT

## How to view sent media files

The first time a media file is sent, a separate object named after the Telegram user is created in the PILOT object list. All subsequent photos and videos from this user are saved in the same object.

1\. Open the “Online” tab in the PILOT web interface

2\. Find the object named after the Telegram user in the tree

3\. Right-click the object

4\. Select “Media”

![](images/drex_kak_peredavat_statusy_i_mediafajly_cherez_telegram_bot_custom_9.png)

5\. Specify the period for which to show materials

![](images/drex_kak_peredavat_statusy_i_mediafajly_cherez_telegram_bot_custom_10.png)

6\. Find the record you need

![](images/drex_kak_peredavat_statusy_i_mediafajly_cherez_telegram_bot_custom_11.png)

7\. Click the photo icon ![](images/drex_kak_peredavat_statusy_i_mediafajly_cherez_telegram_bot_custom_12.png) or the video icon ![](images/drex_kak_peredavat_statusy_i_mediafajly_cherez_telegram_bot_custom_13.png) to open the file

![](images/drex_kak_peredavat_statusy_i_mediafajly_cherez_telegram_bot_custom_14.png)

To save the file to your computer, click the download icon ![](images/drex_kak_peredavat_statusy_i_mediafajly_cherez_telegram_bot_custom_15.png) next to the corresponding record.

The “Media” tab shows the photos and videos sent by this user through the Telegram bot, as well as the date and time they were received.
