title: "New tasks"
---

The “New” tab shows tasks that have been assigned to you and are waiting to be accepted. Until you tap the [“Accept task”](kak-prinyat-novoe-zadanie.html) button, the task stays on this tab.

![](images/drex_novye_zadaniya_custom.png)

Each task is shown as a card with the main information:

— task name

— task number

— planned start date and time

— planned end date and time

— estimated duration

To open a task, tap its card.

## Sorting tasks

If the list contains many tasks, you can change the order in which they are displayed.

To do this:

1\. Open the “New” tab

2\. Tap the list settings icon in the upper right corner

![New tasks](images/drex_novye_zadaniya_screen.png)

3\. In the “List settings” window, select a sorting option:

![](images/drex_novye_zadaniya_custom_2.png)

-   Newest first — later tasks are shown at the top of the list
    
-   Oldest first — earlier tasks are shown at the top of the list
    
    4\. Tap “Apply”
    

The list is updated automatically according to the selected sorting.

## Viewing a task

To open a task, tap its card in the list.

After it opens, the task card with information is displayed.

The top of the card shows:

— start date and time

— end date and time

Below is the “Accept task” button, which puts the task in progress.

![](images/drex_novye_zadaniya_custom_3.png)

### Task information

The “Task information” section shows the main details of the trip. The set of fields depends on the task type, but usually includes:

-   task name
    
-   customer or counterparty details
    
-   information about the vehicle, cargo, etc.
    

### Waybill

Below is the “Waybill” section, which shows the route with all the visit points.

For each point, the following are shown:

-   address
    
-   point number
    

To see detailed information about a point, tap it in the waybill.

![](images/drex_novye_zadaniya_custom_4.png)

The window that opens shows:

— full address

— current point status

— “Actions” button

The “Actions” button gives access to the following functions:

-   Copy address — copy the address to the clipboard to use in a navigator or message
    
-   Show on map — open the map showing the location of the selected point
    

![](images/drex_novye_zadaniya_custom_5.png)

To open the route map, tap the map icon in the upper right corner of the task card. For more on working with the map, see the article “Route map”.
