The “Active” tab shows tasks that you have already accepted and are currently carrying out. Here you can track progress, work with route points and complete tasks.

![](images/drex_aktivnye_zadaniya__custom.png)

Each task is shown as a card with the main information:

— task name and number

— progress — the number of points completed out of the total

— planned start and end time

— a progress indicator showing how much of the route has been completed

## Sorting tasks

If the list contains many tasks, you can change the order in which they are displayed.

To do this:

1\. Open the “Active” tab

2\. Tap the list settings icon in the upper right corner

![Active tasks ](images/drex_aktivnye_zadaniya__screen.png)

3\. In the “List settings” window, select a sorting option:

![](images/drex_aktivnye_zadaniya__custom_2.png)

-   Newest first — newer tasks are shown first
    
-   Oldest first — earlier tasks are shown first
    
    4\. Tap “Apply”
    

The list is updated automatically according to the selected sorting.

## Viewing a task

To open a task, tap its card.

![](images/drex_aktivnye_zadaniya__custom_3.png)

The task card shows:

— planned start and end time

— task type

— additional information (contact details, cargo information and other data)

— the route with the list of visit points

If the task has been accepted, tap the “Start task” button to begin carrying it out.

![Active tasks ](images/drex_aktivnye_zadaniya__screen_2.png)

### Working with route points

After you start the task, the screen shows the “Next point” block — the address to visit next.

The following actions are available for the selected point:

-   Route — build a route in the navigation app installed on the device
    
-   Arrived — mark your arrival at the point
    

After you tap “Arrived”, the point becomes active.

![](images/drex_aktivnye_zadaniya__custom_4.png)

 Additional actions become available for it:

![](images/drex_aktivnye_zadaniya__custom_5.png)

— add a comment

— complete the point

— open the “Other actions” menu

You can use a comment to record additional information about the work performed, delivery or other events.

**Other actions**

Additional operations are available for the current point:

![Active tasks ](images/drex_aktivnye_zadaniya__screen_3.png)![](images/drex_aktivnye_zadaniya__custom_6.png)

-   Copy address — copy the address to the clipboard
    
-   Show on map — open the point location on the map
    
-   Postpone point — temporarily defer the point
    

The postpone function can be useful in the following cases:

— the recipient is temporarily absent

— the point cannot be completed for external reasons

— you need to visit another route point first

After a point is postponed, it gets the “Postponed” status, and the app offers to move to the next route point. You can return to the postponed point later.

![](images/drex_aktivnye_zadaniya__custom_7.png)

### Progress

The current task progress is shown:

— in the active task list

![](images/drex_aktivnye_zadaniya__custom_8.png)

 — in the task card, in the “Progress” section

![](images/drex_aktivnye_zadaniya__custom_7.png)

### Task menu

In the upper right corner of the task card there is a menu button.

![Active tasks ](images/drex_aktivnye_zadaniya__screen_4.png)

It gives access to the following actions:

![](images/drex_aktivnye_zadaniya__custom_9.png)

-   Complete task — finish the task
    
-   Show full route — open the map with all route points
    

![](images/drex_aktivnye_zadaniya__custom_10.png)

For more on working with the map, see the article [“Route map”](karta-marshruta.html).

## Completing a task

After you have performed all the required work and visited the route points, tap “Complete task”.

![Active tasks ](images/drex_aktivnye_zadaniya__screen_5.png)

After completion, the task automatically moves to the [“Completed”](zavershyennye-zadaniya.html) tab, where you can view it.
