title: "Completed tasks"
---

The “Completed” tab shows all tasks that have been finished. Here you can view previously completed tasks and information about them.

![](images/drex_zavershyennye_zadaniya_custom.png)

Each task is shown as a card with the following information:

— task name

— task number

— start date and time

— end date and time

— actual completion time of the task

## Sorting tasks

To change the order in which completed tasks are displayed:

1\. Open the “Completed” tab

2\. Tap the list settings icon in the upper right corner

![Completed tasks](images/drex_zavershyennye_zadaniya_screen.png)

3\. In the “List settings” window, select a sorting method:

![](images/drex_zavershyennye_zadaniya_custom_2.png)

-   Newest first — recently completed tasks are shown at the top of the list
    
-   Oldest first — tasks completed earlier are shown at the top of the list
    
    4\. Tap “Apply”
    

The list is then updated automatically.

## Viewing a completed task

To open the information, tap the card of the task you need in the list.

The task card opens with information about the route, visited points and results.

![](images/drex_zavershyennye_zadaniya_custom_3.png)

### Task information

The top of the card shows:

— start date and time

— end date and time

Below is the “Task information” section. Depending on the system settings, it may contain:

— task name

— company or customer name

— contact phone number

— office address

— task description

— cargo information

— other additional data

### Waybill

The “Waybill” section shows all route points that were part of the task.

![Completed tasks](images/drex_zavershyennye_zadaniya_screen_2.png)

For each point, the following are shown:

— name and address

— point number

— completion status

— visit date and time

To view information about a point, tap it in the list.

![](images/drex_zavershyennye_zadaniya_custom_4.png)

The window that opens shows:

— full address

— point status

— time work started at the point

— time work ended at the point

**Actions for a point**

![Completed tasks](images/drex_zavershyennye_zadaniya_screen_3.png)![](images/drex_zavershyennye_zadaniya_custom_5.png)

The following actions are available for a point:

-   Copy address — copy the address to the clipboard;
    
-   Show on map — open the point location on the map.
    

### Route map

To view the route, tap the map icon in the upper right corner of the task card.

The map shows the route and all the points of the task.

![Completed tasks](images/drex_zavershyennye_zadaniya_screen_4.png)![](images/drex_zavershyennye_zadaniya_custom_6.png)

For more on working with the map, its settings and controls, see the article [“Route map”](karta-marshruta.html).
