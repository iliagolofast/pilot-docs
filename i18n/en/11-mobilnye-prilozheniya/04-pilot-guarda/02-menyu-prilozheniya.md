Below is a detailed description of each tab and its functions.

## Car status

The “Car status” tab helps you quickly understand what is happening with your car right now.

The screen shows:

— car name or number

— address of the current location

— car status — whether it is stationary or moving

— time in the current state — how long the car has been stationary or in another status

— security state — on or off

— lock control button — for opening or closing the car remotely

— Bluetooth icon — shows whether the car can be controlled over Bluetooth

![](images/drex_menyu_prilozheniya_custom_3.png)

To see the car’s location on the map, tap the ![](images/drex_menyu_prilozheniya_custom_4.png) icon on the “Car status” tab. The map screen then opens with the vehicle’s current location.

![](images/drex_menyu_prilozheniya_custom_5.png)

To change the appearance of the map, tap the map layer selection icon ![](images/drex_menyu_prilozheniya_custom_6.png). The “Select layer” window opens, where you can choose a suitable display option.

If it is important for you to assess the traffic situation near the car, you can turn on traffic display.

 ![](images/drex_menyu_prilozheniya_custom_7.png)   ![](images/drex_menyu_prilozheniya_custom_8.png)

## My cars

The “My cars” tab shows the list of all vehicles available to you.

![](images/drex_menyu_prilozheniya_custom_9.png)

To see the status of a specific car, tap it in the list — the screen with the [car status](menyu-prilozheniya.html#Состояние_автомобиля) opens.

How to add a car:

1\. Tap “Add” ![](images/drex_menyu_prilozheniya_custom_10.png) in the upper right corner

2\. Scan the QR code:

— point your smartphone camera at the QR code on the device

— or at the code [generated by PILOT](../../panel-administratora/qr-kody.html)

![](images/drex_menyu_prilozheniya_custom_11.png)

3\. The car is added to your account automatically

## My tags

On the “My tags” tab, you can view and manage the Bluetooth tags (beacons) connected to the device.

<table><tbody><tr><td><span></span></td><td><div>This function is available for Teltonika devices.</div></td></tr></tbody></table>

Tags are used for:

-   driver identification
    
-   controlling access to the car
    
-   automatic scenarios (for example, disarming when approaching)
    

Each tag is a separate device with a unique identifier.

![](images/drex_menyu_prilozheniya_custom_12.png)

The tag list shows:

-   tag name
    
-   identifier (ID)
    
-   status (active / inactive)
    

Tap a tag in the list — the actions menu opens.

-   Enable tag broadcast — when the device detects the tag, the system can automatically perform an action, for example, disarm the car
    
-   Rename tag — a window opens where you can enter a new name and save the changes
    

![](images/drex_menyu_prilozheniya_custom_12.png)   ![](images/drex_menyu_prilozheniya_custom_13.png)

The “Refresh” button loads the current list from the device

The tag list is generated on the device side (for example, Teltonika).

For tags to be displayed in the app:

— they must be configured and registered in the device

— the device must send their list to PILOT

You can find detailed setup instructions for Teltonika devices here: [https://wiki.teltonika-gps.com/view/FMB920\_Beacon\_List](https://wiki.teltonika-gps.com/view/FMB920_Beacon_List)

## Alerts

This is where events and notifications are shown.

The alert list shows:

— the car or object

— event type or notification text

— date and time

— event address

    ![](images/drex_menyu_prilozheniya_custom_20.png)    **![](images/drex_menyu_prilozheniya_custom_21.png)**

To open an event, tap it — a map opens with the event point and information.

   **![](images/drex_menyu_prilozheniya_custom_21.png)   ![](images/drex_menyu_prilozheniya_custom_22.png)**

To filter notifications:

1\. Tap the filter icon ![](images/drex_menyu_prilozheniya_custom_23.png)

2\. Select a period

3\. Tap “Apply”

The screen then shows only the alerts that match the specified period.

**![](images/drex_menyu_prilozheniya_custom_24.png)**

## User settings

In the “Settings” section, you can configure the app and access.

![](images/drex_menyu_prilozheniya_custom_25.png)

-   Language — tap the drop-down list and select the language you need
    
-   Notifications:
    

— Show address — adds the address to the notification text

— Sound notifications — turns on an audible signal

-   Users — add users and configure their rights.
    

How to add a user:

1\. Go to “Users”

2\. Tap “Add”

![](images/drex_menyu_prilozheniya_custom_26.png)   ![](images/drex_menyu_prilozheniya_custom_27.png)   ![](images/drex_menyu_prilozheniya_custom_28.png)

3\. Specify:

-   Email
    
-   phone
    
-   name
    
-   password
    
    4\. Select:
    
-   available objects
    
-   role (administrator or user)
    
    5\. Tap “Save”
    
-   Beacon type (tag type)
    

![](images/drex_menyu_prilozheniya_custom_25.png)  ![](images/drex_menyu_prilozheniya_custom_29.png)

Here you select the type of Bluetooth tag used to communicate with the car:

— iBeacon — an Apple technology that uses Bluetooth Low Energy. It transmits a unique identifier (UUID, Major, Minor) and works with nearby devices

— Eddystone  — an open BLE format that transmits an identifier, URL and telemetry

-   PIN code
    

You can set a PIN code for logging in:

1\. Enter a new code

2\. Confirm it

3\. Tap “Save”

![](images/drex_menyu_prilozheniya_custom_30.png)

-   Car settings
    

![](images/drex_menyu_prilozheniya_custom_31.png)   ![](images/drex_menyu_prilozheniya_custom_32.png)  

Select a car to change its parameters:

— change the car image

— set up notifications — choose which events you want to be notified about and how:

-   loss of connection with the car
    
-   movement with the ignition off
    
-   arming and disarming
    
-   low battery
    

For each event type, you can select one or both delivery methods:

-   Push — push notification to your phone
    
-   E-mail — notification by e-mail
    

![](images/drex_menyu_prilozheniya_custom_33.png)

-   Change theme
    

At the bottom of the screen there is a theme switch.

![](images/drex_menyu_prilozheniya_custom_25.png)   ![](images/drex_menyu_prilozheniya_custom_34.png)

-   Log out
    

Tap “Log out” to exit the app.
