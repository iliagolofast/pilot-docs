---
title: "How to work with geofences"
---

The “Geofences” tab shows the list of all available geofences.

On this tab you can:

— view existing geofences

— create new geofences

— edit existing zones

— set up notifications for geofence-related events

![](images/drex_kak_rabotat_s_geozonami_2_custom.png)

## How to create a geofence

1\. Tap “Add” ![](images/drex_kak_rabotat_s_geozonami_2_custom_2.png)

2\. Specify the parameters:

-   Geofence name
    
-   The group it will belong to (or create a new group)
    

      ![](images/drex_kak_rabotat_s_geozonami_2_custom_3.png)   ![](images/drex_kak_rabotat_s_geozonami_2_custom_4.png)   ![](images/drex_kak_rabotat_s_geozonami_2_custom_5.png)

3\. Set the geofence shape:

 ![](images/drex_kak_rabotat_s_geozonami_2_custom_6.png)Circle — tap the map and drag to set the radius (you can change the radius by dragging the edge)

![](images/drex_kak_rabotat_s_geozonami_2_custom_7.png)Polygon — mark points on the map one by one to set the boundaries

    ![](images/drex_kak_rabotat_s_geozonami_2_custom_3.png)   ![](images/drex_kak_rabotat_s_geozonami_2_custom_8.png)

4\. Select the geofence color

   ![](images/drex_kak_rabotat_s_geozonami_2_custom_9.png)   ![](images/drex_kak_rabotat_s_geozonami_2_custom_10.png)

If needed, tap “Clear” ![](images/drex_kak_rabotat_s_geozonami_2_custom_11.png) to undo your changes.

5\. Tap “Save” — the geofence appears in the list

## Geofence actions

Tap a geofence in the list, then the menu (![](images/drex_kak_rabotat_s_geozonami_2_custom_12.png)) — the available actions open:

![](images/drex_kak_rabotat_s_geozonami_2_custom_13.png)

 ![](images/drex_kak_rabotat_s_geozonami_2_custom_14.png)Delete — delete the geofence

 ![](images/drex_kak_rabotat_s_geozonami_2_custom_15.png)Set up notifications — set up alerts

 ![](images/drex_kak_rabotat_s_geozonami_2_custom_16.png)Edit — go to editing the geofence

 ![](images/drex_kak_rabotat_s_geozonami_2_custom_17.png)Collapse the geofence menu to return to the list

## Setting up notifications

1\. Select the cars that will receive notifications.

   ![](images/drex_kak_rabotat_s_geozonami_2_custom_18.png)   ![](images/drex_kak_rabotat_s_geozonami_2_custom_19.png)

2\. Specify the notification parameters:

-   Notification type
    
-   Message text
    

![](images/drex_kak_rabotat_s_geozonami_2_custom_20.png)

3\. Select how to receive it:

-   Email
    
-   SMS
    
-   Alarm
    
-   Push notifications in the app
    
    4\. To add an e-mail or phone number, tap “Add” and enter the details
    

![](images/drex_kak_rabotat_s_geozonami_2_custom_21.png)

5\. Specify the conditions:

-   entering the geofence
    
-   leaving the geofence
    

![](images/drex_kak_rabotat_s_geozonami_2_custom_20.png)

6\. Save the settings
