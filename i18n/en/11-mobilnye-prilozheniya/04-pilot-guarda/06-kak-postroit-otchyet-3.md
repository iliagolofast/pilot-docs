---
title: "How to build a report"
---

On the “Reports” tab, you can generate a report for selected objects and parameters.

![](images/drex_kak_postroit_otchyet_3_custom.png)

1\. Select vehicles

In the “Vehicles” field, select one or more objects to get the report for.

2\. Select the report type

Specify the report type you need, for example:

— by mileage

— by time in motion and parking

— by fuel consumption

— by sensors

3\. Set the period

Select the start and end dates. If needed, specify the exact time (hours and minutes) — the report is generated only for the selected period.

4\. Select grouping

Determine how the data is grouped:

-   By dates — to track changes over time
    
-   By objects — to compare different vehicles
    

5\. Specify sensor groups

Select one or more sensor groups if they are needed for the report.

6\. Download the report

Tap “Download report”. The file is generated automatically — you can open or save it.
