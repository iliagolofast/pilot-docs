PILOT Tracker is an app that turns your smartphone into a GPS tracker. With it, you can track the device location in real time and send data to the server.

![](images/drex_pilot_treker_custom.png)

## How to install PILOT Tracker

1\. Open Google Play on your smartphone

2\. In the search bar, enter Pilot Tracker or follow this [link](https://play.google.com/store/apps/details?id=com.octys.pilottracker)

3\. Tap the “Install” button and wait for the app to install

## How to turn on the tracker

-   Open the app and turn on the “Service status” switch. When the service is on, location data starts to be sent
    

![PILOT Tracker](images/drex_pilot_treker_screen.png)

2\. Make sure your phone is connected to the internet (via mobile data or Wi-Fi)

3\. To link the device to your account in the system, send the Device ID to technical support

## How to configure tracker parameters

The following settings are available on the app’s main screen:

### Service status

• If the switch is on — the tracker is active and location data is being sent

• If the switch is off — the service is stopped and no data is sent

### Device ID

The unique device number (for example, 705943). You need to give this number to technical support so that your device appears in the system.

### Server URL

The address of the server that data is sent to. You can change this address if necessary.

### Location accuracy

The higher the accuracy, the more precise the track, but it requires more power and traffic. Choose the best setting for your use.

### Frequency

Set how often the tracker sends data to the server (for example, every 5 or 10 seconds). A shorter interval means a more detailed track but uses more battery and data.

### Distance

Specify the distance traveled after which new points are sent. For example, every 50 m. This lets you avoid sending data when the object is barely moving.

### Angle

Select the angle at which a new point is sent (for example, if the turn angle is greater than the set value).

### Offline buffering

If you turn this option on, the tracker saves location data when there is no internet connection. As soon as the connection is restored, all accumulated data is automatically sent to the server.

### Wake lock

If turned on, the app keeps the tracker running in the background, even if the phone is not in use.

## “Status” tab

The “Status” tab shows the tracker’s operation log — here you can see the current state of the service as well as information about its recent operation.

At the top of the screen there is a “Clear” button, which deletes the current list of messages.
