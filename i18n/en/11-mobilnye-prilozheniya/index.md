This section helps you connect to and start using the mobile tools of the PILOT system:

-   PILOT mobile app — an app for monitoring vehicles and working with objects
    

![](images/drex_mobilnye_prilozheniya_custom.png)

• Telegram bot — an assistant that lets you work with the vehicle list, get information about objects and use your phone as a virtual GPS tracker

![](images/drex_mobilnye_prilozheniya_custom_2.png)

-   PTM (PILOT Task Manager) mobile app — an app for drivers and couriers that shows tasks and routes
    

![](images/drex_mobilnye_prilozheniya_custom_3.png)

-   PILOT Guarda — an app for vehicle security and monitoring. With it you can monitor the condition of a car, manage access and track movements
    

![](images/drex_mobilnye_prilozheniya_custom_4.png)

With the app you can:

— monitor the car’s condition

— manage access to the car

— track movements

PILOT Tracker is an app that turns your smartphone into a GPS tracker. With it, you can track the device location in real time and send data to the server

![](images/drex_mobilnye_prilozheniya_custom_5.png)
