---
title: "How to enable access to BI Analytics"
---

Access to the BI Analytics API is configured at two levels:

-   At the partner account level
    

2\. At the user contract level

For access to work, you need to:

— enable the analytics module for the partner

— enable the analytics module in the user’s contract

— add the bi\_analytics = 1 configuration in the partner card

<table><tbody><tr><td><span></span></td><td><div>&nbsp;If you do not have access to the module or configuration settings on the partner contract, contact technical support.</div></td></tr></tbody></table>

-   ### Enable the analytics module on the partner account
    
    1\. In the admin panel, go to the “Partners” section
    

![](images/drex_kak_vklyuchit_dostup_k_bi_analytics_custom.png)

2\. Double-click the partner you need — the partner card opens

3\. Go to the “Modules” tab and enable the “Analytics module”

![How to enable access to BI Analytics](images/drex_kak_vklyuchit_dostup_k_bi_analytics_screen.png)

4\. Then go to the “Configuration” tab

# ![](images/drex_kak_vklyuchit_dostup_k_bi_analytics_custom_2.png)

5\. Click the “Add” button

6\. In the list, select the bi\_analytics configuration and set its value to 1

![](images/drex_kak_vklyuchit_dostup_k_bi_analytics_custom_3.png)

7\. Save the changes

### 2\. Enable the analytics module on the user’s contract

After the module is enabled on the partner account, you also need to enable it on the specific user contract.

1\. In the admin panel, find the contract you need

![](images/drex_kak_vklyuchit_dostup_k_bi_analytics_custom_4.png)

2\. Right-click it and select “Edit”

3\. In the contract card, go to the “Modules” tab

4\. Enable the “Analytics module”

![How to enable access to BI Analytics](images/drex_kak_vklyuchit_dostup_k_bi_analytics_screen_2.png)

5\. Save the changes

Once the analytics module is enabled on both the partner account and the user contract, and the bi\_analytics configuration is set up, access to the BI Analytics API is enabled.
