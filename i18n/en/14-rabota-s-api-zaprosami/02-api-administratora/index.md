---
title: "Admin API"
---

The Admin API is a special set of commands that provides extended capabilities not available to regular users. It is intended for managing the system and performing administrative tasks.

With the Admin API you can:

-   Create, modify or delete user accounts
    
-   Configure access rights and roles
    
-   Get information about the state of objects
    
-   Configure system and module parameters
