---
title: "Refuels by Fuel Cards"
---

Use this API to get data on vehicle refuels for the selected period. With it you can:

— view fuel card transactions (fuel purchase operations, card balance, fuel type, gas station)

— get data on refuels and fuel drains according to the vehicle sensor (coordinates, amount of fuel, event location)

— monitor fuel remaining at the start and end of the day for each vehicle

## How to get the data

### Method

GET

Request address

To get the data, use the address: https://<server\_address>/api/api.php?

### Request parameters

-   cmd=fuel — command to get refuel data
    
-   imei — vehicle identifier in the system
    
-   start — start time of the selection (Unix timestamp)
    
-   stop — end time of the selection (Unix timestamp)
    
-   addr— refuel addresses
    
-   node — the number of the node on which the command must be executed
