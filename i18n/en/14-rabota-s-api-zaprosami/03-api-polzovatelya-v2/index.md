---
title: "User API v2"
---

The User API gives access to the PILOT functions and data that are available to a regular user.

With it, you can:

— view your reports and statistics on trips, objects and expenses

— get information about your settings and personal data

— request data related only to your account and your activity in the system

These APIs do not give access to the data of other users or administrators. You see and work only with the information of your own account.
