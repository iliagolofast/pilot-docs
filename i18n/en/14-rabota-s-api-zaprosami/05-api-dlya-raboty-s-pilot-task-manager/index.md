---
title: "API for working with PILOT Task Manager"
---

PILOT Task Manager ([Task Manager](../../lichnyj-kabinet-polzovatelya/moduli-1/pilot-task-manager/index.html)) is a PILOT module for managing tasks.

With the API of this module, you can:

— create, edit and delete tasks

— assign tasks to assignees

— get the completion status and deadlines

 — get information about current and completed tasks
