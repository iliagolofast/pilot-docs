---
title: "Conceptos y términos básicos de PILOT"
---

Antes de empezar a trabajar en PILOT, le recomendamos familiarizarse con los conceptos y términos básicos:

### Autorización

— determinación de los derechos de acceso del usuario a las funciones y los datos del sistema después de iniciar sesión correctamente.

### Administrador

— usuario del panel de administración que se encarga de configurar y gestionar el sistema de monitoreo.

### Cuenta

— es la cuenta personal de una persona en el sistema de monitoreo. A través de la cuenta, el usuario accede a sus datos y a las funciones del sistema. La cuenta almacena los datos personales del usuario, su nombre de usuario, contraseña, información de contacto y la configuración individual de la interfaz del sistema.

### Alertas

— son notificaciones del sistema sobre eventos importantes o desviaciones de los parámetros establecidos, que se envían al usuario por correo electrónico, SMS o mensajería instantánea.

### Autenticación

— confirmación de la identidad del usuario al iniciar sesión en el sistema mediante nombre de usuario y contraseña.

### Versión del programa

— es el número de lanzamiento del software que indica qué variante del programa se está utilizando. Cada nueva versión contiene actualizaciones, correcciones o nuevas funciones.

### Geocerca

— zona virtual delimitada en el mapa geográfico.

### Geocodificador

— es una herramienta del sistema que convierte las coordenadas GPS en direcciones convencionales.

### Sensor

— es un dispositivo que recopila y transmite datos sobre un parámetro o estado concreto del objeto.

### Dashboard

— panel de control que reúne de forma visual la información principal para el trabajo. En el dashboard se muestran los indicadores clave, los gráficos y el acceso rápido a las funciones importantes.

### Contrato

— es el elemento principal del sistema, que agrupa todos los objetos de monitoreo, los usuarios y las funciones disponibles de un cliente o empresa. El contrato indica qué dispositivos supervisa el sistema y quién puede acceder a ellos.

### Historial

— historial de desplazamientos de un objeto o historial de funcionamiento de un sensor.

### Ficha del objeto

— es el lugar donde puede editar la información del objeto y configurar sus parámetros.

### Caché

— lugar de almacenamiento temporal de datos.

### Contrato de mapeo

— tipo de contrato del sistema que reúne datos de varias cuentas o contratos en una sola interfaz. Funciona como un «espejo» y refleja la información de otras cuentas sin modificarla directamente. A través de él, el usuario consulta la información de distintas cuentas de usuario sin tener que cambiar de una a otra. El contrato de mapeo no contiene datos físicos, solo los refleja desde otras cuentas. Por ejemplo, el servicio de seguridad de una empresa puede crear un contrato de este tipo para supervisar todos los vehículos de la empresa en un solo lugar, sin entrar en cada cuenta por separado.

### Menú del objeto

— lista de acciones disponibles que puede realizar con el objeto seleccionado.

### Módulo

— es una parte independiente del sistema con un conjunto de funciones determinadas. Los módulos se conectan al sistema principal y pueden funcionar tanto de forma independiente como junto con otros módulos.

### Objeto

 — es un vehículo, maquinaria, persona, animal u otro elemento móvil o estacionario sometido a supervisión.

### Informe

— es la información recopilada sobre los objetos supervisados durante el período seleccionado.

### Transmisión de datos

— proceso de recopilación y transporte de la información desde los dispositivos instalados en los objetos hasta el servidor central a través de redes móviles. Los datos de ubicación, velocidad y otros parámetros se procesan, se filtran y se guardan en la base de datos para su análisis y uso posteriores.

### Usuario

— es la persona que trabaja con el sistema de monitoreo PILOT. Cada usuario tiene un determinado nivel de [acceso](roli-i-prava-dostupa.html), que depende de su rol en el sistema. Algunos usuarios solo pueden ver la información básica, mientras que otros tienen acceso a la configuración del sistema.

### Push, notificación push

— notificación de un evento en el teléfono.

### Eventos

— cambios en los parámetros del vehículo, por ejemplo, exceso de velocidad, salida de una geocerca, inicio del movimiento o drenaje de combustible.

### Etiqueta

— marca especial para buscar objetos.

### Token

— es un código de acceso único.

### Rastreador

— es un dispositivo electrónico compacto para seguir los desplazamientos de un objeto. Al encenderse, determina automáticamente la ubicación actual y establece una conexión a internet para transmitir los datos. El rastreador se configura mediante una conexión directa a un ordenador con un software especial que permite establecer todos los parámetros de funcionamiento del dispositivo.

### API

— es un conjunto de reglas y herramientas para que los programas interactúen entre sí. La API se utiliza para intercambiar datos entre sistemas, servicios, aplicaciones y la plataforma PILOT.

### AccountID

— es el identificador único de la cuenta de usuario en el sistema. El sistema lo utiliza para identificar a un usuario concreto al iniciar sesión y durante el trabajo en el sistema.

### AgentID

— es el número único de un dispositivo u objeto de monitoreo en el sistema, por ejemplo, un rastreador GPS instalado en un automóvil.

### ID del dispositivo

— número único del dispositivo instalado en el objeto.

### Configuración del rastreador por SMS

— método de configuración remota del rastreador mediante comandos SMS. Al número de la tarjeta SIM instalada en el dispositivo se envía un mensaje de texto con una instrucción determinada. Cada SMS modifica solo un parámetro de funcionamiento del rastreador. Una vez ejecutado el comando, el dispositivo envía un mensaje de respuesta que confirma el cambio de configuración.

### Unixtimestamp

— es un formato numérico de hora que indica la cantidad de segundos transcurridos desde el 1 de enero de 1970.
