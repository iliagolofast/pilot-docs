---
title: "Tipos de mapas"
---

En la cartografía profesional, al elegir mapas se utiliza el término especial «base cartográfica». Para facilitar la comprensión, utilizaremos un término más claro: «tipo de mapa».

El tipo de mapa es la capa base de la imagen cartográfica que se utiliza en el sistema de monitoreo para mostrar los datos espaciales.

PILOT ofrece varios tipos de mapas para representar el espacio en la interfaz de usuario. La elección de un tipo concreto depende de sus necesidades y preferencias. Algunos mapas son más adecuados para la navegación y otros, para estudiar el terreno o buscar elementos de infraestructura.

Para cambiar el mapa, pulse el botón de selección del mapa ![](images/drex_tipy_kart_custom.png).

![](images/drex_tipy_kart_custom_2.png)

En el menú que se abre, seleccione el tipo de mapa que necesite: pasará a ser el principal y se cargará de forma predeterminada al abrir el sistema.
