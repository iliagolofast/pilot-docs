---
title: "Etiquetas RFID"
---

En la pestaña «Etiquetas RFID» se configura el acceso del usuario a las etiquetas RFID del contrato. El usuario podrá ver y utilizar solo las etiquetas marcadas en su ficha.

La pestaña se muestra en la ficha del usuario si para el contrato está activado el módulo [RFID](../../../moduli-1/rfid-metki-2/index.html).

![](images/drex_rfid_metki_1_custom.png)

En la lista se muestran:

-   ID: identificador de la etiqueta RFID
    
-   Nombre: nombre de la etiqueta
    
-   Descripción: información adicional sobre la etiqueta
    
-   Contrato: contrato al que pertenece la etiqueta
    

## Cómo asignar etiquetas RFID a un usuario

1\. Abra la ficha del usuario

2\. Vaya a la pestaña «Etiquetas RFID» (RFID tags)

3\. Busque las etiquetas necesarias con la búsqueda ![](images/drex_rfid_metki_1_custom_2.png) o el filtro ![](images/drex_rfid_metki_1_custom_3.png)

4\. Marque las casillas de las etiquetas que deben estar disponibles para el usuario

![](images/drex_rfid_metki_1_custom.png)

5\. Pulse «Guardar»

Para asignar al usuario de una vez todas las etiquetas RFID disponibles, pulse el icono de la marca de verificación ![](images/drex_rfid_metki_1_custom_4.png)de la esquina superior derecha. Se marcarán las casillas de todas las etiquetas de la lista.

![](images/drex_rfid_metki_1_custom_5.png)

Para cerrar el acceso a una etiqueta concreta, desmarque la casilla correspondiente y guarde los cambios.

Si la lista de etiquetas ha cambiado, pulse el icono de actualización ![](images/drex_rfid_metki_1_custom_6.png) para cargar los datos actuales.
