Al crear un informe, primero se selecciona el tipo de informe y después se añaden las columnas de datos.

![](images/drex_kolonki_s_dannymi_dlya_raznykh_tipov_otchyetov_custom.png)

El conjunto de datos disponibles depende del tipo de informe seleccionado:

1\. Usted selecciona el tipo de informe

2\. El sistema carga automáticamente las categorías y los campos de datos disponibles

3\. En la sección «Columnas» usted añade los datos necesarios

4\. Al generar el informe solo se muestran las columnas seleccionadas

### Ejemplo: tipo de informe «Etiquetas RFID»

Si selecciona el tipo «Etiquetas RFID», estarán disponibles los datos relacionados con RFID.

Este informe ayuda a analizar:

-   qué etiquetas RFID se registraron
    
-   cuándo se produjo el evento
    
-   dónde se produjo
    
-   a qué objeto o dispositivo corresponde el registro
    

![](images/drex_kolonki_s_dannymi_dlya_raznykh_tipov_otchyetov_custom_2.png)

Al crear el informe se indican los ajustes principales:

-   Nombre: nombre del informe
    
-   Ordenación: campo por el que se ordenarán los datos
    
-   Desc: ordenación descendente
    
-   Columnas: datos que se mostrarán
    
-   Configuración: parámetros adicionales y filtros
    

Después de esto, puede pasar a añadir columnas:

1\. Haga clic en el botón de añadir en la sección «Columnas» ![](images/drex_kolonki_s_dannymi_dlya_raznykh_tipov_otchyetov_custom_3.png)

2\. En el campo «Datos», seleccione el parámetro que necesite de la lista

Los campos disponibles dependerán del tipo de informe seleccionado.

![](images/drex_kolonki_s_dannymi_dlya_raznykh_tipov_otchyetov_custom_4.png)

Ejemplo de datos disponibles (RFID)

Además de los datos generales (vehículo, dispositivo, ID, grupo, etc.), aparecerán campos especializados:

-   RFID Time: hora de lectura de la etiqueta
    
-   RFID Name: nombre de la etiqueta (por ejemplo, el nombre del empleado o un objeto)
    
-   RFID Location: lugar de lectura
    
-   RFID UID: código único de la etiqueta
    
-   RFID Group: grupo de etiquetas
    

Añada las columnas necesarias para formar la estructura del informe.
