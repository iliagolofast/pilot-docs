---
title: "Qué dispositivos se pueden conectar"
---

En el sistema PILOT se pueden utilizar distintos tipos de dispositivos de video. Cada tipo tiene sus propios parámetros de conexión:

### Howen

-   Server 1 (telemática): Server URL, port 20009
    
-   Server 2 (video): video.pilot-gps.com, port 33000
    
    Para Howen se utiliza una clave independiente, url\_howen, en la [«Configuración del módulo»](nastrojka-modulej-v-paneli-administratora.html#Настройка_модуля)
    
    No se necesita contraseña para la conexión.
    

![](images/drex_kakie_ustrojstva_mozhno_podklyuchat_custom.png)

### CMS

-   Dirección del servidor (Host): video.pilot-gps.com
    
-   Puerto: 6608
    

### Cipia

-   Dirección del servidor (Host): video.pilot-gps.com
    
-   Puerto: 1883
    

### Teltonika DualCam

-   Dirección del servidor (Host): video.pilot-gps.com
    
-   Puerto: 20233
    

### Hikvision

La conexión de los dispositivos Hikvision depende del modelo concreto.

Algunos modelos utilizan la conexión estándar al servidor video.pilot-gps.com.

Por ejemplo, para Hikvision G40:

• Dirección del servidor (Host): video.pilot-gps.com

• Puerto: 6608

Otros modelos Hikvision que se conectan a PILOT:

-   DS-MCW407 (BWS): cámara corporal de video y audio con transmisión en línea.
    
-   AE-MN5043 (DVR): videograbador móvil con GPS para vehículos.
    
-   AE-VC583I-IS/P(H): cámara IP de alta resolución para vehículos (reconocimiento de matrículas).
    

Para distintos modelos de Hikvision pueden aplicarse diferentes parámetros de conexión. Para conocer cuáles, comuníquese con el soporte.
