**Retransmisión de datos**.

Es el proceso de transferencia de datos de una fuente a otra en tiempo real, a menudo a través de servidores o nodos intermedios.

Aquí se puede crear cualquier número de retransmisores que envíen los mensajes de los objetos seleccionados a otros sistemas. El funcionamiento del retransmisor puede suspenderse o reanudarse en cualquier momento.

• Abra la pestaña En línea.

• Vaya al menú contextual del objeto.

• Seleccione la opción **Relay list**.

-   \+ Empiece a rellenar los campos.
    

![](images/drex_retranslyatsiya_obektov_custom.png)

![](images/drex_retranslyatsiya_obektov_custom_2.png)

-   **Host** - dirección del host para la retransmisión de datos mediante el protocolo indicado (como dirección IP o nombre de dominio).
    
-   **Puerto** - puerto al que se retransmiten los datos mediante el protocolo indicado.
    
-   **Formato** \- formato de retransmisión (seleccione de la lista desplegable).
    
-   **Identificador externo** \- identificador de retransmisión de un objeto de monitoreo (normalmente se utiliza el bloque imei).
    
-   **Ruta -** al usar un nombre de dominio, este campo contiene parámetros adicionales.
    
-   **USPW** - si se requiere identificación, este campo contendrá el nombre de usuario y la contraseña.
    
-   **Zona horaria** - indica la zona horaria en formato GMT.
    
-   **Control de velocidad** - control de velocidad en km/h.
    
-   **Activado** - estado actual.
    
-   **Json conf** - ventana para añadir la configuración.
    
-   **Comentario** - información adicional sobre la retransmisión.

**Retransmisión SAW**

La retransmisión SAW es un sistema que se utiliza para transmitir señales de alarma y avisos de un dispositivo a otro. Esta retransmisión garantiza la transmisión fiable de notificaciones críticas, especialmente en situaciones en las que la conexión directa puede ser poco fiable o imposible.

-   Active el módulo desde el panel de administración.
    

**![](images/drex_retranslyatsiya_obektov_custom_3.png)**

• Vaya a la interfaz de usuario, al menú del objeto.

![](images/drex_retranslyatsiya_obektov_custom_4.png)

-    Abra y rellene la ventana de retransmisión.
