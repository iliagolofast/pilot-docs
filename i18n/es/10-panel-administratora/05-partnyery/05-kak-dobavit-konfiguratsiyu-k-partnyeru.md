La configuración es un conjunto de parámetros y ajustes del sistema que adaptan su funcionamiento a tareas concretas. Cada configuración consta de una clave, un identificador único, y un valor, que puede ser un número, un texto o una estructura de datos más compleja.

### Cómo añadir una configuración a un socio:

-   # En el panel de administración, vaya a la sección «Socios»

# ![](images/drex_kak_dobavit_konfiguratsiyu_k_partnyeru_custom_2.png)

3\. Vaya a la pestaña «Configuración» y pulse el botón «Añadir»

Para ver la lista de configuraciones, pulse el botón «Lista de configuraciones».

La lista muestra todas las configuraciones que puede añadir en el sistema.

![](images/drex_kak_dobavit_konfiguratsiyu_k_partnyeru_custom_5.png)

## Configuraciones del socio

El sistema incluye una lista de configuraciones disponibles que se pueden establecer para el socio.

Cada configuración consta de:

-   Nombre — nombre del ajuste
    
-   Clave (valor) — nombre técnico del parámetro que utiliza el sistema
    

Si el socio necesita una lógica de funcionamiento especial (por ejemplo, conectar un proveedor de SMS, cambiar la visualización del saldo, integración con Helpdesk, Twilio, Here Maps, etc.), se añade la configuración correspondiente con el valor necesario.

Ejemplo:

-   Para mostrar el saldo en días en lugar de dinero se utiliza la clave balance\_in\_days = 1
    
-   Para conectar un bot de Telegram se indica la dirección del bot, por ejemplo: @PilotGpsBot
    
-   Para conectar SMTP o un proveedor de SMS se indican los parámetros de autorización en forma de objeto (usuario, contraseña, clave API, etc.)
