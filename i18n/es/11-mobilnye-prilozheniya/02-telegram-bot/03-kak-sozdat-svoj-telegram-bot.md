---
title: "Cómo crear su propio bot de Telegram"
---

Para crear usted mismo un bot de Telegram necesitará el servicio oficial @BotFather, el bot principal de Telegram a través del cual se crean y configuran todos los demás bots.

1\. Acceda al enlace: [https://t.me/BotFather](https://t.me/BotFather)

2\. Pulse Start para abrir el menú

               ![](images/drex_kak_sozdat_svoj_telegram_bot_custom.png)

3\. Introduzca el comando: /newbot

              ![](images/drex_kak_sozdat_svoj_telegram_bot_custom_2.png)

4\. Elija un nombre para el bot

BotFather le pedirá que indique el nombre del bot: es el nombre visible que ven las personas.

5\. Elija un username para el bot, su dirección en Telegram

Hay una regla importante: el username debe terminar en \_bot. Por ejemplo, mycompany\_bot, skyelectronics\_helper\_bot

               ![Cómo crear su propio bot de Telegram](images/drex_kak_sozdat_svoj_telegram_bot_screen.png)

6\. Obtenga el token

Una vez que BotFather cree el bot, aparecerá un mensaje de felicitación. Justo debajo verá:

-   Token to access the HTTP API: el token del bot
    

<table><tbody><tr><td><div><img alt="3. " src="images/drex_kak_sozdat_svoj_telegram_bot_control_3.png" data-full-src="drex_kak_sozdat_svoj_telegram_bot_control_3.png" data-full-width="506" data-full-height="95"></div></td></tr><tr><td><div><a href="#top"></a></div></td></tr></tbody></table>

-   Username: el nombre de usuario de su bot
    

7\. Envíe el token y el username de su bot al servicio de soporte técnico para conectar el bot a PILOT

<table><tbody><tr><td><span></span></td><td><div>El contrato en el sistema debe estar activo; de lo contrario, el bot no podrá enviar ni recibir datos.</div></td></tr></tbody></table>
