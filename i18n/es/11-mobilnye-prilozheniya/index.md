title: "Aplicaciones móviles"
---

Esta sección le ayudará a conectarse y empezar a trabajar con las herramientas móviles del sistema PILOT:

-   Aplicación móvil PILOT: aplicación para monitorear el transporte y trabajar con objetos
    

![](images/drex_mobilnye_prilozheniya_custom.png)

• Bot de Telegram: asistente con el que puede trabajar con la lista de vehículos, obtener información de los objetos y utilizar el teléfono como rastreador GPS virtual

![](images/drex_mobilnye_prilozheniya_custom_2.png)

-   Aplicación móvil PTM (PILOT Task Manager): aplicación para conductores y mensajeros en la que se muestran las tareas y las rutas
    

![](images/drex_mobilnye_prilozheniya_custom_3.png)

-   PILOT Guarda: aplicación para la seguridad y el monitoreo de vehículos. Con ella puede controlar el estado del vehículo, gestionar el acceso y seguir los desplazamientos
    

![](images/drex_mobilnye_prilozheniya_custom_4.png)

Con la aplicación puede:

— controlar el estado del vehículo

— gestionar el acceso al vehículo

— seguir los desplazamientos

PILOT Tracker es una aplicación que convierte su smartphone en un rastreador GPS. Con ella se puede seguir la ubicación del dispositivo en tiempo real y enviar los datos al servidor

![](images/drex_mobilnye_prilozheniya_custom_5.png)

En esta sección le explicaremos cómo utilizar las funciones de las aplicaciones móviles.
