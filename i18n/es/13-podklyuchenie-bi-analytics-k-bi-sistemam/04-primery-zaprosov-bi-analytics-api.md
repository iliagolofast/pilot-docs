---
title: "Ejemplos de solicitudes de BI Analytics API"
---

Este artículo contiene ejemplos de solicitudes para trabajar con BI Analytics API. Puede utilizarlos como base para conectar Power BI u otro sistema de BI compatible con REST API.

Según la tarea, puede elegir una de las dos opciones:

-   Ejemplo básico: es adecuado para familiarizarse con la API, probar la conexión y crear integraciones sencillas. Muestra el conjunto mínimo de acciones necesarias para autorizarse, ejecutar una solicitud y obtener datos.
    
-   Ejemplo avanzado: se recomienda para integraciones de producción y para la actualización periódica de datos. Además de la autorización y la obtención de datos, incluye el manejo de errores de la API, la verificación de la estructura de la respuesta, el tratamiento de resultados vacíos y la conversión automática de los datos a un formato cómodo para Power BI.
