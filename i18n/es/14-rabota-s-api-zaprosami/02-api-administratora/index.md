---
title: "API de administrador"
---

La API de administrador es un conjunto especial de comandos que ofrece funciones avanzadas no disponibles para los usuarios normales. Está destinada a administrar el sistema y realizar tareas administrativas.

Con la API de administrador puede:

-   Crear, modificar o eliminar cuentas de usuario
    
-   Configurar los derechos de acceso y los roles
    
-   Obtener información sobre el estado de los objetos
    
-   Configurar los parámetros del sistema y de los módulos
    

<table><tbody><tr><td><span></span></td><td><div>Para trabajar con la API de administrador, utilice el nombre de usuario y la contraseña de la cuenta de administrador.</div></td></tr></tbody></table>
