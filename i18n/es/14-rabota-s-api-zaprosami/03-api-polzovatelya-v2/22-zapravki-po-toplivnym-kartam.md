---
title: "Repostajes con tarjetas de combustible"
---

Utilice la API para obtener los datos de repostajes de un vehículo durante el período seleccionado. Con ella se puede:

— consultar las transacciones de las tarjetas de combustible (operaciones de compra de combustible, saldo de la tarjeta, tipo de combustible, gasolinera)

— obtener datos de repostajes y drenajes de combustible según el sensor del automóvil (coordenadas, cantidad de combustible, lugar del evento)

— controlar el combustible restante al inicio y al final del día para cada vehículo

## Cómo obtener los datos

### Método

GET

Dirección de la solicitud

Para obtener los datos utilice la dirección: https://<server\_address>/api/api.php?

### Parámetros de la solicitud

-   cmd=fuel: comando para obtener los datos de repostajes
    
-   imei: identificador del vehículo en el sistema
    
-   start: hora de inicio de la selección (Unix timestamp)
    
-   stop: hora de fin de la selección (Unix timestamp)
    
-   addr: dirección de las gasolineras
    
-   node: número del nodo en el que se debe ejecutar el comando
