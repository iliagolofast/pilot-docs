---
title: "Configuración de notificaciones"
---

Esta API sirve para crear, obtener, editar y eliminar configuraciones de notificaciones en PILOT. No es una API para enviar notificaciones, sino para definir las condiciones con las que se activarán las notificaciones en el sistema en el futuro.

## Métodos

POST, GET, PUT, DELETE

### Dirección de la solicitud

Para obtener los datos, utilice la dirección:  https://<address>/api/ptm/notification.php

<address\> — dirección del sitio

## POST 

Crea una nueva configuración de notificación.

El cuerpo de la solicitud es obligatorio.

##  DELETE 

Elimina una o varias notificaciones.

Parámetros de la solicitud:

-   id (opcional): ID de una notificación concreta
    
-   agent\_id (opcional): si se indica, se eliminan todas las notificaciones del agente especificado
    

### Ejemplo de solicitud

<table><tbody><tr><td><span></span></td><td><div>https://&lt;address&gt;/api/ptm/notification.php?id=123</div></td></tr></tbody></table>

También es posible eliminar todas las notificaciones por agent\_id:

<table><tbody><tr><td><span></span></td><td><div>https://&lt;address&gt;/api/ptm/notification.php?agent_id=456</div></td></tr></tbody></table>

### Respuesta

<table><tbody><tr><td><span></span></td><td><div>{</div><div>&nbsp; "count": 1 // número de notificaciones eliminadas</div><div>}</div></td></tr></tbody></table>
