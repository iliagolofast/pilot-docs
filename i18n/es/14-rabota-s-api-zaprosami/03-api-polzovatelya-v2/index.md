---
title: "API de usuario v2"
---

La API de usuario da acceso a las funciones y los datos de PILOT permitidos para un usuario normal.

Con ella puede:

— consultar sus informes y estadísticas de viajes, objetos y gastos

— obtener información sobre su configuración y sus datos personales

— solicitar datos relacionados únicamente con su cuenta y con su actividad en el sistema

Mediante estas API no se puede acceder a los datos de otros usuarios ni de administradores. Usted ve y trabaja únicamente con la información de su cuenta.
