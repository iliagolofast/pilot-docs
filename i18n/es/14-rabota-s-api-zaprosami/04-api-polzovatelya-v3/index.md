title: "API de usuario v3"
---

Para trabajar con la **API de usuario v3**, utilice la interfaz de Swagger: [https://pilot-swagger.pilot-gps.com/](https://pilot-swagger.pilot-gps.com/)

En esta versión de la API están disponibles métodos actualizados y estructurados para trabajar con el sistema.

En Swagger puede:

— ver la lista de todos los métodos disponibles

— consultar los parámetros de las solicitudes y las respuestas

— probar la API directamente en el navegador
