title: "API para trabajar con PILOT Task Manager"
---

PILOT Task Manager ([Gestor de tareas](../../lichnyj-kabinet-polzovatelya/moduli-1/pilot-task-manager/index.html)) — es un módulo del sistema PILOT para la gestión de tareas.

Con la API de este módulo puede:

— crear, editar y eliminar tareas

— asignar tareas a los ejecutores

— obtener el estado de ejecución y los plazos

 — obtener información sobre las tareas en curso y las completadas
