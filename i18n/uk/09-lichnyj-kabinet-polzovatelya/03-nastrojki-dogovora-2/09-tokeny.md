Токен — це унікальний код доступу, який дає змогу іншим користувачам бачити місцезнаходження об’єктів, не маючи доступу до вашого акаунта.

Простіше кажучи, токен — це як тимчасова перепустка. Він надає обмежений доступ до певної інформації, не розкриваючи ваші особисті дані чи пароль.

На вкладці «Токени» можна створити два типи токена:

-   [Monitor token](tokeny.html#Токен_для_просмотра_\(Monitor_token\)) — для перегляду місцезнаходження вибраних об’єктів за загальнодоступним посиланням
    
-   [Access token](tokeny.html#Токен_для_входа_\(Access_token\)) — для входу в PILOT без введення пароля
    

![](images/drex_tokeny_custom.png)

## Токен для перегляду (Monitor token)

Monitor token надає іншій людині доступ до карти з вибраними об’єктами та їхніми переміщеннями. Отримувач посилання не отримує логін, пароль і повний доступ до акаунта.

### Права на керування токенами для перегляду

Для керування Monitor tokens використовуються окремі права:

-   Edit Tokens — дозволяє створювати та змінювати токени моніторингу й посилання спільного доступу до місцезнаходження.
    
-   Delete Tokens — дозволяє видаляти токени моніторингу.
    

Щоб звичайний користувач міг створити, змінити або видалити посилання у веб-версії PILOT, адміністратор або майстер має надати йому право на зміну та видалення токенів.

### Як надати права користувачеві

-   У «Налаштуваннях договору» відкрийте вкладку [«Персонал і групи»](personal-i-gruppy/index.html)
    

2\. Двічі клацніть користувача в списку, щоб відкрити його картку

3\. Перейдіть на вкладку [«Права»](personal-i-gruppy/kartochka-polzovatelya/prava.html)

4\. Розгорніть групу «Токени»

5\. Виберіть потрібні права:

-   Edit Tokens — для створення та зміни токенів
    
-   Delete Tokens — для видалення токенів
    

![](images/drex_tokeny_custom_2.png)

6\. Натисніть «Зберегти»

### Як створити токен для перегляду

-   У секції «Monitor tokens» натисніть кнопку «Додати токен» ![](images/drex_tokeny_custom_3.png)
    
    2\. У вікні, що відкрилося, заповніть інформацію про токен:
    

![](images/drex_tokeny_custom_4.png)

-   Вкажіть період дії — виберіть дату й час початку та завершення роботи токена
    
-   Виберіть, яку карту використовувати для відображення об’єктів
    
-   Вкажіть, чи відображати на карті маркери об’єктів або датчики
    
-   Зі списку виберіть об’єкти, які потрібно відстежувати через цей токен
    
    3\. Натисніть «Зберегти»
    
    4\. Система створить унікальне посилання або iframe — код для вбудовування
    
    5\. Скопіюйте отримане посилання або код і надішліть тому, кому потрібен доступ до інформації
    

## Токен для входу (Access token)

Цей тип токена використовується для авторизації в системі без пароля. Під час переходу за спеціальним посиланням PILOT виконує вхід від імені користувача так само, як за використання логіна та пароля. Токен може мати обмежений строк дії або бути безстроковим.

### Як створити токен входу

-   Натисніть у секції «Access tokens» кнопку «Додати токен» ![](images/drex_tokeny_custom_3.png)
    
-   У новому вікні вкажіть дату й час початку та завершення дії токена. Якщо не вкажете завершення дії — токен працюватиме безстроково. 
    
-   Натисніть «Зберегти»
    

![](images/drex_tokeny_custom_5.png)

Щоб змінити токен, натисніть на значок олівця ![](images/drex_tokeny_custom_6.png), а для видалення — на значок кошика ![](images/drex_tokeny_custom_7.png).

![](images/drex_tokeny_custom_8.png)
