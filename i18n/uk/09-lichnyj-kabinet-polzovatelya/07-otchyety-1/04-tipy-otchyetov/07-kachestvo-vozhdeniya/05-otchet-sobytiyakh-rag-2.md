title: "Звіт про події RAG №2"
---

**Звіт містить:**

-   # Об’єкт  -

    об’єкт моніторингу, на якому фіксувалася якість водіння;

-   # Загальна відстань (км) -

    відстань, протягом якої вчинялося порушення;

-   # Тривалість поїздки -

    тривалість, протягом якої вчинялося порушення;

-   # Макс. швидкість-

    максимальна швидкість, зафіксована під час поїздки.

-   # Зона перевищення швидкості - **ділянка дороги, на якій установлено обмеження максимальної швидкості руху транспортних засобів**;

-   # Перевищення швидкості норма - **рух транспортного засобу зі швидкістю, що перевищує обмеження, встановлені законом або дорожніми знаками**;

-   # Область тривалості перевищення швидкості -  **тривалість перевищення швидкості;**

-   # Тривалість перевищення швидкості нормальна-**час, протягом якого транспортний засіб рухається з перевищенням встановленого обмеження швидкості**;

-   # Загальна тривалість перевищення швидкості -**час, протягом якого транспортний засіб рухається з перевищенням встановленого обмеження швидкості**;

-   # Оцінка швидкості -  **значення оцінки швидкості;**

-   # Загальне прискорення разом -  **значення загального прискорення за вказаний період;**

-   # Оцінка прискорення -**значення оцінки прискорення;**

-   # Загальна кількість уповільнень - **значення загального уповільнення за вказаний період;**

-   # Оцінка уповільнення  - **значення оцінки уповільнення;**

-   # Час без паса безпеки- **час поїздки без паса безпеки за звітний період;**

-   # Оцінка порушень пасів безпеки - **значення за порушення без паса безпеки;**

-   # Надмірний холостий хід **\-двигун автомобіля працює на холостих обертах довше, ніж це необхідно;**

-   # Тривалість простою - **значення про тривалість простою;**

-   # Загальний рахунок - **підсумкова оцінка поїздки.**
