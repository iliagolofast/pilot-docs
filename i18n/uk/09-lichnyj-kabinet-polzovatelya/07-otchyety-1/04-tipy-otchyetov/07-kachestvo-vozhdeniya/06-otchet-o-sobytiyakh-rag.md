# **Звіт про події RAG - це звіт, у якому міститься огляд основних подій** **з якості водіння.**

**Звіт містить:**

-   # Водій -

    водій, призначений на цей об’єкт;

-   # Загальна відстань (км) -

    відстань, протягом якої вчинялося порушення;

-   # Загальне прискорення -  **загальне значення оцінки прискорення;**

-   # Оцінка прискорення - **значення оцінки прискорення;**

-   # Загальна кількість уповільнень- **загальне значення оцінки уповільнення;**

-   # Оцінка уповільнення -**значення оцінки уповільнення;**

-   # Максимальна швидкість (км/год) -

    максимальна швидкість, зафіксована під час поїздки.

-   # Загальний час перевищення швидкості -

    загальний час, протягом якого було перевищено швидкість;

-   # Оцінка швидкості - **значення оцінки швидкості;**

-   # Час без паса безпеки - **час, протягом якого водій рухався без паса безпеки;**

-   # Оцінка порушень пасів безпеки - **значення оцінки руху без паса безпеки;**

-   # Рахунок -

    формується на основі суми різких поворотів, гальмувань і прискорень.
