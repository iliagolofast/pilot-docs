#  **Реєстр ТЗ — це реєстр транспортних засобів.**

 **Звіт містить :**

-   # Номер машини -   **об’єкт у системі моніторингу;**
    
-   # Марка - **марка об’єкта;**
    
-   # Модель - **модель об’єкта;**
    
-   # Рік випуску - **рік випуску об’єкта;**
    
-   # Тип ТЗ  -   **тип транспорту в системі ;**
    
-   # Номер двигуна - **номер двигуна;**
    
-   # Об’єм двигуна - **об’єм двигуна**;
    
-   # VIN - **VIN-код кузова;**
    
-   # Ліцензія на транспортний засіб **\- відомості ліцензії;**
    
-   # Дата видачі ПТС - **дата видачі паспорта транспортного засобу.**
