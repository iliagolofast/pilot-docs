---
title: "Які пристрої можна підключати"
---

У системі PILOT можна використовувати різні типи відеопристроїв. Для кожного типу є свої параметри підключення:

### Howen

-   Server 1 (телематика): Server URL, port 20009
    
-   Server 2 (відео): video.pilot-gps.com, port 33000
    
    Для Howen використовується окремий ключ url\_howen в [«Налаштуванні модуля»](nastrojka-modulej-v-paneli-administratora.html#Настройка_модуля)
    
    Пароль для підключення не потрібен.

### CMS

-   Адреса сервера (Host): video.pilot-gps.com
    
-   Порт: 6608
    

### Cipia

-   Адреса сервера (Host): video.pilot-gps.com
    
-   Порт:1883
    

### Teltonika DualCam

-   Адреса сервера (Host): video.pilot-gps.com
    
-   Порт: 20233
    

### Hikvision

Підключення пристроїв Hikvision залежить від конкретної моделі.

Для деяких моделей використовується стандартне підключення до сервера video.pilot-gps.com.

Наприклад, для Hikvision G40:

• Адреса сервера (Host): video.pilot-gps.com

• Порт: 6608

Інші моделі Hikvision, що підключаються до PILOT:

-   DS-MCW407 (BWS) — нагрудна камера для відео й аудіо з онлайн-передаванням.
    
-   AE-MN5043 (DVR) — мобільний відеореєстратор із GPS для транспорту.
    
-   AE-VC583I-IS/P(H) — автомобільна IP-камера високої роздільної здатності (розпізнавання номерів).
    

Для різних моделей Hikvision можуть застосовуватися різні параметри підключення. Щоб уточнити, які саме, зверніться до підтримки.
