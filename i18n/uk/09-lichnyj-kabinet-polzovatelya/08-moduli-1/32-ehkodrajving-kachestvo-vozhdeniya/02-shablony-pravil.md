title: "Шаблони правил"

Шаблон правил — це збережений набір налаштувань якості водіння. За допомогою шаблону можна застосувати готові правила до транспортного засобу, не налаштовуючи кожне правило вручну. Шаблон можна підібрати за типом пристрою та транспортного засобу, застосувати до об’єкта або створити самостійно.

## Готові шаблони

Щоб відкрити список шаблонів:

1\. Відкрийте картку транспортного засобу

2\. Перейдіть на вкладку «Якість водіння»

3\. Розкрийте список «Шаблон»

У списку відображаються відповідні шаблони та окрема група «Універсальні шаблони».

![](images/drex_shablony_pravil_custom.png)

 Універсальні шаблони не пов’язані з певним пристроєм або типом транспортного засобу, тому їх можна застосовувати до різних транспортних засобів.

У системі також доступні готові шаблони для певних моделей телематичного обладнання:

-   CIPIA
    

![](images/drex_shablony_pravil_custom_2.png)

-   FLEX — для пристроїв, що працюють за протоколом Flex, наприклад, Smart 2333
    

![](images/drex_shablony_pravil_custom_3.png)

-   GB100 ECO — для Queclink GB100
    

![](images/drex_shablony_pravil_custom_4.png)

-   GV65 ECO — для Queclink GV65
    

![](images/drex_shablony_pravil_custom_5.png)

-   Ruptela
    

![](images/drex_shablony_pravil_custom_6.png)

-   Teltonika
    

![](images/drex_shablony_pravil_custom_7.png)

Вибирайте шаблон, що відповідає обладнанню та типу транспортного засобу.

## Як застосувати шаблон

1\. Відкрийте вкладку «Якість водіння»

2\. У полі «Шаблон» виберіть потрібний шаблон

![](images/drex_shablony_pravil_custom.png)

3\. Натисніть «Застосувати» ![](images/drex_shablony_pravil_custom_8.png)

![Шаблони правил](images/drex_shablony_pravil_screen.png)

4\. Правила з шаблону завантажаться в таблицю. Перевірте їх і натисніть «Зберегти» в нижній частині картки транспортного засобу.

![](images/drex_shablony_pravil_custom_9.png)

Якщо тип транспортного засобу не вказано, для підбору використовується тип «Легковий», але поле в картці автоматично не заповнюється.</div></td></tr></tbody></table>

## Як створити власний шаблон

Спочатку налаштуйте правила якості водіння. Щоб додати правило:

1\. Натисніть значок плюса ![](images/drex_shablony_pravil_custom_10.png)

2\. Заповніть параметри правила

3\. Натисніть «Зберегти» в рядку правила

![](images/drex_shablony_pravil_custom_11.png)

Щоб зберегти налаштовані правила як шаблон:

1\. Натисніть значок збереження ![](images/drex_shablony_pravil_custom_12.png) поруч зі списком «Шаблон»

![Шаблони правил](images/drex_shablony_pravil_screen_2.png)

2\. У вікні «Зберегти як шаблон» вкажіть:

-   Ім’я шаблону
    
-   Тип пристрою — необов’язково
    
-   Тип ТЗ — необов’язково
    

![](images/drex_shablony_pravil_custom_13.png)

3\. Натисніть «Зберегти»

<table><tbody><tr><td><span></span></td><td><div>Якщо залишити тип пристрою або тип транспортного засобу незаповненим, шаблон можна буде використовувати з будь-яким значенням цього параметра.</div></td></tr></tbody></table>

Створений шаблон з’явиться у списку доступних шаблонів.

![](images/drex_shablony_pravil_custom_14.png)

## Як налаштувати застосовність шаблону

Застосовність визначає, для яких пристроїв і транспортних засобів буде доступний шаблон.

### Область застосування шаблону

Шаблон можна пов’язати:

— з типом пристрою та типом транспортного засобу

— лише з типом пристрою

— лише з типом транспортного засобу

-   — не пов’язувати ні з одним із типів — такий шаблон вважається універсальним
    

<table><tbody><tr><td><span></span></td><td><div>Якщо тип пристрою не вказано, шаблон можна використовувати з будь-яким пристроєм. Якщо не вказано тип транспортного засобу, шаблон підходить для всіх типів транспортних засобів.</div></td></tr></tbody></table>

### Щоб налаштувати застосовність:

-   У правій верхній частині вікна знайдіть інструменти для керування налаштуваннями екодрайвінгу
    

![Шаблони правил](images/drex_shablony_pravil_screen_3.png)

2.  Натисніть значок

### ![](images/drex_shablony_pravil_custom_15.png)

у верхній частині вкладки «Якість водіння»

3\. У вікні «Застосовність шаблону» виберіть:

-   Тип пристрою
    
-   Тип ТЗ
    
-   Шаблон
    

![](images/drex_shablony_pravil_custom_16.png)

-   Тип пристрою
    
-   Тип ТЗ
    
-   Шаблон
    
    3\. Натисніть «Прив’язати»
    

У полі «Тип пристрою» можна вибрати конкретну модель обладнання.

![](images/drex_shablony_pravil_custom_17.png)

У полі «Тип ТЗ» можна вибрати конкретний тип транспортного засобу або залишити значення «Для всіх типів ТЗ».

![](images/drex_shablony_pravil_custom_18.png)

У полі «Шаблон» виберіть шаблон, для якого налаштовується застосовність.

![](images/drex_shablony_pravil_custom_19.png)

Наприклад, шаблон можна пов’язати з пристроєм FleetGuide та типом транспортного засобу «Легковий».

![](images/drex_shablony_pravil_custom_20.png)

Щоб очистити вибране значення, натисніть значок хрестика у відповідному полі.

Після прив’язування PILOT враховує тип пристрою та тип транспортного засобу під час підбору доступних шаблонів. Шаблон не застосовується автоматично: ви вибираєте його та підтверджуєте застосування.

## Імпорт та експорт правил

Імпорт та експорт дають змогу переносити правила між транспортними засобами або зберігати їхню копію.

У верхній частині вікна «Якість водіння» знайдіть інструменти експорту та імпорту.

![Шаблони правил](images/drex_shablony_pravil_screen_4.png)

**Експорт **![](images/drex_shablony_pravil_custom_21.png) — зберігає поточні правила у файл JSON

Для цього:

1\. Натисніть кнопку експорту

2\. Збережіть файл на комп’ютер

У файл JSON зберігаються всі параметри правил.

**Імпорт **![](images/drex_shablony_pravil_custom_22.png) — завантажує  раніше збережений файл JSON

Для цього:

1\. Натисніть кнопку імпорту

2\. Виберіть файл

3\. Налаштування автоматично завантажаться в таблицю

<table><tbody><tr><td><span></span></td><td><div>Імпортовані правила замінюють поточний набір правил у таблиці. За потреби збережіть наявні налаштування за допомогою експорту перед імпортом нового файлу.</div></td></tr></tbody></table>
