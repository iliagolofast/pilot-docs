---
title: "Модулі"
---

**Модулі системи** – це окремі компоненти, які разом утворюють складну систему, забезпечуючи її функціональність і взаємопов’язану роботу.

Кожен модуль виконує конкретні завдання або функції, і вони можуть розроблятися й оновлюватися незалежно один від одного.

Керувати активацією може лише адміністратор системи через панель адміністратора.

Список модулів у договорі може змінюватися залежно від налаштувань Партнера.

![](images/drex_moduli_2_custom.png)

[СMS](../../lichnyj-kabinet-polzovatelya/moduli-1/video-i-cms/index.html) [і Відео-](../../lichnyj-kabinet-polzovatelya/moduli-1/video-i-cms/index.html) компонент системи, який дає змогу відстежувати стан і поведінку водія та пасажирів усередині салону.

[Модуль водіїв](../../lichnyj-kabinet-polzovatelya/moduli-1/voditeli-3/index.html) - це компонент системи, який використовується для керування та відстеження роботи водіїв у системі.

[Модуль Контрагенти (Торговий представник)](../../lichnyj-kabinet-polzovatelya/moduli-1/torgovyj-predstavitel.html) - призначений для керування інформацією про контрагентів, включно з клієнтами, постачальниками, партнерами й торговими представниками. Цей модуль допомагає організувати взаємодію з контрагентами, покращити якість обслуговування.

[Control room](../../lichnyj-kabinet-polzovatelya/moduli-1/situatsionnyj-tsentr-2/index.html) - компонент системи для відстеження місцезнаходження авто, сканування його стану.

[Клімат-контроль](../../lichnyj-kabinet-polzovatelya/moduli-1/klimat/index.html) - це система автоматичного регулювання кліматичних умов у замкненому просторі, наприклад, в автомобілі, офісі або житловому приміщенні. Основна мета – підтримання комфортних умов для перебування людей, включно з оптимальними рівнями температури, вологості та якості повітря.

[Модуль RFID міток](../../lichnyj-kabinet-polzovatelya/moduli-1/rfid-metki-2/index.html) - модуль призначений для контролю зчитування RFID міток, вузькоспрямований модуль, створений для контролю забору сміття (на баку стоїть мітка, на автомобілі - зчитувач).

[Модуль аналітики (Панель)](../../lichnyj-kabinet-polzovatelya/moduli-1/analitika.html)\- компонент системи, який надає можливості для збору, обробки, аналізу даних з об’єктів моніторингу з метою отримання цінної інформації про них.

[Модуль блокування двигуна](../../lichnyj-kabinet-polzovatelya/moduli-1/blokirovka-dvigatelya.html) -це компонент системи, який призначений для запобігання несанкціонованому доступу та запуску двигуна.

[Модуль геозони](../../lichnyj-kabinet-polzovatelya/moduli-1/geozony-2/index.html) - призначений для територіального контролю об’єктів моніторингу. Дає змогу фіксувати факти перебування об’єкта в заданій зоні, перевищення допустимого часу простою в зоні та виїзд із зони.

[Модуль команд](../../lichnyj-kabinet-polzovatelya/moduli-1/komandy-1.html) - компонент системи включає набір команд, які можуть бути надіслані користувачами на пристрої.

[Модуль контролю часу](../../lichnyj-kabinet-polzovatelya/moduli-1/kontrol-vremeni.html) - компонент системи, призначений для відстеження, обліку та керування робочим часом.

[Модуль контролю порушень](../../lichnyj-kabinet-polzovatelya/moduli-1/kontrol-narushenij.html)  -це компонент системи, який використовується для відстеження та виявлення порушень за набором наперед визначених правил.

[Модуль логістики](../../lichnyj-kabinet-polzovatelya/moduli-1/logistika-2/index.html) - компонент системи, який призначений для керування та оптимізації логістичних операцій у межах постачань, складування й транспортування товарів або послуг.

[Модуль перерахунків](../../lichnyj-kabinet-polzovatelya/moduli-1/pereschyet-dannykh.html) - це компонент системи, який використовується для проведення перерахунків і перетворень даних у системі. Перерахунок можливий за двома типами: Зони та Поїздки.

 [Модуль причепів](../../lichnyj-kabinet-polzovatelya/moduli-1/pritsepy.html) -  призначений для моніторингу стану причепів і напівпричепів, прикріплених до основних транспортних засобів. Цей модуль дає змогу відстежувати місцезнаходження, стан і рух причепів, а також переглядати історію з’єднань і роз’єднань з ТЗ.

[Модуль ретрансляції](../../lichnyj-kabinet-polzovatelya/moduli-1/retranslyatsiya/index.html) \- це компонент системи, який використовується для передавання даних з одного джерела в інше або одразу в кілька інших джерел. Він відіграє роль посередника між відправником і отримувачем даних.

[Модуль сервіс](../../lichnyj-kabinet-polzovatelya/moduli-1/servis/index.html) - компонент системи, який призначений для зручності планування або відображення факту проведення технічного огляду ТЗ.

[Модуль подій](../../lichnyj-kabinet-polzovatelya/moduli-1/sobytiya.html) -компонент системи, який призначений для відстеження та запису різних налаштованих у системі подій. Він відіграє ключову роль у моніторингу об’єктів та аналізі дій користувачів.

[Модуль паливних карток](../../lichnyj-kabinet-polzovatelya/moduli-1/toplivnye-karty/index.html)  - вибір палива залежить від конкретних вимог, умов експлуатації та екологічних факторів.

[Модуль сповіщень](../../lichnyj-kabinet-polzovatelya/moduli-1/uvedomleniya/index.html) \- компонент системи, призначений для надсилання сповіщень користувачам про різні події, зміни або стани. Він забезпечує оперативне інформування користувача та дає змогу вчасно реагувати на важливі події.

[Модуль Рейси](../../lichnyj-kabinet-polzovatelya/moduli-1/rejsy-2/kak-dobavit-ostanovki.html)\- компонент системи, призначений для автоматизації та оптимізації роботи автобусних маршрутів, підвищення якості обслуговування пасажирів і забезпечення ефективності роботи транспортного парку.

[Модуль маршрути](../../lichnyj-kabinet-polzovatelya/moduli-1/marshruty-3/index.html) -компонент системи, призначений для контролю пасажиропотоку.

[PILOT диспетчер завдань](../../lichnyj-kabinet-polzovatelya/moduli-1/pilot-task-manager/index.html) - модуль, призначений для моніторингу, керування та координації виконання завдань або процесів у системі. Він надає користувачам можливість спостерігати за поточними процесами та керувати ними

[Розклад](../../lichnyj-kabinet-polzovatelya/moduli-1/raspisanie.html) -модуль, що використовується для створення, керування та оптимізації розкладів роботи транспортних засобів і водіїв.

[Екодрайвінг](../../lichnyj-kabinet-polzovatelya/moduli-1/ehkodrajving-kachestvo-vozhdeniya/index.html) \- це компонент системи керування транспортом, призначений для моніторингу, аналізу та покращення стилю водіння.

[Модуль Тахограф](../../lichnyj-kabinet-polzovatelya/moduli-1/takhograf-2.html) -призначений для моніторингу та реєстрації даних про режим роботи й відпочинку водіїв, швидкість руху та інші важливі параметри, пов’язані з експлуатацією транспортних засобів. Тахографи відіграють ключову роль у забезпеченні безпеки на дорогах і дотриманні нормативних вимог.

[Crash detected](../../lichnyj-kabinet-polzovatelya/moduli-1/obnaruzhenie-avarij.html) -компонент системи керування транспортом, призначений для автоматичного виявлення дорожньо-транспортних пригод за участю транспортних засобів.  Модуль використовує різні датчики для моніторингу параметрів руху.

[Rent Сar](../../lichnyj-kabinet-polzovatelya/moduli-1/rent-car/index.html) \- модуль, призначений для керування та автоматизації процесів оренди транспортних засобів.

[Модуль збір сміття](../../lichnyj-kabinet-polzovatelya/moduli-1/sbor-musora/index.html) - призначений для планування, оптимізації та моніторингу операцій зі збору й вивезення сміття.

[Модуль Агро (Trailers module)](../../lichnyj-kabinet-polzovatelya/moduli-1/agro.html)\- призначений для автоматизації та оптимізації процесів керування сільськогосподарською технікою та ресурсами в агропромисловому комплексі.

Модуль контролю працездатності обладнання - компонент системи, який призначений для моніторингу стану різних компонентів і систем транспортних засобів. Цей модуль допомагає виявляти несправності, запобігати поломкам та оптимізувати технічне обслуговування.

[Модуль LogBook](../../lichnyj-kabinet-polzovatelya/moduli-1/logbook/index.html) - це портал для водіїв, де вони можуть відстежувати статистику своїх поїздок, дані економного водіння, витрати на паливо, вартість дорожніх зборів і свої рейтинги.

Кожен водій може отримати доступ до порталу, маючи лише власну статистику, яка аналізується на основі всіх поїздок усіх використаних ним автомобілів.
