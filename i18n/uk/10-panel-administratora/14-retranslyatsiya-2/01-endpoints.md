## Що таке endpoint

Endpoint — це напрямок передавання даних у зовнішню систему. У ньому налаштовуються параметри підключення: адреса сервера, порт, протокол передавання даних і параметри авторизації.

Після створення endpoint до нього можна підключити один або кілька об’єктів.

## Список endpoints

Щоб відкрити список endpoint, перейдіть у розділ «Ретрансляція» → «Endpoints».

![](images/drex_endpoints_custom.png)

На цій вкладці відображаються всі доступні напрямки передавання даних та їх поточний стан.

**![](images/drex_endpoints_custom_2.png)**

Тут ви можете:

— створювати нові endpoints

— змінювати налаштування наявних endpoints

— підключати об’єкти

— налаштовувати автоматичне підключення нових об’єктів

— переглядати статистику передавання даних

— вмикати, вимикати та видаляти endpoints

### Верхня панель

На верхній панелі доступні такі дії:

1\. Додати — створення нового endpoint

2\. Statistics — вибір періоду для відображення статистики

3\. Шукати — пошук endpoint у таблиці

4\. Очистити фільтри — скидання всіх фільтрів

![Endpoints](images/drex_endpoints_screen.png)

### Вибір періоду відображення статистики

![](images/drex_endpoints_custom_3.png)

Параметр Statistics впливає на відображення мініграфіків у колонках:

-   Err — помилки
    
-   Відправка (Send) — надсилання даних
    
-   Ack — підтверджені пакети
    

![Endpoints](images/drex_endpoints_screen_2.png)

Мініграфіки допомагають швидко оцінити стан ретрансляції за вибраний період.

На графіку відображаються:

— динаміка показника

— загальна кількість подій за вибраний період

Під час наведення курсора відображається інформація за вибраною точкою графіка.

Доступні такі періоди:

![](images/drex_endpoints_custom_3.png)

-   12 hours — останні 12 годин
    
-   Day — остання доба
    
-   Week — останній тиждень
    
-   2 weeks — останні два тижні
    
-   Month — останній місяць

### Як створити endpoint

1\. Натисніть на верхній панелі «Додати»

## ![Endpoints](images/drex_endpoints_screen_4.png)

2\. Заповніть параметри підключення

![](images/drex_endpoints_custom_14.png)

Основні параметри

Назва — назва endpoint

Хост — адреса зовнішнього сервера, на який надсилатимуться дані

Порт — порт підключення зовнішньої системи

Формат — протокол або формат передавання даних

Шлях — додатковий шлях або URL-маршрут, якщо він потрібен використовуваному протоколу

Uspw — дані авторизації для підключення до зовнішньої системи

Time zone — часовий пояс, який використовуватиметься за замовчуванням для об’єктів цього endpoint

Speed Limit — максимальна швидкість, яка передаватиметься в зовнішню систему

Прапорець «Увімкнено» — ввімкнення або вимкнення endpoint

Testing — дає змогу створити тестовий endpoint. Параметр доступний лише адміністраторам

Json config — додаткові налаштування підключення у форматі JSON

Коментар — довільний коментар для користувачів системи

Mapping fields — налаштування зіставлення полів для спеціальних форматів передавання даних

Розклад — розклад, протягом якого дозволено передавання даних через цей endpoint

3\. Натисніть «Зберегти»

Після збереження endpoint стане доступним для підключення об’єктів.

### Як редагувати endpoint

1\. Натисніть кнопку «Редагувати»  ![](images/drex_endpoints_custom_9.png) у колонці дій або двічі клацніть по рядку endpoint

## ![Endpoints](images/drex_endpoints_screen_3.png)

2\. Змініть необхідні параметри

![](images/drex_endpoints_custom_15.png)

3\. Натисніть «Зберегти»

Зміни автоматично застосовуються до всіх об’єктів, які використовують цей endpoint.

Якщо система виявить endpoint з такими самими параметрами, вона запропонує об’єднати їх. Перед підтвердженням уважно перевірте налаштування.

Якщо об’єднання не підтвердити, зміни не буде збережено.

![](images/drex_endpoints_custom_16.png)

### Як увімкнути або вимкнути endpoint

Щоб тимчасово зупинити або відновити передавання даних:

1\. Натисніть кнопку ввімкнення ![](images/drex_endpoints_custom_8.png) або вимкнення  ![](images/drex_endpoints_custom_7.png)  у колонці дій

![Endpoints](images/drex_endpoints_screen_5.png)

Якщо endpoint вимкнено, усі об’єкти, підключені до нього, перестають передавати дані в зовнішню систему.

### Як видалити endpoint

1\. Натисніть кнопку видалення ![](images/drex_endpoints_custom_13.png) у колонці дій

2\. Підтвердіть видалення

Перед видаленням система покаже кількість об’єктів, які використовують цей endpoint.

Після видалення передавання даних через endpoint буде повністю зупинено.

## Об’єкти endpoint

Щоб переглянути об’єкти, підключені до endpoint:

1\. Знайдіть потрібний endpoint

2\. Натисніть кнопку «Машини/Об’єкти»  ![](images/drex_endpoints_custom_12.png) у колонці дій

Відкриється список об’єктів, які передають дані через вибраний endpoint.

![](images/drex_endpoints_custom_17.png)

З цього вікна можна:

— підключати нові об’єкти

— змінювати параметри ретрансляції окремих об’єктів

— тимчасово вимикати передавання даних

— видаляти об’єкти з endpoint

### Колонки списку об’єктів

![](images/drex_endpoints_custom_17.png)

Agent ID — ідентифікатор об’єкта

Машина — назва об’єкта моніторингу

IMEI — унікальний ідентифікатор пристрою

Договір — договір об’єкта

External ID — ідентифікатор об’єкта у зовнішній системі

On/off — увімкнена чи вимкнена ретрансляція об’єкта

Err — мініграфік помилок за об’єктом

Відправка (Send) — мініграфік спроб надсилання за об’єктом

Ack — мініграфік прийнятих пакетів за об’єктом

Дії з об’єктами:

![](images/drex_endpoints_custom_7.png) і ![](images/drex_endpoints_custom_8.png)  — увімкнути або вимкнути об’єкт у цьому endpoint

![](images/drex_endpoints_custom_18.png) — видалити об’єкт із цього endpoint

### Як додати об’єкти

1\. Натисніть у вікні «Об’єкти/Машини» кнопку «Додати»

![Endpoints](images/drex_endpoints_screen_6.png)

2\. Виберіть один або кілька об’єктів

![](images/drex_endpoints_custom_19.png)

3\. За потреби змініть External ID. За замовчуванням як External ID використовується IMEI пристрою

4\. Натисніть «Додати», щоб підключити вибрані об’єкти до endpoint

Якщо список об’єктів великий, скористайтеся пошуком угорі в полі «Шукати» —  введіть назву або номер об’єкта.

### Як редагувати об’єкт

1\. Двічі клацніть по об’єкту в списку

![](images/drex_endpoints_custom_17.png)

2\. Внесіть зміни у форму редагування об’єкта

![](images/drex_endpoints_custom_20.png)

У формі можна змінити об’єктні параметри ретрансляції:

-   Endpoint — напрямок передавання даних, через який об’єкт надсилає інформацію в зовнішню систему
    
-   External ID — ідентифікатор об’єкта у зовнішній системі
    
-   Чекбокс «Увімкнено» — вмикає або вимикає передавання даних лише для вибраного об’єкта
    
-   Обмеження швидкості — максимальна швидкість, яка передаватиметься в зовнішню систему для цього об’єкта
    
-   Часова зона — часовий пояс, що використовується для передавання даних цього об’єкта
    
-   Uspw — дані авторизації для цього об’єкта
    
-   Json config — додаткові налаштування ретрансляції у форматі JSON
    
-   Розклад — розклад передавання даних для об’єкта.
    

Параметри Host, Port, Format і Path у цій формі змінити не можна. Вони успадковуються від endpoint.

Якщо необхідно змінити підключення до зовнішньої системи, відкрийте налаштування endpoint або виберіть інший endpoint.

3\. Збережіть налаштування

## Автоматичне підключення об’єктів до endpoint

Функція Auto add дає змогу автоматично підключати нові об’єкти до endpoint.

Цю функцію використовують, якщо всі об’єкти певного договору мають автоматично передавати дані в одну зовнішню систему. Після налаштування правила нові об’єкти підключатимуться автоматично без додаткових дій користувача.

### Як налаштувати Auto add

1\. Натисніть кнопку Auto add  ![](images/drex_endpoints_custom_10.png)у колонці дій

## ![Endpoints](images/drex_endpoints_screen_7.png)

2\. Відкриється вікно зі списком договорів для ввімкнення автоматичного додавання об’єктів. Натисніть «Додати»

![](images/drex_endpoints_custom_21.png)

3\. Виберіть один або кілька договорів

![](images/drex_endpoints_custom_22.png)

4\. Натисніть «Додати»

Після збереження всі нові об’єкти вибраних договорів автоматично підключатимуться до цього endpoint.
