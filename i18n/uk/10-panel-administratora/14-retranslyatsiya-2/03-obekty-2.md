title: "Об’єкти"

На вкладці «Об’єкти» відображаються всі ретрансляції об’єктів, доступні поточному користувачу.

## Список об’єктів

Щоб відкрити список об’єктів, перейдіть у розділ «Ретрансляція» → «Об’єкти».

![](images/drex_obekty_2_custom.png)

Тут ви можете:

— знайти потрібний об’єкт

— переглянути, через який endpoint передаються дані

— увімкнути або вимкнути ретрансляцію об’єкта

— відкрити налаштування ретрансляції

— переглянути статистику передавання даних за об’єктом

![](images/drex_obekty_2_custom_2.png)

### Верхня панель

На верхній панелі доступні такі дії:

-   Конфіги — налаштування конфігурацій ретрансляції
    
-   Експорт — вивантаження списку об’єктів
    
-   Statistics — вибір періоду відображення мініграфіків
    
-   Шукати — пошук за таблицею
    
-   Очистити фільтри — очищення фільтрів
    

![](images/drex_obekty_2_custom_2.png)

### Колонки таблиці

-   Actions — доступні дії з ретрансляцією об’єкта.
    
-   ID — ідентифікатор запису ретрансляції.
    
-   Agent id — ідентифікатор об’єкта.
    
-   Хост —  IP-адреса або доменне ім’я зовнішнього сервера.
    
-   Порт — порт зовнішнього сервера
    
-   Формат — використовуваний протокол передавання даних.
    
-   Статистика / Err — мініграфік помилок
    
-   Статистика / Відправка (Send) — мініграфік спроб надсилання за вибраний період
    
-   Статистика / Ack — мініграфік прийнятих пакетів за вибраний період
    
-   Last id — ідентифікатор останнього обробленого пакета.
    
-   Uspw — дані авторизації
    
-   Часова зона — часова зона ретрансляції об’єкта
    
-    ![](images/drex_obekty_2_custom_3.png) ![](images/drex_obekty_2_custom_4.png) — стан ретрансляції об’єкта (увімкнена або вимкнена).
    

### Дії з об’єктом

У колонці Actions доступні такі дії:

![Об’єкти](images/drex_obekty_2_screen.png)

![](images/drex_obekty_2_custom_5.png) ![](images/drex_obekty_2_custom_6.png)   — увімкнути або вимкнути ретрансляцію об’єкта

![](images/drex_obekty_2_custom_7.png) Редагувати — відкрити налаштування ретрансляції об’єкта. Також форму редагування можна відкрити подвійним клацанням по рядку об’єкта.

У формі редагування можна змінити параметри, що стосуються лише вибраного об’єкта:

![](images/drex_obekty_2_custom_8.png)

Якщо необхідно змінити адресу сервера, порт, протокол передавання даних або шлях підключення, відкрийте налаштування відповідного endpoint на вкладці [Endpoints](endpoints.html).

## Робота з ретрансляціями з розділу «Машини»

Керувати ретрансляціями можна не лише через вкладку «Об’єкти» в розділі «Ретрансляція», а й безпосередньо зі списку об’єктів у розділі «Машини».

Для цього:

1\. Перейдіть у розділ «Машини»

![](images/drex_obekty_2_custom_9.png)

2\. Виберіть одну або кілька машин

3\. Натисніть правою кнопкою миші

4\. У контекстному меню виберіть пункт «Ретрансляції»

![](images/drex_obekty_2_custom_10.png)

### Ретрансляції однієї машини

Якщо вибрано одну машину, відкриється вікно ретрансляцій вибраного об’єкта.

![](images/drex_obekty_2_custom_11.png)

Вікно складається з двох секцій:

**Конфігурація — м**істить список налаштованих ретрансляцій об’єкта.

Тут можна:

— додати нову ретрансляцію

— змінити наявну

— видалити ретрансляцію

— увімкнути або вимкнути передавання даних

**Resend requests** — містить запити на повторне передавання історичних даних за вибраний період.

### Ретрансляції кількох машин

Якщо вибрано кілька машин, пункт меню відображається як «Ретрансляція (N)», де N — кількість вибраних об’єктів.

![](images/drex_obekty_2_custom_12.png)

Після відкриття вікна можна створити однакову ретрансляцію одразу для кількох машин.

![](images/drex_obekty_2_custom_13.png)

У цьому разі система створить окремий запис ретрансляції для кожного вибраного об’єкта з використанням одного вибраного endpoint.

### Як додати ретрансляцію

1\. У розділі «Машини» виберіть один або кілька об’єктів

2\. Відкрийте контекстне меню правою кнопкою миші

3\. Виберіть пункт «Ретрансляції»

![](images/drex_obekty_2_custom_10.png)

4\. У секції «Конфігурація» натисніть кнопку ![](images/drex_obekty_2_custom_14.png)

![](images/drex_obekty_2_custom_11.png)

Відкриється форма створення ретрансляції.

![](images/drex_obekty_2_custom_15.png)

Заповніть необхідні параметри:

-   Endpoint — напрямок передавання даних
    
-   External ID — ідентифікатор об’єкта у зовнішній системі
    
-   Обмеження швидкості — обмеження швидкості передавання
    
-   Часова зона — часовий пояс
    
-   Uspw — дані авторизації
    
-   Прапорець «Увімкнено» — ввімкнення або вимкнення ретрансляції
    
-   Json config — додаткові параметри у форматі JSON
    
-   Розклад  — розклад передавання даних
    

Поля хост, порт, формат, шлях визначаються налаштуваннями endpoint і в цій формі не редагуються. Для зміни цих параметрів необхідно змінити налаштування відповідного [endpoint](endpoints.html).

Після збереження об’єкт почне передавати дані через вибраний endpoint.

### Resend requests

Секція Resend requests призначена для повторного надсилання раніше збережених даних за вказаний період.

![Об’єкти](images/drex_obekty_2_screen_2.png)

Ця функція використовується, якщо дані з якоїсь причини не були передані в зовнішню систему або потрібне повторне вивантаження історичної інформації.

Як створити запит:

1\. У секції Resend requests натисніть кнопку ![](images/drex_obekty_2_custom_14.png)

2\. Вкажіть дату початку періоду

3\. Вкажіть дату закінчення періоду

![](images/drex_obekty_2_custom_16.png)

4\. Натисніть «Додати»

Після створення запит з’явиться в таблиці.

![](images/drex_obekty_2_custom_17.png)

### Колонки таблиці Resend requests

-   Час початку — початок періоду повторного передавання
    
-   Час зупинки  — закінчення періоду повторного передавання
    
-   Create at — дата й час створення запиту
    
-   Update at — дата й час останньої зміни запиту
    
-   Status — поточний стан запиту:
    
-   New — запит створено та очікує на обробку
    
-   In Process — виконується повторне надсилання даних
    
-   Complete — обробку завершено
    

Після завершення запиту дані за вказаний період буде повторно передано через вибрану ретрансляцію.
