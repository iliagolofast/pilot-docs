---
title: "Підключення BI Analytics до BI-систем"
---

BI Analytics дає змогу підключити дані системи моніторингу до зовнішніх BI-платформ для створення власних звітів, графіків, дашбордів і аналітичних панелей.

![](images/drex_podklyuchenie_bi_analytics_k_bi_sistemam_custom.png)

За допомогою BI Analytics API можна отримувати дані про транспортні засоби, водіїв, поїздки, витрату палива, порушення «Екодрайвінгу» та інші показники, а потім використовувати їх у будь-якій BI-системі, що підтримує роботу з REST API.

BI Analytics підходить як для створення простих звітів, так і для побудови корпоративної аналітики з використанням власних показників, фільтрів і візуалізацій.

Отримані дані можна використовувати в таких BI-системах, як:

-   Microsoft Power BI
    
-   Tableau
    
-   Qlik Sense
    
-   Apache Superset
    
-   Grafana
    
-   інших платформах, що підтримують REST API
    

## Що необхідно для підключення

Перед підключенням переконайтеся, що:

— на партнерському обліковому записі [увімкнено модуль аналітики](kak-vklyuchit-dostup-k-bi-analytics.html#Включение_модуля_аналитики_на_партнёрском_аккаунте)

— на договорі користувача також [увімкнено модуль аналітики](kak-vklyuchit-dostup-k-bi-analytics.html#Включение_модуля_аналитики_на_договоре_пользователя)

— у конфігурації партнера [встановлено параметр bi\_analytics = 1](kak-vklyuchit-dostup-k-bi-analytics.html#Подключение_конфигурации)

— відомі [логін і пароль](podklyuchenie-k-bi-analytics-api.html#Где_взять_логин_и_пароль) партнерського облікового запису

 — вибрано правильну [адресу сервера](podklyuchenie-k-bi-analytics-api.html#Как_выбрать_адрес_сервера)

Після виконання цих налаштувань можна підключатися до BI Analytics API з будь-якої підтримуваної BI-платформи.

## Документація API (Swagger)

Для перегляду структури методів BI Analytics API ви можете використовувати документацію API у форматі Swagger: [BI API v1 — Swagger](https://bi-swagger.pilot-gps.com/?urls.primaryName=BI+API+v1+Russian#/)

У Swagger-документації ви можете:

— переглянути всі доступні методи API

— подивитися структуру запитів і відповідей

— завантажити специфікацію API у форматі JSON
