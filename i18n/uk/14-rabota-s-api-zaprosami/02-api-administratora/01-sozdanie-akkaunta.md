---
title: "Створення облікового запису"
---

Цей API використовується для створення нового облікового запису (договору), зокрема інформації про обліковий запис і користувацьких даних (разом із логіном і паролем адміністратора). Після виконання запиту створюється обліковий запис з унікальним ID, а також додається перший користувач (адміністратор) із заданими логіном і паролем.

## Як отримати дані

Для отримання даних використовуйте адресу: https://<server\_address>/ax/api.php?

### Метод

POST

### Параметри запиту

Обов’язкові параметри:

-   cmd=accountadd — команда для додавання нового облікового запису
    
-   bill\_price — ID прайсу (потрібно отримати з команди pricelist).
    
-   inn —  ІПН організації
    
-   node — номер вузла, на якому потрібно виконати команду
    

Додаткові параметри:

-   acc\_deposit — сума депозиту (за замовчуванням 0)
    
-   acc\_type — тип тарифікації:
    
    — за замовчуванням 1 — постоплата
    
    — 2— передоплата
    
    — 3— постоплата лайт (з порогом відключення)
    
-   org\_type — тип організації
    
    — за замовчуванням 1 — юрособа
    
    — 2— фізособа
    
    — 3— ФОП
    
-   bill\_phone — телефон організації
    
-   comment — коментар до облікового запису
    
-   code — код 1С
    
-   kpp —КПП
    
-   block\_limit — поріг відключення для тарифікації постоплата лайт
    
-   modules — ID підключених модулів через кому (отримуємо з команди modlist)
    
-   bill\_email — Email для облікового запису
    
-   org\_name — назва організації

У відповідь на API-запит повертається:

-   code — статус відповіді
    
    — 0— операція пройшла успішно
    
-   data — дані про новий обліковий запис
    
-   id — унікальний ідентифікатор облікового запису
    
-   login — логін адміністратора, створеного в межах цього облікового запису
    
-   password — пароль адміністратора
    
-   msg — повідомлення з результатом виконання операції
