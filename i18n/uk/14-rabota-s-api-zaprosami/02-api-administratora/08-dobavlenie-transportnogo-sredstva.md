---
title: "Додавання транспортного засобу"
---

Щоб додати об’єкт до договору, використовуйте цей API.

## Як отримати дані

### Метод

POST

### Адреса запиту

Для отримання даних використовуйте адресу:  https://<server\_address>/backend/api.php?

### Параметри запиту

Щоб отримати потрібні дані, додайте до адреси запиту параметри. Параметри вказуються після знака питання «?» і розділяються знаком «&».

Обов’язкові:

-   cmd = vehadd — команда для додавання транспортного засобу
    
-   account\_id — номер договору в системі
    
-   vehmodel — модель пристрою моніторингу. ID моделі береться з відповіді команди vehmodellist
    
-   imei — унікальний номер пристрою моніторингу
    
-   type — тип транспортного засобу. ID типу транспортного засобу береться з відповіді команди vehtypelist. Якщо потрібного типу немає у списку, можна вказати новий ID
    
-   name — державний номер або назва транспортного засобу
    
-   msisdn — номер основної SIM-картки пристрою
    
-   msisdn2 — номер другої SIM-картки пристрою
    
-   mac — MAC-адреса, ідентифікатор пристрою автокондуктора.  Якщо вказано параметр mac, система автоматично створить запис про об’єкт на вкладці «Автобуси» в панелі адміністратора. 
    
-   node — номер вузла, на якому потрібно виконати команду
    

Додаткові:

-   folder — назва папки для додавання транспорту. Якщо вказаної папки немає — її буде створено. Якщо папку не вказано, транспорт буде додано до загального списку — кореневої папки
    
-   info — додаткова інформація про транспорт
    
-   summer\_fuel — витрата палива в літній період
    
-   winter\_fuel — витрата палива в зимовий період
    
-   fuel\_type — тип використовуваного палива . 50-дизель, 80-92-95-98-бензин, 100-газ. Якщо параметр не вказано, система автоматично встановить дизель
    
-   lost\_connection\_time — час, після якого фіксується втрата зв’язку (у секундах)
    
-   time\_zone — часовий пояс транспорту. За замовчуванням встановлюється Europe/Moscow
    
-   initial\_motor\_hours — початкові показники мотогодин
    
-   driver\_id — ідентифікатор водія
    
-   initial\_mileage — початковий пробіг транспорту. Якщо не вказано, відлік іде з нуля
    
-   speed\_limit — максимально допустима швидкість. Якщо не вказано, контроль швидкості вимкнено
    
-   minsat — мінімальна кількість супутників. За замовчуванням встановлено 4
    
-   maxhdop — максимальний HDOP. За замовчуванням встановлено 21
    
-   mintime — мінімальний час стоянки для розбиття треків. За замовчуванням встановлено 3600 секунд
    
-   maxspeed — максимально можлива швидкість. За замовчуванням встановлено 250
    
-   minspeed — мінімальна швидкість для виявлення початку руху. За замовчуванням встановлено10 км/год
    
-   minparking — мінімальний час паркування на маршруті. За замовчуванням встановлено 300 секунд
    
-   model — марка та модель транспорту
    
-   year — рік випуску транспорту. Якщо рік випуску не вказано, за замовчуванням буде вважатися 1900 рік
    
-   vin — ідентифікаційний номер транспорту
    
-   engine\_horse: — потужність двигуна
    
-   organization — назва організації-власника
    
-   column — номер колони
    
-   subdivision — підрозділ

Відповідь

У відповідь на API-запит повертається:

-   code — код відповіді, який показує, як було оброблено запит
    
-   msg — повідомлення з текстовим описом результату операції
    
-   agent\_id — ідентифікатор агента, який обробив запит
    
-   veh\_id — ідентифікатор транспортного засобу, до якого належить ця відповідь
