---
title: "Редагування транспортного засобу"
---

Цей API використовується для редагування даних транспортного засобу. Можна змінити інформацію про транспорт, зокрема тип, модель, держномер, VIN, рік випуску, потужність двигуна, початковий пробіг і мотогодини, а також прив’язку до папки, водія або підрозділу.

## Як отримати дані

### Метод

POST

### Адреса запиту

Для отримання даних використовуйте адресу: https://<server\_address>/backend/api.php?

### Параметри запиту

Обов’язкові:

-   cmd=vehedit — команда для зміни інформації про ТЗ
    
-   agentid— ідентифікатор транспорту або imei — унікальний ID пристрою
    
-   node — номер вузла, на якому потрібно виконати команду
    

Додаткові:

-   type — тип ТЗ, ID береться з команди vehtypelist
    
-   veh\_number — відображуване ім’я/держномер машини
    
-   veh\_type — користувацький тип машини (рядок)
    
-   folder\_id — папка, до якої поміщається об’єкт; якщо папки немає — вона створюється автоматично. За замовчуванням — коренева папка
    
-   model — модель транспортного засобу
    
-   initial\_motor\_hours — початкові мотогодини
    
-   driver\_id — ID водія
    
-   initial\_mileage — первісний пробіг (за замовчуванням 0)
    
-   year — рік випуску машини (за замовчуванням 1900)
    
-   vin — VIN транспортного засобу
    
-   engine\_horse — потужність двигуна
    
-   organization — організація
    
-   column — колона
    
-   subdivision — підрозділ
