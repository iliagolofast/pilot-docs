---
title: "Переміщення об’єкта між договорами"
---

Цей API використовується для переміщення транспортного засобу між обліковими записами.

## Як отримати дані

### Метод

GET

### Адреса запиту

Для отримання даних використовуйте адресу: https://<server\_address>/backend/api.php?

### Параметри запиту

Щоб отримати потрібні дані, додайте до адреси запиту параметри. Параметри вказуються після знака питання «?» і розділяються знаком «&».

-   cmd = veh\_move\_account — команда для переміщення об’єктів в інший обліковий запис
    
-   vehicle\_id — ідентифікатор транспортного засобу, який потрібно перемістити в обліковий запис
    
-   account\_id — номер нового облікового запису
    
-   node — номер вузла, на якому потрібно виконати команду

У відповідь на API-запит повертається:

-   code — код результату:
    

— 1 — операцію виконано успішно

— 0 — помилка під час виконання операції

-   msg —повідомлення з текстовим описом результату операції
