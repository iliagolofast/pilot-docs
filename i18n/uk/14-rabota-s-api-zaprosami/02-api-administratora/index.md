---
title: "API Адміністратора"
---

API адміністратора — це спеціальний набір команд, який дає розширені можливості, недоступні звичайним користувачам. Він призначений для керування системою та виконання адміністративних завдань.

За допомогою API адміністратора ви можете:

-   Створювати, змінювати або видаляти облікові записи користувачів
    
-   Налаштовувати права доступу та ролі
    
-   Отримувати інформацію про стан об’єктів
    
-   Налаштовувати параметри системи та модулів
