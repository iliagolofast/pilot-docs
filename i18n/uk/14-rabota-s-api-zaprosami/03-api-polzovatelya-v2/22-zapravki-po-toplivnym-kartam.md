---
title: "Заправки за паливними картками"
---

Використовуйте API, щоб отримувати дані про заправки транспортного засобу за вибраний період. За його допомогою можна:

— переглядати транзакції за паливними картками (операції купівлі пального, баланс картки, тип пального, АЗС)

— отримувати дані про заправки та зливи пального за датчиком автомобіля (координати, кількість пального, місце події)

— контролювати залишки пального на початок і кінець доби для кожного транспортного засобу

## Як отримати дані

### Метод

GET

Адреса запиту

Для отримання даних використовуйте адресу: https://<server\_address>/api/api.php?

### Параметри запиту

-   cmd=fuel — команда для отримання даних про заправки
    
-   imei — ідентифікатор транспортного засобу в системі
    
-   start — час початку вибірки (Unix timestamp)
    
-   stop — час закінчення вибірки (Unix timestamp)
    
-   addr— адреса заправок
    
-   node — номер вузла, на якому потрібно виконати команду
