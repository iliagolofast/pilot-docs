---
title: "Список звітів"
---

Цей API отримує список усіх доступних звітів в обліковому записі з їхніми ідентифікаторами, назвами та групами, до яких вони належать.

## Як отримати дані

### Адреса запиту

Для отримання даних використовуйте адресу: https://<server\_address>/api/api.php?

### Метод запиту

GET або POST

### Параметри запиту

-   cmd=reports\_list — команда для отримання списку звітів
    
-   node — номер вузла, на якому виконується команда

У відповідь на API-запит повертається:

-   code — код результату (0 — успішна операція)
    
-   data — масив звітів, де кожен звіт містить:
    
-   id — унікальний ідентифікатор звіту
    
-   name — назва звіту
    
-   group — група, до якої належить звіт
