---
title: "Прив’язати геозону до об’єкта"
---

Цей API дає змогу прив’язати наявну геозону до транспортного засобу, задавши параметри контролю, такі як обмеження швидкості, час бездіяльності та сповіщення.

## Як отримати дані

### Метод

GET

### Адреса запиту

Для виконання запиту використовуйте адресу: https://<server\_address>/api/api.php?

### Параметри запиту

-   cmd=geofencelink — команда для прив’язування геозони
    
-   zone\_id — ідентифікатор геозони (обов’язковий, якщо external\_id не задано)
    
-   external\_id — зовнішній ідентифікатор геозони (необов’язково, ігнорується, якщо вказано zone\_id)
    
-   agent\_id — ідентифікатор агента (транспортного засобу)
    
-   idle — контроль бездіяльності в геозоні в хвилинах (необов’язково)
    
-   speedlimit — обмеження швидкості в геозоні в км/год (необов’язково)
    
-   alerts — сповіщення:
    
-   0 — не надсилати
    
-   1 — бездіяльність
    
-   2 — перетин меж
    
-   3 — межі та прикордонні переходи
    
-   node — номер вузла, на якому потрібно виконати команду
