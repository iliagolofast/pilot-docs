---
title: "Відв’язати геозону від об’єкта"
---

Цей API видаляє прив’язку наявної геозони від транспортного засобу.

## Як отримати дані

### Метод

GET

### Адреса запиту

Для виконання запиту використовуйте адресу: https://<server\_address>/api/api.php?

### Параметри запиту

-   cmd=geofenceunlink — команда для видалення прив’язки геозони
    
-   zone\_id — ідентифікатор геозони (обов’язковий, якщо external\_id не задано)
    
-   external\_id — зовнішній ідентифікатор геозони (необов’язково, ігнорується, якщо вказано zone\_id)
    
-   agent\_id — ідентифікатор агента (транспортного засобу)
    
-   node — номер вузла, на якому потрібно виконати команду
