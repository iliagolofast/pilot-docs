---
title: "Медіафайли подій"
---

Цей API використовується для отримання медіафайлів вибраних об’єктів за вказаний період. З його допомогою можна отримати посилання на фото та відео, пов’язані з подіями, зокрема ADAS і DMS.

## Як отримати дані

### Метод

GET

### Адреса запиту

Для отримання даних використовуйте адресу: https://<server\_address>/api/api.php?

### Параметри запиту

-   cmd=get\_media — команда для отримання медіафайлів
    
-   agent\_id — ідентифікатор об’єкта або ідентифікатори кількох об’єктів, перелічені через кому
    
-   start — час початку вибірки у форматі Unix timestamp
    
-   stop — час завершення вибірки у форматі Unix timestamp
    

### Приклад запиту

У відповідь на успішний API-запит повертаються відомості про медіафайли вибраних об’єктів за вказаний період і посилання для їх перегляду. Після переходу за посиланням пов’язане з подією зображення або відео відкривається в браузері.
