---
title: "API Користувача v2"
---

API користувача надає доступ до функцій і даних PILOT, дозволених для звичайного користувача.

З його допомогою ви можете:

— переглядати власні звіти та статистику за поїздками, об’єктами й витратами

— отримувати інформацію про свої налаштування та персональні дані

— запитувати дані, пов’язані лише з вашим акаунтом і вашою діяльністю в системі

Через ці API не можна отримати доступ до даних інших користувачів або адміністраторів. Ви бачите й працюєте лише з інформацією свого акаунта.
