title: "API Користувача v3"
---

Для роботи з **API Користувача v3** використовуйте Swagger-інтерфейс: [https://pilot-swagger.pilot-gps.com/](https://pilot-swagger.pilot-gps.com/)

У цій версії API доступні оновлені та структуровані методи для роботи із системою.

У Swagger ви можете:

— переглянути список усіх доступних методів

— вивчити параметри запитів і відповіді

— протестувати API просто в браузері
