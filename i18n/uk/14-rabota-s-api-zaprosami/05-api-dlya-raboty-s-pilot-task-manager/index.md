title: "API для роботи з PILOT Task Manager"
---

PILOT Task Manager ([Диспетчер завдань](../../lichnyj-kabinet-polzovatelya/moduli-1/pilot-task-manager/index.html)) — це модуль системи PILOT для керування завданнями.

За допомогою API цього модуля ви можете:

— створювати, редагувати та видаляти завдання

— призначати завдання виконавцям

— отримувати статус виконання та строки

 — отримувати інформацію про поточні та завершені завдання
